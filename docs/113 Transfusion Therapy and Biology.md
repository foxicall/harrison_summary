# 輸血醫學生物學與臨床治療全解：從細胞成分、免疫溶血到患者血液管理
- **主講人/來源**：Pierre Tiberghien, Olivier Garraud, Jacques Chiaroni / 113 Transfusion Therapy and Biology.pdf
- **核心主旨**：深入剖析血液成分製備、紅血球抗原多型性與免疫溶血分子病理，並以「患者血液管理（Patient Blood Management, PBM）」為核心，將輸血視為異體移植級別的高風險介入，透過術前自體造血最佳化、精準控管儲存損傷與鐵過載毒性，追求臨床療效極大化與併發症極小化。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **體外儲存損傷（Storage Lesions）**：血液組分在低溫（1–6°C 或 22°C）與抗凝保存液中經歷代謝劇變，包含 ATP 與 2,3-DPG 耗竭、氧化壓力累積、微粒（microparticles）釋放與紅血球膜變形性下降，輸注後易誘發微循環受阻、游離血紅素釋出及血管內皮功能障礙。
  - **同種異體免疫與補體級聯活化**：受血者針對紅血球、HLA 或血小板抗原產生同種抗體（alloAbs）。ABO 天然抗體（主要是 IgM）能高效率活化補體 C5b–C9 膜攻擊複合物（MAC），引起暴發性血管內溶血；而 Rh、Kidd、Duffy 等 IgG 抗體則主導 C3b 調理作用或 Fc 受體媒介之血管外吞噬溶血。
  - **系統性微環境發炎與器官過負荷**：
    - **肺毒性**：TRALI（輸血相關急性肺損傷）經由供體抗-HLA/HNA 抗體或生物活性脂質引發肺微血管嗜中性球活化與血管外滲，導致非心因性肺水腫。
    - **循環負荷**：TACO（輸血相關循環超負荷）因輸注速度過快或容量過剩引發急性心肺負荷過載。
    - **鐵沉積毒性**：每單位紅血球濃縮液含 200–250 mg 鐵，長期輸血將迅速飽和轉鐵蛋白，產生具高度細胞毒性的非轉鐵蛋白結合鐵（NTBI）與活性氧（ROS），破壞心肌、肝臟及內分泌細胞粒線體。

- **演講亮點與臨床洞察**：
  - **PBM 範式轉移（Paradigm Shift）**：輸血絕非單純「補充血色素」，而是伴隨免疫調節（TRIM）、血栓與感染風險的同種異體組織移植。現代臨床強調「限制性輸血策略（Restrictive Transfusion Strategy）」，常規血液動力學穩定者將閾值嚴格限縮至 $\text{Hb} < 7\text{ g/dL}$。
  - **死亡致因結構改變**：根據 FDA 最新統計，輸血致死首要原因為 **TACO (32%)**，次為 **TRALI (26%)**，超過了急性溶血 (18%) 與敗血症 (14%)，提示循環容量與免疫反應監控比單純感染防控更具迫切性。
  - **普遍性白血球減除（Universal Leukoreduction）**：將殘存白血球控制於 $<1\text{–}5 \times 10^6/\text{unit}$，已證實可大幅降低非溶血性發熱反應（FNHTR）、巨細胞病毒（CMV）傳播及 HLA 同種異體免疫。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與病理生理評估目標 | 理想 / 臨床決策閾值標準 |
| :--- | :--- | :--- |
| **血紅蛋白 (Hemoglobin, Hb)** | 評估全身組織氧合狀態，決定是否啟動紅血球輸注 | - 血液動力學穩定者：$<7\text{ g/dL}$ 考慮輸血<br>- 心血管疾病/骨科/心臟術後：$<8\text{ g/dL}$<br>- 急性冠心症 (ACS)：$<9\text{–}10\text{ g/dL}$ |
| **校正血小板計數增加值 (CCI)** | 評估血小板輸注療效，偵測免疫性/非免疫性血小板輸注無效（Refractoriness） | 輸注後 $1\text{ h} \ge 10 \times 10^9/\text{L}$；$24\text{ h} \ge 7.5 \times 10^9/\text{L}$（低於此值提示免疫性破壞或消耗） |
| **直接抗球蛋白試驗 (DAT / Coombs)** | 偵測受血者體內紅血球表面結合的同種異體抗體 (IgG) 或補體 (C3d) | 陰性（陽性常見於急性/延遲性溶血反應、自體免疫性溶血） |
| **間接抗球蛋白試驗 (IAT / Screen)** | 偵測受血者血清中游離的「非預期/不規則」紅血球同種抗體 | 陰性（陽性需進一步鑑定抗體特異性，如抗-Rh, Kell, Duffy, Kidd） |
| **血清鐵蛋白 (Ferritin) & 轉鐵蛋白飽和度** | 評估長期輸血患者之網狀內皮系統與實質器官鐵沉積狀態 | - 正常維持：$<200\text{–}300\text{ ng/mL}$<br>- 重度鐵沉積警戒：$>1000\text{–}2500\text{ ng/mL}$（需啟動螯合治療） |
| **溶血生化指標 (LDH, Haptoglobin, 膽紅素)** | 鑑別急性血管內或延遲性血管外溶血反應 | - 結合珠蛋白 (Haptoglobin)：耗竭性下降<br>- 間接膽紅素 (Unconjugated Bilirubin)：顯著升高<br>- 游離血紅素 (Hemoglobinemia/uria)：強陽性 |
| **腦鈉肽 (BNP / NT-proBNP)** | 鑑別急性呼吸困難為 TACO（容量過載）抑或 TRALI（非心因性滲漏） | 輸血後顯著升高（數倍於基準值）強力支持 TACO 診斷 |
| **離子鈣 ($\text{Ca}^{2+}$) 與血鉀 ($\text{K}^+$)** | 大量輸血時評估枸櫞酸鹽（Citrate）螯合毒性及儲存紅血球溶漏高鉀血症 | 離子鈣維持在正常生理範圍（防手足抽搐與心律不整）；血鉀防止心臟毒性陡升 |

## 三、 關鍵機制詳解與重點筆記

### 1. 血液成分特性、製備品質與儲存損傷（Storage Lesions）
- **紅血球濃縮液 (RBCC)**：
  - 容積約 $250\text{–}300\text{ mL}$，血容比 (Hct) 50–70%，游離血漿僅殘留 $10\text{–}30\text{ mL}$。
  - **儲存病變**：保存於 $4 \pm 2^\circ\text{C}$，時限 25–42 天。隨著存放時間拉長，紅血球釋出微粒、變形能力喪失、一氧化氮（NO）清除活性劇增，導致輸注後微血管反常收縮與缺血再灌流損傷。對於新生兒與嚴重腎衰竭患者，應嚴格限制使用保存超過 7–10 天或輻照後超過 24 小時的血液，避免致死性高血鉀。
- **血小板濃縮液 (PC)**：
  - 保存於 $20\text{–}24^\circ\text{C}$ 且需持續震盪，保存期僅 3–7 天。
  - 室溫環境極易促成伺機性細菌繁殖（如表皮葡萄球菌、格蘭氏陰性桿菌）；加入血小板添加液（PAS）可替代 2/3 血漿，降低非溶血性發熱與過敏反應。
- **新鮮冷凍血漿 (FFP) 與冷凍沉澱品 (Cryoprecipitate)**：
  - FFP 含所有凝血因子及抗凝血蛋白（Protein C, S, AT-III）；主要適應症為多重凝血因子缺乏與大量輸血之稀釋性凝血病變。
  - Cryoprecipitate 富含纖維素原（Fibrinogen $\ge 140\text{ mg}$）、Factor VIII、vWF 與 Factor XIII，為低纖維蛋白原血症的首選。

```
[體外儲存紅血球]
   │
   ├─► ATP & 2,3-DPG 耗竭 ───► 氧解離曲線左移 (組織釋氧困難)
   ├─► 脂質過氧化 & 膜硬化 ──► 微循環毛細血管嵌塞
   ├─► 鉀離子溶漏 (K+ Leak) ──► 大量輸注引發心律不整
   └─► 游離血紅素/微粒釋出 ──► 清除內皮 NO ──► 血管攣縮、發炎、高血壓
```

### 2. 紅血球血型生物學與溶血路徑剖析
- **醣類血型系統（ABO, H, Lewis, P1PK）**：
  - 抗原為細胞膜上糖基轉移酶修飾的寡醣鏈。腸道微生態菌群的交叉抗原刺激人體產生強效「天然抗體」（IgM 為主）。
  - **急性血管內溶血機制（圖 113-1A）**：不相容輸血時，受血者天然抗體結合輸入之 RBC，強烈活化補體系統至 C5b–C9，形成 MAC 孔洞導致紅血球滲透性溶解。釋放之大量游離血紅素迅速耗竭結合珠蛋白（Haptoglobin）與血液 NO，誘發嚴重血管收縮、休克、DIC 及急性腎小管壞死。
- **蛋白質血型系統（Rh, Kell, Duffy, Kidd, MNS）**：
  - 均屬跨膜多肽，具高度免疫原性，必須經異體暴露（妊娠或輸血）誘導產生「免疫性抗體」（IgG 為主）。
  - **血管外溶血機制（圖 113-1B/C）**：
    - **Kidd 系統 ($Jk^a, Jk^b$)**：常引發不完全補體活化至 C3，紅血球表面 C3b 調理素被肝臟巨噬細胞（Kupffer cells）識別吞噬；易引起**延遲性溶血反應（DHTR）**（抗體力價輸血前常測不到，輸血後 3–10 天記憶性爆發）。
    - **Rh 系統 (D, C, c, E, e) 與 Kell 系統 (K, k)**：IgG 抗體主要不活化補體，而是透過抗體依賴性細胞毒性（ADCC）及脾臟巨噬細胞 Fc 受體辨識進行吞噬，臨床表現為進行性貧血、黃疸及脾腫大。
  - **臨床特例**：
    - **Duffy ($Fy^{a-b-}$)**：西非族群高達 70–100%，因缺乏 *Plasmodium vivax* 侵入受體而具抗瘧優勢；此類患者多次輸血後易產生抗-Fy3/Fy5 抗體。
    - **鐮刀型貧血的超溶血症候群 (Hyperhemolytic Syndrome)**：輸血後巨噬細胞過度活化，除清除輸注之紅血球外，連帶吞噬患者自體原生紅血球及骨髓紅血球前驅細胞（Bystander hemolysis），使血色素跌破輸血前水準，此時再行輸血通常致命。

### 3. 致命性輸血併發症鑑別與分子機轉
- **TRALI vs. TACO 之臨床與病理鑑別**：
  - **TRALI（輸血相關急性肺損傷）**：本質為「免疫/微血管內皮損傷」。供體血漿中高力價抗-HLA Class II 或抗-HNA 抗體，與受血者活化之嗜中性球結合，引發嗜中性球於肺泡微血管壁聚集、脫顆粒並釋放發炎介質，導致肺毛細血管滲透性水腫（非心因性，胸透可見雙側廣泛間質浸潤，BNP 通常正常，血壓偏低）。
  - **TACO（輸血相關循環超負荷）**：本質為「流體靜力學衰竭」。輸注速度過快或容量過剩超過心臟受納極限，引發肺毛細血管靜水壓陡升（心因性，表現為收縮期高血壓、肺泡水腫、頸靜脈怒張、BNP 暴增）。
- **輸血相關移植物抗宿主病 (TA-GVHD)**：
  - 見於受血者細胞免疫受損，或供受者帶有部分相合 HLA 單倍型（如近親輸血）。供體活 T 淋巴球未被宿主清除，反而植入並攻擊宿主骨髓、皮膚與消化道，引起骨髓衰竭（全血球減少）、皮疹、腹瀉，**死亡率 $>90\%$**。必須經由 **$\gamma$ 射線/X 射線照射（$\ge 25\text{ Gy}$）** 徹底破壞供體淋巴球 DNA 進行絕對預防。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性造血營養支持（PBM 第一支柱：自體紅血球生成最佳化）
- **積極矯治營養缺乏性貧血（嚴禁以輸血取代營養素補充）**：
  - **鐵代謝重建處方**：
    - 對於缺鐵性貧血，優先評估鐵調素（Hepcidin）與吸收能力。若口服耐受差或面臨即期手術，應選用靜脈鐵劑（如 Ferric carboxymaltose 或 Iron sucrose），避開腸道屏障與發炎性鐵滯留。
    - 口服補充建議使用甘胺酸亞鐵（Ferrous Bisglycinate），配合 200–500 mg 維生素 C 提升十二指腸 DMT-1 轉運效率。
  - **一碳代謝與紅血球成熟輔助因子**：
    - 活化甲基葉酸（L-5-MTHF）：$800\text{–}1000\text{ }\mu\text{g/day}$。
    - 甲基鈷胺素（Methyl-B12）：$1000\text{ }\mu\text{g/day}$（必要時肌注），解決紅血球核質發育不平衡與無效造血。
    - 輔因子：吡哆醛-5-磷酸（P5P，活性 B6）支持血紅素（Heme）合成之第一步 ALA 合成酶；搭配微量元素銅（$1\text{–}2\text{ mg}$）與鋅（$15\text{–}30\text{ mg}$）維持紅血球超氧化物歧化酶（SOD）活性。

### 2. 鐵過載解毒與抗氧化內皮防禦（長期輸血患者管理）
- **醫學鐵螯合處方**：
  - 定期監測鐵蛋白，當 $>1000\text{ ng/mL}$ 時啟動螯合劑：Deferasirox（口服）、Deferiprone 或 Deferoxamine，防止鐵沉積性心肌病變與肝纖維化。
- **對抗游離鐵與血紅素介導之氧化傷害**：
  - **N-乙醯半胱胺酸 (NAC)**：$600\text{–}1200\text{ mg/day}$，提升體內還原型穀胱甘肽（GSH）儲備，對抗游離血紅素催化之脂質過氧化。
  - **天然植化素輔助鐵螯合與抗發炎**：
    - 水飛薊賓（Silibinin / Silymarin）：具備天然鐵螯合活性並能保護肝細胞粒線體膜。
    - 綠茶萃取物（EGCG）與薑黃素（Curcumin）：干擾胃腸道非血基質鐵過度吸收，下調 NF-$\kappa$B 途徑以抑制輸血相關慢性低度發炎。

### 3. 臨床輸血程序風險阻斷策略
- **大量輸血方案 (Massive Transfusion Protocol)**：
  - 若 3 小時內輸注量超過總血量 50% 或大於 5–10 單位 RBCC，嚴格採用 **1 : 1 : 0.25** 比例聯合輸注（1 RBCC : 1 FFP : 0.25 單位 PC，等同於全血成分比例），防止稀釋性凝血障礙。
  - 全程採用加溫管路（Inline warmer）維持核心體溫，每輸注 2–4 單位補充 10% 葡萄糖酸鈣預防低血鈣。
- **TACO 高危險群之輸液動力學管控**：
  - 高齡、心衰竭或少尿型腎衰竭患者，紅血球輸注速率嚴格限縮至 **$1\text{ unit} / 3\text{–}4\text{ hours}$**。
  - 輸注前後預防性給予靜脈袢利尿劑（Furosemide 20–40 mg），維持肺微血管毛細楔壓平衡。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **嚴格踐行限制性輸血閾值**：
   - 無自覺缺氧症狀且生命徵象穩定者，血色素 $<7\text{ g/dL}$ 方考慮輸血；切勿將輸血作為營養缺乏性貧血（缺鐵、缺 B12/葉酸）的快捷代償手段。
2. **守護生育年齡女性的抗原防線**：
   - 育齡期女性及小兒患者，輸血**必須**保證 **RhD 與 Kell (KEL1)** 系統高度相合，防範同種抗體形成誘發未來的胎兒新生兒溶血症（HDFN）。
3. **高危險族群血液製品的特製化處理**：
   - 嚴重細胞免疫缺乏、骨髓移植、近親輸血者，製品**必經輻照（$\ge 25\text{ Gy}$）**防 TA-GVHD；重度過敏體質或 IgA 缺乏伴抗體者，選用**洗滌紅血球（Washed RBC）**以移除致敏血漿蛋白。
4. **急性輸血不良反應標準急救流程**：
   - 輸血過程中一旦出現體溫升高 $\ge 1^\circ\text{C}$、發紺、寒顫、背痛、低血壓或氣促：
     1. **即刻停輸**並保持靜脈通路；
     2. 啟動核對程序（病患手圈與血袋標籤）；
     3. 抽血驗尿送檢溶血指標（DAT、Free Hb、結合珠蛋白）；
     4. 給予大量等張生理鹽水維持尿量，必要時給予鹼化利尿劑保護腎小管。
5. **慢性輸血者的器官保護藍圖**：
   - 對地中海貧血、鐮刀型貧血或骨髓分化不良症候群（MDS）患者，將鐵蛋白與心臟/肝臟 T2* MRI 納入例行追蹤；結合功能醫學抗氧化排毒方案，阻絕鐵過載導致的多重器官衰竭。
