# 心臟創傷與心肌損傷的急性評估、病理生理機制與全人修復指引
- **主講人/來源**：272 Cardiac Trauma.pdf（Harrison's Principles of Internal Medicine, 21st ed., Chap. 272, Eric H. Awtry）
- **核心主旨**：全面剖析鈍性（BCI）與穿刺性心臟創傷的血流動力學破壞、心肌電生理不穩定性與延遲性結構異常，並建立從「急重症分子標記鑑別」到「亞急性期自體免疫/發炎修復」的全程臨床策略。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **機械挫傷與心肌壞死**：鈍性剪力或穿刺導致心肌細胞挫傷破裂，病理學變化與急性心肌梗塞類似，常合併冠狀動脈裂傷、夾層或血栓形成。
  - **電生理脆弱性撞擊（Commotio Cordis）**：在無結構性病變下，衝擊力於心室再極化脆弱期（T 波頂峰前）精準落於心臟投影區，誘發致命性心室顫動（VF）。
  - **神經內分泌風暴（Takotsubo Syndrome）**：巨大身心創傷引發兒茶酚胺超量激增，造成微血管痙攣與心肌頓抑（心尖氣球樣病變）。
  - **自體免疫與無菌性慢性發炎**：創傷後數週至數月的心臟創傷後症候群（Post-cardiac injury syndrome），本質為心包與心肌暴露抗原後誘發的延遲性自體免疫發炎反應。
- **演講亮點與臨床洞察**：
  - **骨折與損傷非等價**：胸骨或肋骨骨折與鈍性心臟損傷（BCI）無必然相關；即使完全沒有外傷痕跡的高速減速創傷，仍可能潛藏重度致命心臟撕裂。
  - **診斷黃金「排除」組合**：CK-MB 在骨骼肌創傷中極易出現偽陽性；傷後 6~8 小時結合「正常心電圖 + 正常高敏感心肌肌鈣蛋白（Troponin）」，可實質排除 BCI。
  - **穿刺傷的隱匿性陷阱**：多達 20% 的穿刺性胸部創傷病人在初期血流動力學完全穩定，但已存在隱匿性心臟創傷（Occult cardiac injury）。
  - **右心室（RV）最易受傷**：解剖位置上 RV 緊貼前胸壁，為最常受損腔室，但多腔室損傷死亡率顯著高於單腔室。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **Cardiac Troponin (I / T)** | 最具心肌專一性的壞死標記，排除鈍性心臟損傷（BCI）的核心指標 | 傷後 6~8 小時維持正常序列數值，可高度排除顯著心肌受損 |
| **CK-MB（肌酸激酶心肌同工酶）** | 反映橫紋肌溶解與組織破壞；約 20% 鈍傷患者升高，但**易因骨骼肌損傷呈偽陽性** | 不建議作為鈍性心臟損傷的單一確診依據 |
| **12 導程心電圖 (ECG)** | 篩檢心律不整（窦性心搏過速、RBBB、ST-T 變化、房性/室性心律不整） | 基準正常；若異常需住院接受 24~48 小時連續遙測心電圖（Telemetry） |
| **心臟超音波 (TTE / TEE)** | 評估解剖結構：心包積液/填塞、局部心壁運動異常（RV/心尖/室間隔）、瓣膜斷裂（二尖瓣/三尖瓣反流）、VSD | 經胸前 (TTE) 為首選；若影像不清或懷疑大血管裂傷改採經食道 (TEE) |
| **胸部 X 光 (CXR)** | 評估縱膈腔寬度（篩檢主動脈減速性撕裂傷、假性動脈瘤）與心臟輪廓 | 縱膈腔增寬（Mediastinal widening）為大血管破裂高危徵兆 |
| **延遲發炎指標 (hs-CRP / ESR)** | 評估亞急性期創傷後發炎反應、監測「心臟創傷後症候群（PCIS）」 | 創傷後數週若出現反彈性升高，警惕延遲性心包炎/積液 |

## 三、 關鍵機制詳解與投影片重點筆記

- **鈍性心臟損傷（BCI）與易損期電衝擊（Commotio Cordis）**：
  - **心肌受損光譜**：輕至無症狀的心電圖異常、心肌酶升高，重至急性室間隔缺損（VSD）、自由壁破裂與致死性心包填塞。最常累及右心室游離壁、左心室心尖部及室間隔。
  - **震盪心臟猝死（Commotio Cordis）**：多見於青少年運動員（棒球、曲棍球、曲棍網球等）。低能量鈍擊於心電圖易損期（T 波頂峰前 15~30 毫秒）觸發離子通道力學牽張，引發 VF，**存活率完全取決於是否能在數分鐘內施行去顫（Defibrillation）**。
- **穿刺性心臟創傷（Penetrating Cardiac Injury）與隱匿性危象**：
  - **致死機轉**：槍傷死亡率顯著高於刀刺傷（存活率：刀傷達 65% vs. 槍傷 <20%），主因彈道創傷常造成多腔室穿透與爆裂性大出血。
  - **解剖受損頻率**：右心室（前胸表面積最大）> 左心室；心房孤立性破裂較罕見。
  - **延遲機械性併發症**：倖存者可能在數天甚至數週後，才因心瓣膜乳頭肌/腱索斷裂或外傷性心內分流（VSD、ASD、動靜脈瘻管）進展出新發心臟雜音或高輸出量心衰竭。
- **主動脈減速性創傷（Aortic Transection）**：
  - 常見於主動脈瓣上方或動脈導管韌帶（ligamentum arteriosum）處。因急遽減速剪力造成主動脈近乎全層撕裂。
  - 臨床表徵類似主動脈剝離：上肢血壓與脈搏充盈、下肢血壓與脈搏低弱；若外膜完整包裹可形成假性動脈瘤（Pseudoaneurysm），可潛伏數月甚至數年才被發現。
- **腫瘤心臟轉移（Cardiac Metastases）的診斷與姑息減壓**：
  - 轉移途徑包括血行、淋巴與直接浸潤，心包為最常見受侵犯部位。
  - 心包穿刺術（Pericardiocentesis）細胞學診斷敏感度達 67~92%；對於惡性積液，留置引流管 3~5 天並局部灌注硬化劑（如四環黴素、博來黴素 Bleomycin）或行心包開窗術（Pericardial window），可防止積液復發。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

*(本節結合創傷急性期後的組織抗發炎、微循環修復與自主神經調理概念)*

- **功能性營養素/植化素補充（亞急性心肌修復與發炎控制）**：
  - **高純度 Omega-3 脂肪酸 (EPA/DHA)**：抑制 NF-κB 發炎途徑，調控巨噬細胞表型（M1 轉向 M2），降低心臟創傷後症候群（PCIS）的無菌性心包炎風險。
  - **輔酶 Q10 (Ubiquinol) 與 鎂 (Magnesium)**：支持挫傷邊界區心肌粒線體能量合成（ATP），穩定心肌肌漿網鈣通道，減少創傷後室性早搏與心律不整。
  - **薑黃素 (Curcumin) / 白藜蘆醇 (Resveratrol)**：抗氧化與減輕心包纖維化，協同降低微細血管內皮損傷引發的慢性發炎水腫。
- **飲食與抗炎代謝策略**：
  - **創傷後保護性低鈉高鉀飲食**：對於合併瓣膜逆流、心壁挫傷或分流的心臟，嚴格控制鈉鹽（<2 g/day），減輕前負荷，預防急性或亞急性代償性心衰竭。
  - **多酚類地中海抗炎架構**：提供充足抗氧化多酚與優質蛋白質，支持膠原蛋白基質修復破損心壁與心包膜。
- **自主神經平衡與生活型態介入**：
  - **阻斷過度交感風暴**：預防 Takotsubo 症候群的關鍵在於中樞降壓與自主神經調節；創傷恢復期應導入深層橫膈膜呼吸與心率變異度（HRV）生物回饋訓練。
  - **血壓嚴格控管**：針對大血管減速傷或形成假性動脈瘤患者，維持平穩血壓，杜絕激增的剪力刺激破裂。
  - **運動重返安全防護**：青少年運動員應配置合格胸部護具；所有高衝擊運動場所必須配置自動體外去顫器（AED），以應對突發 Commotio cordis。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實 6~8 小時 BCI 排除法則**：鈍性胸部創傷患者抵達急診，不可僅憑外表無肋骨骨折而輕忽；需在傷後 6~8 小時確認「12 導程心電圖完全正常」且「高敏感 Troponin 為陰性」，方可安全排除顯著心肌挫傷。
2. **穿刺創傷必做超音波（TTE/FAST）**：所有穿刺性胸傷患者，即使血流動力學穩定無休克徵象，必須常規進行心臟超音波檢查，以抓出高達 20% 的隱匿性心包積血或心肌穿孔。
3. **異常心電圖之監測守則**：若心電圖顯示新發 RBBB、ST-T 改變或心肌酶異常但超音波結構正常，必須收治進行 24~48 小時連續遠端心電遙測（Telemetry），防範突發心律不整。
4. **警惕延遲性心臟併發症**：胸部創傷倖存者出院後數週至數月，門診務必再次進行心臟聽診與追蹤超音波，仔細排除延遲性瓣膜逆流、室間隔缺損（VSD）及心臟創傷後症候群（心包炎）。
5. **機械性損傷立即啟動外科干預**：一旦確診急性瓣膜撕裂破裂、心壁穿透或大血管截斷撕裂，藥物與支持療法僅為橋接，應爭分奪秒進行緊急開胸修補術。
