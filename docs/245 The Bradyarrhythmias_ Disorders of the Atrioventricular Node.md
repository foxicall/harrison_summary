# 房室結傳導障礙與緩慢型心律不整（Disorders of the Atrioventricular Node）之臨床評估與前瞻治療策略
- **主講人/來源**：William H. Sauer, Bruce A. Koplan / *Harrison's Principles of Internal Medicine* (21st ed.), Chapter 245
- **核心主旨**：深入剖析房室結（AV node）與希氏-浦肯野系統（His-Purkinje system）之電生理機制，精準鑑別結內（Intranodal）與結下（Infranodal）傳導阻滯的病理病因（自老化纖維化、缺血、自體免疫至感染），並結合生理性起搏與全身性代謝機能評估，建立兼具精準度與生命長壽效益的臨床決策樹。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **細胞電生理特性**：房室結細胞缺乏強大的內向整流鉀電流（$I_{\text{K1}}$）與快速鈉通道（$I_{\text{Na}}$），其動作電位 Phase 0 去極化完全依賴 L 型鈣電流（$I_{\text{Ca-L}}$），故傳導速度緩慢；間隙連接蛋白（Connexin-40）表達稀疏且細胞外基質豐富，構成「遞減傳導（Decremental conduction）」以扮演阻隔心房過快激動的「電學守門人（Gatekeeper）」。
  - **退化、纖維化與衰老**：心臟傳導系統纖維化佔後天性傳導阻滯約 50%。老年特發性纖維鈣化（Lev's disease，侵犯左心基底骨架與近端束支）與青壯年硬化退化性病變（Lenègre's disease，侵犯遠端束支）為重要組織學病因；發炎、缺血、浸潤（類肉瘤病、類澱粉沉積症）與基因變異（*SCN5A*、*LMNA*）則加速傳導組織老化與中斷。
- **演講亮點與臨床洞察**：
  - **解剖與自律神經分水嶺**：房室結受豐富交感與副交感神經支配，而 His bundle 及以遠組織對自律神經調節極不敏感。因此，迷走刺激可使結內傳導惡化但改善結下傳導；阿托品（Atropine）與運動則加速結內傳導，反可能暴露潛在的結下功能衰竭。
  - **起搏典範轉移（Paradigm Shift）**：從傳統右心室心尖部起搏（RVP，易致心室不同步及心衰竭）全面轉向「生理性起搏（Physiological Pacing）」，包括希氏束起搏（His Bundle Pacing, HBP）與左束支區域起搏（Left Bundle Branch Area Pacing, LBBAP），藉由直接激發內源性傳導束，保留自然的心室收縮同步性，大幅降低心房顫動、心衰竭再住院及死亡風險。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（臨床臨界點） |
| :--- | :--- | :--- |
| **體表心電圖 PR 間期** | 評估房室傳導總延遲（含心房、AV 結與希浦系統） | 正常值 120–200 ms；**>200 ms** 定義為一度房室阻滯（First-degree AV block）。 |
| **心內電生理 AH 間期 (AH interval)** | 反映自低位右房通過房室結至希氏束的傳導時間 | 正常值 **<130 ms**；若心房起搏週期間期 >500 ms 出現延長或文氏現象提示結內病變。 |
| **心內電生理 HV 間期 (HV interval)** | 反映希氏束至心室心肌激動（束支-浦肯野系統）的傳導時間 | 正常值 **$\le$55 ms**；**>100 ms** 時完全性房室阻滯年發生率趨近 10%，為絕對起搏適應證。 |
| **經胸心臟超音波 (TTE) / LVEF** | 評估瓣膜鈣化、心室重塑、收縮功能；決定是否需生理性起搏或 CRT | **LVEF <50%** 且預期心室起搏比例 **>40%** 者，強烈建議導入生理性心室起搏（CRT/HBP/LBBAP）。 |
| **心臟核磁共振 (CMR) / FDG-PET** | 年輕患者（$\le$60 歲）不明原因 AV 阻滯，鑑別類肉瘤病、心肌炎或類澱粉沉積 | 延遲顯像（LGE）陽性或 FDG 局灶性高代謝代謝攝取，提示發炎/浸潤性心肌病變。 |
| **萊姆病抗體篩檢 (Lyme Serology)** | 鑑別年輕或具暴露史患者急性房室阻滯（Lyme Carditis），具可逆性 | 確診後抗生素治療 1 週內多可逆轉，避免永久性起搏器植入。 |
| **血清電解質與甲狀腺機能** | 排除急性可逆誘因（高血鉀、嚴重低甲狀腺素血症、腎上腺皮質功能低下） | 促甲狀腺素（TSH）正常、血鉀 3.5–5.0 mmol/L；排除高血鉀引起的偽性傳導阻滯。 |
| **基因檢測 (*LMNA*, *SCN5A*)** | 家族性進行性傳導疾病、擴張型心肌病伴心律不整高猝死風險評估 | 檢出 *LMNA*（Lamin A/C）突變即使一度房室阻滯亦應提早評估起搏器/ICD。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 房室結微細解剖與細胞離子流動學（Cellular Electrophysiology）
- **Koch 三角結構定位**：
  - 邊界：後方為冠狀靜脈竇口（Coronary Sinus Ostium）、前方為三尖瓣隔瓣環（Septal Tricuspid Annulus）、上方為 Todaro 腱（Tendon of Todaro）。
  - 功能區塊：頂端為緻密房室結（Compact AV node），向下延伸出下結延伸部（慢徑路 Slow pathway 所在，鄰近三尖瓣環至冠狀靜脈竇）與向左沿 Todaro 腱走行的快徑路（Fast pathway）。
- **去極化與復極化離子通道特性**：
  - **Phase 0**：缺乏心房心室肌中的快速鈉電流（$I_{\text{Na}}$），由 L 型鈣通道（$I_{\text{Ca-L}}$）緩慢內流主導，上升速率極慢（$<10\text{ V/s}$），提供生理性房室延遲，利於心室充盈。
  - **Phase 4 舒張期去極化**：由起搏電流（Funny current, $I_{\text{f}}$）、L/T 型鈣電流（$I_{\text{Ca-L}}, I_{\text{Ca-T}}$）及鈉鈣交換體電流（$I_{\text{NCX}}$）協同驅動，受乙醯膽鹼活化鉀電流（$I_{\text{K,ACh}}$）抑制。其固有起搏頻率約 20–60 bpm。
  - **遞減傳導（Decremental Conduction）本質**：愈快速的刺激頻率導致動作電位振幅減小、傳導速度進一步放慢，是房室結防止心房撲動/顫動引發極速心室率的生物保護屏障。

### 2. 房室阻滯的解剖水平定位與自律神經反應
- **結內阻滯（Intranodal Block）**：
  - 心電圖典型表徵：Mobitz I（Wenckebach）、PR 間期漸長至脫落、QRS 寬度正常（窄 QRS $<120\text{ ms}$）。
  - 自律神經調節：迷走神經刺激（頸動脈竇按摩、睡眠）使阻滯加劇；交感興奮（運動、Atropine、Isoproterenol）使傳導改善。
  - 逃逸心律（Escape Rhythm）：源自結區/近端希氏束，頻率較穩（$>40\text{ bpm}$），血流動力學通常穩定。
- **結下阻滯（Infranodal / Infra-Hisian Block）**：
  - 心電圖典型表徵：Mobitz II、固定 PR 間期突發 P 波無法下傳、常伴隨束支傳導阻滯（寬 QRS $\ge 120\text{ ms}$）。
  - 自律神經調節：運動或 Atropine 增快心房率時，由於結下組織不具自律神經應答性且不應期長，反而增加結下傳導負擔，使阻滯惡化（例如由 2:1 變為高高度阻滯）。
  - 臨床威脅：低位起搏點（Purkinje 纖維）不穩定且緩慢（$<30\text{ bpm}$），猝死風險極高，**為絕對永久性起搏器指徵**。

### 3. 心肌梗塞（MI）合併房室傳導障礙的對照病理
- **下壁心肌梗塞（Inferior MI）**：
  - 機轉：多涉及右冠狀動脈（RCA 佔 80–90% 支配 AV nodal artery）；常合併 Bezold-Jarisch 反射（迷走神經過度興奮）或局部水腫腺苷釋放。
  - 水平與預後：90% 位於房室結近端（Intranodal）；為窄 QRS 逃逸心律，心率多 $>40\text{ bpm}$。多數於數日至 1 週內自發逆轉，藥物反應佳，極少需長期永久起搏。
- **前壁心肌梗塞（Anterior MI）**：
  - 機轉：左前降支（LAD）第一間隔支閉塞，造成室間隔大面積廣泛壞死，波及雙側束支。
  - 水平與預後：阻滯位於結下（His-Purkinje 系統）；常突然進展為完全性阻滯，表現為極不穩定的寬 QRS 逃逸心律，死亡率高，需緊急放置暫時性經靜脈起搏器，且往往轉為永久起搏。

### 4. 起搏器技術革新：從傳統 RV Pacing 到生理性傳導系統起搏
```
傳統心室起搏 (RVP)           生理性傳導系統起搏 (CSP)
[ 右心室心尖 / 間隔導線 ]   ───>  [ 希氏束 (HBP) 或 左束支區域 (LBBAP) ]
         ↓                                    ↓
非生理性心室激動延遲 (LBBB-like)       直接奪獲固有傳導系統，QRS 窄且對稱
         ↓                                    ↓
機械不同步、二尖瓣逆流、心衰竭增加     保留雙心室同步收縮，預後優化、減少心房顫動
```
- **無導線起搏器（Leadless Pacemaker）**：
  - 透過股靜脈遞送，直接植入右心室內膜壁。最新世代利用內建加速度計（Accelerometer）感應心房機械收縮，達到心房感知-心室起搏之生理同步（VDD 模式），消除了囊袋感染與導線斷裂（Lead fracture）風險。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

雖然結構性傳導系統病變（如退化硬化、纖維化、廣泛壞死）常需心臟電生理手術與起搏器介入，但在「功能性衰退、慢性發炎、藥物交互作用與早期心肌浸潤」範疇中，功能醫學與整合支持扮演保護微循環與逆轉機能的關鍵角色：

### 1. 關鍵營養素與細胞離子平衡支持
- **高生物利用度鎂離子（甘胺酸鎂 Magnesium Glycinate / 蘋果酸鎂 Magnesium Malate）**：
  - *劑量*：300–400 mg 元素鎂/日，分次隨餐服用。
  - *機轉*：鎂為細胞膜 $\text{Na}^+/\text{K}^+$-ATPase 的必要輔因子，能穩定細胞靜止膜電位；同時扮演生理性天然鈣通道調節劑，防止心肌因細胞內鈣超載引發傳導組織代謝障礙。
- **還原劑與線粒體支持複合方（CoQ10 + 乙醯基肉鹼 L-Carnitine + PQQ）**：
  - *劑量*：Ubiquinol 100–200 mg/日，配合 Acetyl-L-Carnitine 1000 mg/日。
  - *機轉*：維持房室交界處及 His-Purkinje 束等高耗能特化傳導細胞的 ATP 生成，減緩因線粒體老化造成的細胞間傳導功能衰退（特別是粒線體肌病如 Kearns-Sayre 症候群之支持）。
- **天然抗發炎抗纖維化植化素（薑黃素高吸收劑型 + 白藜蘆醇）**：
  - *劑量*：優化吸收薑黃素 500–1000 mg/日。
  - *機轉*：抑制 NF-$\kappa$B 與 TGF-$\beta$ 信號通路，減輕心臟骨架（Cardiac Skeleton）的慢性低度發炎反應與進行性細胞外基質膠原沉積。

### 2. 代謝與心血管微循環保護策略
- **逆轉動脈硬化與內皮細胞保護（抗晚期糖化終產物 AGEs）**：
  - 嚴格控制血糖波動，降低糖化血色素（HbA1c）至理想範圍（<5.7%），阻斷糖尿病加速進行性心臟傳導纖維化（Progressive cardiac conduction disease）。
  - 補充足夠的維生素 K2（MK-7，100–200 mcg/日）與維生素 D3：引導鈣質沉積於骨質，抑制主動脈瓣環與心臟纖維骨架的異位鈣化（Lev's disease 之防範）。
- **藥物審查與去處方（Deprescribing）**：
  - 系統性回顧患者用藥，避免「降心率藥物級聯效應」：評估非二氫吡啶類鈣離子阻斷劑（Verapamil、Diltiazem）、$\beta$-受體阻斷劑、Digoxin 及第三類抗心律不整藥（如 Amiodarone）之劑量過載或潛在交互作用。

### 3. 自律神經張力重置與生活型態調控
- **睡眠呼吸障礙（Sleep Apnea）矯正**：
  - 阻塞型睡眠呼吸中止症（OSA）常在夜間伴隨極端交感-迷走神經劇烈震盪，誘發嚴重的迷走神經介導性夜間竇性緩脈及 Mobitz I 房室阻滯。
  - *處方*：陽壓呼吸器（CPAP）治療、減重與氣道維持，臨床實證能有效逆轉功能性夜間 AV 阻滯，避免不必要的侵入性起搏器植入。
- **心率變異度（HRV）生物反饋與神經張力調節**：
  - 長期耐力運動員或高迷走神經張力族群需監測運動負荷與靜息心率；配合深慢腹式呼吸訓練（Resonance frequency breathing，約每分鐘 6 次），避免自主神經調節失衡所引發的嚴重結性停搏。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實心電圖「脫漏 P 波前 PR 間期」黃金比對原則**：
   - 當懷疑二度房室阻滯時，比對「脫漏前最後一個 PR 間期」與「脫漏後第一個 PR 間期」。若脫漏後 PR 明顯縮短、伴隨文氏週期，屬良性 **Mobitz I（結內）**；若脫漏前後 PR 間期恆定不變，診斷為 **Mobitz II（結下）**，必須立即收治評估起搏器。
2. **警惕「年輕（$\le$60 歲）傳導阻滯」背後的隱匿性全身疾患**：
   - 青年或中年突發傳導阻滯者，切勿僅當作退化性疾病。必須啟動全身性排查：萊姆病抗體（詢問戶外叮咬史）、心臟核磁共振（CMR）或 FDG-PET（篩檢心臟類肉瘤病）、自體免疫抗體（排除狼瘡性結締組織病）以及 *LMNA* 基因檢測。
3. **區分急性心梗下壁與前壁的房室阻滯威脅度**：
   - 下壁心梗伴發者，多為結內、窄 QRS，通常暫不急於置入永久起搏器，可先給予 Atropine 或藥物支持觀察自發恢復；前壁心梗伴發者多為 His 束以下廣泛壞死，多為寬 QRS，極易猝死，需立即建立暫時經靜脈起搏通道。
4. **恪守起搏器適應證「症狀 vs. 部位」準則**：
   - 結內阻滯（一度、無症狀 Mobitz I）：通常無需起搏，以觀察並處理潛在發炎、藥物與睡眠呼吸中止症為主。
   - 結下阻滯（Mobitz II、高度、三度阻滯）：**不論有無症狀**，均具 Class I 永久起搏器植入指徵；若左心射血分數（LVEF）<50% 且起搏比例預期高於 40%，首選生理性傳導系統起搏（LBBAP/HBP）或 CRT，維護長期心臟機能與壽命長度。
