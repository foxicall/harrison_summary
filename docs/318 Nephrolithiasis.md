# 腎結石症（Nephrolithiasis）：病理生理機制、代謝評估與個體化預防策略
- **主講人/來源**：Gary C. Curhan / 318 Nephrolithiasis.pdf（*Harrison's Principles of Internal Medicine*）
- **核心主旨**：腎結石不僅是泌尿道局部結晶沈積，更是一種與全身代謝症候群、腸道吸收及骨質代謝密切相關的全身性疾病；臨床應透過兩次 24 小時尿液代謝分析精準定位致病驅動因子，並以適量膳食鈣、鹼性抗氧化飲食（DASH）與水分管理為核心，實現終身復發預防。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **成核與 Randall 斑塊（Randall’s Plaque）典範轉移**：過去認為結石起源於集合管內尿液結晶，現已證實多數草酸鈣結石源自腎間質（亨利氏環細支）沉積的磷酸鈣，延伸侵蝕腎乳頭上皮後形成 Randall 斑塊，提供後續草酸鈣結晶附著生長的基底。
  - **過飽和度與結晶抑制劑失衡**：成石取決於尿液中溶質過飽和度（Supersaturation, SS）與內源性抑制劑（尤其是**檸檬酸鹽 Citrate**）之間的動態平衡。
  - **腸—腎軸與內源性代謝酸負荷**：高動物性蛋白飲食導致淨酸負荷（NEAP）上升，誘導近端腎小管細胞內酸中毒，促進已過濾檸檬酸的重吸收，導致低檸檬酸尿症；同時伴隨腸道草酸吸收亢進、高尿鈣與高尿酸。
- **演講亮點與臨床洞察**：
  - **「鈣質悖論」（Calcium Paradox）**：傳統「低鈣飲食防結石」已被完全顛覆。限制膳食鈣反而導致腸道游離草酸吸收顯著增加、尿草酸飆升並加劇骨質流失。每日攝取 1200 mg 膳食鈣能有效結合腸道草酸，顯著降低復發風險。
  - **連續性風險模型（No Arbitrary Cutoffs）**：尿鈣、尿草酸與結石風險呈連續線性關係，傳統「高尿鈣症」的二分法切點在臨床上不具實質指導意義。
  - **維生素 C 代謝轉化警訊**：高劑量外源性維生素 C 在男性體內可代謝轉化為草酸，顯著提高草酸鈣結石風險，臨床應避免大劑量濫用。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

臨床建議在病患**維持常規飲食與生活狀態下**，進行至少**兩次獨立的 24 小時尿液代謝評估**，以排除日間排泄變異性。

| 檢測項目 / 生物標記 | 臨床意義與病理生理評估目標 | 理想 / 臨床干預目標標準 |
| :--- | :--- | :--- |
| **24 小時尿總量 (Urine Volume)** | 評估整體溶質稀釋度；排尿量 <1 L/d 成石風險倍增 | **目標 $\ge 2.0\ \text{L/day}$** |
| **尿液檸檬酸 (Urine Citrate)** | 體內最關鍵的內源性鈣鹽結晶抑制劑；過低反映細胞內酸中毒/高蛋白負荷 | 偏低需積極提升（以鹼性飲食/檸檬酸鉀校正） |
| **尿液草酸 (Urine Oxalate)** | 草酸鈣過飽和度的關鍵驅動因子（主要受飲食草酸與鈣結合狀態影響） | 越低越好（呈連續性風險相關） |
| **尿液鈣 (Urine Calcium)** | 評估腸道高吸收、腎臟漏鈣或骨質高周轉（破骨活性亢進） | 控制於理想範圍（需同時限制鈉攝取） |
| **尿液 pH 值 (Urine pH)** | 指導結晶類型鑑別：$\le 5.5$ 易形成尿酸結石；$\ge 6.5$ 易形成磷酸鈣結石 | 尿酸結石目標：6.0–6.5；磷酸鈣結石避免過鹼 |
| **尿鈉 (Urine Sodium)** | 鈉排泄直接驅動近曲小管鈣的共同排泄；高鈉飲食直接抵消降尿鈣療效 | **目標飲食鈉 $< 2.5\ \text{g/day}$**（約 100 mmol/d） |
| **血清電解質 / 鈣 / 肌酸酐 / 尿酸** | 篩檢潛在代謝異常、腎小管酸中毒（RTA）及高尿酸血症 | 維持電解質平衡，排除代謝性酸中毒 |
| **血清 PTH 與 25(OH)D** | 針對高尿鈣或高血鈣患者，鑑別原發性副甲狀腺機能亢進或維生素 D 缺乏相關代償 | PTH 正常，排除原發性甲狀旁腺亢進 |
| **尿沉渣顯微鏡鏡檢** | 觀察結晶形態：二水草酸鈣（雙錐體/信封狀）、胱胺酸（六角形） | 結晶尿（Crystalluria）為活躍成石期之強預後指標 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 結石成核與生長微環境：從間質鈣化到臨床結石
- **Randall 斑塊生長假說**：
  - 磷酸鈣晶體最先沉積於亨利氏環細上升支（thin limb of Henle's loop）的腎間質中。
  - 隨時間推移，沉積物向下擴展至腎乳頭並穿透乳頭被覆上皮，暴露於腎盂尿液中。
  - 暴露的磷酸鈣斑塊表面成為異質成核（Heterogeneous nucleation）基底，草酸鈣晶體開始在上方附著並覆蓋基質蛋白，歷時數月至數年終形成有臨床意義的結石。
- **尿液理化過飽和度（Supersaturation, SS）**：
  - 尿液為高度複雜溶液，SS 超越熱力學溶解度積時，晶體即有成核傾向。
  - 檸檬酸能與游離鈣離子強力螯合形成可溶性檸檬酸鈣錯合物，大幅降低游離鈣離子濃度，從而抑制磷酸鈣與草酸鈣的自發成核與聚集。

### 2. 營養素交互作用網絡：鈣、草酸與動物蛋白
- **鈣—草酸腸道螯合軸**：
  - 飲食中的鈣在腸道內與草酸結合成不可溶的草酸鈣，直接隨糞便排出。
  - 若限制膳食鈣，未結合的游離草酸在腸道被大量過度吸收，經門脈循環至腎臟排泄，尿草酸顯著升高，促發草酸鈣極度過飽和。
- **高非乳製品動物蛋白對腎臟代謝的打擊**：
  - 提供大量含硫胺基酸（半胱胺酸、甲硫胺酸），在體內氧化生成硫酸根，誘發輕度亞臨床代謝性酸中毒。
  - 酸中毒刺激腎臟近端小管上皮細胞，上調鈉-二羧酸共轉運體（NaDC-1），加劇檸檬酸的重吸收，導致尿液抑制劑匱乏（Hypocitraturia）。
  - 同時誘發骨質微溶出與腎小管鈣重吸收受損，導致高尿鈣及高尿酸排泄，形成結石的三重危險環境。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 飲食與生活型態架構（Dietary Patterns）
- **全面導入 DASH 飲食模式（Dietary Approaches to Stop Hypertension）**：
  - 大型前瞻性佇列證實，富含蔬果、堅果、全穀、適量低脂乳品，並嚴格限制紅肉與精緻糖的 DASH 飲食，與結石風險呈現高度負相關。
  - DASH 飲食提供充沛的鉀、鎂與鹼性前驅物（有機陰離子），可天然提升尿液 pH 值與尿檸檬酸排泄量。
- **充足且均質化的水分攝取**：
  - 核心目標為**每日尿量維持 $\ge 2.0\ \text{L}$**。
  - 若每日基礎尿量僅 1.5 L，應衛教患者「每天額外固定增加 500 mL 水分」。
  - 推薦飲品：水、茶、咖啡、柑橘類果汁（富含檸檬酸與鉀）；**嚴格禁絕含糖飲料（特別是高果糖玉米糖漿加糖飲料）**，果糖代謝會消耗細胞內 ATP，刺激尿酸生成並增加尿鈣排泄。

### 2. 宏量與微量營養素精準微調
- **膳食鈣管理**：維持每日膳食鈣 **1000–1200 mg/day**（優選由全食物如低脂乳品、高鈣蔬菜或芝麻攝取，且應與富含草酸之正餐共食）。非必要時避免空腹服用單一高劑量鈣補充劑。
- **嚴格限鈉**：每日鈉攝取量控制在 **$< 2.5\ \text{g}$（約 $< 6\ \text{g}$ 食鹽）**。降低近端腎小管鈉重吸收驅動的被動鈣排泄，有效降低尿鈣。
- **明智管理高草酸食材**：不建議全面極端限制蔬菜，但應適度減少極高草酸食物的大量過量攝取（如：菠菜、大黃、甜菜根、杏仁、生可可粉、帶皮馬鈴薯）。
- **禁絕高劑量維生素 C 補充劑**：草酸鈣結石成石者（特別是男性），應避免每日使用超過生理劑量（如 $> 500\text{--}1000\ \text{mg}$）的純維生素 C 補充品。

### 3. 功能性營養與藥理學介入
- **鹼化尿液與補充結晶抑制劑（首選）**：
  - **檸檬酸鉀（Potassium Citrate）**：用於低尿檸檬酸及酸性尿酸結石患者。鹼化尿液並有效提供檸檬酸鹽。
  - *臨床禁忌提示*：避免使用碳酸氫鈉或檸檬酸鈉，因其所含的高鈉負荷會加劇高尿鈣，抵消抗成石效果。
- **降尿鈣藥物干預（頑固型高尿鈣草酸鈣結石）**：
  - **長效型噻嗪類利尿劑（Thiazides，如 Chlorthalidone）**：促進遠端小管鈣的主動重吸收。**必須嚴格搭配低鈉飲食**，否則腎小管排鈉利尿反應將阻礙降尿鈣療效並加速低血鉀。
- **高尿酸血症介入**：
  - 針對伴有高尿酸尿症的草酸鈣結石復發患者，可評估使用黃嘌呤氧化酶抑制劑（Allopurinol）。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **破除低鈣迷思，落實共餐補鈣**：
   即刻向結石患者衛教「停止極端限制鈣質」，指導將富含膳食鈣的食物（目標每日 1200 mg）與正餐一同食用，以最大化腸道草酸沉澱阻斷效率。
2. **開立雙次 24 小時尿液代謝全套處方**：
   在患者未改變日常飲食的前提下，完成兩次週末或工作日的 24 小時尿液代謝檢驗（包含尿量、pH、鈣、草酸、檸檬酸、尿酸、鈉、鉀、磷、肌酸酐），作為精準個人化介入的基線依據。
3. **推動以 DASH 飲食為核心的鹼性飲食轉型**：
   降低飲食中紅肉、禽肉與海鮮等非乳製動物蛋白攝取，提高深色蔬果比例，以減輕腎臟酸負荷、天然提升尿檸檬酸，並嚴格限制飲食鈉至 $<2.5\ \text{g/day}$。
4. **量化補水處方與剔除果糖飲品**：
   依據 24 小時尿量測量值開立補水缺口處方（確保排尿量 $\ge 2.0\ \text{L/day}$），並強制戒除所有市售含果糖飲料與高劑量維生素 C 補充劑。
