# 呼吸系統疾病之診斷程序、介入技術與胸部影像精準評估
- **主講人/來源**：George R. Washko, Hilary J. Goldberg, Majid Shafiq / 286 Diagnostic Procedures in Respiratory Disease.pdf (*Harrison's Principles of Internal Medicine*)
- **核心主旨**：本章系統性架構了當代呼吸系統疾病的診斷階梯，涵蓋床邊微創胸膜處置、先進介入支氣管鏡（EBUS、冷凍切片與電磁導航）、放射導引穿刺（TTNA）以及高解析胸部影像（CT次級肺小葉分析、MRI與PET），為臨床醫師建立結構精準度、組織獲取率與病患安全平衡的診斷決策模型。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **解剖結構性破壞與微環境衰退**：外源性毒素（如菸草、環境微粒）、氧化壓力及異常免疫發炎反應，主要攻擊呼吸系統的解剖功能基元——**次級肺小葉（Secondary Pulmonary Lobule）**。病理進程沿著小葉中心（細支氣管炎、小葉中心型肺氣腫 CLE）、肺間質/淋巴管（間質性肺病 ILD、纖維化牽拉）或肺泡結構擴展（全小葉型肺氣腫 PLE）。
  - **微血管床與血流動力學失衡**：長期的肺泡缺氧、組織纖維化或血管床破壞，驅動肺動脈管壁重塑與阻力升高，誘發肺動脈主幹擴張及微血管外滲（如充血性心衰竭之 Kerley B 線、頭端血管充血 Cephalization），形成不可逆的心肺代償失調。
- **演講亮點與臨床洞察**：
  - **影像生物標記的典範轉移**：胸部電腦斷層（CT）不僅用於偵測腫瘤，其**主肺動脈/升主動脈直徑比值（PA/A ratio > 1）**以及**主動脈幹直徑 > 3 cm**，是評估肺血管壓力升高、預測 COPD 急性發作與死亡風險的關鍵客觀預後指標。
  - **微創介入與細胞學獲取革命**：內視鏡超音波導引穿刺（EBUS-TBNA）已全面取代縱隔腔鏡成為淋巴結分期的第一線工具；經支氣管冷凍切片（Cryobiopsy）顯著提升瀰漫性間質肺病（如 IPF）診斷率；結合電磁導航（ENB）與錐狀射束 CT（Cone-beam CT）大幅提高周邊肺結節取樣的「Tool-in-lesion」準確率。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **主肺動脈幹直徑 (PA Diameter)** | 評估中心肺動脈擴張程度，反映肺動脈高壓與心肺血管重塑風險 | **> 3 cm** 提示存在肺動脈高壓 |
| **PA/A 比值 (PA trunk / Aorta)** | 主肺動脈直徑與升主動脈直徑之比，預測慢性呼吸道疾病急性惡化與死亡率 | **PA/A > 1.0** 提示肺血管阻力顯著上升、預後不良 |
| **次級肺小葉 CT 衰減特徵** | 鑑別小葉中心型（CLE）、全小葉型（PLE）、旁間隔型（PSE）肺氣腫及間質變化 | CLE偏好**上肺葉**；PLE偏好**基底部**；IPF偏好**基底與周邊**；NSIP偏好**頂部** |
| **CT 組織密度值 (Hounsfield Units, HU)** | 定量組織衰減特性，校準肺實質（低密度）與縱隔/軟組織（高密度） | 水 = **0 HU**；空氣 = **-1000 HU** |
| **BAL 序列沖洗紅血球計數** | 支氣管肺泡灌洗液序列回抽分析，診斷瀰漫性肺泡出血 (DAH) | 序列灌洗中紅血球計數**持續遞增**且回抽液肉眼呈現血色加深 |
| **支氣管黏膜基因表現分類器** | 評估吸菸者未定性肺結節之惡性機率，減少不必要的侵入性切片 | 依基因標記區分惡性機率；由中度轉為**低後驗機率**者可安全進入影像追蹤 |
| **移植排斥組織切片門檻** | 經支氣管切片評估肺移植急性細胞性排斥 (ACR) | 需取得至少 **≥ 5 塊**含肺泡之實質組織結構 |
| **肋膜腔積液 Mesothelin-1** | 肋膜微創穿刺液之腫瘤標記檢測 | 輔助評估惡性肋膜病變，特別是惡性間皮瘤 (Mesothelioma) |
| **TTNA 組織充足度 (Molecular Testing)** | 評估基因突變、次世代定序 (NGS) 與免疫化學染色 (IHC) 之檢體要求 | Core needle 檢體質量優於 FNA；陰性預測值約 **70%**（陰性不可完全排除惡性） |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 次級肺小葉（Secondary Pulmonary Lobule）解剖病理學與 CT 表現
- **微結構組成**：次級肺小葉是肺結構的最基本功能單元（大小約 1~2.5 cm），由結締組織的小葉間隔（Interlobular septa，厚度約 0.1 mm）所包繞。
  - **小葉核心**：包含伴行的小葉細支氣管（直徑約 1 mm，管壁厚度約 0.05~0.1 mm）與小葉動脈（直徑約 1 mm）。
  - **周邊間質**：小葉間隔內走行肺靜脈（直徑約 0.5 mm）與淋巴管網。
- **病理型態影像對應**：
  - **細支氣管炎**：表現為小葉中心性結節（Centrilobular nodules）。
  - **肺氣腫分型**：小葉中心型（CLE）破壞小葉核心區域（吸菸誘導，上肺為主）；全小葉型（PLE）破壞整個小葉（如 $\alpha_1$-抗胰蛋白酶缺乏，下肺為主）；旁間隔型（PSE）破壞鄰近胸膜的小葉周邊。
  - **牽拉性支氣管擴張（Traction Bronchiectasis）**：肺實質間質纖維化導致肺順應性顯著下降，因周邊纖維組織牽拉導致支氣管非感染性繼發管腔擴張，直接反映疾病嚴重度。

### 2. 進階介入支氣管鏡技術：診斷力與安全性的取捨
- **EBUS-TBNA 與 EUS**：
  - 結合凸陣超音波探頭與即時細針抽吸，對上皮性惡性腫瘤敏感度約 90%，惡性淋巴瘤約 70%，肉芽腫性疾病（如結節病）敏感度 $\ge 80\%$。
  - 可輔助經食道（EUS）穿刺特定後縱隔淋巴結站，擴大分期覆蓋範圍。
  - 結合現場快速細胞學評估（ROSE）可即時確認檢體充足性，減少重複穿刺次數。
- **經支氣管冷凍切片（Cryobiopsy） vs. 傳統夾鉗切片（Forceps Biopsy）**：
  - 利用探頭急凍技術（液態氮或 $\text{CO}_2$ 焦耳-湯姆森效應）凍結吸附組織，獲取的肺泡結構完整、無壓迫假象（Crush artifact）。
  - 在特發性肺纖維化（IPF）等間質性肺病中，組織診斷率顯著高於傳統夾鉗，但併發**嚴重出血**與**氣胸**風險亦明顯攀升，操作時多需搭配硬式支氣管鏡或氣球止血導管建立安全氣道。
- **周邊肺結節導航系統**：
  - 利用電磁導航（ENB）、虛擬支氣管鏡結合 Radial EBUS（探頭進入病灶中心呈現同心圓圖像 concentric image 時診斷率最高）以及術中錐狀射束 CT（Cone-beam CT），克服以往周邊盲切的定位盲區。

### 3. 經胸壁針刺切片（TTNA）之決策矩陣與併發症分析
- **引導技術比較**：CT 引導為目前金標準；超音波引導則具備無輻射、即時成像、操作時間短、費用低等優勢，適用於貼近胸壁的病灶。
- **針具選擇與併發症權衡**：
  - **粗針切片 (Core Needle)**：組織取得量充沛，可提供次世代基因定序（NGS）與精準免疫染色，但總體併發症發生率（38.8%）顯著高於細針抽吸（FNA, 24.0%）。
  - **常見併發症**：肺實質出血（25%~33%）、氣胸（17%~28%，大部分無需胸管引流）。
  - **風險加劇因子**：結節直徑過小、穿刺針徑過粗、穿經正常含氣肺組織路徑過長、病灶鄰近縱隔大血管。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

> **功能醫學整合視角**：針對需反覆接受放射線影像追蹤（CT/PET）、呼吸道上皮屏障受損、或進行侵入性切片前後之肺部微環境修復，給予抗氧化、粒線體保護與抗纖維化發炎調節策略。

- **功能性營養素/植化素補充**：
  - **N-乙醯半胱氨酸 (NAC)**：口服 600–1200 mg/day。作為穀胱甘肽（GSH）合成前驅物，提供直接抗氧化力、稀釋氣道黏液、降低微環境發炎，保護肺泡二型細胞與纖毛上皮。
  - **游離輻射防護複方（CT/PET檢查前後支持）**：
    - **維生素 C（1000 mg）+ 脂質體穀胱甘肽（250–500 mg）+ $\alpha$-硫辛酸（ALA, 300 mg）**：於高階影像檢查前後補充，降低電離輻射引發的活性氧自由基（ROS）與 DNA 雙股螺旋斷裂損傷。
    - **褪黑激素 (Melatonin)**：檢查前夜 3–5 mg，強化粒線體抗氧化酵素系統（SOD, Catalase）。
  - **薑黃素 (Curcumin, 500–1000 mg/day) + 槲皮素 (Quercetin, 500 mg/day)**：抑制 NF-$\kappa$B 與 TGF-$\beta$ 發炎途徑，減少纖維母細胞過度活化，維持肺血管內皮穩定性。
  - **高純度 Omega-3 脂肪酸 (EPA/DHA 2–3 g/day)**：促進促分解素（SPMs: Resolvins, Protectins）生成，促進氣道微損傷後的組織修復並減緩血管外周阻力。
- **飲食與禁食策略**：
  - **抗發炎植化素多酚飲食**：採用豐富深色蔬果、特級初榨橄欖油、堅果與十字花科蔬菜的高多酚地中海飲食，藉由蘿蔔硫素（Sulforaphane）活化 Nrf2 路徑，提升內源性解毒與抗氧化屏障。
  - **間歇性斷食（16/8 或 14/10 斷食法）**：在身體代謝允許下進行限時進食，啟動細胞自噬機制（Autophagy），有助清除受損之衰老細胞（Senescent cells），降低氣道慢性低度全身性發炎。
- **環境毒素阻斷/代謝排毒/生活型態**：
  - **呼吸道外源毒素徹底阻斷**：嚴格落實戒菸（阻斷小葉中心型破壞）、居家使用醫療級 HEPA 空氣清淨設備（過濾 PM2.5 與揮發性有機物 VOCs），減少氣道黏膜生物薄膜（Biofilm）負擔。
  - **橫膈膜呼吸與肺泡擴張訓練**：進行緩慢深長呼吸訓練（如 4-7-8 呼吸法），促進肺基底部長期塌陷肺泡之通氣，增加肺泡表面張力素分泌，改善局部淋巴與微血管循環回流。
  - **淋巴與肝臟排毒支援**：適度溫和有氧運動、充足水份攝取（促進黏液纖毛清除系統作用），加速顯影劑（碘造影劑、釓顯影劑）於影像檢查後的腎臟代謝排除。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **影像常規篩檢肺血管指標**：判讀胸部高解析 CT 時，除關注肺實質結節外，務必例行量測**主肺動脈幹直徑（是否 > 3 cm）**與**PA/A 比值（是否 > 1.0）**，提早發現隱匿性肺血管重塑與心肺衰竭高危患者。
2. **依病理表型建立精準採樣策略**：
   - 縱隔/肺門淋巴結評估：**首選 EBUS-TBNA**（配合 ROSE 即時判讀確認檢體充足）。
   - 瀰漫性間質性肺病（ILD/IPF）：評估病患心肺耐受度，優先考量**經支氣管冷凍切片（Cryobiopsy）**，以取得無變形之足量間質組織。
   - 周邊實質結節：評估電磁導航支氣管鏡或即時超音波引導 TTNA，平衡診斷率與氣胸風險。
3. **低劑量與輻射風險控管**：嚴格遵循 ALARA（合理抑低）原則，肺癌高危族群篩檢應採用低劑量 CT（LDCT），並評估非電離輻射檢查（如超音波、超極化氣體 MRI）於反覆追蹤患者的可行性。
4. **檢查前後的黏膜修復與代謝護理**：針對進行侵入性採樣或高游離輻射掃描的病患，臨床上應及早衛教外源毒素隔離（防 PM2.5、戒菸），並輔以 NAC、穀胱甘肽等抗氧化策略，守護肺泡微結構健康。
