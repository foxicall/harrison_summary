# 咯血（Hemoptysis）的鑑別診斷、病理機轉與急慢整合處置指南
- **主講人/來源**：39 Hemoptysis.pdf（Carolyn M. D'Ambrosio / *Harrison's Principles of Internal Medicine*）
- **核心主旨**：以呼吸道雙重血流動力學與危急分層為基礎，系統化剖析感染、惡性腫瘤、自體免疫血管病變及環境毒性（如電子煙霧）誘發的咯血機制；在確保急性氣道防護的同時，以功能醫學視角探討微血管完整性修復與慢性發炎黏膜修護策略。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **雙重循環動力學失衡**：肺臟具備低壓系統（肺循環，負責氣體交換）與源自主動脈的高壓系統（支氣管循環，負責氣道血供）。慢性感染（如支氣管擴張、結核空洞）與腫瘤會促使高壓支氣管動脈**病態新生血管形成（Neovascularization）**，一旦破裂易導致猛烈且難以自行凝閉的出血。
  - **微血管炎與屏障崩解**：自體免疫性毛細血管炎（Capillaritis，如 GPA、抗 GBM 疾病）或環境外源毒素（如電子煙氣霧、古柯鹼）直接破壞肺泡-毛細血管屏障，引發瀰漫性肺泡出血（DAH）。
  - **氣道死腔窒息危象**：氣管支氣管樹之解剖容積僅約 $100 \sim 200\text{ mL}$。急性大出血時，病患致命主因為血液灌滿氣道與肺泡導致的**窒息（Asphyxiation）**，而非全身循環衰竭性失血休克。

- **演講亮點與臨床洞察**：
  - **臨床 Paradigm Shift**：咯血量評估重於一切。定義「威脅生命之大量咯血（Life-threatening / Massive Hemoptysis）」為 **$24$ 小時內 $>400\text{ mL}$ 或單次 $>100 \sim 150\text{ mL}$**（約半杯美制標準杯），此類佔整體咯血約 $5 \sim 15\%$，需立即啟動氣道保護與血管栓塞介入。
  - **新興環境病因**：電子煙相關肺損傷（Vaping-induced lung injury / EVALI）已確立為誘發 DAH 與急性咯血的新興毒理因子。
  - **支氣管擴張症之首位威脅**：在已開發國家，反覆感染使支氣管擴張處呈現高度充血與扭曲擴張的支氣管動脈網，是導致大量致命性咯血的首要病因。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **出血量客觀定量**<br>(Volume Quantification) | 評估窒息與氣道淹沒風險，決定是否進入急救路徑 | **危急指標**：單次 $>100 \sim 150\text{ mL}$ 或 $24\text{ h} > 400\text{ mL}$（1 美制杯約 $236\text{ mL}$） |
| **全血球計數 (CBC)** | 評估急性/慢性貧血、血小板減少性出血傾向，以及白血球上升所提示之感染反應 | 血小板 $<50,000/\mu\text{L}$ 為出血高危；白血球升高提示急性感染 |
| **凝血功能 (PT/INR, aPTT)** | 評估外源性/內源性凝血路徑，排除抗凝劑過量或凝血因子缺乏 | $\text{INR} > 1.5$ 或 $\text{aPTT}$ 延長需警惕並評估凝血因子阻斷狀態 |
| **尿液常規分析 (UA) 與 肌酸酐** | 評估是否存在微小血尿/蛋白尿，排除「肺-腎症候群」自體免疫侵犯 | 鏡檢紅血球、紅血球圓柱體（RBC casts）提示需緊急排查血管炎 |
| **顯影胸部電腦斷層 (Contrast-enhanced CT)** | 鑑別支氣管擴張、肺膿瘍、血管瘤（如 Rasmussen 動脈瘤）、真菌球（Mycetoma）及中心型肺癌；可加做 CTPA 排除肺栓塞 (PE) | 明確指出出血源頭血管分佈與實質病灶浸潤狀態 |
| **可彎曲支氣管鏡 (Flexible Bronchoscopy)** | 直視氣道黏膜、排除支氣管原發性腫瘤（如類癌症候群、鱗狀細胞癌）、採集深部組織與灌洗液 | 影像無明顯腫瘤但具危險因子（年齡 $>40$ 歲、吸菸史）者為必備檢查 |
| **自體免疫抗體組**<br>*(功能醫學/免疫延伸)* | 排查抗嗜中性白血球細胞質抗體 (ANCA: PR3, MPO)、抗 GBM 抗體、ANA 等血管炎誘因 | 陽性反應提示免疫複合物或抗體驅動之微血管壞死性破壞 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 氣道血管動力學機制：高壓支氣管循環之病態演變
- **肺循環（低壓系統）**：承接心輸出量，平均壓極低，主要用於肺泡氣體交換；罕見主動引發噴射狀出血（除非如 Rasmussen 動脈瘤破裂侵蝕肺動脈）。
- **支氣管循環（高壓系統）**：直接源自體循環主動脈，負責氣道壁、支氣管周圍組織及局部淋巴結之養分灌流。
- **發炎血管新生（Inflammatory Neovascularization）**：
  - 慢性支氣管發炎、支氣管擴張及慢性開洞病變（結核、曲麴菌球 *Aspergillus*、非結核分枝桿菌 NTM）釋放持續性血管新生因子（如 VEGF、bFGF）。
  - 誘發支氣管動脈扭曲、擴張與側支循環增生，血管壁平滑肌發育不全且脆弱。
  - 遭遇氣道急性感染加劇時，黏膜充血潰破，體循環之動脈高壓導致出血洶湧且自限性凝固極難達成。

### 3. 特殊病理與環境毒理誘發之咯血型態
- **瀰漫性肺泡出血（DAH）與環境傷害**：
  - 特色：肺泡腔內廣泛紅血球外滲，但臨床上**不一定伴隨明顯咯血**，常隱匿呈現，影像表現為瀰漫性毛玻璃樣混濁（Diffuse Ground-Glass Opacities, GGO）。
  - 病因：涵蓋全身性紅斑狼瘡（SLE）、肉芽腫併多發性血管炎（GPA）、抗 GBM 疾病，以及吸入性毒素（古柯鹼、**電子煙氣霧暴露**）。
- **特異性感染病因**：
  - **肺吸蟲症（Paragonimiasis）**：常因生食未煮熟淡水甲殼類（淡水螯蝦、螃蟹）引起，臨床與影像表現高度模擬肺結核，為流行區旅遊/移民史中常被忽略的病原。
  - **曲麴菌球（Mycetoma / Aspergilloma）**：寄生於舊有結核或發炎空洞，分泌毒素並促成局部新生血管形成，極易爆發致死性大出血。
- **機械與內分泌異常**：
  - **異位子宮內膜（Thoracic Endometriosis）**：導致週期性隨月經週期發生的「異位月經性咯血（Catamenial hemoptysis）」。
  - **醫源性損傷**：心房顫動肺靜脈隔離術後誘發的肺靜脈狹窄、肺動脈導管（Swan-Ganz）球囊過度充氣造成肺動脈破裂。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

> **急症紅線警示**：若病患處於大量咯血（單次 $>100\text{ mL}$ 或伴隨血氧下降/呼吸窘迫），必須優先採取常規醫療之**氣道保護（患側向下側臥以防健側溺血）、動脈栓塞術（BAE）或胸腔外科手術**。本章節處方專注於**非大量咯血、急性出血止血後之微血管修復、黏膜消炎與慢性發炎病根治療**。

### 1. 功能性營養素與血管內皮修護配方
- **維生素 C（高劑量抗壞血酸）+ 柑橘生物類黃酮（Hesperidin & Rutin）**：
  - **機轉**：強化內皮下基底膜第一型與第三型膠原蛋白交聯，提升微血管結構強度，降低通透性與脆性；芸香素（Rutin）可顯著減少微血管微小滲漏。
  - **建議劑量**：維生素 C $1000 \sim 2000\text{ mg/day}$，搭配混合生物類黃酮 $500\text{ mg/day}$。
- **維生素 K 複方（K1 植物甲萘醌 + K2 MK-7）**：
  - **機轉**：活化凝血因子 II、VII、IX、X 之羧化反應（Carboxylation），確保微血管破損時凝血級聯反應能即時形成穩定的初級止血栓。
  - **建議劑量**：經評估凝血功能後補充，維生素 K1 $100 \sim 200\text{ mcg/day}$、K2 $100\text{ mcg/day}$（**注意：使用抗凝血劑 Warfarin 者禁用**）。
- **N-乙醯半胱氨酸（NAC）**：
  - **機轉**：裂解氣道黏液雙硫鍵以利引流，避免血塊機化阻塞細支氣管；同時作為穀胱甘肽（GSH）前驅物，平息氧化壓力誘發的肺泡-毛細血管破壞。
  - **建議劑量**：$600\text{ mg}$，每日 $2$ 次。
- **槲皮素（Quercetin）搭配 鋅（Zinc Glycinate）**：
  - **機轉**：抑制 NF-$\kappa$B 途徑與肥大細胞去顆粒，降低氣道急性血管擴張性前列腺素與組織胺釋放，並促進受損呼吸道上皮之黏膜再上皮化修復。
  - **建議劑量**：槲皮素 $500\text{ mg/day}$，鋅 $25 \sim 30\text{ mg/day}$。

### 2. 抗炎飲食與呼吸道黏膜保護策略
- **抗氧化生津抗炎飲食（Anti-inflammatory Mucosal Diet）**：
  - 攝取富含花青素（藍莓、黑醋栗）與多酚類食物，增強微血管彈性蛋白保護。
  - 嚴格避開誘發支氣管黏膜充血之刺激物：酒精、極度辛辣食品、高油炸脂質過氧化物。
- **溫度與質地管理**：
  - 急性出血期至修復初期，飲食宜採**溫涼、柔軟質地**，切忌滾燙熱湯或高溫飲品，因熱刺激可經迷走神經與局部血流反射，誘發近端支氣管血管床劇烈充血擴張。
- **胃酸微吸入阻斷策略**：
  - 避免睡前 $3$ 小時進食，床頭抬高 $15 \sim 30$ 度，防止胃酸/膽鹽微吸入（Micro-aspiration）對本已受損之呼吸道上皮造成二次化學灼傷與發炎刺激。

### 3. 環境毒素阻斷、排毒與生活型態醫學
- **絕對環境毒素阻斷（Environmental Cleansing）**：
  - **即刻戒絕電子煙（Vaping）與傳統煙草**：消除霧化載體（如維生素 E 醋酸酯、丙二醇）對肺泡巨噬細胞與微血管內皮的急性毒性破壞。
  - **室內空氣優化**：全天候運行具備 HEPA 與活性碳濾網之空氣清淨機，控制室內 PM2.5 $<5\,\mu\text{g/m}^3$，阻絕超細懸浮微粒誘發支氣管過敏性充血。
- **避免氣胸與微血管張力破裂之生活規範**：
  - 避免劇烈瓦氏動作（Valsalva maneuver）：補充充足水分與鎂（如甘胺酸鎂 $300\sim 400\text{ mg/day}$），軟化排便，防止用力屏氣導致胸腔內壓驟升進而撐破新生血管。
  - 暫停高強度阻力訓練及劇烈屏氣運動，出血停止後 $2 \sim 4$ 週內以溫和有氧散步為主。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **量化重於定性，直覺單位問診**：詳細評估咳血量，若無法精確描述毫升數，以「量杯（1 美制杯約 $236\text{ mL}$）」或「湯匙/茶匙」為參照基準；單次大於半杯即屬呼吸道急症。
2. **謹記致命病理為「窒息」非「失血」**：氣道解剖容積僅 $100\sim 200\text{ mL}$，大量咯血時立即執行**保護健側肺原則**（使出血側朝向下方側臥），防止血液淹沒對側正常肺葉。
3. **常規進行「肺-腎軸線」快速篩查**：遇未知原因咯血，尿液常規分析（UA）與腎功能（Creatinine）為第一線必檢項目，防止遺漏早期肺-腎自體免疫血管炎。
4. **落實年齡與抽菸危險分層**：年齡 $>40$ 歲或具吸菸史病患，即使胸部 X 光正常，亦**不得**單純以急性支氣管炎結案，必須進行對比顯影胸部電腦斷層（CT）與可彎曲支氣管鏡檢以排除惡性腫瘤。
5. **全面追問新興環境毒素與特殊飲食史**：問診應常規納入電子煙（Vaping）使用史（排查 DAH）及生食未煮熟淡水甲殼類史（排查肺吸蟲）。
