# 漿細胞疾病與多發性骨髓瘤：從微環境發炎、免疫失調到標靶整合治療（Plasma Cell Disorders）
- **主講人/來源**：111 Plasma Cell Disorders.pdf（Harrison's Principles of Internal Medicine, 21st Edition, Chap. 111）
- **核心主旨**：本章系統性剖析晚期 B 細胞單株演進（MGUS → SMM → 多發性骨髓瘤）之遺傳與免疫發炎微環境驅動機轉，深入探討溶骨性病變、腎小管毒性與高黏滯症候群的病理生理，並整合現代標靶化療、幹細胞移植及全人支持性器官保護策略。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **基因突變與選汰**：疾病源於生發中心後（post-germinal center）已歷經體細胞超突變的晚期 B 細胞。起始於重鏈類別轉換重組（switch recombination）異常、超二倍體（Hyperdiploidy）或 14q32 易位（如 $t(11;14)$、$t(4;14)$），繼而因次級突變（*KRAS*、*NRAS*、*BRAF*、*TP53*）演化為侵襲性單株。
  - **發炎微環境共生**：骨髓瘤細胞藉由黏附分子（VLA-4 等）固著於骨髓基質細胞（BMSCs），誘發大量 IL-6、VEGF、IGF-1 與 SDF-1α 分泌，啟動 Ras/Raf/MAPK、PI3K/Akt 及 NF-κB 路徑，形成抗凋亡與抗藥性惡性循環。
  - **蝕骨與成骨失衡**：骨髓瘤細胞分泌蝕骨活化因子（RANKL、MIP-1α、TNF、IL-1），同時分泌 **Dickkopf-1 (DKK-1)** 阻斷 Wnt 路徑強烈抑制成骨細胞，造成「純溶骨性蝕骨（purely lytic bone lesions）」，無法形成新骨修復。
  - **免疫微環境耗竭**：腫瘤微環境中髓源抑制細胞（MDSC）、漿細胞樣樹突細胞（pDC）及 $T_H17$ 細胞增加，促發炎反應加劇；相反地，抗腫瘤之 $T_H1$、CTL、NK 細胞則高度耗竭，且因正常抗體合成受抑及加速分解，呈現全面性次發性低丙種球蛋白血症（Hypogammaglobulinemia）。
- **演講亮點與臨床洞察**：
  - **純溶骨現象之診斷陷阱**：由於成骨作用被 DKK-1 徹底阻斷，血清鹼性磷酸酶（ALP）通常正常，傳統核醫骨骼掃描（Bone Scan）極易出現假陰性，必須採用低劑量全身 X 光、全脊椎/骨盆 MRI 或 $^{18}\text{F}$-FDG PET/CT 作為標準影像工具。
  - **電解質異常的生化盲點**：單株 M 蛋白（特別是陽離子型 IgG）過多時，會帶動氯離子滯留，導致**陰離子間隙（Anion Gap）異常偏低**；同時高球蛋白血症會佔據血清體積，引發**假性低血鈉（pseudohyponatremia）**。
  - **早期腎損傷標記**：過量游離輕鏈重吸收到近端腎小管細胞，溶酶體破裂釋出毒性酵素，最早期的臨床表徵為**成人型范可尼症候群（Adult Fanconi's Syndrome, Type 2 Proximal RTA）**，伴隨糖尿、胺基酸尿與電解質流失，但尿常規試紙（主要測白蛋白）常呈偽陰性。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（診斷與分期標準） |
| :--- | :--- | :--- |
| **血清/尿液蛋白電泳 (SPEP/UPEP) 與免疫固定 (IFE)** | 定量與定性單株蛋白（M-spike），評估腫瘤負荷與治療反應；鑑別單株重鏈/輕鏈型別 | 診斷敏感度界線：SPEP 可偵測 $\ge 5\text{ g/L}$；MGUS 標準為 $<30\text{ g/L}$；SMM/MM 常 $\ge 30\text{ g/L}$ |
| **血清游離輕鏈比值 (sFLC $\kappa/\lambda$ ratio)** | 評估非分泌型骨髓瘤、輕鏈型骨髓瘤；作為惡性轉變之超高風險指標 | 正常比值約 0.26–1.65；**Involved/uninvolved 比值 $\ge 100$**（且侵犯輕鏈濃度 $\ge 100\text{ mg/L}$）為骨髓瘤定義事件（MDE） |
| **骨髓切片與穿刺 (BMA & Biopsy)** | 評估漿細胞侵犯比例，流式細胞儀/免疫組化檢測 CD138、CD56 及輕鏈侷限性（Clonality） | 漿細胞 $>10\%$ 為 MM 診斷門檻；**$\ge 60\%$** 直接列為骨髓瘤定義事件（MDE） |

| **校正血鈣 (Corrected Ca) 與腎功能 (Cr / eGFR)** | 監測骨質急遽崩解（高血鈣）與輕鏈管型腎病變（Cast nephropathy） | 鈣離子 $>2.75\text{ mmol/L} (>11\text{ mg/dL})$ 或高於上限 $1\text{ mg/dL}$；$\text{Cr} >177\ \mu\text{mol/L} (>2\text{ mg/dL})$ 或 $\text{CCr} <40\text{ mL/min}$ |
| **陰離子間隙 (Serum Anion Gap)** | 生化代謝代償指標；$[\text{Na}^+ - (\text{Cl}^- + \text{HCO}_3^-)]$，評估陽離子 M 蛋白濃度衝擊 | 顯著下降（常 $<8\text{ mEq/L}$ 或接近負值），為未確診骨髓瘤的重要生化線索 |
| ***MYD88* L265P & *CXCR4* 突變分析** | 鑑別診斷 Waldenström 巨球蛋白血症 (WM)、邊緣區淋巴瘤與 IgM 骨髓瘤；預測 BTK 抑制劑反應 | *MYD88* L265P 突變率在 WM 中 $>90\%$；*CXCR4* 突變與高腫瘤負荷及 ibrutinib 抗藥/延遲反應相關 |

## 三、 關鍵機制詳解與重點筆記

### 1. 骨髓微環境網絡與發炎免疫逃逸機制（Figure 111-4 深度拆解）
- **基質黏附分子活化**：骨髓瘤細胞表面表現整合素（Integrins）與細胞表面受體，與骨髓基質細胞（BMSC）及細胞外基質（ECM）蛋白直接嵌合。
- **旁分泌與自分泌細胞激素風暴**：
  - **IL-6（介白素-6）**：最重要的促增殖與抗凋亡細胞激素，經由 JAK/STAT3 與 Ras/Raf/MEK/MAPK 訊號級聯，活化 Mcl-1 與 Bcl-xL，阻斷細胞內凋亡途徑。
  - **VEGF 與 IGF-1**：促進骨髓內微血管新生（Neoangiogenesis），並提供持續性自分泌生存訊號。
  - **SDF-1α（CXCL12）**：引導骨髓瘤細胞在骨髓腔內定向遷移（Migration）與原位定植。
- **免疫抑制微環境重塑**：
  - 骨髓瘤細胞誘導骨髓內 pDC（漿細胞樣樹突細胞）與 MDSC（髓源抑制細胞）聚集，釋放 TGF-$\beta$ 等因子。
  - 上調 PD-L1 與 CTLA-4 軸線，誘發細胞毒性 T 細胞（CD8+ CTL）進入無能（Anergy）或耗竭（Exhaustion）狀態。
  - 骨髓微環境中 $T_H17$ 細胞大幅擴增並分泌 IL-17，協同 IL-6 進一步加劇發炎與破骨作用。

### 2. 純溶骨性病變（Osteolytic Lesions）的解偶聯病理生化
- **破骨細胞過度活化（Hyperactive Osteoclasts）**：
  - 腫瘤細胞過度分泌 RANKL、MIP-1α、IL-1、TNF 及淋巴毒素（Lymphotoxin）。
  - RANKL 與破骨前驅細胞之 RANK 結合，活化 NF-$\kappa$B 訊號，驅使破骨細胞增生、分化與溶骨活性增強。
- **成骨細胞極度抑制（Suppressed Osteoblasts）**：
  - 骨髓瘤細胞分泌高濃度的 **DKK-1（Dickkopf-1）**，直接結合 LRP5/6 輔助受體，阻斷成骨細胞中的 Wnt/$\beta$-catenin 傳導路徑。
  - 結果：破骨作用進行而**完全缺乏成骨修復**，因此病灶於 X 光片上呈現極具特徵的打洞樣（"Punched-out"）穿透性骨缺損，血清 ALP 正常，病理性骨折與高血鈣風險極高。

### 3. 輕鏈腎病變（Myeloma Kidney）與體液代謝機轉
- **腎小管負荷與管型沉積（Light Chain Cast Nephropathy）**：
  - 正常狀態下游離輕鏈由腎小球濾過後於近端腎小管完全重吸收並水解。
  - 當單株游離輕鏈過量，超過近端小管轉運最大值（Tm），輕鏈溢流至遠端小管，與 Tamm-Horsfall 黏液蛋白共聚合形成蠟樣硬質管型（Cast），阻塞管腔並引發異物巨細胞反應。
- **細胞內毒性與范可尼症候群（Adult Fanconi Syndrome）**：
  - 輕鏈被近端腎小管上皮吞飲後積累於溶酶體，造成胞內氧化壓力與溶酶體水解酶外洩，造成近端小管粒線體與轉運蛋白功能崩解。
  - 臨床表現為 Type 2 近端腎小管酸中毒（RTA）：葡萄糖、胺基酸、磷酸鹽流失及尿液酸化障礙。

### 4. 巨球蛋白血症 (WM) 與重鏈疾病 (Heavy Chain Diseases) 的特殊生理
- **Waldenström 巨球蛋白血症 (WM)**：
  - 淋巴漿細胞分泌大型五聚體 IgM（約 80% 侷限於血管內），造成嚴重血清高黏滯度（Hyperviscosity），常於血清黏度 $>4\text{ cP}$（通常 M 蛋白 $\ge 40\text{ g/L}$）時爆發。
  - 常見症狀包括視網膜靜脈怒張分節（Sausage-link appearance）、神經性失調、頭痛、心衰竭。
  - 50% 合併周邊神經病變者體內具有對抗**髓鞘相關醣蛋白（Anti-MAG）**的自體抗體。
  - *MYD88* L265P 突變導致 IRAK4/IRAK1 活化，續發 NF-$\kappa$B 與 BTK 路徑持續性活化。
- **重鏈疾病（Heavy Chain Diseases）之分子缺損**：
  - 腫瘤細胞分泌缺乏輕鏈的異常重鏈片段（Fc 片段完整，但 Fd 區基因缺失）。
  - **$\alpha$ 重鏈病（Seligmann's disease / IPSID）**：最常見，局限於小腸固有層，與**空腸彎曲菌（*Campylobacter jejuni*）**持續抗原刺激密切相關，早期對口服抗生素治療具高度反應。
  - **$\gamma$ 重鏈病（Franklin's disease）**：好發於自體免疫疾病（RA）患者，典型特徵為 Waldeyer 淋巴環受侵犯引起之**懸雍垂/軟顎水腫（Palatal edema）**。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 現代標準醫學治療階梯（Conventional Protocols）
- **移植候選者（Transplant Eligible）**：
  - **誘導治療（Induction）**：首選三藥或四藥聯合方案，例如 **VRD**（Bortezomib + Lenalidomide + Dexamethasone）或加入 Anti-CD38 抗體之四藥方案（Daratumumab-VRD），進行 4–6 週期，達到最大細胞減滅（Deep Cytoreduction）。
  - **高劑量化療合併自體幹細胞移植（HDT with ASCT）**：利用高劑量 Melphalan 進行摧毀性骨髓清除後回輸自體造血幹細胞。*注意事項：收集幹細胞前應避免早期長期使用烷化劑（Melphalan），Lenalidomide 使用應於 6 個月內完成幹細胞採集以防幹細胞毒性。*
  - **維持治療（Maintenance）**：ASCT 後使用 Lenalidomide 單藥維持；高風險基因亞型建議聯合蛋白酶體抑制劑（Bortezomib 或口服 Ixazomib）。
- **非移植候選者（Elderly / Frail / Transplant Ineligible）**：
  - 採用低強度但高深度的持續方案：如改良式 **RVD-lite** 或 **Daratumumab + Lenalidomide + Dexamethasone (DRd)**。
- **復發與難治型（Relapsed/Refractory MM）之標靶與細胞療法**：
  - 新一代蛋白酶體抑制劑（Carfilzomib）、IMiD（Pomalidomide）。
  - 核輸出蛋白抑制劑：**Selinexor**（Exportin-1 抑制劑）。
  - 肽綴合烷化劑：**Melflufen**（標靶氨肽酶陽性骨髓瘤細胞）。
  - **BCMA 標靶系統**：抗體藥物複合體（Belantamab mafodotin）、雙特異性抗體（Bispecifics）及 **CAR-T 細胞療法**（Idecabtagene vicleucel, Ide-cel）。

### 2. 功能醫學、代謝保護與支持性介入策略（Supportive & Metabolic Strategies）

```
[骨髓瘤微環境發炎 / IL-6 / NF-κB / 輕鏈釋出]
       │
       ├─► 腎小管酸化與輕鏈沉積 ──► [強制水合] 每日尿量 >2.5L / 避免脫水與顯影劑
       ├─► 純溶骨性病變 (RANKL↑/DKK-1↑) ──► [破骨阻斷] 雙磷酸鹽 (Zoledronic acid) 或 Denosumab
       ├─► 體細胞免疫耗竭 / 丙球缺乏 ──► [被動免疫與疫苗] 結合型肺炎鏈球菌疫苗 / 週期性 IVIG
       └─► 藥物引發神經病變 (PIs / IMiDs) ──► [劑型調整與神經軸突支持] 改為每週皮下注射 / 神經保護營養素
```

- **骨骼微環境重建與蝕骨抑制**：
  - **破骨抑制劑**：Zoledronic acid（4 mg 每月一次，持續 12–24 個月）或 Pamidronate，可大幅降低骨相關事件（SRE）並具潛在抗腫瘤活性；腎功能不全者可考慮轉換為 RANKL 單株抗體 **Denosumab**（120 mg 每月皮下注射）。
  - **嚴格監控骨壞死（ONJ）**：定期進行口腔與齒顎檢查，拔牙或侵入性齒科處置需提早預防。
  - **禁忌警告**：高血鈣期嚴禁盲目補充大劑量活性維生素 D 與鈣片，以免加劇腎鈣質沉積與急性腎衰竭。
- **腎小管與內皮保護網絡**：
  - **強制水合作用（Hydration）**：每日維持水分攝取使尿量達 $2.5\sim 3\text{ L}$ 以上，降低遠端小管中輕鏈濃度與沉積臨界點。
  - **腎毒性物質徹底阻斷**：臨床嚴格禁用非類固醇抗發炎藥（NSAIDs），影像檢查極力避免碘顯影劑；若必須使用顯影劑，應於檢查前後以等張生理鹽水充分水合。
  - **急性輕鏈毒性之血漿置換**：於急性無尿型腎衰竭早期，血漿置換（Plasmapheresis）清除循環游離輕鏈效率為腹膜透析之 10 倍以上。
- **慢性感染預防與免疫支援**：
  - **疫苗接種修正**：多發性骨髓瘤患者對細菌莢膜「多醣體疫苗」反應極差，**必須採用「結合型疫苗」（Pneumococcal Conjugate Vaccine, PCV）**以引發 T 細胞依賴型保護反應。
  - **標靶藥物併發症預防**：
    - Bortezomib（PI 類）抑制細胞免疫，常規必備**帶狀疱疹（Herpes Zoster）預防用藥**（Acyclovir / Valacyclovir）。
    - Lenalidomide / Thalidomide 合併 Dexamethasone 具高栓塞風險，必須根據風險分級給予 **Aspirin 或 LMWH / DOAC 預防深層靜脈血栓（DVT）**。
    - 抗 BCMA 治療後引發極重度無丙球蛋白血症者，定期補充**靜脈注射免疫球蛋白（IVIG）**。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實「CRAB + SLiM」診斷篩檢標準**：
   - 當懷疑漿細胞異常時，勿僅依賴傳統 CRAB（高血鈣、腎衰竭、貧血、骨蝕），必須積極檢驗 **SLiM 生物標記**：骨髓漿細胞 $\ge 60\%$、血清游離輕鏈比值（Involved:Uninvolved）$\ge 100$、或 MRI 顯示 $>1$ 處 $\ge 5\text{ mm}$ 局部骨髓病灶，及早啟動全身性治療。
2. **警惕特殊生化數值警訊**：
   - 門診發現常規生化檢查中出現**「陰離子間隙異常偏低」**（$<8\text{ mEq/L}$）、**「無法解釋的假性低血鈉」**或常規試紙陰性但定量蛋白尿極高的**「成人范可尼症候群（糖尿、低尿酸、低血鉀）」**時，應第一時間加驗血清/尿液免疫固定電泳（IFE）與游離輕鏈（sFLC）。
3. **全面淘汰常規核醫骨掃描，升級精準影像**：
   - 多發性骨髓瘤骨病變屬純溶骨性，**嚴禁以 Technetium-99m 傳統骨骼掃描作為排除骨髓瘤之依據**。疑似骨髓瘤或冒煙型骨髓瘤（SMM）個案，標準診斷與分期應強制安排全身低劑量骨骼 CT、全脊椎/骨盆 MRI 或 $^{18}\text{F}$-FDG PET/CT。
4. **精準鑑別巨球蛋白血症（WM）與 IgM 骨髓瘤**：
   - 出現 IgM 單株蛋白伴隨淋巴結與肝脾腫大時，常規檢測骨髓細胞之 ***MYD88* L265P** 與 ***CXCR4* 突變**。陽性者支持 WM 診斷，首選 BTK 抑制劑（如 Ibrutinib）或 Rituximab 為基礎的方案；若血清黏度 $>4\text{ cP}$ 併發視網膜充血或嗜睡，應立即實施**血漿置換術（Plasmapheresis）**。
5. **啟動早期多重器官保護工程**：
   - 確診骨髓瘤當下即刻建立器官防禦計畫：每日維持大量飲水排毒；嚴禁使用 NSAIDs 止痛（以 Acetaminophen 或神經調節劑取代）；啟動 Bortezomib 治療者務必開立抗病毒藥預防皮蛇；使用 IMiDs 類藥物必須評估並開立抗血栓預防處方。
