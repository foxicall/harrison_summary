# 間質性肺病（ILD）的整合評估、分子機制與長壽醫學展望
- **主講人/來源**：293 Interstitial Lung Disease.pdf（Gary M. Hunninghake, Ivan O. Rosas / 摘自經典內科學教科書《Harrison's Principles of Internal Medicine》第 293 章）
- **核心主旨**：間質性肺病（ILD）涵蓋逾 200 種異質性發炎與進行性纖維化病變；臨床診斷與預防策略必須整合「端粒耗損與遺傳老化標記」、「環境與微量胃酸反流毒性」、「免疫失調」及高解析電腦斷層（HRCT）與多學科會診，方能精準阻斷不可逆的肺泡基質硬化。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **細胞衰老與幹細胞耗損（Cellular Senescence & Stem Cell Exhaustion）**：特別在特發性肺纖維化（IPF）中，第 II 型肺泡上皮細胞（AECII）因端粒酶反轉錄酶（*TERT*）突變或端粒異常縮短，引發細胞衰老分泌表型（SASP），驅動肌成纖維細胞異常活化與細胞外基質（ECM）不可逆沉積。
  - **慢性發炎與異常傷口癒合（Inflammation to Aberrant Repair）**：結締組織病（CTD-ILD）或隱源性機化性肺炎（COP）以廣泛淋巴細胞、漿細胞浸潤與纖維母細胞增生為特徵；而抽菸（RB-ILD/DIP）則驅動肺泡巨噬細胞長期蓄積氧化色素與促發炎細胞因子。
  - **微環境毒素與屏障受損**：抽菸、矽塵、石綿、黴菌/鳥類抗原吸入（過敏性肺炎, HP）以及食道動力障礙導致的「微量胃酸吸入（Microaspiration）」，持續觸發肺泡-微血管內皮界面損傷。
- **演講亮點與臨床洞察**：
  - **治療典範轉移（Paradigm Shift）**：以往普遍使用免疫抑制劑治療所有 ILD，但臨床試驗已證實**免疫抑制劑在特發性肺纖維化（IPF）中反而顯著增加發病率與死亡率**；IPF 已轉向以「抗纖維化藥物（Pirfenidone、Nintedanib）」為主軸，而免疫抑制劑則主要保留於自體免疫相關（CTD-ILD、COP、細胞型 NSIP）。
  - **早期遺傳與影像標記**：高達 35~45% 的 IPF 患者帶有 *MUC5B* 啟動子變異（罹病風險增加 6 倍），且一般人口中有 7~9% 在無明顯症狀時已具有早期間質性影像異常，為功能醫學與抗老預防醫學提供了「肺纖維化亞臨床期（Subclinical window）」的介入先機。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **肺功能檢查（PFTs: TLC, FVC）** | 評估限制型通氣障礙（Restrictive Deficit）；肺容量對稱性下降是 ILD 進展的核心指標。 | FVC 與 TLC 應 >80% 預測值；動態監測 FVC 年降幅（降幅 ≥5-10% 預警高死亡風險）。 |
| **一氧化碳擴散量（DLCO）** | 評估肺泡-毛細血管膜氣體交換效率；常早於肺容積下降前出現異常，反映早期基質硬化或血管重塑。 | 理想 >80% 預測值；輕度下降（60-80%）、重度下降（<40% 提示預後極差）。 |
| **自體免疫全套抗體（Autoantibody Panel）** | 鑑別隱匿型 CTD-ILD；包括 Anti-CCP（RA）、Anti-Scl-70、Anti-centromere（SSc）、Anti-Jo-1、Anti-PL-12（抗合成酶症候群）。 | 陰性（若陽性提示為次發性 CTD-ILD，治療策略自抗纖維化轉向免疫調節）。 |
| **高解析胸部電腦斷層（HRCT）** | 評估病變分佈與基質破壞形態（蜂窩狀 honeycombing、牽拉性支氣管擴張 traction bronchiectasis、毛玻璃影 GGO）。 | 排除 UIP 網狀蜂窩形態；識別可逆之發炎期（以 GGO 為主）與不可逆之纖維化期。 |
| **端粒長度檢測與基因變異（TERT, MUC5B）** | 評估細胞衰老速率、遺傳易感性與家族性肺纖維化（FPF）風險；指導長壽醫學抗老介入。 | 無 *MUC5B* 高風險等位基因；周邊血白血球端粒長度維持在同齡第 50 百分位數以上。 |
| **支氣管肺泡灌洗液（BALF）細胞分類** | 鑑別瀰漫性肺泡出血（DAH）、慢性嗜酸性粒細胞肺炎或外源性脂質肺炎。 | 嗜酸性粒細胞 >25%（提示嗜酸性肺炎）；含鐵血黃素巨噬細胞（提示出血）。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 疾病光譜與臨床病理分類模式（Classification Landscape）
- **已知病因（Known Causes）**：
  - **職業與環境暴露**：石綿沉著症（Asbestosis）、矽肺症（Silicosis）、過敏性肺炎（HP，如養鳥者肺）。
  - **藥物誘發性**：心律不整藥（Amiodarone）、抗生素（Nitrofurantoin）、化療藥（Bleomycin）、免疫調節劑（Methotrexate、TNF-α 抑制劑）。
  - **自體免疫結締組織病（CTD-ILD）**：全身性硬化症（SSc，約佔 50% 瀰漫型患者）、類風濕性關節炎（RA-ILD，男性吸菸者好發）、多發性肌炎/皮肌炎（抗合成酶抗體 Anti-Jo-1/PL-12 相關）。
- **未知病因（特發性間質性肺炎, IIPs）**：
  - **IPF（特發性肺纖維化）**：佔比最高、預後最差（3-5 年死亡率約 50%），以 Usual Interstitial Pneumonia (UIP) 為病理/影像特徵。
  - **NSIP（非特異性間質性肺炎）**：多見於中年非吸菸女性，病理均質（Uniform），分為細胞型（Cellular，對免疫治療反應佳）與纖維化型（Fibrotic）。
  - **COP（隱源性機化性肺炎）**：呼吸道肉芽組織栓塞（Masson bodies），常呈游走性浸潤，類固醇反應極佳。
  - **吸菸相關 ILD**：呼吸性細支氣管炎伴間質性肺病（RB-ILD）與脫屑性間質性肺炎（DIP），核心為含色素巨噬細胞沉積。

```
                    ┌── 已知原因 (暴露/藥物/全身性結締組織疾病 CTD)
                    │
間質性肺病 (ILD) ──┼── 肉芽腫性 (結節病 Sarcoidosis / 肉芽腫性血管炎 GPA)
                    │
                    └── 未知原因 (IIPs: IPF、NSIP、COP、AIP、RB-ILD/DIP)
```

### 2. 影像學（HRCT）與組織病理學特異特徵（Imaging & Histopathology）
- **UIP / IPF**：
  - **HRCT**：主要分佈於基底部、後側與胸膜下（Subpleural basal predominance）；典型表現為粗糙網狀陰影、牽拉性支氣管擴張及**蜂窩狀改變（Honeycombing）**；缺乏廣泛毛玻璃影。
  - **病理**：空間與時間異質性（Temporal and spatial heterogeneity），成熟纖維化與正常肺泡交雜，可見活躍的**纖維母細胞病灶（Fibroblast foci）**。
- **NSIP**：
  - **HRCT**：對稱性、廣泛性毛玻璃影（GGO），可伴隨網狀結構，**常出現胸膜下保留（Subpleural sparing）**，蜂窩狀病變極罕見。
  - **病理**：均一時間間隔的肺泡壁發炎或纖維化，無纖維母細胞病灶。
- **COP**：
  - **HRCT**：斑片狀、多發性胸膜下或支氣管周圍實變，常具游走性（Migratory），可見特異性「**反向光暈徵/環礁徵（Reversed halo / Atoll sign）**」。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素與植化素補充（抗發炎、抗纖維化與端粒保護）
- **N-乙醯半胱氨酸（NAC, N-Acetylcysteine）**：
  - **劑量/機轉**：臨床常用高劑量（1200–1800 mg/天，分次服用）。作為穀胱甘肽（GSH）前驅物，提供直接抗氧化力，減輕 AECII 的氧化損傷與肺泡微環境發炎。
- **薑黃素（Curcumin）與白藜蘆醇（Resveratrol）**：
  - **機轉**：抑制 NF-κB、TGF-β1/Smad3 訊息傳遞路徑，下調纖維母細胞向肌成纖維細胞的轉化（FMT），並降低膠原蛋白（Collagen I/III）沉積。
- **槲皮素（Quercetin）搭配 綠茶萃取物（EGCG）**：
  - **機轉**：作為天然衰老細胞清除化合物（Senolytic-like agents），輔助清除肺泡內過早衰老的 AECII 細胞，減弱促纖維化 SASP 因子釋放。
- **維生素 D3 + K2**：
  - **目標**：維持血清 25(OH)D 在 50–70 ng/mL；調節肺部上皮防禦素表現，穩定自體免疫失調。

### 2. 飲食、禁食與粒線體修復策略
- **抗發炎地中海型飲食（Anti-inflammatory Mediterranean Diet）**：
  - **原則**：高比例 Omega-3 脂肪酸（深海魚、亞麻仁油）、豐富彩虹植化素，降低促發炎的前列腺素 E2（PGE2）及白三烯（Leukotrienes）。
  - **限制 AGEs（糖化終產物）**：減少高溫油炸與過度烘烤食物，防止 AGEs 與 RAGE 受體結合加重肺泡基底膜硬化。
- **微量斷食與細胞自噬活化（Time-Restricted Eating, 14:10 至 16:8）**：
  - **目標**：促進溶酶體對細胞內受損蛋白及失能粒線體（Mitophagy）的清除，緩解第 II 型肺泡細胞的內質網壓力（ER Stress）。

### 3. 環境毒素阻斷、排毒管道與腸-肺軸（Gut-Lung Axis）支持
- **絕對阻斷暴露源**：
  - **戒菸與遠離二手菸/三手菸**：吸菸為 IPF、RB-ILD、DIP 的絕對危險與加重因子。
  - **居家環境黴菌與抗原排查**：清除環境中羽毛被褥、鳥類排泄物、真菌孢子，降低外源性過敏性肺炎（HP）風險。
  - **空氣淨化**：使用醫療級 HEPA 與活性碳濾網，阻絕 PM2.5 與揮發性有機化合物（VOCs）。
- **嚴密防堵「微量胃酸反流（Microaspiration）」**：
  - **臨床要點**：全身性硬化症（SSc）及多數 ILD 患者常伴隨無症狀的食道蠕動障礙；反流酸性液體吸入肺部是驅動進行性纖維化的隱形推手。
  - **介入**：睡前 3 小時禁食、抬高床頭、評估消化酶與胃酸功能，必要時配合消化道修復營養素（如 L-麩醯胺酸、鋅肌肽、榆樹皮粉）。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **早期肺部聽診「魔鬼氈囉音（Velcro Crackles）」與指甲評估**：
   - 凡年齡 >60 歲、有吸菸史、不明原因慢性乾咳或活動性氣促患者，雙側肺底吸氣末細濕囉音與杵狀指（Clubbing）是 IPF 的極早期警訊，切勿單純視為支氣管炎或老化氣喘。
2. **高危險群第一線影像務必選用「胸部高解析度 CT（HRCT）」**：
   - 一般胸部 X 光（CXR）易漏診早期病灶。HRCT 是目前非侵入性確立 UIP 模式的黃金標準，若影像符合典型 UIP，在適當臨床背景下可免除高風險的開胸或胸腔鏡肺切片（VATS）。
3. **精準區分「發炎型」與「純纖維化型」，切忌濫用類固醇**：
   - 若為 IPF（UIP 表現），**禁用高劑量類固醇合併免疫抑制劑**，應及早轉介評估抗纖維化藥物（Pirfenidone / Nintedanib）；若為自體免疫 CTD-ILD、COP 或細胞型 NSIP，則應以積極免疫調節控制發炎源頭。
4. **全方位落實「抗反流」與「環境肺毒素阻絕」**：
   - 常規詢問胃食道反流與夜間嗆咳史，尤其在硬皮症與進行性纖維化患者中，積極管理胃反流並完全戒除菸害、排查環境過敏原，是減緩肺功能（FVC）斷崖式惡化的關鍵生活型態處方。
