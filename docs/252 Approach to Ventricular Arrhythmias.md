# 心室心律不整之臨床全方位評估與處置策略（Approach to Ventricular Arrhythmias）
- **主講人/來源**：William H. Sauer, Usha B. Tedrow / *Harrison's Principles of Internal Medicine*, 21e (252 Approach to Ventricular Arrhythmias.pdf)
- **核心主旨**：精準鑑別心室心律不整（良性特發性 vs. 惡性器質性病變），透過心電圖解剖定位與結構性心臟影像鎖定致律病灶，並權衡抗心律不整藥物的致心律不整風險與器官毒性，以確立植入式心臟去顫器（ICD）與導管消融的最佳介入時機。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **觸發性與異常自律性（Focal Triggered Activity / Automaticity）**：常源於心肌細胞或浦肯野纖維（Purkinje cells），心電圖多表現為特發性、起源於右心室流出道（RVOT）或間隔區之單形性病灶，常受交感神經刺激與兒茶酚胺濃度驅動。
  - **折返迴路（Reentrant Circuits）**：常奠基於陳舊性心肌梗塞後疤痕（Scar tissue）、心肌病變引發之間質纖維化，或病態浦肯野傳導系統。慢速傳導通道（Slow conduction zone）與傳導阻滯共同構成維持室性心搏過速（VT）的電生理解剖基質。
- **演講亮點與臨床洞察**：
  - **單一導聯定位價值**：V1 導聯形態（LBBB 形態提示右室或間隔起源；RBBB 形態提示左室起源）合併額面電軸（下壁導聯 II/III/aVF 為 R 峰提示上側/流出道起源；呈深 S 波提示下壁起源），為無創電生理定位的核心。
  - **抗心律不整藥物的雙面刃（Proarrhythmia）**：多數抗心律不整藥物具負性肌力與致心律不整潛能（如 Class I 藥物增加心梗後死亡率；Class III 藥物延長 QT 間期誘發 Torsades de Pointes），治療策略應以安全性為第一考量（β-受體阻斷劑為首選基石）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（文獻與臨床常模） |
| :--- | :--- | :--- |
| **12 導聯心電圖 (12-Lead ECG)** | 鑑別 QRS 寬度（>0.12 s）、電軸、LBBB/RBBB 形態、QTc 間期及病理性 Q 波 | 正常竇性心律；QTc 男 <450 ms，女 <460 ms；無異常 J 波或 Brugada 波 |
| **高解析心臟核磁共振 (CMR + LGE)** | 評估心室收縮功能，並利用延遲釓增強（LGE）精確定位心肌纖維化/心內膜下疤痕通道 | 無心肌疤痕（LGE 陰性）；LVEF > 50% |
| **血清電解質（K⁺ / Mg²⁺）** | 評估心肌跨膜電位穩定度，低鉀、低鎂為誘發 Polymorphic VT (TdP) 之關鍵推手 | 血清 K⁺ 維持於 4.0–4.5 mEq/L；Mg²⁺ ≥ 2.0 mg/dL |
| **甲狀腺功能 (TSH / Free T4)** | 排除甲狀腺毒症誘發之交感亢進，並作為 Amiodarone 治療前後之長期器官毒性監測 | TSH: 1.0–2.5 μIU/mL (功能醫學理想範圍)；避免 Amiodarone 引發之甲狀腺功能異常 |
| **肝、肺功能監測 (LFTs, DLCO/CXR)** | 評估 Amiodarone 長期使用引發之肺間質纖維化（發生率約 1%）與肝毒性 | 肺瀰散功能（DLCO）維持 baseline；AST/ALT 維持於正常上限 2 倍以內 |
| **高敏感度 C 反應蛋白 (hs-CRP)** | 評估血管與心肌微環境之慢性發炎狀態，慢性全身性發炎為心肌結構重塑與心律不整的促發因子 | < 1.0 mg/L |

## 三、 關鍵機制詳解與投影片重點筆記

- **心室心律不整之電生理分類與心電圖判讀法則（圖 252-1, 252-2, 252-4）**：
  - **早搏頻率與形態**：單源性（Unifocal PVCs）展現相同 QRS 波形，二聯律（Bigeminy）常因心臟充盈不足致使橈動脈搏動減弱，產生臨床「偽慢脈（Pseudobradycardia）」；多源性（Multifocal PVCs）則提示心肌瀰漫性受損或多處異位激發灶。
  - **解剖源頭辨識（Figure 252-4）**：
    - *V1 呈 LBBB 形態*：右心室（RV）或室間隔起源（如常見的良性 RVOT 室速）。
    - *V1 呈 RBBB 形態*：左心室（LV）游離壁起源。
    - *額面電軸判定*：II、III、aVF 出現主波向下之深 S 波（Superior axis），提示心室下壁/底部起源；若為高聳 R 波（Inferior axis），則提示起源於基底心室流出道（Cranial portion）。
  - **VT 分類**：非持續性（NSVT，發作 <30 秒且自行終止）與持續性（Sustained VT，>30 秒或合併血流動力學不穩定需電擊/藥物介入）。

- **惡性致死性心律不整的轉機與特殊圖形（圖 252-3）**：
  - **竇狀心室速（Sinusoidal VT / Ventricular Flutter）**：QRS 與 T 波融合呈正弦曲線。極快速者為心室撲動；慢速且極度寬大者，高度警示**嚴重高血鉀症（Hyperkalemia）**、**鈉離子通道阻斷劑過量（如 Flecainide、TCA 類三環抗憂鬱藥中毒）**或**全心大範圍嚴重缺血**。
  - **尖端扭轉型室速（Torsades de Pointes, TdP）**：多形性 VT，QRS 振幅呈波浪狀蠟燭燃燒式變化（Waxing and waning），常由先天或後天 QTc 延長所觸發。
  - **心室顫動（VF）**：無離散 QRS 波之混亂電活動，最常見的基礎病因為**急性冠狀動脈缺血**。

- **藥理學評估與現代裝置療法（圖 252-5, 252-6）**：
  - **Class I 鈉離子阻斷劑**：抑壓傳導速度使 QRS 增寬，由於具負性肌力與潛在促心律不整作用，心肌梗塞後或結構性心臟病患者應**嚴格禁用**。
  - **Class III 鉀離子阻斷劑（Sotalol, Dofetilide）**：阻斷 $I_{Kr}$ 延長動作電位時程，有 3–5% 機率誘發 TdP；且經由腎臟排泄，腎功能不全者需劑量調整或禁用。
  - **Amiodarone**：多重離子阻斷效果，為壓制室性心律不整最強效藥物，但長期毒性極高（甲狀腺亢進/低下、肺毒性、肝毒性、周邊神經病變）。
  - **ICD 與導管消融策略**：
    - 經靜脈 ICD 提供**抗心動過速起搏（ATP，以超越起搏終止折返 VT）**與高能電擊；皮下 ICD（S-ICD）避免血管閉塞風險，但無法提供抗緩脈起搏與 ATP。
    - 3D 電解剖標測系統（Electroanatomic Mapping，如 CARTO）：能辨識疤痕低電位區（<0.5 mV），以射頻消融精準阻斷疤痕內慢傳導通道（Figure 252-5）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **功能性營養素/植化素補充（心肌細胞電位穩定基質支持）**：
  - **鎂離子複合物（Magnesium Glycinate / Taurate）**：建議每日元素鎂 300–400 mg。牛磺酸（Taurine）具有心肌保護與鈉/鈣動態平衡調節特性，協同甘胺酸穩定心肌細胞膜電位，降低早期後除極（EAD）觸發之 PVCs。
  - **高純度 Omega-3 脂肪酸 (EPA/DHA)**：建議每日 2–3 g (高純度 TG 型式)。調節心肌細胞膜流動性，直接調控 L 型鈣通道與心肌鈉通道，提高心室顫動之閾值（嚴重心律不整患者宜由醫師追蹤）。
  - **輔酶 Q10（Ubiquinol）**：每日 100–200 mg，修復受損心肌線粒體電子傳遞鏈，降低氧化壓力誘發之電不穩定性與纖維化信號。

- **代謝、飲食與生活型態策略**：
  - **自律神經張力重置**：迷走神經張力不足與交感過度活化是 VT 的主要驅動因子。導入**4-7-8 腹式共振呼吸法**或**心率變異度（HRV）生物反饋訓練**，以降低中樞交感輸出。
  - **戒除外源性激發物**：嚴格限制咖啡因過量攝入、含麻黃素類感冒藥、能量飲料及酒精；戒除尼古丁以阻斷心肌異位節律點的直接觸發。
  - **間質抗炎飲食（Anti-inflammatory Diet）**：以地中海原型食物為基底，降低高升糖食物造成的胰島素阻抗與內皮發炎，阻斷由慢性低度發炎所推進的心肌間質纖維化重塑。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **危險分層與警訊症狀辨識**：若患者主訴為「運動中心悸/暈厥（Syncope）」或「無前兆突發性暈厥」，高度懷疑血流動力學不穩之持續性 VT，應立即安排心電監護與轉診住院評估，切勿僅當作一般自律神經失調。
2. **基線影像檢測排除器質性心臟病**：初次發現 PVCs 或 VT 患者，必須常規進行**經胸心臟超音波（TTE）**，評估射血分數（LVEF）與瓣膜狀況；若疑似結構異常或心肌炎，應進一步安排**心臟核磁共振（CMR-LGE）**排除心肌疤痕基質。
3. **電解質嚴密監控與校正**：常規篩檢血清鉀與鎂。對於服用 QT 延長藥物、利尿劑或具有心律不整病史者，維持鉀離子 $\ge$ 4.0 mEq/L 及充足血鎂是臨床防範 TdP 最經濟且高效的保護手段。
4. **長期藥物毒性監控清單**：長期服用 Amiodarone 之病患，必須建立每 6 個月追蹤甲狀腺功能（TSH/FT4）與肝功能、每年接受胸部 X 光檢查或肺功能評估的嚴謹機制，確保早期發現無症狀性肺纖維化。
