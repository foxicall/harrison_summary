# 心血管系統身體檢查與血流動力學臨床精要（Physical Examination of the Cardiovascular System）
- **主講人/來源**：Patrick T. O'Gara, Joseph Loscalzo / *Harrison's Principles of Internal Medicine (HPIM)* 專題講義（239 Physical Examination of the Cardiovascular System.pdf）
- **核心主旨**：透過精準的床邊理學檢查（外觀病徵、頸靜脈波形、動脈脈搏、心音動態聽診）即時評估心血管容量負荷、瓣膜結構障礙與血流動力學異常，建立高預測價值的臨床前測機率，減少非必要過度影像檢查，並早期阻斷心血管老化與病變進程。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **血管硬化與動脈脈衝波反射異常**：老化、慢性高血壓及廣泛性動脈粥狀硬化導致外周血管阻力增加與順應性下降，使收縮壓上升、舒張壓降低，破壞冠狀動脈灌注，誘發左心室後負荷增加與心室重塑。
  - **心室順應性下降與舒張功能障礙**：慢性壓力超載或心肌缺血導致心室纖維化與僵硬度上升，使心室充盈依賴更強烈的心房收縮（心房充盈波 $S_4$ 與頸靜脈巨大 $a$ 波）。
  - **容量超載與靜脈高壓反饋**：右心衰竭、三尖瓣反流或心包縮窄導致中心靜脈壓（CVP）異常升高，破壞外周微循環回流，造成肝脾淤血、腹水及下肢間質水腫。
  - **CHIP（意義未明的自發性造血純系擴增）與代謝性促發炎態**：文獻指出 CHIP 患者發生冠狀動脈心臟病（CHD）的風險激增至 2 倍，凸顯全身性低度發炎在心血管退化中的關鍵驅動角色。
- **演講亮點與臨床洞察**：
  - **床邊技能式微與過度依賴影像的臨床困境**：臨床醫師僅少數能精準辨識經典心臟物理表徵，導致低發病前測機率下非侵入性影像檢查過度濫用；精準理學檢查是醫病信賴與精準診斷的第一基石。
  - **頸靜脈壓（JVP）是評估容量狀態的黃金標準**：床邊預測右心房壓（RAP）$>10\text{ mmHg}$ 對預測肺動脈楔壓（PAWP）$>22\text{ mmHg}$ 的陽性預測值高達 $88\%$；JVP 升高是心衰竭住院與死亡的獨立預後指標。
  - **動態聽診（Dynamic Auscultation）的鑑別威力**：利用 Valsalva、蹲下/起立、心室早期收縮後心搏（Post-VPB beat），可精準區分肥厚型阻塞性心肌病變（HOCM）、主動脈瓣狹窄（AS）與二尖瓣反流（MR）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（文本記載） |
| :--- | :--- | :--- |
| **頸靜脈壓（JVP / CVP）** | 評估右心充盈壓、全身容量負荷與預測肺動脈楔壓（PAWP）。 | 半臥 $30^\circ$ 時頂端距胸骨角（Angle of Louis）$>4.5\text{ cm}$ 屬異常；坐姿時搏動高於鎖骨（距離右心房 $\ge 10\text{ cm}$）為明確升高。 |
| **腹頸靜脈反流試驗（Abdominojugular Reflux）** | 評估靜脈順應性與容量超載；預測 PAWP $>15\text{ mmHg}$。 | 右上腹加壓 $>15\text{ s}$，頸靜脈壓持續升高 $>3\text{ cm}$ 為陽性（壓迫 $10\text{ s}$ 後讀取）。 |
| **奇脈（Pulsus Paradoxus）** | 偵測心室互相依賴性（Interventricular dependence）、心包填塞、張力性氣胸或嚴重 COPD。 | 吸氣時收縮壓下降 $>10\text{ mmHg}$ 屬異常；$>12\text{ mmHg}$ 診斷心包填塞之敏感度 $98\%$、特異度 $83\%$（LR+ 5.9）；$>15\text{ mmHg}$ 可直接觸診橈/股動脈感測。 |
| **姿位性低血壓（Orthostatic Hypotension）** | 評估自律神經調節功能、脫水、血管神經張力與跌倒風險。 | 由臥位轉為立位 3 分鐘內：收縮壓下降 $>20\text{ mmHg}$ 或舒張壓下降 $>10\text{ mmHg}$（缺乏代償性心搏加速提示自主神經功能不全）。 |
| **踝肱動脈指數（ABI）** | 下肢周邊動脈疾病（PAD）篩檢與長期心血管死亡率強烈預測指標。 | 兩側足背動脈/後脛動脈收縮壓較低者 $\div$ 兩側肱動脈收縮壓較高者。正常比值通常介於 $0.90\sim 1.30$；嚴重鈣化或主動脈瓣重度反流可致腿臂壓差異常放大。 |
| **指趾血氧差（Pulse Oximetry Difference）** | 周邊組織微循環缺血與 PAD 床邊非侵入快篩。 | 手指與腳趾末梢血氧飽和度差異 $>2\%$ 提示下肢動脈顯著阻塞。 |
| **雙側臂間血壓差** | 評估主動脈剝離、鎖骨下動脈狹窄或主動脈縮窄。 | 兩臂收縮壓差應 $<10\text{ mmHg}$；差值 $>10\text{ mmHg}$ 具高度血管病變警訊。 |
| **腰圍與腰臀比（WHR）** | 內臟脂肪累積、胰島素阻抗及長期心血管代謝風險評估。 | 常規測量身高體重並計算 BMI、體表面積（BSA）與腰臀比以預測代謝風險。 |
| **外周代謝性沉積體徵** | 早期家族性高膽固醇血症、高三酸甘油酯血症與過早動脈粥狀硬化。 | 結節性/肌腱黃色瘤（Extensor xanthomas）、掌紋黃斑（Type III 高脂蛋白血症特異標記）、發疹性黃色瘤與視網膜脂血症（極高 TG）。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 頸靜脈波形（JVP Waveform）與心臟血流動力學映射
- **各波形生化與機械對應機轉**：
  - **$a$ 波**：代表心房收縮期（Presystolic contraction），對應心電圖 $P$ 波之後、第一心音（$S_1$）之前。當右心室順應性降低（如肺高壓、肺動脈瓣狹窄）時會形成巨大 $a$ 波；若心房收縮遇上三尖瓣關閉（房室分離，如心室頻脈 VT），則產生巨大的**砲聲波（Cannon $a$ wave）**；心房顫動（AF）時 $a$ 波完全消失。
  - **$x$ 下降**：心房舒張、心房壓力下降所致。中途被三尖瓣被心室收縮推向右心房所形成的 **$c$ 波** 打斷。
  - **$v$ 波**：心室收縮期間，血液持續回流進入右心房的充盈波。若有**三尖瓣反流（TR）**，反流血流使 $v$ 波提早並劇烈放大，與 $c$ 波融合形成「心室化（Ventricularization）」波形。
  - **$y$ 下降**：三尖瓣打開、心室早期快速充盈時右心房壓的驟降。**心包縮窄（Constrictive Pericarditis）**會表現為深且陡峭的 $y$ 下降（伴隨 Pericardial knock）；而心包填塞（Tamponade）或三尖瓣狹窄時 $y$ 下降則被阻鈍或延長。
- **Kussmaul's Sign**：吸氣時 JVP 不降反升（正常吸氣時胸內負壓應使 JVP 下降至少 $3\text{ mmHg}$）。見於心包縮窄、限制型心肌病變、右室心肌梗塞及嚴重右心衰竭。

### 2. 動脈脈搏型態（Arterial Pulse Contours）及其病理映射
```
  [遲緩脈 Pulsus Parvus et Tardus]      [水錘脈 Corrigan's Pulse]        [雙峰脈 Bisferiens Pulse]
        / \ (緩慢上升、低振幅)                  /\ (陡升驟降)                    / \  / \ (收縮期雙峰)
       /   \                                   /  \                            /   \/   \
  Aortic Stenosis (AS)                  Aortic Regurgitation (AR)         HOCM / Severe AR
```
- **遲緩脈（Pulsus Parvus et Tardus）**：上升慢、振幅低，有時伴隨震顫（Anacrotic pulse / thrill），為重度主動脈瓣狹窄（Severe AS）的特異標誌。
- **水錘脈（Corrigan's / Water-Hammer Pulse）**：上升極快且快速塌陷，反映主動脈瓣重度反流（AR）造成舒張期大量血液逆流（Run-off）、脈壓極寬。
- **雙峰脈（Bisferiens Pulse）**：一次收縮期內觸及兩個收縮峰（Percussion wave 與 Tidal wave），見於肥厚型阻塞性心肌病變（HOCM）或重度 AR。
- **交替脈（Pulsus Alternans）**：心律規則下，脈搏振幅強弱交替出現。機轉為細胞內鈣離子循環（Intracellular Calcium cycling）異常與動作電位時程波動，代表嚴重左心室收縮功能衰竭；若合併心電圖 T 波交替，心律不整猝死風險劇增。

### 3. 心音（Heart Sounds）時序與分裂機制
- **第一心音（$S_1$）**：二尖瓣與三尖瓣關閉。早期二尖瓣狹窄（MS）、高心輸出量、短 PR 間期時 $S_1$ 亢進；瓣膜嚴重鈣化僵硬、長 PR、左心收縮不良或使用 $\beta$-blocker 後 $S_1$ 減弱。
- **第二心音（$S_2$）分裂現象**：
  - **生理性分裂**：吸氣時胸腔負壓增加右心回血，肺動脈瓣延遲關閉（$A_2-P_2$ 間距在吸氣時拉大，吐氣時縮小）。
  - **固定性分裂（Fixed Splitting）**：不隨呼吸週期改變，是**心房中膈缺損（ASD）**的經典標誌。
  - **奇異性/逆行性分裂（Reversed/Paradoxical Splitting）**：主動脈瓣關閉延遲（見於左束支傳導阻滯 LBBB、嚴重 AS、HOCM），導致吐氣時分裂拉大、吸氣時因 $P_2$ 延後反而重疊閉合。
- **第三心音（$S_3$） vs 第四心音（$S_4$）**：
  - **$S_3$**：發生於舒張早期快速充盈期，在老年人代表左心容量過載與心衰竭（不論 HFrEF 或 HFpEF 皆可能出現），與心血管高死亡率高度相關。
  - **$S_4$**：發生於舒張晚期心房收縮充盈期，反映心室僵硬、順應性降低（心室肥厚、缺血），心房顫動（AF）患者必定無 $S_4$。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

從血管衰老逆轉、微循環灌注改善與心血管代謝修復視角整合文本與功能醫學：

- **功能性營養素 / 標靶分子處方**：
  - **血管內皮一氧化氮（NO）與血管順應性支持**：針對動脈彈性降低與高後負荷，補充左旋精胺酸（L-Arginine）與左旋瓜胺酸（L-Citrulline），協同高活性葉酸（5-MTHF）避免 eNOS 解偶聯（uncoupling）。
  - **粒線體能量與心肌保護代謝底質**：心肌肥厚與衰竭患者心肌細胞能量代謝失衡，處方輔酶 Q10（Ubiquinol 100–300 mg/day）、D-核糖（D-Ribose 5–15 g/day）與肉鹼（L-Carnitine），提升心肌舒張期能量需求（鈣離子再回收進肌漿網需大量 ATP）。
  - **內皮抗發炎與抗動脈粥狀硬化**：針對 CHIP 相關發炎驅動與脂質沉積，補充足量 Omega-3 脂肪酸（EPA/DHA 2–4 g/day 降低高 TG）、薑黃素（Curcumin）及反式白藜蘆醇（Resveratrol），下調全身慢性血管炎性訊號。
  - **心肌細胞內鈣平衡微量元素**：規律補充甘胺酸鎂（Magnesium Glycinate 300–500 mg/day）與牛磺酸（Taurine），抑制過度血管痙攣、維持細胞膜電位穩定並緩解 Pulsus alternans 潛在的鈣離子循環缺陷。
- **生活型態與心血管重塑策略**：
  - **群體與個體化預防處方（Polypill 概念之生活型態轉化）**：文本提及阿斯匹靈、Statin 與降壓藥之複方概念；在功能醫學層次，倡導天然抗血小板（高劑量純化 EPA）、天然降脂（紅麴 Monacolin K / 柑橘生物類黃酮）與內皮保護飲食。
  - **心臟自主神經張力訓練**：針對姿位性低血壓及心搏調控失常，導入心率變異度（HRV）生物反饋呼吸訓練（6 次/分鐘深長共振呼吸），激發迷走神經張力，調節過度活化的交感神經。
  - **外周微循環水壓療法（Hydrotherapy / Contrast Shower）**：對周邊靜脈回流不全及無顯著心衰竭者，冷熱交替水療能促使末梢毛細血管反覆收縮與舒張，強化血管平滑肌收縮彈性。
  - **精準抗阻力與間歇運動（Cardiovascular Conditioning）**：避免長時間過度高強度等長收縮（Isometric，如搬重物引發劇烈後負荷暴增），改採適度阻力與第二區間有氧訓練（Zone 2 Training），擴增粒線體容量並軟化中央大動脈。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實精確血壓量測標準化流程**：
   - 確保壓脈帶氣囊長度達手臂圍的 $80\%$、寬度達 $40\%$（過小壓脈帶會假性高估血壓）。
   - 雙臂必測，差值 $>10\text{ mmHg}$ 應立即排查鎖骨下動脈狹窄與主動脈剝離；下肢壓差過大需評估重度 AR 或動脈鈣化。
2. **常態性納入體位生命徵象與 JVP 評估**：
   - 懷疑體液蓄積或衰竭者，必查坐姿鎖骨上方靜脈搏動與腹頸靜脈反流試驗（持續按壓右上腹 15 秒）。
   - 眩暈與老年衰弱患者，必測臥立位 3 分鐘血壓與心率，鑑別自律神經病變或脫水。
3. **運用動態聽診精準分流心臟雜音**：
   - 收縮期雜音遇上長週期（Post-VPB 或房顫長週期）心搏：強度**增加**高度指向**主動脈瓣狹窄（AS）**或 **HOCM**；強度**恆定不變**則指向**二尖瓣反流（MR）**。
   - 站立/Valsalva 雜音**變大**、下蹲**變小**者，鎖定 **HOCM** 與 **MVP**，切勿盲目給予強效利尿劑或後負荷增加劑。
4. **周邊血管與全身微循環快速篩檢**：
   - 視診常規檢視眼底微血管（Hollenhorst plaque）、指甲床（Splinter hemorrhages）、掌紋與肌腱（黃色瘤）。
   - 結合指趾血氧儀測定差值（$>2\%$）與 ABI，早期篩檢無症狀下肢周邊動脈硬化，及早介入抗衰老血管處方。
