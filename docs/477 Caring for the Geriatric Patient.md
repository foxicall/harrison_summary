# 高齡醫學照護與長壽生物學臨床實踐指引 (Caring for the Geriatric Patient & Biology of Aging)
- **主講人/來源**：Harrison's Principles of Internal Medicine (HPIM 21e), Chapter 477, Joseph G. Ouslander & Bernardo Reyes.
- **核心主旨**：老化非疾病，而是「生理儲備遞減（Homeostenosis）」的動態歷程；臨床照護核心應從傳統「單一疾病治癒」轉型為以人為本的「5M's 架構」，結合抗老生物學（毒物興奮效應、營養感應路徑）與功能性評估，藉由減藥（Deprescribing）、預防衰弱及優化生活品質來實現健康餘命（Healthspan）的最大化。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **細胞與分子層次**：粒線體功能障礙、端粒縮短、氧化壓力與 DNA 損傷累積、幹細胞耗竭、發炎反應（Inflammaging）以及內皮一氧化氮（NO）生成降低。
  - **系統儲備衰退（Homeostenosis）**：正常老化不會直接引起急性症狀，但會顯著削弱各器官系統的代償儲備。當面臨外在微小壓力源（如感染、新藥物導入、水份不足）時，極易崩解並引發骨牌效應（如急性譫妄、跌倒、衰弱）。
  - **衰弱惡性循環（Frailty Cycle）**：能量代謝不平衡結合肌少症（Sarcopenia），導致生理儲備與功能呈非線性崩跌。

- **演講亮點與臨床洞察**：
  - **Paradigm Shift（典範轉移）**：從「疾病驅動模式（Disease-driven）」全面轉向「以人為本（Person-centered）」的 **5M's 架構**（Mentation 心智、Medication 藥物、Mobility 活動力、Multicomplexity 多重複雜性、Matters Most 最在乎的事）。
  - **Choosing Wisely（明智選擇反思）**：
    - 嚴禁於重度失智症末期常規置入經皮胃造瘻管（PEG），應採口服輔助進食。
    - 避免為了追求嚴格血糖（如 HbA1c < 7.5%）而對高齡多病患者過度用藥，低血糖風險遠大於高血糖帶來的微血管獲益。
    - 鎮靜安眠藥（Benzodiazepines）與第一代抗精神病藥切忌作為高齡譫妄或失眠的第一線選擇。
  - **毒物興奮效應（Hormesis）與營養感應**：適度的間歇性壓力（如短暫氧化壓力、熱休克、熱量限制 CR、間歇性禁食 IF）可活化細胞自噬與抗逆轉錄因子（哺乳類的 NRF2、FOXO），是延緩退化的核心長壽機轉。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 評估工具 | 臨床意義與評估目標 | 理想 / 關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **Fried 衰弱表型 (Frailty Phenotype)** | 評估非刻意體重減輕、肌力低、疲憊、步速慢、活動量低 | 符合 $\ge 3$ 項定義為衰弱（Frailty）；1~2 項為衰弱前期（Pre-frail） |
| **糖化血色素 (HbA1c)** | 避免嚴格控制帶來的致死性低血糖與認知損害 | 多病/功能受損長者：寬鬆設定於 **<7.5% ~ 8.0%**；僅在極健康無共病者維持 <7.5% |
| **立姿生命徵象 (Postural Vital Signs)** | 評估自主神經病變、低血容量與姿勢性低血壓（跌倒主因） | 站立 1~3 分鐘後，收縮壓下降 $\ge 20\text{ mmHg}$ 或舒張壓下降 $\ge 10\text{ mmHg}$ 為異常 |
| **收縮壓 (SBP) 臨床目標** | 預防中風與心血管事件 vs 預防低血壓誘發跌倒與腎損傷 | 健康無跌倒風險者目標 **<130 mmHg**；共病多、跌倒高風險、糖尿病者宜維持 **<150 mmHg** |
| **肌酸酐清除率 (CrCl, Cockcroft-Gault)** | 評估腎臟排泄功能以調整藥物劑量（避免高估腎功能） | 嚴格依年齡、體重校正；GFR < 30 mL/min/1.73m² 時雙胍類（Metformin）禁用或減量 |
| **餘尿量測定 (PVR, Postvoid Residual)** | 鑑別溢出性失禁、排尿障礙及膀胱出口阻塞 | **0~100 mL**：正常；**100~200 mL**：視臨床症狀評估；**>200 mL**：明確異常 |
| **營養不良篩檢 (Weight Loss Screening)** | 篩檢惡病質、蛋白質流失與隱性發炎/惡性腫瘤 | 體重 **< 100 磅 (約 45 kg)** 或 6 個月內非刻意體重減輕 **$\ge 10$ 磅** 需立即介入 |
| **CAM (Confusion Assessment Method)** | 快速篩檢急性譫妄（Delirium），避免誤診為失智惡化 | 需具備：(1)急性發作與起伏病程 + (2)注意力不集中 + (3)思維混亂 或 (4)意識狀態改變 |
| **Mini-Cog (3項回憶 + 畫鐘測驗)** | 基層診所快速評估輕度認知障礙（MCI）與失智症 | 快速篩檢工具；若異常應進一步進行 MoCA 或神經心理學檢測 |
| **貧血專項檢驗 (CBC, Ferritin, Reticulocyte)** | 鑑別缺鐵性貧血與慢性疾病貧血（高齡貧血絕非正常老化） | 血色素異常即需檢查；高齡合併心臟病/缺血症狀者輸血閥值提高至 **Hb < 8~9 g/dL** |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 抗老生物學與毒物興奮效應（Hormesis & Nutrient-Sensing Pathways）
- **細胞彈性與保護機轉**：
  - 酵母菌與線蟲模式顯示，低劑量氧化壓力可誘導體內產生保護性蛋白，抵抗後續致死劑量攻擊。
  - 在人類缺血預適應（Ischemic Preconditioning）中，短暫缺血可減少隨後腦與心臟的心肌梗塞/中風再灌流傷害。
  - **熱量限制（CR）與禁食**：被視為生理性 Hormetic Stress，會關閉營養感應激酶（mTOR/IGF-1），活化 **FOXO** 與 **NRF2** 轉錄因子，誘導超氧化物歧化酶（SOD）、過氧化氫酶及熱休克蛋白（HSPs）合成，強化清除自由基與修復蛋白質的能力。

### 2. 生理儲備耗竭（Homeostenosis）與衰弱表型（Frailty Phenotype）
- **衰弱的立體多維病理學**：
  ```
  [細胞層級: 粒線體衰退 / DNA損傷 / 氧化壓力 / 端粒縮短]
                          ↓
  [生理層級: 慢性低度發炎 / 內皮NO減少 / 肌少症 / 能量代謝失衡]
                          ↓
  [表型展現: 體重銳減 / 步速變慢 / 握力下降 / 極度疲憊 / 活動力匱乏]
  ```
- **臨床表徵**：衰弱長者的 BMI 呈 **U 型分佈**（極度肥胖與極度消瘦者均有高衰弱率）。生理儲備降低使得多器官處於代償邊緣，極易因輕微尿路感染或微量脫水觸發多重器官失代償。

### 3. 高齡專科 5M's 核心架構與處方精簡（Deprescribing）
- **5M's 臨床整合架構**：
  - **Matters Most（最在乎的事）**：以患者意願與功能自主為優先考量，取代常規檢查清單。
  - **Mind/Mentation（心智）**：涵蓋譫妄（Delirium）、失智（Dementia）、憂鬱（Depression）鑑別診斷。
  - **Mobility（活動力）**：維持關節功能、步態平衡、肌力訓練與跌倒防範。
  - **Medication（用藥）**：嚴格依 Beers Criteria 與 STOPP 標準進行處方精簡（Deprescribing）。
  - **Multicomplexity（多重複雜性）**：統合多病共存（Multimorbidity）與社會心理脆弱度。
- **多重用藥（Polypharmacy）與減藥策略**：
  - 65 歲以上長者約 40% 服用 5~9 種藥物，近 20% 服用 $\ge 10$ 種。
  - **首要減藥目標類別**：
    1. **質子幫浦抑制劑（PPI）**：無明確適應症應停用（長期使用增加骨質疏鬆、難辨梭菌感染、肺炎及失智風險）。
    2. **抗精神病藥與苯二氮平類（Benzodiazepines）**：降低中樞神經毒性、步態不穩及跌倒風險。
    3. **具抗膽鹼活性藥物（Anticholinergics）**：阻斷乙醯膽鹼會急遽惡化認知功能，並導致口乾、便秘、尿滯留。
    4. **強效降血糖藥（Sulfonylureas / 胰島素過度使用）**：積極降階以避免致命性低血糖。

### 4. 老年四大核心症候群之生理病理剖析
- **跌倒（Falls）**：
  - 跌倒多為「多因素交互作用」，單純歸咎於「機械性絆倒」常掩蓋潛在病因（如心律不整、主動脈瓣狹窄、餐後/姿勢性低血壓、頸椎病變脊髓壓迫）。
  - 失智症患者半數以上的「不明原因跌倒」實際上源自於低血壓引起的近乎暈厥（Near-syncope）。
- **譫妄（Delirium）**：
  - 屬於**醫療急症**，反映潛在全身性重症（感染、電解質紊亂、低血氧、糞便嵌塞或急性尿滯留）。
  - 治療核心在於「病因排除與環境/非藥物重導向（Reorientation）」，抗精神病藥物（如低劑量 Haloperidol 0.25~0.5 mg）僅限於患者出現嚴重自傷或傷人風險且非藥物介入無效時之短期手段。
- **尿失禁（Urinary Incontinence）**：
  - 分為應力性（骨盆底肌鬆弛）、急迫性（逼尿肌過度反射/OAB）、溢出性（膀胱排空不良/PVR上升）及功能性（活動受限無法及時如廁）。
  - 尿路症狀可直接增加夜間跌倒與髖關節骨折機率，必須常規進行 PVR 檢查以避免盲目使用抗膽鹼藥導致急性尿滯留。
- **睡眠障礙（Sleep Disorders）**：
  - 常見原因包括睡眠呼吸中止症（OSA）、不寧腿症候群（RLS）、週期性肢體抽動（PLMS）及夜尿症。
  - 禁用安眠藥作為反射性治療，應優先執行「睡眠刺激控制療法（Stimulus-Control Therapy）」與「睡眠衛生規則」。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素補充處方
- **維生素 D3（Cholecalciferol）**：
  - **臨床策略**：建議每日補充維持劑量 **800~1000 IU**，維持骨骼肌肉神經穩定。
  - **重要警訊**：嚴格避免單次超高劑量口服衝擊療法（如單次月給藥 60,000 IU），研究證實此法反會**增加長者跌倒與骨折風險**。
- **維生素 E（Alpha-tocopherol）**：
  - 在部分阿茲海默症臨床試驗中，經醫師評估的高劑量抗氧化療法在延緩功能性退化指標上甚至展現優於 NMDA 受體拮抗劑（Memantine）的趨勢（需密切評估心血管出血風險）。
- **維生素 B12 與甲基化支持**：
  - 高齡族群因萎縮性胃炎或長期使用 PPI / Metformin 導致胃酸與內在因子不足，應定期檢測並積極補充甲基鈷胺（Methylcobalamin）以保護認知神經與預防巨球性貧血。
- **高品質蛋白質補充**：
  - 為逆轉肌肉減少症（Sarcopenia）與衰弱，建議每日蛋白質攝取目標調高至 **1.2 ~ 1.5 g/kg 體重**（伴隨嚴重腎功能不全者需個別調整），維持正氮平衡。

### 2. 飲食與生活型態醫學處方
- **退化性關節炎（OA）非 NSAIDs 階梯式疼痛管理**：
  - **第一線**：局部外用 NSAIDs 凝膠、Lidocaine 貼布、物理伸展與關節保護。
  - **口服基礎**：對乙醯氨基酚（Acetaminophen）每日最高不超過 **3~4 g**（監控肝毒性）。
  - **謹慎評估**：嚴格限制口服非選擇性與 COX-2 抑制劑，因其誘發嚴重腸胃道出血、體液滯留惡化心衰竭、以及加重慢性腎衰竭之風險極高。
- **認知退化與失智非藥物神經修復**：
  - **神經可塑性活化**：建立規律社交連結、環境結構化、定向感時鐘/標示、記憶輔具。
  - **照護者減壓與安全管理**：及早啟動駕駛能力評估（如 Trails B 測驗、視力視野檢查），保障公共安全與病患自主權之平衡。
- **失眠之「刺激控制療法（Stimulus-Control）」標準臨床指引**：
  - 只有在真正產生睏意時才上床躺臥。
  - 若躺床超過 20 分鐘無法入睡，**必須離開床與臥室**，至微暗環境進行放鬆活動，直至有睏意再返回。
  - 無論前夜睡眠時間長短，每日固定時間起床；嚴格**限制日間小睡 $\le 30$ 分鐘**，且下午後禁止小睡。
  - 傍晚多至戶外接觸自然光線（抑制不適當時機分泌的褪黑激素，重新校準生理時鐘）。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實診間 5M's 評估與以人為本對話**：
   - 每次看診不以單一器官疾病開立處方為唯一目的，先詢問病患：「在未來的日常生活中，對您而言**最在乎的事（Matters Most）**是什麼？（例如：能自己走去公園、能認得家人、維持生活尊嚴）。」
2. **啟動主動式「除階減藥（Deprescribing）」行動**：
   - 全面盤點患者清單：針對長期使用的 PPI、苯二氮平類安眠藥、長效磺醯尿素類（如 Glyburide，高齡禁用）以及無心血管適應症的多重降血壓藥進行減量或停藥計畫。
3. **建立多維跌倒預防與衰弱阻斷機制**：
   - 診間常規執行「起身步行測驗（Get Up and Go test）」與姿勢性血壓量測。
   - 推薦長者參與太極拳（Tai Chi）或漸進式抗阻力肌力訓練；每日補充維生素 D3 800 IU，嚴禁採用超高劑量衝擊療法。
4. **重塑慢性病目標值（降壓與控糖彈性化）**：
   - 放棄一體適用的數值指引。針對虛弱多病長者，收縮壓維持於 130~150 mmHg 區間，HbA1c 容許於 7.5%~8.0%，杜絕醫源性低血壓及低血糖休克。
5. **預立安寧緩和與醫療自主決策（Advance Care Planning）**：
   - 及早與重度失智症及末期器官衰竭病患家屬討論醫療意願（如 POLST），明確認知機構住民急救（CPR）之極低存活率與潛在創傷，堅決拒絕於末期失智階段置入常規鼻胃管/胃造瘻管，保障長者生命末期的舒適與尊嚴。
