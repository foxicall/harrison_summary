# 念珠菌感染症（Candidiasis）臨床病理機制、新興抗藥性威脅與全人整合防治策略
- **主講人/來源**：216 Candidiasis.pdf（節選自《哈里遜內科學》*Harrison's Principles of Internal Medicine*, 第 216 章；作者：Michail S. Lionakis, Shakti Singh, Ashraf S. Ibrahim, John E. Edwards, Jr.）
- **核心主旨**：深入剖析念珠菌從人體正常共生菌轉化為伺機性致病原的病理生理機制（腸道微生態失衡、黏膜屏障破損與免疫防禦缺陷），並針對新興多重抗藥性「超級真菌」*Candida auris* 提供跨領域的早期精準診斷、抗真菌藥物選擇與整體臨床處置方針。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **微生態失衡與屏障破壞**：念珠菌廣泛共生於人體胃腸道、口咽部、女性生殖道及皮膚。抗生素濫用會大幅消滅共生細菌叢，使真菌異常繁衍；當腸道黏膜或皮膚屏障受損（或留置中心靜脈導管）時，念珠菌藉由分泌黏附素（Adhesins）與黏膜毒素（Candidalysin），引發由酵母態（Blastospore）向假菌絲/真菌絲的侵襲性轉型（註：*C. glabrata* 與 *C. auris* 雖不形成真菌絲，但仍具高度致病力），進而突破基底穿入血管，引發血行性播散（Hematogenous dissemination）。
  - **宿主免疫分工缺失**：宿主對抗念珠菌具明確的「分區免疫」機制。**黏膜免疫**高度仰賴 **$\text{T}_\text{H}17$ 淋巴細胞**分泌之 IL-17 及 IL-22，若訊號傳導異常（如 Dectin-1、CARD9、STAT1 或 AIRE 突變）將導致頑固性慢性皮膚黏膜念珠菌病（CMC）；**全身性/深層組織防禦**則完全依賴**嗜中性白血球（Neutrophils）與巨噬細胞**的吞噬氧化殺傷力，嗜中性白血球低下是誘發致死性血行播散感染的最危險因子。
- **演講亮點與臨床洞察**：
  - **菌種流行病學轉變**：抗真菌藥物（特別是三唑類）的普及，導致非白念珠菌（Non-*albicans* species，如 *C. glabrata*, *C. krusei*, *C. tropicalis* 等）佔比攀升至侵襲性感染的 50% 以上，此類菌株對傳統藥物敏感度顯著降低。
  - **超級真菌 *Candida auris* 的全球公衛危機**：具耐高溫（可達 42°C 生長）、耐高鹽（10% NaCl）、極易黏附於塑膠與醫療器械表面並形成生物膜的特質；部分菌株在體內具聚集特性以逃避吞噬，且常對三類主要抗真菌藥物（Azoles、Polyenes、Echinocandins）產生多重抗藥，粗死亡率達 30–60%。
  - **血流感染不可視為「污染」**：血液培養一旦長出念珠菌（Candidemia），絕不可輕忽為無害暫態或導管污染，所有患者均須接受全身性抗真菌治療，且**必須強制進行散瞳眼底鏡檢查**以排除內源性眼內炎（Candida endophthalmitis）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **$(1,3)\text{-}\beta\text{-D-Glucan (BDG)}$** | 真菌細胞壁核心多醣成分，用於評估侵襲性真菌感染；臨床最大價值在於**高陰性預測值（NPV）**。 | **NPV 約達 90%**；陰性結果有助於排除侵襲性血行播散，但陽性需搭配臨床進一步確認。 |
| **溶血離心血液培養（Lysis Centrifugation Blood Culture）** | 提高血液中真菌回收率與檢出敏感度的標準技術，評估是否存在念珠菌血症。 | 血液中「零檢出」；一旦陽性即屬病理性，需即刻啟動抗真菌治療。 |
| **散瞳眼底鏡檢查（Dilated Ophthalmologic Exam）** | 評估視網膜/脈絡膜是否發生血行轉移性肉芽腫或玻璃體炎；是全身深層器官膿瘍的指標。 | **陰性（無病灶）**。若發現脈絡膜視網膜炎（Chorioretinitis），預示合併深層器官膿瘍機率高達 **~90%**。 |
| **MALDI-TOF 質譜儀 / rDNA 定序（ITS / D1–D2）** | 傳統生化常誤判 *C. auris*（常誤植為 *C. haemulonii*），質譜分析與分子定序為精準菌種鑑定的黃金標準。 | 精確鑑定至菌種等級（Species-level）；確認是否為抗藥性菌株（如 *C. auris*）。 |
| **CHROMagar 顯色培養基生化初篩** | 藉由菌落顏色（白、粉、紅、紫等）及 40–42°C 高溫耐受測試，早期篩檢可疑的非白念珠菌與 *C. auris*。 | 觀察特定產色反應；具出芽酵母型態但**無菌絲生長/無發芽管（Germ tubes）**者需高度懷疑 *C. auris*。 |
| **免疫基因標記評估（Dectin-1 / CARD9 / STAT1 / AIRE）** | 評估宿主對真菌的先天性免疫與抗真菌黏膜防禦缺陷，針對復發性黏膜念珠菌病或不明原因真菌腦膜炎。 | 評估是否存在 Dectin-1/CARD9 突變、STAT1 功能增益（GOF）突變或 AIRE 基因缺陷（APECED 症候群）。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 念珠菌的毒力因子、生物膜與型態轉化（Virulence & Dimorphism）
- **雙態性（Dimorphic Switching）**：念珠菌在黏膜表面常呈卵圓形出芽酵母態（4–6 $\mu\text{m}$），一旦微環境變化或組織受損，便轉化為假菌絲（Pseudohyphae）與真菌絲（Hyphae），穿透上皮與血管內皮細胞。
- **黏膜毒素 Candidalysin**：由菌絲生長時分泌的溶細胞肽，直接造成上皮細胞膜孔洞形成與組織壞死，進一步促進菌體深層侵襲。
- **生物膜（Biofilms）形成**：附著於靜脈導管、人工瓣膜、導尿管或人工關節表面，分泌細胞外基質包覆菌群，大幅降低化學消毒劑與抗真菌藥物穿透性，構成抗藥性與長期移生（Colonization）的核心溫床。

```
[廣效抗生素使用 / 黏膜受損 / 留置導管] 
                │
                ▼
      [共生菌叢崩解，念珠菌過度增生]
                │
                ▼
     [酵母態 ➔ 菌絲態轉換 (分泌 Candidalysin)]
                │
                ▼
     [破壞上皮/內皮屏障，侵入微血管]
                │
                ▼
 [念珠菌血症 (Candidemia) ➔ 播散至心、腦、眼、腎形成微膿瘍]
```

### 2. 宿主免疫屏障分工體系：黏膜防禦 vs. 全身性清除
- **黏膜免疫軸線（$\text{T}_\text{H}17$ / IL-17 / IL-22 途徑）**：
  - 樹突細胞與巨噬細胞表面的 **Dectin-1** 辨識念珠菌細胞壁的 $\beta$-glucan，藉由細胞內轉接蛋白 **CARD9** 傳遞訊號，驅動初始 T 細胞分化為 $\text{T}_\text{H}17$ 細胞。
  - $\text{T}_\text{H}17$ 細胞分泌 IL-17 與 IL-22，刺激黏膜上皮合成抗菌肽（Antimicrobial peptides）並強化細胞間緊密連接（Tight junctions）。此途徑基因突變（如 STAT1 突變、AIRE 基因異常引發之 APECED 症候群）會導致慢性皮膚黏膜念珠菌病（CMC），但此類患者因嗜中性白血球功能完好，極少發生深層血行播散。
- **全身性免疫軸線（嗜中性白血球與吞噬作用）**：
  - 一旦念珠菌穿透入血，**嗜中性白血球（Neutrophil）是防禦最關鍵的細胞武器**。白血球發揮吞噬作用、釋放活性氧自由基（ROS）與嗜中性球胞外網狀結構（NETs）清除真菌。
  - 嗜中性白血球低下（Absolute Neutrophil Count 下降）、嚴重燒傷、腹部重大手術、全靜脈營養（TPN）及免疫抑制劑使用，為全身血行播散（Disseminated Candidiasis）的高危險驅動因子。

### 3. 超級真菌 *Candida auris* 的獨特病理學特徵
- **極端環境耐受力**：最適生長溫度可達 42°C，能於 10% 高鹽環境存活；對人體皮膚、鼻腔、耳道及無生命之醫療器械表面（塑膠、金屬）具有異常強大的附著移生能力。
- **多重抗藥性（MDR）機制**：
  - **Azole 類抗藥**：高達 93% 菌株對 Fluconazole 抗藥，主因為 *ERG11* 基因突變（編碼 lanosterol 14-$\alpha$-demethylase）以及藥物外排泵（Efflux pumps）的大量過度表達。
  - **Amphotericin B 抗藥**：約 35% 菌株具抗藥性。
  - **Echinocandin 類抗藥**：約 7% 抗藥（*FKS1* 基因突變）；甚至有 4% 菌株對現存三大類抗真菌藥物均產生全抗藥性（Pan-resistance）。

### 4. 血行播散的靶器官轉移與警訊表徵
- **視網膜/脈絡膜受累（Endophthalmitis）**：血行播散的經典表現，呈現視網膜突向玻璃體的白色絨毛狀炎性滲出物（主要由炎性細胞浸潤構成，圖 216-2）。發生率達 15–20%，可造成不可逆失明；**只要檢出眼底病灶，代表體內深層器官存在膿瘍的機率高達約 90%**。
- **大結節狀皮疹（Macronodular Skin Lesions）**：多見於免疫低下或白血球低下者，呈現廣泛分佈於軀幹與四肢的紅色至紫紅色大結節（圖 216-1），切片鏡檢可見真菌成分，皮下肌肉組織常伴隨壓痛性肌炎。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 全身性抗真菌精準用藥階梯（藥物處方指引）

```
[確診念珠菌血症 / 疑似侵襲性播散]
                 │
                 ▼
[第一線經驗性治療：Echinocandin 靜脈輸注]
 ├── Caspofungin：首劑負荷量 70 mg IV，隨後 50 mg/d
 ├── Micafungin：100 mg/d IV
 └── Anidulafungin：首劑負荷量 200 mg IV，隨後 100 mg/d
                 │
                 ▼
[評估臨床狀態與藥敏試驗結果]
 ├── 情況一：臨床穩定、無深層組織轉移、菌株對 Fluconazole 敏感
 │     └── 降階轉換為：Fluconazole 400 mg/d（口服或靜脈）
 └── 情況二：高度懷疑或確診 C. auris 感染
       └── 維持 Echinocandin；若具抗藥性，換用 Liposomal Amphotericin B (5 mg/kg/d)
```

- **念珠菌眼內炎特殊處置**：
  - 棘白菌素（Echinocandins）在玻璃體內的滲透力極差，**嚴禁單獨使用**。
  - 首選處方：**靜脈 Amphotericin B（脂質體型或去氧膽酸鹽 0.7–1.0 mg/kg/d）聯合 Flucytosine（25 mg/kg qid）**；或選用眼內穿透性佳的新型三唑類（如 Voriconazole）。
  - **玻璃體部分切除術（Partial Vitrectomy）**：病灶擴大或威脅黃斑部時，必須立即由眼科介入清創並行眼內玻璃體藥物注射，防止視網膜纖維化結痂失明。
- **感染源移除（Source Control）**：所有留置之中心靜脈導管（CVC）只要可行，**必須盡速拔除或更換**；人工心臟瓣膜或關節感染，單靠藥物難以根除生物膜，通常需手術清創置換。
- **療程規範**：念珠菌血症患者之標準抗真菌治療時程，必須維持至**最後一次血液培養陰性轉陰後，且全身臨床感染症狀完全緩解後，至少持續 2 週**。

### 2. 黏膜型念珠菌感染的分級處方指引

| 臨床表型 | 首選治療方案（Preferred） | 替代方案（Alternatives） |
| :--- | :--- | :--- |
| **口咽部鵝口瘡（Oral Thrush）** | Clotrimazole 喉片含服 | 局部 Nystatin 懸液、口服 Fluconazole |
| **食道念珠菌病（Esophageal）** | 口服 Fluconazole 錠劑（100–200 mg/d）或 Itraconazole 口服液（200 mg/d） | 靜脈 Caspofungin、Micafungin 或 Amphotericin B |
| **外陰陰道念珠菌病（VVC）** | 單劑口服 Fluconazole 150 mg，或局部 Azole 類軟膏/栓劑 | 局部 Nystatin 栓劑 |
| **皮膚/擦爛紅斑（Intertrigo）** | 局部外用 Azole 類抗真菌藥膏 | 局部外用 Nystatin 軟膏 |

### 3. 微生態修復與感染防護生活策略
- **微生態重塑與抗生素審慎管理（Antibiotic Stewardship）**：嚴格限制不必要的非專一性廣效抗生素使用，避免盲目預防性投藥，保留腸道有益共生厭氧菌群（如雙歧桿菌屬、乳酸桿菌屬），維持腸道定殖抗性（Colonization resistance）。
- **黏膜屏障修復支持**：提供腸道上皮黏膜修復所需的代謝基質（如麩醯胺酸 L-Glutamine、短鏈脂肪酸丁酸鹽丁酸前體），降低促發炎細胞因子對緊密連接蛋白（Claudin, Occludin）的破壞，阻止共生菌轉化為血行侵襲源。
- **新興抗藥菌（*C. auris*）院感阻斷防線**：
  - 手部衛生：雙手無明顯髒污時使用酒精性乾洗手液；有髒污時務必使用肥皂與清水徹底洗淨。
  - 環境消毒：一般四級銨鹽消毒劑對其無效，**必須使用 EPA 註冊、具殺滅困難梭菌芽孢等級（*Clostridioides difficile* spore-killing）的醫院級消毒劑**。
  - 移生不治療原則：CDC 明確建議，**無症狀的皮膚/黏膜 *C. auris* 移生（Colonization）切忌盲目給予全身性抗真菌藥**，以免誘導更廣泛的抗藥性產生；關鍵在於落實接觸隔離與加強型防護屏障。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **血液培養陽性即刻全身治療，嚴禁視為導管污染**：念珠菌血症患者無論有無深層器官受累症狀，皆須接受標準全身性抗真菌治療，首選棘白菌素（Echinocandins），並在可能範圍內拔除留置導管。
2. **所有念珠菌血症患者強制會診眼科排查眼底**：不論患者主訴是否有視力模糊，皆須於散瞳下執行眼底檢查。一旦發現絨毛狀脈絡膜視網膜炎（Chorioretinitis），抗真菌療程須顯著延長，並評估是否需改用高玻璃體穿透性藥物（如 Ampho B + 5-FC / Voriconazole）及玻璃體切除手術。
3. **無症狀尿液與痰液培養陽性通常不需全身治療**：尿導管患者之尿液念珠菌或氣切痰液分離出念珠菌，多屬移生現象。除非患者處於極度重症、合併敗血症或為中性球低下者，否則應先更換管路並停止不必要抗生素，避免抗真菌藥物濫用。
4. **青年/無共病患者發生鵝口瘡，務必篩檢 HIV**：在無長期使用類固醇吸入劑或配戴活動假牙的健康年輕人身上發現口咽念珠菌感染，應將其視為細胞免疫受損的重要警訊，常規安排人類免疫缺乏病毒（HIV）篩檢。
5. **對難治性感染建立 *C. auris* 預警與專用清消機制**：若遇長照機構轉入、帶有中心導管且常規抗真菌治療無效的病患，微生物室應採用 MALDI-TOF 或分子檢驗精確定種；環境清消嚴格採用「抗困難梭菌芽孢」等級消毒劑，徹底阻斷抗藥菌株在醫療場域的水平擴散。
