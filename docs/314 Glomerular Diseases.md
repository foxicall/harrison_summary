# 腎絲球疾病的病理生理演進、臨床分型與整合醫學防護全攻略

- **主講人/來源**：314 Glomerular Diseases.pdf（*Harrison's Principles of Internal Medicine*, 21st Edition, Chapter 314, by Julia B. Lewis & Eric G. Neilson）
- **核心主旨**：腎絲球疾病是由基因易感性、免疫複合體沉積、補體失衡與血流動力學壓力共同驅動的複雜病理過程；臨床預後並非單純取決於原發性腎絲球損傷類型，而是由**蛋白尿介導的下游腎小管間質發炎與纖維化（Tubulointerstitial Fibrosis）**決定，因此整合抗發炎、抑制氧化壓力、改善微循環與調控代謝負載是保存腎功能壽命的關鍵。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  1. **濾過屏障受損與足細胞病變**：腎絲球過濾屏障由「有孔內皮細胞、基底膜（GBM）與足細胞裂隙孔膜（Slit-pore membranes）」構成。足細胞結構蛋白（Nephrin, Podocin）突變、循環穿透因子、APOL1 變異或自體抗體（如抗 PLA2R）攻擊，均會引發足突融合（Foot process effacement）與細胞脫落。
  2. **免疫沉積位點決定病理表現**：
     - **上皮下（Subepithelial）沉積**：如膜性腎病變（MGN）、鏈球菌感染後腎炎（PSGN）的“Humps”，主要引發補體 C5b-9 攻擊與大量非發炎性蛋白尿。
     - **內皮下（Subendothelial）與繫膜區（Mesangial）沉積**：如狼瘡性腎炎（LN）、第一型膜增生性腎小球腎炎（MPGN），易直接接觸血流召喚中性球與單核細胞，引發嚴重血管炎與內皮增生。
  3. **蛋白尿毒性與纖維化終末路徑**：過濾至腎小管的蛋白質攜帶活性細胞因子、促氧化脂蛋白，誘發腎小管上皮細胞產生活性氧（ROS），啟動 TGF-β、FGF-2、PDGF 及 HIF-1α 訊號鏈，驅動上皮-間質轉化（EMT）與成纖維細胞增殖，最終導致不可逆的「無細胞疤痕化（Acellular scar）」與腎功能衰竭。
- **演講亮點與臨床洞察**：
  - **組織間質病變比腎絲球病變更能預測腎衰竭**：組織切片中「腎小管間質萎縮與纖維化程度」，與 GFR 的長期惡化相關性顯著高於腎絲球本身的發炎病灶型態。
  - **腸道-黏膜-腎臟軸（Mucosal-Kidney Axis）在 IgA 腎病變的核心地位**：發病起源於迴腸/黏膜組織分泌異常 O-聚醣基化、鉸鏈區半乳糖缺失的 IgA1（Gd-IgA1），被自體抗體辨識為抗原並沉積於繫膜區引發免疫反應。
  - **非白蛋白尿型糖尿病腎病（Normoalbuminuric DKD）日益增加**：現代臨床多達 24% 的第 1 型與 50% 的第 2 型糖尿病合併慢性腎病變患者尿蛋白正常，突顯出微血管硬化與間質缺血等非典型機制在腎功能退化中的獨立角色。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（基於原文） |
| :--- | :--- | :--- |
| **尿白蛋白排泄率（24-h Albumin）** | 評估初期腎絲球內皮/基底膜電荷屏障破壞與早期高過濾狀態 | 正常：`8–10 mg/24h`；微量白蛋白尿：`30–300 mg/24h`；顯性蛋白尿：`>300 mg/24h` |
| **尿白蛋白/肌酸酐比值（UACR）** | 門診評估腎絲球漏出蛋白及長期心血管事件風險之標準化指標 | 正常：`<30 mg/g`；微量：`30–300 mg/g`；顯性：`>300 mg/g` |
| **24 小時尿蛋白總量（24-h Urine Protein）** | 區分功能性/良性蛋白尿與病理性腎絲球疾病（腎病症候群 vs 腎炎症候群） | 正常：`<150 mg/24h`；腎炎性：`1–2 g/24h`；腎病性：`>3.0–3.5 g/24h` |
| **尿液沉渣顯微鏡鏡檢（Urine Sediment）** | 辨識活動性腎小球發炎；紅血球圓柱體（RBC casts）或異形紅血球為確診 GN 標誌；卵圓脂肪體（Maltese cross）提示大量蛋白尿/脂質沉積 | 正常晨尿：`<3–5 RBCs/HPF`；出現變形紅血球、紅白血球圓柱體即具病理意義 |
| **血清補體（C3, C4, CH50, C3NeF）** | 區分補體消耗路徑（傳統路徑消耗 C3+C4，如狼瘡/低補體血症；替代路徑僅消耗 C3，如 C3 腎小球病、DDD、PSGN） | C3 下降合併 C4 正常提示替代路徑激活；C3NeF(+) 支持 DDD 或 C3GN |
| **專一性自體抗體（Anti-PLA2R / THSD7A）** | 原發性膜性腎病變（IMN）之無創診斷標記，抗體滴度與自發緩解及疾病活性密切平行 | 70% 原發性膜性腎病 anti-PLA2R 陽性；3–10% anti-THSD7A 陽性 |
| **ANCA（PR3-ANCA / MPO-ANCA）** | 評估小血管炎與寡免疫複合體性壞死性腎絲球炎（Pauci-immune GN） | PR3 與肉芽腫併多發性血管炎（GPA）相關；MPO 與微小多發血管炎（MPA）/EGPA 相關 |
| **抗 GBM 抗體（Anti-α3 NC1 Collagen IV）** | 專一性結合第 IV 型膠原蛋白 α3 鏈 NC1 結構域，用以確診 Goodpasture 症候群 | 必須針對 α3 NC1 鏈測定以排除副腫瘤假陽性 |
| **收縮壓與血壓控制標的** | 降低腎絲球內微血管剪切應力、延緩間質硬化與心血管病發風險 | 一般建議降低至 `120–130 / 70–80 mmHg`；心血管高風險族群收縮壓 `<120 mmHg` |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 腎絲球微循環結構與過濾屏障的生化物理學
- **解剖構造特性**：兩顆腎臟包含約 180 萬個腎絲球。入球小動脈進入 Bowman's 囊後分支為微血管網，最後匯流至出球小動脈，構成**動脈門脈系統（Arteriolar Portal System）**。
- **排斥機轉的物理與電荷極限**：
  - 腎絲球每日濾過 120–180 L 血漿水。濾過屏障主要仰賴基底膜（GBM）富含硫酸乙醯肝素（Heparan sulfate）的負電荷層與 4 nm 的濾過孔徑。
  - **白蛋白悖論**：血清白蛋白分子半徑為 3.6 nm 且帶負電，原本會受負電荷排斥，但仍有部分穿透屏障，隨後由近端腎小管的 **巨蛋白（Megalin）與幼蛋白（Cubilin）受體** 回吸收；每日尿液排泄的微量白蛋白約為 8–10 mg。當基底膜電荷喪失或孔膜破裂時，白蛋白漏出大幅增加，超過近曲小管回收極限。

### 2. 腎小球發炎向「腎小管間質纖維化（Tubulointerstitial Fibrosis）」推進的級聯反應
- **間質病變導致 GFR 喪失的假說**：
  1. **管腔物理性阻塞**：發炎碎屑與間質外在壓迫導致小管阻塞，形成「無腎小球的腎元（Aglomerular nephrons）」。
  2. **逆向反饋與血管阻力失衡**：近端腎小管對水與溶質吸收失衡產生等滲尿（Isosthenuria），管-球反饋（Tubuloglomerular feedback）瓦解；發炎浸潤近腎球囊旁器，導致局部腎素-血管張力素調控崩潰。
  3. **微血管受壓缺血**：間質纖維化壓迫直小血管與腎管周微血管，造成腎小管長期缺氧壞死。
- **纖維化細胞來源與分子因子**：
  - 腎臟成纖維細胞主要來自：**在地成纖維細胞增殖（50%）**、**骨髓源性纖維細胞（35%）**與**上皮/內皮-間質轉化（EMT/EndMT, 15%）**。
  - **生化訊號促發**：TGF-β、FGF-2、HIF-1α、PDGF 共同促進細胞外基質、腱生蛋白（Tenascin）及第 I/III 型膠原蛋白交聯沉積。

### 3. 六大臨床症候群及其病理特徵（Harrison 分類核心）
- **急性腎炎症候群（Acute Nephritic Syndrome）**：突發血尿（含變形紅血球與 RBC casts）、輕中度蛋白尿（1–2 g/d）、高血壓、水腫與少尿型急性腎損傷。
- **肺-腎症候群（Pulmonary-Renal Syndrome）**：壞死性新月體腎炎合併危及生命的肺出血（Goodpasture's、ANCA 相關血管炎、SLE、冷凝球蛋白血症）。
- **腎病症候群（Nephrotic Syndrome）**：大量蛋白尿（>3.0–3.5 g/24h）、低白蛋白血症（<30 g/L）、重度水腫、高膽固醇血症與高凝血傾向（抗凝血酶 III 經尿液流失）。
- **基底膜症候群（Basement Membrane Syndromes）**：包括遺傳性 Alport 症候群（α3/α4/α5[IV] 突變引發 GBM 分裂層狀化伴隨聽力受損）與薄基底膜病（TBMD/良性家族性血尿）。
- **腎小球血管症候群（Glomerular-Vascular Syndromes）**：高血壓性腎硬化、動脈粥樣硬化、膽固醇栓塞（雙凸狀裂隙/Biconvex clefts）、血栓性微血管病變（TMA/TTP/HUS，以毛細血管內皮腫脹與血小板血栓為特徵）。
- **感染相關症候群（Infectious Disease–Associated Syndromes）**：全球最常見的腎小球疾病致病原，包含瘧疾、血吸蟲、HIV（造成塌陷型 FSGS 之 HIVAN）、B型與C型肝炎（誘發 MPGN 或膜性腎病變）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素 / 植化素補充方針
- **高純度 Omega-3 脂肪酸（EPA / DHA）**：
  - **臨床機轉**：文獻記載魚油補充可藉由競爭抑制花生四烯酸代謝、下調 COX-2 與 5-LOX 路徑，減少發炎介質與血栓素 A2 合成，在 IgA 腎病變等慢性腎小球發炎中具有延緩腎功能惡化的臨床實證。
  - **應用考量**：選用高純度 rTG 型態，輔助抗氧化劑預防過氧化。
- **標靶抗氧化與抗纖維化策略（阻斷 ROS / TGF-β 路徑）**：
  - **N-乙醯半胱氨酸（NAC） / 穀胱甘肽前驅物**：補充胞內穀胱甘肽儲備，清除蛋白尿刺激小管上皮細胞產生的大量 ROS，減少小管間質壞死。
  - **反式白藜蘆醇（Resveratrol）與薑黃素（Curcumin）**：抑制 NF-κB 發炎轉錄因子並下調 TGF-β 與 Snail 表達，減輕上皮-間質轉化（EMT）及膠原基質沉積。
- **活化型維生素 D（Calcitriol / 補充 D3）**：
  - **足細胞保護作用**：足細胞富含維生素 D 受體（VDR）；充足的維生素 D 可上調 Nephrin 與 Podocin 表現，維持足突縫隙完整性，抑制 RAAS 本地過度活化。

### 2. 飲食與禁食策略
- **限制進階糖化終產物（Anti-AGE Diet）**：
  - **機轉**：糖尿病腎病變與類澱粉沉積症（AA/AL）中，AGE 與其受體（RAGE）結合會直接刺激繫膜細胞增生與基底膜增厚。
  - **原則**：避免高溫油炸、烘烤食物；採用低溫、慢煮、蒸煮為主的烹調方式，減少外源性 AGEs 累積。
- **精準蛋白質攝取調節（保護腎絲球血流動力學）**：
  - **非透析期腎病策略**：在維持氮平衡與白蛋白的前提下，避免極端高蛋白飲食引起的入球小動脈過度擴張與「高濾過（Hyperfiltration）」壓力；蛋白質來源應優先選擇富含抗發炎植化素的植物性蛋白（Plant-dominant diet），降低尿毒素（如硫酸吲哚酚 Indoxyl sulfate）生成。
- **微量營養素與電解質平衡**：嚴格限制鈉攝取（<2 g/d 鈉，相當於 5 g 食鹽），以解除腎元水鈉滯留負擔，提升 RAAS 阻斷劑與 SGLT2 抑制劑的降蛋白尿療效。

### 3. 環境毒素阻斷 / 代謝排毒 / 生活型態
- **環境促發物與化學溶劑阻絕**：
  - 文獻特別指出：**矽塵（Silica dust）**暴露與 ANCA 相關血管炎（GPA）的誘發與復發顯著相關；**烴類溶劑（Hydrocarbon solvents）**則會促使第 IV 型膠原蛋白 α3 NC1 結構域暴露，引發抗 GBM 疾病（Goodpasture's）。應落實職業安全防護並阻絕化學毒物吸入。
- **全面戒菸（Cessation of Smoking）**：
  - 吸菸為 Goodpasture 症候群誘發致命性肺出血（Hemoptysis）與微血管發炎的最主要危險因子，同時加速糖尿病與高血壓腎微血管硬化。
- **血管血流動力學最佳化**：
  - 落實嚴格血壓管理（標的收縮壓 `<120–130 mmHg`）。
  - 標準一線藥物整合：優先建議使用 RAAS 抑制劑（ACEI / ARB）降低出球小動脈阻力；第二型糖尿病或腎病患者評估使用 SGLT2 抑制劑，藉由恢復緻密斑鈉離子傳遞（Macula densa sodium delivery），促進入球小動脈收縮，逆轉微血管高壓。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **鏡檢優先思維**：面對未明原因的水腫或腎功能下降，常規進行高品質晨尿沉渣顯微鏡檢驗；一旦辨識出**異形紅血球（Dysmorphic RBCs）**或**紅血球圓柱體（RBC casts）**，即應優先考慮活動性腎炎並及時啟動腎臟專科轉介與切片評估。
2. **追蹤抗體滴度與補體消長**：原發性膜性腎病（IMN）以 **Anti-PLA2R 抗體** 作為疾病進展與治療反應的即時生物標記；低補體血症（C3/C4 下降）則可作為辨別紅斑性狼瘡、鏈球菌後感染與 MPGN 的核心鑒別工具。
3. **終結蛋白尿的惡性循環**：體認到「蛋白尿本身具備小管毒性」。臨床處方無論是免疫抑制療法、生活型態介入或血壓管理，均應以**降低尿蛋白至 <0.3–0.5 g/24h 作為主要目標**，以阻斷腎小管間質纖維化的進展。
4. **排除感染與血管繼發因素**：在給予強效類固醇或免疫抑制劑前，務必先行篩檢或排除 **C型肝炎、B型肝炎、HIV、梅毒與亞急性細菌性心內膜炎（SBE）**，因上述感染誘發的免疫複合體腎炎必須以抗微生物治療為根基，貿然免疫抑制可能導致全身性感染惡化。
