# 急性認知障礙與譫妄的全方位評估與神經復原策略 (Confusion and Delirium)
- **主講人/來源**：27 Confusion and Delirium.pdf（*Harrison's Principles of Internal Medicine*, 21st Edition, Chapter 27, S. Andrew Josephson, Bruce L. Miller）
- **核心主旨**：譫妄（Delirium）本質上是「大腦生理儲備（Cerebral Reserve）的壓力測試」，多由周邊感染、發炎、藥物或代謝紊亂誘發；臨床應以非藥物神經保護、晝夜節律重建與病因根除為核心，切忌盲目使用化學鎮靜掩蓋神經退化警訊。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **神經傳導失衡**：乙醯膽鹼（Acetylcholine）缺乏為核心驅動機轉（基底前腦膽鹼能神經元退化導致），常伴隨多巴胺（Dopamine）相對過剩，進而引發幻覺、定向力障礙與認知波動。
  - **神經發炎與細胞因子風暴**：全身性感染（如敗血症、泌尿道感染、肺炎）引發前發炎細胞因子（Proinflammatory cytokines）釋放，穿透或影響血腦屏障，導致瀰漫性大腦皮質與皮質下功能障礙（腦電圖呈對稱性慢波）。
  - **大腦脆弱度與代謝崩解**：高齡、潛在神經退化（如阿茲海默症、路易氏體失智症）使神經元抗逆力降低；極微小的外在刺激（如輕微電解質異常、脫水、抗膽鹼藥物）即足以引爆神經代謝失代償。
- **演講亮點與臨床洞察**：
  - **Paradigm Shift（觀念翻轉）**：過去視譫妄為短暫良性病程，現已證實其代表嚴重的神經元損傷，與高住院死亡率（25%~33%）、出院後數月內死亡率上升 5 倍、永久性認知缺損及加速失智病程直接相關。
  - **警訊指標**：譫妄往往是未診斷出的潛在神經退化性疾病（Neurodegenerative diseases）之初次臨床表徵。
  - **亞型陷阱**：臨床極易漏診「低活動型譫妄（Hypoactive Delirium）」（常被誤認為憂鬱或單純嗜睡），其預後甚至比表現出激躁、自主神經亢進的「高活動型譫妄（Hyperactive Delirium）」更差。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（文中依據） |
| :--- | :--- | :--- |
| **順向數字廣度測驗 (Digit Span Forward)** | 床邊快速篩檢注意力（譫妄的核心神經心理學標記，大腦前額葉與頂葉網絡整合指標） | **正常成人為 5～7 位數**；若 **$\le$ 4 位數** 表示注意力缺陷，譫妄患者常 **$\le$ 3 位數** |
| **CAM 評估法 (Confusion Assessment Method)** | 診斷譫妄之金標準工具（評估急性起病/波動、注意力缺失、思維混亂、意識狀態改變） | 必須具備 **特徵 1 + 特徵 2**，且合併 **特徵 3 或 4 其中之一** 即確診 |
| **電解質與水合狀態 (Na, Ca, Mg, Glucose, BUN/Cr)** | 評估神經細胞膜電位穩定度、滲透壓休克、脫水（住院第一常見問題）或體液容積過負荷 | 嚴格維持電解質於生理正常中位區間；避免低血鈉、高/低血鈣及血糖急劇波動 |
| **感染標記與尿液分析 (UA, CXR, 血液培養)** | 排除引發敗血性腦病變的隱匿性周邊感染（尤其是高齡患者的 UTI 與肺炎） | 尿液白血球、細菌培養陰性；胸部 X 光無浸潤陰影 |
| **維生素神經代謝組 (Thiamine, B12, Folate, Niacin)** | 評估線粒體能量代謝輔酶、髓鞘完整性與一碳代謝途徑（甲硫胺酸循環） | 排除硫胺素（B1）與維生素 B12 耗竭所致之急性可逆性腦病變 |
| **神經發炎與自體免疫抗體 (ANA, ANCA, 腦炎自體抗體)** | 排除中樞神經系統血管炎、副腫瘤性腦炎或自體免疫性腦炎 | 第二線評估項目；抗體滴度陰性、補體水平正常 |
| **腦電圖 (EEG)** | 鑑別非抽搐性癲癇重積狀態 (NCSE) 與瀰漫性代謝性腦病變 | 排除亞臨床癲癇波；瀰漫性對稱性慢波（Symmetric slowing）支持代謝性腦功能障礙 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 譫妄的解剖網絡與神經傳導假說
- **神經迴路廣泛受損**：注意力缺陷反映了腦幹網狀活化系統、丘腦（尤其是背內側核）、前額葉皮質與右頂葉組成的神經迴路失調。
- **神經化學失衡機制**：
  - **膽鹼能抑制（Cholinergic Deficiency）**：阿茲海默症、路易氏體失智症與帕金森氏症失智均存在前腦基底核膽鹼能神經元退化，因此對外源性抗膽鹼藥物（如第一代抗組織胺、三環抗憂鬱劑、解痙劑）極度敏感。
  - **多巴胺亢進（Dopaminergic Excess）**：多巴胺路徑過度興奮會觸發視幻覺、妄想與嚴重激躁（類似多巴胺藥物治療帕金森病時誘發的混亂狀態）。

### 2. 「大腦壓力測試」理論與多重打擊假說
- **脆弱大腦假說**：
  $$\text{譫妄發生風險} = \frac{\text{外在誘發打擊 (Precipitating Insults)}}{\text{大腦基礎儲備 (Baseline Cerebral Reserve)}}$$
  - 在大腦儲備極低（高齡 $>65$ 歲、既有失智症佔譫妄病患至少 2/3）的患者中，微小的誘因（如換床、常規換藥、置放導尿管、單次失眠）即可誘發譫妄。
  - 健壯青年個體則需極高劑量毒素或極重度系統性疾病（如敗血性休克）才會出現譫妄。

### 3. 住院環境醫源性風險（In-Hospital "Tethers"）
- **束縛與外在導管（Tethers）的惡性循環**：
  - 留置導尿管（Foley catheter）、靜脈輸液管、鼻導管、遠端遙測心電圖（Telemetry）及連續血氧監測儀（CPO）限制了活動力，引發感覺剝奪與受困焦慮。
  - 身體約束（Physical restraints）會加劇失定向感與恐慌，已被證實是誘發與延長譫妄的危險因子，應全面改用床邊警報器（Bed alarms）與專人陪護（Sitters）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素與神經代謝支持
- **褪黑激素（Melatonin）**：
  - **劑量/機轉**：睡前給予低劑量褪黑激素，調節視交叉上核（SCN）之生物鐘受體，促使核心體溫下降與睡眠驅動，預防夜間混亂（Sundowning）。
- **神經輔酶補充（Thiamine & Methyl-B12）**：
  - **活性 B 群支持**：若懷疑營養不良、酗酒或代謝衰竭，在給予葡萄糖輸液前，必須即刻補充**高劑量維生素 B1（Thiamine）**，防止 Wernicke 腦病變；同步監測 B12 與葉酸，維持單碳代謝與神經傳導物質合成。
- **審慎的水合與電解質平衡**：
  - 脫水是住院患者第一大誘因；維持常態血容量以確保腦部灌流，但需避免過度輸液導致低血氧或心衰竭惡化。

### 2. 營養、飲食與代謝穩定策略
- **維持血糖恆定**：避免急性低血糖或高滲透壓高血糖狀態，防止神經元滲透壓急劇變化。
- **促進清醒時的進食生理學**：
  - 嚴格落實**三餐離開病床，移至椅子上進食**（Out of bed to chair for all 3 meals），透過重力刺激前庭系統與本體感覺，活化上行網狀活化系統（ARAS）。
- **限制神經毒性物質**：午後嚴格限制咖啡因攝取，避免干擾深層慢波睡眠架構。

### 3. 環境與晝夜節律多模態介入（非藥物照護檢核清單 - 核心介入）

```
【日間促進清醒 (AM: Promote Wakefulness)】
  ├── 光照與視覺：拉開窗簾、打開全燈；佩戴自身眼鏡與助聽器
  ├── 時間空間定向：白板清楚標示日期、護理人員姓名；病房放置時鐘與日曆
  ├── 神經認知活化：提供遊戲、閱讀材料、維持交談；避免白天小睡
  ├── 早期活動化：每天下床走動 3 次 (Walk patient 3x/day)
  └── 去除醫源約束：每日評估並盡早拔除導尿管、氧氣導管與非必要生理監視器

【夜間促進睡眠 (PM: Promote Sleep)】
  ├── 黑暗與靜音：關閉電視、拉下窗簾、全室熄燈；提供耳塞與眼罩
  ├── 集群護理 (Task Clustering)：集中夜間給藥與處置，減少夜間喚醒次數
  ├── 簡化監測：經醫師評估病情穩定者，免除半夜常規量測生命徵象
  └── 人性化心理支持：引入熟悉家人物品、熟悉衣物被褥，減輕「陌生環境恐慌」
```

### 4. 藥物整合原則（Deprescribing）
- **抗精神病藥物的嚴格限制**：
  - 臨床試驗證實第一代及非典型抗精神病藥物**無法縮短譫妄病程**，且會增加高齡者死亡率；**僅能作為極度激躁、有立即自傷或傷人風險時的「最後手段」**，並以極低劑量、必要時（PRN）短暫使用。
  - **嚴格禁用 Benzodiazepines**（除非病因為酒精戒斷或鎮靜劑戒斷症候群），因其會顯著加重低活動型譫妄與神經認知紊亂。
  - **全面撤除抗膽鹼能藥物**：包含三環抗憂鬱劑、抗帕金森抗膽鹼藥、特定止吐劑與鎮靜類麻醉止痛劑。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實床邊注意力篩檢**：常規將「順向數字廣度測驗（Digit Span）」與「CAM 評估法」納入長者或術後病患的生命徵象查房中；凡遇急性認知退化，**預設為譫妄**直至排除其他可能。
2. **啟動非藥物「日夜節律包裹式照護（Bundle）」**：落實日間開燈/拉窗簾、佩戴眼鏡/助聽器、下床坐椅用餐與步行；夜間落實集約化護理（避免半夜反覆敲門喚醒）、提供耳塞眼罩。
3. **每日清點並解除「醫療枷鎖（De-tethering）」**：每班查房主動檢視並盡早移除不必要的鼻導管、導尿管、連續血氧夾與束縛帶，以環境感官豐富化與陪護員（Sitter）取代保護約束。
4. **回溯用藥清單（Medication Reconciliation）**：逐一審查處方藥、成藥與草藥，優先停用具抗膽鹼能活性、鎮靜催眠及麻醉性止痛藥物，並檢查是否有急性停用酒精或安眠藥的戒斷情形。
5. **門診追蹤與失智篩檢規劃**：譫妄完全緩解後，不可直接視為「痊癒結案」；必須安排患者於門診進行神經退化性疾病（如阿茲海默症、路易氏體失智症）之長效追蹤與認知功能完整評估。
