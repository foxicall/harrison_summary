# 心血管崩潰、心臟驟停與心因性猝死（Cardiovascular Collapse, Cardiac Arrest, and Sudden Cardiac Death）
- **主講人/來源**：Christine Albert, William H. Sauer / *Harrison's Principles of Internal Medicine*, 21st Edition (Chapter 306)
- **核心主旨**：心因性猝死（SCD）多數發生於既往無已知心臟病或左心室射出分率（LVEF）保留的廣大群體中；臨床管理需結合院前快速急救鏈、復甦後神經重症保護，並藉由代謝風險修正、功能營養素補充與抗心律不整生活型態，建立全方位的一級與二級預防體系。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **基質異常（Substrate）**：心肌梗塞後纖維化瘢痕（Scar）、心室肥厚（LVH，特別常見於高血壓與黑人群體）、心肌伸展/擴張，以及離子通道功能修飾與異常的細胞內鈣離子處理（Abnormal calcium handling），構成電生理異質性（Electrical heterogeneity）與折返（Reentry）迴路。
  - **誘發觸發因子（Triggers）**：急性缺血、交感神經過度活化（自律神經失調）、電解質失衡（低血鉀、低血鎂）、劇烈運動、環境/心理壓力，最終促發致命性多型性心室頻脈（Polymorphic VT）與心室顫動（VF）。
  - **血流動力學崩潰**：大面積急性心肌梗塞、心臟破裂併心包填塞、急性重度二尖瓣逆流，或非心因性因素（大片肺栓塞、張力性氣胸、低血容量），直接導致無脈性電氣活動（PEA）或心搏停止（Asystole）。
- **演講亮點與臨床洞察**：
  - **SCD 流行病學典範轉移**：急救現場首見 VF 的比例從以往的 >50% 大幅下降至目前的 20–25%，而 PEA 和 Asystole 成為最常見表現，反映人口老化、末期共病增加及 β 阻斷劑/ICD 的普及。
  - **SCD 預防的流行病學悖論（Prevention Paradox）**：雖然低 LVEF（≤35%）族群的年猝死率最高（3.0–7.2%/年），但**全體猝死事件中高達 80% 是發生在 LVEF >35% 或事前無已知心臟病的一般大眾**。因此，僅依賴傳統 ICD 植入無法有效降低總人口的 SCD 負擔，必須仰賴全面性代謝與生活型態介入。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）
| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **左心室射出分率 (LVEF)** | 評估收縮功能與猝死風險之關鍵指標；低於 40% 時 SCD 風險呈指數級攀升 | • 正常: >50%<br>• ICD 適應症門檻: ≤35% (NYHA II–III) 或 ≤30% (NYHA I) |
| **心電圖 (12-Lead ECG)** | 篩檢離子通道病變、電生理異質性及傳導異常 | • QTc 延長 (>450 ms 男, >460 ms 女)<br>• Brugada pattern (V1–V3 ST 段上升)<br>• 早期再極化 (Early Repolarization)<br>• QRS 寬度 (>120 ms 提示傳導延遲)<br>• 左心室肥厚 (LVH 標記) |
| **血清鎂與紅血球鎂 (Mg)** | 鎂為心肌細胞膜電位穩定劑；缺乏會阻礙 Na+/K+-ATPase 並誘發 Torsades de Pointes (TdP) | • 臨床常規: >2.0 mg/dL<br>• 功能醫學/急症預防: 維持於中高標 (≥2.2 mg/dL) |
| **血清鉀離子 (K⁺)** | 影響靜止膜電位與再極化；過高引起正弦波 VT，過低誘發室性心律不整 | 嚴格維持於 4.0–4.8 mEq/L (避免低於 3.5 或高於 5.5 mEq/L) |
| **高敏感肌鈣蛋白 (hs-cTn)** | 偵測急性冠心症 (ACS) 或持續性心肌微缺血與心肌壞死 | 低於檢驗試劑第 99 百分位數上限值 |
| **NT-proBNP / BNP** | 反映心室容量負荷與心壁壓力；高張力狀態會刺激伸展活化離子通道誘發心律不整 | DANISH 試驗門檻: NT-proBNP >200 pg/mL 代表顯著心室伸展負荷 |
| **Omega-3 指數 (RBC EPA+DHA)** | 評估心肌細胞膜磷脂質脂肪酸組成，高比例具顯著電生理穩定與抗心律不整效益 | 目標值: ≥8%（高風險防護區間） |

## 三、 關鍵機制詳解與投影片重點筆記
### 1. 急性心臟驟停之時間軸病理機轉與復甦階層
- **最初電擊黃金期**：復甦成功率（ROSC）在倒地 5 分鐘後迅速衰減。若為 VF/無脈性 VT，每延遲 1 分鐘電擊，生存率即銳減；經由 AED 早期去顫是改善院外存活率的核心。
- **電氣轉變（Degeneration）**：未治療的 VT/VF 會在短時間內因心肌細胞 ATP 耗竭、嚴重酸中毒及離子梯度崩解，退化為 PEA 甚至 Asystole。
- **復甦後腦損傷（Post-cardiac arrest brain injury）**：佔復甦成功後院內死亡原因的三分之二以上。大腦缺血-再灌流損傷誘發興奮性毒性、自由基風暴與微血管無再流現象。
  - **目標溫度管理（TTM）**：建議維持核心體溫於 32–36°C 至少 24 小時，並積極抑制寒戰與發燒，延緩神經元凋亡。
  - **預後評估時間窗**：鎮靜與低溫狀態干擾神經學評估，應延遲至恢復正常體溫後至少 72 小時（心跳驟停後 4–5 天）再判定腦幹反射、肌陣攣與腦電圖（EEG 爆發抑制為不良預後指標）。

### 2. 結構性基質 vs. 原發性電氣異常
```
[心因性猝死病因光譜]
├── 冠狀動脈疾病 (CAD) (~40–70%):
│    ├── 急性缺血 → 多型性 VT/VF
│    └── 陳舊性梗塞瘢痕 (Scar) → 慢傳導折返性 VT → VF
├── 非缺血性心肌病變 (10–35%):
│    ├── 擴張型心肌病變 (DCM) / 肥厚型心肌病變 (HCM)
│    └── 心律不整性右心室心肌病變 (ARVC) / 心臟類肉瘤病
└── 原發性離子通道病變 (1–10%):
     ├── 長 QT 症候群 (LQTS)、Brugada 症候群、CPVT
     └── 藥物誘發之次發性 QT 延長與電解質紊亂
```

### 3. 一級與二級預防 ICD 植入適應症（基於臨床指引精華）
- **二級預防（Class I）**：排除完全可逆原因後，VF 或血流動力學不穩定持續性 VT 的倖存者；或合併結構性心臟病之自發持續性 VT。
- **心肌梗塞後一級預防**：
  - 心肌梗塞後 ≥40 天且接受適當藥物治療：LVEF ≤35% 伴隨 NYHA Class II–III，或 LVEF ≤30% 伴隨 NYHA Class I（均為 Class I 適應症）。
  - 心肌梗塞急性期（<40 天內）：植入 ICD 未顯示總體生存效益（早期死因多為心臟破裂或嚴重再梗塞），高危險群過渡期可考慮配戴式去顫背心（Wearable Cardioverter Defibrillator）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）
### 1. 功能性營養素/植化素補充（膜電位穩定與粒線體修復）
- **高純度 Omega-3 脂肪酸 (EPA/DHA)**：
  - **劑量/機轉**：每日 2,000–4,000 mg。EPA/DHA 嵌入心肌細胞膜磷脂質，可調節電壓門控鈉離子通道與 L 型鈣離子通道，提高室性顫動門檻（Fibrillation threshold）。
- **甘胺酸鎂 (Magnesium Glycinate) 或 牛磺酸鎂 (Magnesium Taurate)**：
  - **劑量/機轉**：元素鎂 300–500 mg/天。牛磺酸具滲透調節及心肌鈣離子調控效應；鎂為心肌細胞鈉-鉀幫浦活化劑，能拮抗異常去極化，抑制早期後去極化（EADs）。
- **輔酶 Q10 (CoQ10 / Ubiquinol)**：
  - **劑量/機轉**：每日 100–300 mg。提升心肌細胞 ATP 生成效率，保護粒線體免受再灌流氧化損傷，改善心室收縮代償儲備。

### 2. 飲食與代謝調控策略
- **地中海型飲食（Mediterranean Dietary Pattern）**：
  - 大量攝取初榨橄欖油（富含多酚）、多色蔬菜、堅果與富含油脂的深海魚類。
  - 文獻證實此飲食型態與 SCD 發生率顯著負相關，機轉在於減輕全身性微發炎、改善血管內皮功能及平抑交感活性。
- **嚴格限酒與戒菸**：
  - 戒菸能迅速降低交感神經刺激與血管痙攣風險，尤其未確診 CAD 的高危險群獲益最大。
  - 避免重度飲酒（每日 >3 份酒精），防範酒精性心律不整（Holiday Heart Syndrome）與心肌毒性。
- **碳水化合物管理與胰島素敏感度優化**：
  - 糖尿病是 SCD 的獨立強烈預測因子（使風險增加數倍）；積極控制血糖震盪可防止自主神經病變引發的心律變異度（HRV）降低。

### 3. 環境、神經自律調節與運動處方
- **晝夜節律與睡眠呼吸障礙治療**：
  - SCD 發生具生理時鐘高峰（清晨與傍晚）。阻塞性睡眠呼吸中止症（OSA）導致夜間間歇性低血氧與交感風暴，需積極使用 CPAP 呼吸器改善缺氧性心臟驟停風險。
- **規律且漸進式的運動訓練**：
  - 劇烈極限運動會短暫提升 SCD 風險（尤其男性），但長期規律的有氧訓練能提高迷走神經張力、降低基礎心率與兒茶酚胺敏感度，從整體上消除運動引發的猝死風險。
- **心理壓力調適**：
  - 災難、情緒恐慌與重度抑鬱均為 SCD 臨床觸發點，應導入心律呼吸調控（Heart Rate Variability Biofeedback）與正念減壓。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **重視「隱形高危險群」的全面篩檢**：不能僅將 SCD 預防侷限於 LVEF ≤35% 的患者；對所有合併高血壓、左心室肥厚、糖尿病或有猝死家族史的個體，均應進行心電圖（QTc、早期再極化）與電解質評估。
2. **第一時間落實院前生命鏈（Hands-Only CPR + AED）**：教育患者家屬與社區大眾，心跳驟停時立即實施每分鐘 100–120 下、按壓深度 5 公分的持續胸部按壓，並第一時間使用公眾 AED，最大化神經學復原機會。
3. **心梗與復甦後的黃金時間管理**：心肌梗塞後 48 小時後的 VF 多與心肌瘢痕相關，需完整評估 ICD 適應症；若處於心梗後 40 天內或再血管化 90 天內，不可貿然植入常規 ICD，應優先評估穿戴式去顫設備。
4. **處方抗心律不整營養基底**：常規評估高風險患者的電解質（K⁺ 穩固在 4.0–4.8 mEq/L、優化鎂狀態），並開立高純度醫療級 Omega-3 脂肪酸與抗發炎抗氧化植化素，鞏固心肌電生理穩定性。
