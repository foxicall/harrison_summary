# 痘病毒科感染臨床指引：病理機轉、鑑別診斷與抗病毒介入策略
- **主講人/來源**：196 Molluscum Contagiosum, Monkeypox, and Other Poxvirus Infections.pdf（*Harrison's Principles of Internal Medicine*, Inger K. Damon）
- **核心主旨**：系統性剖析各屬痘病毒（正痘病毒、副痘病毒、軟疣痘病毒與亞塔痘病毒）的基因體結構與免疫逃逸特性，聚焦宿主先天免疫與干擾素屏障在阻斷發熱性病毒血症中的關鍵角色，並確立臨床診斷流程、新型抗病毒藥物（Tecovirimat/Brincidofovir）應用指引及疫苗防護策略。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **基因體雙重架構**：痘病毒為雙鏈 DNA（dsDNA）病毒，中央區（高達 200 kb）高度保守，負責病毒複製與組裝；兩端非保守區編碼多樣化的「免疫逃逸基因（Immune Evasion Genes）」與宿主交互作用開放閱讀框（ORFs），決定病毒宿主範圍與致病力表現。
  - **二階段系統性播散**：正痘病毒（如猴痘、天花）經皮黏膜接觸或呼吸道進入人體後，先於局部淋巴結增殖，隨後播散至全身淋巴網狀系統（Lymphoreticular tissues），最終誘發高發熱性病毒血症（Febrile Viremia）並擴散至皮膚上皮組織。
  - **先天免疫與干擾素軸**：初期的先天免疫防線（Innate Immunity）及干擾素（IFN）反應強度，是決定自限性病程或重症播散（如進行性牛痘 progressive vaccinia、濕疹性牛痘 eczema vaccinatum）的核心調節因素。
- **演講亮點與臨床洞察**：
  - **流行病學典範轉移**：隨著全球天花疫苗（牛痘疫苗）接種終止導致群體免疫力衰退，猴痘（Monkeypox）的有效傳染數（$R_0$）提升，已具備不需依賴野生動物重複接觸、即能於人群間持續性傳播之流行病特徵。
  - **皮疹分期與離心性分佈**：正痘病毒皮疹具有典型「離心性（Centrifugal）」特徵（肢端與面部多於軀幹，常侵犯掌蹠），依序經歷斑疹 $\rightarrow$ 丘疹 $\rightarrow$ 水皰 $\rightarrow$ 具臍凹特徵的膿皰（Umbilicated Pustules） $\rightarrow$ 結痂脫落。若出現「第三期發熱（Tertiary Fever）」，通常是續發性細菌感染的臨床警訊。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（病理特徵） |
| :--- | :--- | :--- |
| **核酸檢測（PCR / 定序）** | 確診病毒屬與種（區分猴痘、牛痘、Akhmeta、AK2015、NY-014 等）；檢體採自皮疹刮取物或痂皮 | 檢測特異性病毒基因序列；區分變異株 |
| **負染色電子顯微鏡檢（Negative-stain EM）** | 形態學初步快速鑑別病毒科別與屬別 | 正痘病毒、亞塔病毒、MCV：**大磚形（Brick-shaped）** 顆粒；副痘病毒：**卵形交錯條紋（Ovoid with crisscross spicules）** |
| **皮膚組織病理切片** | 鑑別不明發炎性丘疹、傳染性軟疣或巨型副痘病灶 | 傳染性軟疣可見特徵性 **亨德森-帕特森小體（Henderson-Patterson bodies / 軟疣小體）** |
| **眼科裂隙燈檢查（Slit Lamp）** | 評估正痘病毒面部病灶是否侵犯結膜或角膜，預防失明併發症 | 角膜透明無潰瘍、無角膜炎（Keratitis）浸潤病灶 |
| **正痘病毒血清學試驗（Serology）** | 評估抗體反應與群體暴露史（但因屬內廣泛交叉反應，不易鑑別具體病毒種） | 正痘病毒屬抗體效價上升（無法精準區分疫苗誘發或自然感染） |

## 三、 關鍵機制詳解與重點筆記

### 1. 痘病毒科基因體多樣性與免疫逃逸機轉
- **中央複製核心 vs. 兩端免疫調節因子**：痘病毒基因體龐大，其兩端編碼大量可干擾宿主免疫信號的分子（如干擾素拮抗蛋白、細胞因子誘餌受體、補體結合蛋白）。這些分子的組成差異決定了其人畜共通潛力（如牛痘、駱駝痘、水牛痘 buffalopox）及致死率差異（天花 2–30% vs. 局部感染）。
- **宿主免疫抑制狀態下的病程失控**：
  - **Eczema Vaccinatum**：異位性皮膚炎患者因表皮屏障破損與 Th2 偏向免疫，接觸牛痘後引發廣泛性皮損。
  - **Progressive Vaccinia**：細胞免疫低下宿主無法啟動局部發炎反應以局限病毒，造成原發病灶無痛性、無發炎性的進行性組織壞死擴散。
  - **Giant Orf**：免疫功能低落個體遭受副痘病毒感染時，皮損無法自我限局，演變為巨大腫塊樣病灶。

### 2. 臨床特徵鑑別與病程動態對照
```
[暴露/接種潛伏期] 
       ↓ (~1-2週)
[發熱前驅期] → 突發高熱、類流感症狀（亞塔痘病毒常伴隨極高熱，易誤診為瘧疾）
       ↓ (數天後)
[皮疹演變期] 
  - 正痘病毒：斑疹(Macule) → 丘疹(Papule) → 水皰(Vesicle) → 臍凹膿皰(Umbilicated Pustule) → 結痂
    （分佈：離心性、面部、手掌、腳底；痂皮完全脫落前均具傳染性）
  - 軟疣病毒：肉色珍珠樣丘疹、中央微小臍凹、周圍無明顯發炎紅暈、無痛。
  - 副痘病毒：紅斑丘疹 → 標靶樣皮損（Target lesion） → 結節/乳頭瘤樣肉芽腫。
```

## 四、 臨床介入處方與醫療處置策略（Therapeutic Strategies）

### 1. 標靶抗病毒藥物與特異性免疫球蛋白
- **Tecovirimat (TPOXX)**：
  - **適應症**：FDA 核准治療天花；持 IND 方案用於實驗室確診之猴痘與嚴重牛痘併發症。
  - **成人劑量**：**600 mg 口服，每日兩次（BID），連續治療 14 天**。
  - **臨床藥動學關鍵**：**必須隨含脂肪餐食（Fatty meal）併服**，以確保足夠之生體可用率。
- **Brincidofovir (Tembexa)**：
  - FDA 於 2021 年 6 月核准之正痘病毒抗病毒口服藥物。
- **牛痘免疫球蛋白（Vaccinia Immune Globulin, VIG）**：
  - 靜脈注射（IV）標準劑量：**6000 U/kg**；視病情進展可重複給藥，劑量最高可調至 **9000 U/kg**。
- **眼部角膜侵犯處置**：
  - 若病灶鄰近眼周或侵犯結膜/角膜，給予外用抗病毒滴劑 **Trifluridine**，以避免角膜瘢痕化及失明風險。

### 2. 傳染性軟疣（MCV）與局部病灶處理
- **處置原則**：多數健康個體具自限性（6–12 個月內消退）；加速清除可採物理破壞（刮除術 Curettage、冷凍治療 Liquid nitrogen）或局部免疫調節劑（Imiquimod）。
- **HIV / 免疫低下合併感染**：首要策略為啟動高活性抗反轉錄病毒療法（HAART）重建細胞免疫；需警惕**免疫重建發炎症候群（IRIS）**可能引發軟疣病灶暫時性惡化或再燃。

### 3. 感控防護與疫苗預防策略
- **接觸與呼吸道隔離**：疑似或確診猴痘/天花患者，必須安置於**負壓隔離病房（Negative-pressure isolation room）**，醫護人員嚴格執行接觸與空氣防護措施。
- **新世代預防疫苗**：
  - **JYNNEOS**：FDA 核准之非複製型（Replication-deficient）痘病毒疫苗，於哺乳動物細胞內僅進行單輪複製，大幅降低傳統複製型牛痘疫苗引起的反應原性與心肌炎/腦炎風險，安全適用於預防天花與猴痘。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **嚴格鑑別高風險皮疹**：遇「發熱後數天出現離心性分佈、手掌與腳底有病灶、膿皰伴隨中央臍凹」之病患，立即啟動接觸與負壓呼吸道隔離，通報並進行採檢。
2. **眼周病灶早期阻斷**：凡臉部痘病毒皮損接近眼眶者，每日嚴格監測角膜表皮完整性；一旦懷疑侵犯，即刻會診眼科並備妥 **Trifluridine** 點眼治療。
3. **優化 Tecovirimat 吸收衛教**：臨床開立 TPOXX（600 mg BID）時，衛教重點必須明確告知患者**「隨高脂飲食服用」**，避免空腹導致血中濃度不足而影響抗病毒療效。
4. **標準化檢體採集路徑**：確診依賴核酸檢驗（PCR）；應直接刮取活動性皮疹滲出物或採集乾燥痂皮送驗，避免僅依賴血清學檢測。
5. **監測續發感染警訊**：皮疹病程中若出現再度升溫（第三期發熱），高度懷疑皮膚屏障破損併發之細菌性雙重感染，應及早進行傷口培養並介入針對性抗菌治療。
