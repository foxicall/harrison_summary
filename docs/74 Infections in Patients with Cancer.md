# 癌症病患感染症之全方位防禦與精準臨床處置
- **主講人/來源**：74 Infections in Patients with Cancer.pdf（Robert W. Finberg 醫學專題）
- **核心主旨**：癌症病患的感染多源自解剖屏障破壞、免疫監視缺陷及抗癌治療引發的嗜中性白血球低下；臨床需透過早期經驗性抗生素、精準抗黴菌介入與個體化屏障維護，降低移位感染與重症敗血症風險。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **物理與黏膜屏障崩解**：化療導致胃腸道上皮黏膜破壞（Mucositis）、腫瘤侵犯造成皮膚破損或管腔阻塞（膽道、輸尿管），促使人體正常共生菌叢（原生皮表菌與腸道革蘭氏陰性菌）移位（Translocation）入血。
  - **骨髓抑制與嗜中性球低下（Neutropenia）**：絕對嗜中性球計數（ANC）$<500/\mu\text{L}$ 時，吞噬功能近乎停擺，典型發炎體徵（紅、腫、化膿、肺浸潤陰影）常被掩蓋，僅以發燒為首要表徵。
  - **體液與細胞免疫雙重缺損**：CLL 及多發性骨髓瘤導致低丙種球蛋白血症（Hypogammaglobulinemia）；何杰金氏病、類固醇與標靶藥物（如抗 CD20 Rituximab、抗 TNF 抗體、Fludarabine）阻斷 T/B 細胞訊號，引發細胞內病原體（結核菌、李斯特菌、真菌）與潛伏病毒（HBV、HSV、VZV、JC 病毒）再活化。
- **演講亮點與臨床洞察**：
  - **治療思維的典範轉移（Paradigm Shift）**：早期經驗性抗生素使白血病菌血症死亡率從 1965 年的 84% 降至現今 <10%；若廣效抗生素使用 4～7 天後發燒未退，應果斷經驗性加入抗黴菌藥物（如 Caspofungin、Voriconazole、Liposomal Amphotericin B）。
  - **避免盲目升級抗生素**：反對無實證的「Double coverage」抗陰性菌組合或無適應症自動加用 Vancomycin（增加毒性且無助改善預後），應依血培養與醫院抗藥性監測精準調整。
  - **微觀非典型表現**：嗜中性球低下病患的蜂窩性組織炎常「無膿」，肺炎常「無痰或無典型 X 光大葉性實質化」，盲腸炎可能表現為盲腸壁肥厚之嗜中性球低下性結腸炎（Typhlitis）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準 |
| :--- | :--- | :--- |
| **絕對嗜中性球計數 (ANC)** | 評估感染風險與骨髓造血免疫防禦極限 | **警戒值**：$<500/\mu\text{L}$（重度風險）；預期低下 $>7$ 天需最高規格經驗性涵蓋；$>500/\mu\text{L}$ 連續 2 天為抗生素停藥安全參考。 |
| **血清總 IgG 濃度** | 評估多發性骨髓瘤、CLL 或 HSCT 後體液免疫缺損 | **臨床介入臨界**：$<400\text{ mg/dL}$ 伴隨反覆嚴重感染時，方考慮 IVIG 替代療法。 |
| **血清 1,3-$\beta$-D-葡聚醣 ($\beta$-D-Glucan) / 半乳甘露聚醣 (Galactomannan)** | 輔助侵襲性真菌感染（*Candida*, *Aspergillus*, *Pneumocystis jirovecii*）之早期分子篩檢 | **關注標準**：血清陽性提示深部真菌侵襲，非侵入性評估肺部與全身黴菌負荷（需注意假陽性）。 |
| **高解析度胸部電腦斷層 (HRCT)** | 嗜中性球低下時 X 光易呈假陰性，HRCT 評估早期微細結節與浸潤 | **特異性徵象**：結節伴隨光暈徵（Halo sign）或空氣新月徵（Crescent sign）提示侵襲性麴菌感染（*Aspergillus*）。 |
| **腹部顯影 CT / 超音波** | 評估不明發熱時的微小膿瘍、盲腸壁厚度及深部念珠菌病 | **關注標準**：盲腸壁增厚（Typhlitis 診斷依據）；造血恢復期肝脾出現「牛眼徵（Bull's-eye lesions）」提示慢性瀰漫性念珠菌病。 |
| **鹼性磷酸酶 (ALP)** | 嗜中性球恢復期不明熱之微小肝脾浸潤標記 | **關注標準**：ANC 回升時 ALP 不明原因升高，需高度警惕肝脾念珠菌病（Hepatosplenic candidiasis）。 |

## 三、 關鍵機制詳解與重點筆記

### 1. 免疫受損架構與病原體對應光譜（Tables 74-1 & 74-3）
- **脾臟清除功能喪失（Splenectomy / Functional Asplenia）**：
  - 機制：失去對莢膜抗原之網狀內皮清除及調理素吞噬能力。
  - 高危病原：肺炎鏈球菌（*S. pneumoniae*）、腦膜炎雙球菌（*N. meningitidis*）、流感嗜血桿菌（*H. influenzae*），以及原蟲 *Babesia*、動物咬傷相關之 *Capnocytophaga canimorsus*。
- **細胞免疫受損（T 細胞抑制 / 類固醇 / Fludarabine / 抗 TNF）**：
  - 易感病原：細胞內寄生菌（結核分枝桿菌、李斯特菌 *Listeria*、沙門氏菌）、黴菌（隱球菌 *Cryptococcus*、組織胞漿菌）與病毒（HSV、VZV、CMV、EBV 誘發淋巴增生症、JC 病毒誘發 PML）。
- **體液免疫受損（B 細胞清除 / 抗 CD20 / 多發性骨髓瘤 / CLL）**：
  - 失去專一性抗體產生能力，易發生反覆性莢膜菌呼吸道感染與伺機性病毒活化。

### 2. 特殊臨床症候群的病理機制與鑑別
- **嗜中性球低下性小腸結腸炎（Typhlitis / 盲腸炎）**：
  - 機制：化療引起腸黏膜缺血壞死，常駐腸內陰性菌與厭氧菌侵入腸壁，造成右下腹壓痛、發燒、甚至腹瀉血便；首選顯影 CT 確認腸壁增厚，多數採取廣效抗生素保守治療以避免穿孔。
  - 盲腸炎應與 *C. difficile* 腸炎鑑別（化療本身即使未用抗生素亦為 *C. difficile* 高危險群）。
- **嗜中性發熱性皮病（Sweet Syndrome）**：
  - 特徵：好發於 AML，表現為臉部、頸部與上肢無水泡的紅紫斑塊，伴隨高熱與 ESR 劇增。組織學為真皮下層密集白血球浸潤伴水腫，對高劑量類固醇（Prednisone 60 mg/d）反應顯著。
- **血管導管相關感染（Catheter-Related Infections）**：
  - **隧道感染（Tunnel-site erythema）**：沿皮下導管紅腫，**必須立即拔除導管**，否則恐致廣泛壞死與深層蜂窩組織炎。
  - **強制拔管指徵**：綠膿桿菌（*P. aeruginosa*）、念珠菌（*Candida*）、金黃色葡萄球菌（*S. aureus*）、腸球菌、困難陰性菌（*Stenotrophomonas*, *Acinetobacter*, *Burkholderia*）及分枝桿菌感染。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 預防性抗微生物介入準則
- **肺囊蟲肺炎（PJP/PCP）化學預防**：
  - **適應症**：ALL 病患、非何杰金氏淋巴瘤、接受高劑量類固醇治療或抑制 T 細胞訊號療法者。
  - **首選**：Trimethoprim-sulfamethoxazole (TMP-SMX)，需維持至化療與高劑量類固醇結束。
- **長天期嗜中性球低下之預防**：
  - 預期 ANC $<500/\mu\text{L}$ 超過 7 天者，口服 Fluoroquinolone（Ciprofloxacin 或 Levofloxacin）可顯著降低菌血症發生率與總體死亡率。
  - 預防性抗黴菌藥：針對高風險血液腫瘤病患，口服 Posaconazole 能有效預防侵襲性麴菌感染。

### 2. 營養防護與微生態屏障管理（Dietary & Microbiome Strategy）
- **「低菌飲食」（Low-Bacteria Diet）實踐原則**：
  - 烹調需徹底全熟，嚴格禁止生食（生菜沙拉、生魚片、未經巴氏消毒之牛奶、生乳酪、生冷熟食切片肉品）。
  - 防範李斯特菌（*Listeria*）與綠膿桿菌（*P. aeruginosa*）等食源性病原穿透化療脆弱之腸黏膜。
- **維持口腔與腸道微生態完整度**：
  - 積極口腔護理，減少放射/化療性黏膜炎（Oral mucositis），降低草綠色鏈球菌（*Viridans Streptococci*）破壁引發菌血症。
  - 審慎使用制酸劑與廣效抗生素，避免腸道微生態重度失衡（Dysbiosis）誘發致命性 *C. difficile* 偽膜性腸炎。

### 3. 環境阻斷、淋巴引流與生活型態防護
- **空氣傳播真菌之物理屏障**：
  - 醫療環境應配備高效率空氣過濾（HEPA）系統；院內周邊若有施工拆除工程，麴菌孢子負荷劇增，重度骨髓抑制患者應嚴格迴避。
  - 醫護人員與照護者「嚴格落實洗手」是阻斷院內抗藥性菌株移行的首要步驟。
- **淋巴水腫與解剖屏障減壓**：
  - 乳癌根治術或大範圍淋巴結廓清術後，患側肢體需防範淋巴水腫，避免任何微小穿刺傷、抽血、量血壓，防範鏈球菌與葡萄球菌引發頑固蜂窩性組織炎。
- **黏膜外傷阻斷**：
  - 嗜中性球低下期間禁止量測肛溫、灌腸、肛門指診；避免任何可能造成黏膜顯微破損之性行為（嚴禁糞口途徑接觸），防止腸道病原菌瞬時侵入血液引發感染性休克。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實發燒即刻經驗性投藥（Door-to-Antibiotic Time）**：
   - 腫瘤病患一旦出現發熱（$\ge 38.3^\circ\text{C}$ 或持續 $\ge 38.0^\circ\text{C}$）伴隨 ANC $<500/\mu\text{L}$，應於 1 小時內抽取兩套血液培養並立即給予廣效抗假單胞菌單一 $\beta$-內醯胺類抗生素（如 Cefepime、Piperacillin/tazobactam），嚴禁因等待檢驗結果延誤治療。
2. **遵守 4～7 天真菌升級窗口**：
   - 嗜中性球低下不明熱病患經廣效抗生素治療 4～7 天仍持續發燒者，切忌盲目更換或疊加抗陰性菌抗生素，應即時啟動經驗性抗黴菌治療（Echinocandin 或 Voriconazole），並排程胸部 HRCT 與血清真菌抗原檢測。
3. **高危管路紅線警戒與果斷拔管**：
   - 每日評估中央靜脈導管，凡皮下隧道紅腫（Tunnel infection）或血液培養出金黃色葡萄球菌、綠膿桿菌、念珠菌時，應視為「絕對拔管指徵」，不可單靠藥物保守治療。
4. **辨識造血重建期的免疫反彈表徵**：
   - 當嗜中性球回升時出現持續發燒、右上腹不適與 ALP 顯著上升，應高度警覺為「肝脾念珠菌病」，切勿誤判為抗生素無效而過度治療，應安排腹部影像學評估靶向抗真菌療程。
