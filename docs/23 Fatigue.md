# 臨床醫學指引：疲勞（Fatigue）的病理生理機轉、鑑別診斷與全方位臨床處置策略

- **主講人/來源**：Jeffrey M. Gelfand, MD; Vanja C. Douglas, MD（摘錄自 *Harrison's Principles of Internal Medicine*, 21st Edition, Chapter 23 "Fatigue"）/ `23 Fatigue.pdf`
- **核心主旨**：疲勞為多重系統失衡、神經免疫反應與精神心理因素交織的主觀表徵；臨床上必須精準區分「真性肌無力、嗜睡與勞力性呼吸困難」，採取階梯式實驗室篩檢與多模態身心復健策略，以避免無謂的過度醫療與過度檢查。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **中樞神經免疫與發炎軸線**：促發炎細胞因子（特別是 **IL-1α、IL-1β 與 TNF-α**）活化中樞神經系統發炎反應，干擾神經傳導物質代謝與能量感知，是慢性感染後（如 SARS-CoV-1/2、Ebola）、自體免疫與腫瘤性疲勞的核心驅動路徑。
  - **能量代謝與內分泌失衡**：下視丘-腦下垂體-腎上腺軸（HPA axis）失調、隱性腎上腺功能不全、甲狀腺低下、粒線體產能受損（如低鐵蛋白導致之酵素系統低落）及維生素 D 缺乏，共同促成細胞能量匱乏與中樞疲勞感。
  - **神經肌肉訊號傳導障礙**：區分上/下運動神經元損傷、神經肌肉交界處傳導疲勞（如重症肌無力 Myasthenia Gravis）與意向性出力困難（Breakaway weakness）。

- **演講亮點與臨床洞察**：
  - **診斷率的「臨床倒置現象」**：在不明原因慢性疲勞的評估中，**常規理學檢查的病因確診率僅約 2%**，**廣泛實驗室抽血確診率僅約 5%**；相反地，**詳細的神經精神與心理狀態評估（Mental Status Exam）可解釋高達 75%–80% 的慢性疲勞案例**。
  - **過度檢查（Diagnostic Cascade）危害**：盲目進行全身影像掃描（Whole-body imaging）或無適應症的自體抗體（如低價數 ANA）篩檢，極易產生無臨床意義的偶見瘤（Incidentalomas）與假陽性，不僅無法解決疲勞，反增添患者焦慮與醫療負擔。
  - **多模態長期療效驗證**：大型臨床試驗（如 PACE Trial）證實，**認知行為治療（CBT）** 與 **分級漸進式運動療法（Graded Exercise Therapy, GET）** 能帶來顯著且長期維持（追蹤 2.5 年）的功能改善，優於單純常規醫療照護。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

臨床面對未明原因的慢性疲勞，建議採取**聚焦、階梯式**的檢驗策略：

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（參考文獻指引） |
| :--- | :--- | :--- |
| **全血球計數與分類 (CBC with diff)** | 排除潛在感染、嚴重慢性貧血或血液惡性腫瘤 | 血紅素正常，白血球分類無異常 Blast 或顯著核左移 |
| **血清鐵蛋白 (Serum Ferritin)** | 評估體內鐵儲存量；**低鐵蛋白即使在無貧血狀態下亦會引發細胞缺氧性疲勞** | 關注是否處於低儲存狀態；低於參考區間時補鐵具逆轉效應 |
| **促甲狀腺素與游離甲狀腺素 (TSH / Free T4)** | 評估甲狀腺功能亢進（伴心悸、盜汗）或低下（伴水腫、怕冷、便秘） | TSH 維持在臨床最佳參考區間內 |
| **基礎電解質 (Na, K, Ca)** | 排除腎上腺功能不全（低鈉、高鉀）、惡性腫瘤或副甲狀腺引發之高血鈣（致發呆呆滯） | 血鈣正常；血鈉與血鉀平衡無低鈉高鉀表徵 |
| **空腹血糖 (Fasting Glucose)** | 排除高血糖、低血糖及第 1/2 型糖尿病引起的代謝性疲乏 | 血糖穩定，避免劇烈血糖波動引發之中樞疲倦 |
| **肝腎功能指標 (Cr, eGFR, AST/ALT, Bilirubin)** | 評估慢性腎臟病（血液透析患者 >80% 具重度疲勞）及慢性肝衰竭 | 排除代謝廢物毒素蓄積引發之尿毒性/肝性腦病前驅疲勞 |
| **25-羥基維生素 D [25(OH)D]** | 評估全身免疫調節、骨骼肌機能與神經內分泌健康 | 臨床文獻指引：偏低狀態補充維生素 D 能顯著改善疲勞 |
| **晨間皮質醇與腎上腺刺激試驗** | 評估原發性或次發性腎上腺機能不全（合併低血壓、色素沉著、消瘦） | 早晨皮質醇分泌曲線正常，必要時進行 ACTH 刺激試驗 |
| **紅血球沉降率 (ESR) / 選擇性 ANA** | 排除隱匿性發炎性風濕免疫疾病（狼瘡、多發性肌痛風濕症、血管炎） | **不建議常規無指徵篩檢**；僅在具備典型系統性徵兆或 ESR 極度升高時深入追查 |

## 三、 關鍵機制詳解與重點筆記

### 1. 症狀鑑別本質學：疲勞 vs. 肌無力 vs. 嗜睡 vs. 呼吸困難
臨床診斷首要任務為語意與生理學拆解：
- **疲勞（Fatigue）**：主觀感受上的身體與心智疲憊、低能量、無動力，臨床操作型定義為「**難以啟動或維持自主性的心智與肢體活動**」。
- **真性肌無力（True Muscle Weakness）**：神經肌肉動力輸出的客觀減損。神經學徒手肌力測試（Confrontational testing）可明確鑑別：
  - *皮質脊髓路徑/運動單元病變*：肌力呈現平穩但持續無法抵抗阻力（Smooth, steady weakness）。
  - *疲勞/精神心理因素*：呈現**突發性脫力（Breakaway weakness）**，即受試者一開始能發出短暫全力，隨後突然放棄崩塌。
  - *神經肌肉交界處病變（如重症肌無力）*：表現為**易疲勞性肌無力（Fatigable weakness）**，反覆收縮後肌力明確遞減，但絕不具備突發脫離的特徵。
- **日間嗜睡（Somnolence）**：睡眠-清醒節律生理障礙所致之過度困倦，多源於阻塞型睡眠呼吸中止症（OSA）或嚴重睡眠剝奪。
- **勞力性呼吸困難（Dyspnea on exertion）**：常反映心肺功能衰竭（如 CHF、COPD），需透過胸部影像、心臟超音波與肺功能檢查鑑別。

### 2. 神經發炎網絡與細胞因子媒介（Neuroinflammation & Proinflammatory Cytokines）
- 身體發炎反應中釋放的促發炎細胞因子（**IL-1α、IL-1β、TNF-α**）可透過體液與迷走神經傳導路徑影響中樞神經系統，活化微小膠質細胞，改變基底核與邊緣系統功能，進而產生病態行為模式（Sickness Behavior）與頑固性疲勞。
- **感染後疲勞（Post-infectious Fatigue）**：感染單核白血球增多症（EBV）、SARS-CoV-1、SARS-CoV-2、伊波拉病毒後，部分患者發炎反應未完全平息，促使神經免疫長期活化，成為慢性疲勞症候群（ME/CFS）的核心致病環節。

### 3. 多系統實體器質性病變的疲勞特徵
- **心血管與肺部疾病**：心臟衰竭與 COPD 帶來長期的心輸出量下降與慢性組織缺氧。英國大型世代研究（EPIC-Norfolk）指出，疲勞與一般族群的全因死亡率上升顯著相關，尤其與心血管死亡風險關聯最強。
- **腫瘤與副腫瘤症候群**：癌因性疲憊（Cancer-related fatigue）在診斷時盛行率達 40%，疾病進程中更高達 80% 以上。
- **肥胖與生活型態沉痾**：肥胖患者常伴隨體內慢性低度發炎；接受減重代謝手術之患者，其日間精神改善往往早於大幅減重與睡眠呼吸中止緩解的時間點，證實脂肪發炎毒素與代謝混亂對中樞疲勞的直接負面衝擊。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

面對多成因的慢性疲勞，必須採取**結合營養代謝調控、行為認知重塑與藥物減法**的整合處方：

### 1. 功能性營養素與代謝支持
- **標靶維生素 D 矯正**：針對檢測確認為維生素 D 缺乏/不足者，進行積極補充至理想生理濃度，臨床實證能有效減輕主觀疲勞感並活化免疫。
- **無貧血性低鐵蛋白補充策略**：若血清鐵蛋白（Ferritin）偏低，即使無臨床貧血（Hb 正常），亦建議適度口服或靜脈補鐵，因鐵為粒線體電子傳遞鏈（細胞色素複合物）關鍵輔因子，鐵補充足夠後疲勞具高度可逆性。
- **藥物審查與減法醫療（Deprescribing）**：詳細審查各類誘發性藥物，包括中樞抗憂鬱劑、抗精神病藥、安眠鎮靜劑、抗痙攣劑、抗癲癇藥及 $\beta$-阻斷劑。若療效不明顯或產生嗜睡副作用，應考慮減量或停藥。
- **精神興奮劑之審慎評估**：隨機對照試驗顯示，Modafinil、Armodafinil 或安非他命類藥物對創傷性腦損傷（TBI）、帕金森氏症、癌症及多發性硬化症所致之疲勞療效有限，不建議常規作為疲勞的第一線處方。

### 2. 生活型態與神經行為介入
- **分級漸進式運動療法（Graded Exercise Therapy, GET）**：
  - 運動模式以步行等低衝擊帶氧運動為主。
  - **嚴格監控目標心率（Target Heart Rate）**，由極低強度開始逐週微幅增加時間與步數，**嚴格預防用力過度後引發之勞動後症狀加劇（PEM）與病情崩潰**。
- **認知行為治療（Cognitive-Behavioral Therapy, CBT）**：
  - 破除「活動必引發崩潰」之恐懼迴避迴圈（Fear-avoidance loop），重構患者對疲勞感受的認知評估。
  - PACE 大型臨床試驗證實 CBT 與 GET 能顯著改善行走距離與疲勞自評指標，且療效可維持數年。
- **睡眠衛生全面優化**：
  - 規律就寢/起床時間，阻絕睡前藍光與酒精攝取；若合併打鼾與肥胖，應及早安排多項睡眠生理檢查（PSG）以鑑別與治療 OSA。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **確立主訴邊界，精準執行神經學檢查**：
   - 藉由徒手肌力對抗測試，區分**真性肌無力**與**突發性脫力（Breakaway weakness）**；若懷疑重症肌無力，需評估重複活動後的**易疲勞性減弱（Fatigable weakness）**與安排肌電圖（EMG/NCS）。
2. **優先進行精神心理與神經精神狀態篩檢**：
   - 詢問憂鬱、焦慮、創傷壓力與重大生活變故。臨床 75% 以上的長期未明疲勞可歸因於或共病精神心理失調，及早導入多模態諮商是治本關鍵。
3. **拒絕非特異性全面篩檢，實施精準實驗室檢查**：
   - 第一線常規項目：CBC with diff、電解質（Na, K, Ca）、血糖、肝腎功能、TSH、Ferritin、Vitamin D。
   - **避免在缺乏臨床關聯下常規檢驗 ANA 或全身 CT/MRI**，以免誘發無謂的侵入性切片與醫療焦慮。
4. **排除紅旗警訊（Red Flag Symptoms）**：
   - 若合併不明原因體重減輕、發燒、畏寒、夜間盜汗、淋巴結腫大或器官腫大，應優先排查隱匿性惡性腫瘤、結核病、HIV、心內膜炎等重大感染與消耗性疾患。
5. **落實雙軌治療架構（醫患同盟與漸進康復）**：
   - 面對慢性疲勞症候群（ME/CFS）與長期疲勞個案，建立互信的治療同盟；採用**漸進式運動訓練（GET）搭配認知行為治療（CBT）**，設定切實的生活步調，以提升生活品質與日常自主功能為首要目標。
