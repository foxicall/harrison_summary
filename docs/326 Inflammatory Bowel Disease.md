# 發炎性腸道疾病（IBD）之病理機轉、精準評估與全方位整合治療策略
- **主講人/來源**：326 Inflammatory Bowel Disease.pdf（Sonia Friedman, Richard S. Blumberg / *Harrison's Principles of Internal Medicine*）
- **核心主旨**：剖析發炎性腸道疾病（克隆氏症 CD 與潰瘍性結腸炎 UC）在遺傳易感性、腸道微菌叢共生失調、上皮屏障受損及免疫耐受崩解下的病理生理連鎖反應，整合現代標靶生物製劑、精準臨床檢驗及以腸道微生態修復為核心的營養治療方針。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **三方平衡失調（Tridirectional Dysregulation）**：宿主基因（如 *NOD2*、*ATG16L1*、*XBP1*）、腸黏膜上皮屏障（IECs）與共生菌叢（Microbiota）三者失衡。在環境觸發物（如抗生素、高 $\omega$-6 與超加工飲食、NSAIDs、感染、壓力）刺激下，導致對共生菌群失去**「口服/黏膜免疫耐受（Oral Tolerance）」**。
  - **微生態共生失衡（Dysbiosis）**：致病性細菌增加（如變形菌門 *Proteobacteria*、侵入性大腸桿菌 *AIEC*），抗發炎益菌銳減（如厚壁菌門之普氏糞桿菌 *Faecalibacterium prausnitzii*），進而驅動過度活化的 $\text{T}_{\text{H}}1$（CD, 透壁發炎/肉芽腫）、$\text{T}_{\text{H}}2$（UC, 黏膜淺層病變）及 $\text{T}_{\text{H}}17$ 免疫發炎瀑布。
- **演講亮點與臨床洞察**：
  - **表型光譜與非典型表現**：發炎性腸道疾病不僅局限於消化道，高達三分之一的病患併發關節、皮膚、眼睛或肝膽（如原發性硬化性膽管炎 PSC）等腸外表現（EIMs）。
  - **飲食與全腸道營養療法（EEN）實證**：在活動期克隆氏症中，全腸道營養（Exclusive Enteral Nutrition, EEN）誘導緩解的成功率**等同於全身性皮質類固醇**，凸顯阻斷腸道外源抗原暴露與重整微生態對修復黏膜屏障的關鍵價值。
  - **深層緩解（Deep Remission）目標轉移**：從單純臨床症狀改善，進步到內視鏡與組織學上的黏膜癒合（Mucosal Healing），方能扭轉纖維狹窄或瘻管等不可逆器官損傷。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **糞便鈣衛蛋白 (Fecal Calprotectin)** | 嗜中性球與單核球發炎指標；鑑別 IBS 與 IBD、監測黏膜發炎與術後/儲袋炎復發 | 臨床緩解目標通常希望回歸正常基準；顯著升高反映活動性腸道發炎 |
| **糞便乳鐵蛋白 (Fecal Lactoferrin)** | 活化嗜中性球釋放之醣蛋白；極高敏感度與特異度反映腸道發炎 | 陰性 / 正常參考值以內 |
| **CRP 與 ESR** | 全身性急性期發炎反應物；CD 較敏感，遠端直腸炎（UC）常不升高 | 緩解期 CRP 應回歸正常；重度 UC 評估標準為 $\text{ESR} \ge 30\text{ mm/h}$ |
| **血清白蛋白 (Albumin)** | 反映蛋白質流失性腸病變（Protein-losing enteropathy）與系統性高代謝消耗 | 急性嚴重期快速下降；需維持於正常範圍以確保藥物（如 Infliximab）半衰期 |
| **血清血紅素 (Hemoglobin)** | 評估慢性腸道失血與腸道吸收不良引起的混合型貧血 | 嚴重活動期：$\text{Hb} < 10.5\text{ g/dL}$（伴隨重度出血） |
| **ASCA 與 pANCA 血清抗體** | 輔助鑑別 CD（ASCA$^+$ / pANCA$^-$）與 UC（pANCA$^+$）；特異度高（93%）但敏感度偏低（55%） | 依臨床疑義型結腸炎（Indeterminate Colitis）鑑別使用 |
| **血清微量營養素 (B12, 葉酸, 鐵, Vit D, 鋅, 硒)** | 評估迴腸末端或廣泛小腸病變造成之消化吸收障礙、骨質疏鬆與貧血風險 | 定期監測，尤其長期腹瀉、切除手術或類固醇使用者 |
| **雙能量 X 光骨質密度吸收儀 (DEXA)** | 評估發炎細胞激素驅動及長期皮質類固醇導致之低骨質密度（14–42%）與骨質疏鬆 | 預防骨折，高風險族群（年齡 >60、長期用藥）應常規追蹤 |

## 三、 關鍵機制詳解與投影片重點筆記

- **腸道微生態、屏障功能與黏膜免疫耐受機轉（圖 326-1）**：
  - **恆定態維護**：正常生理狀態下，調節性 T 細胞（Treg，表現 $\text{FoxP3}^+$）分泌抗發炎細胞激素（如 IL-10、TGF-$\beta$、IL-35），壓制對共生菌叢與飲食蛋白質的免疫反應。
  - **自噬與內質網壓力（ER Stress）**：基因變異（如 *NOD2* 胞內受體缺陷阻礙細菌識別、*ATG16L1* 突變影響自噬體清除、*XBP1* 缺陷導致上皮細胞未摺疊蛋白質反應失常），使腸上皮凋亡增加，管腔抗原無防阻地透入固有層（Lamina Propria）。
  - **細胞激素網絡瀑布**：巨噬細胞與樹突細胞釋放 IL-1、IL-6、IL-12、IL-23 與 TNF，進一步募集白血球經由內皮細胞上的 $\alpha_4\beta_7$ 整合素與 MAdCAM-1 黏附分子浸潤組織，形成無法止息的自體發炎迴路。

- **病理型態學與組織學鑑別特徵（圖 326-3 至 326-6）**：
  - **潰瘍性結腸炎 (UC)**：
    - *巨觀*：病變侷限於黏膜與黏膜下層；始於直腸，連續性向近端延伸；黏膜脆易出血、顆粒狀（砂紙樣）、偽息肉（Pseudopolyps）；無腸壁肥厚。
    - *微觀*：隱窩結構扭曲、分叉、萎縮，隱窩基底與黏膜肌層間隙增加；基底漿細胞增多（Basal lymphoplasmacytosis）、中性粒細胞浸潤形成隱窩炎（Cryptitis）與隱窩膿瘍（Crypt abscesses）。
  - **克隆氏症 (CD)**：
    - *巨觀*：全層透壁性發炎（Transmural）；好發迴腸末端但可侵犯全消化道；節段性分佈（跳躍性病灶 Skip lesions）；鵝卵石樣外觀（Cobblestoning）、深層縱向裂隙潰瘍；腸繫膜爬行脂肪（Creeping fat）、腸壁纖維化增厚導致管腔狹窄與瘻管。
    - *微觀*：非乾酪性肉芽腫（Noncaseating granulomas，於各層可見）、黏膜下層淋巴濾泡聚集、透壁性裂隙。

- **腸道外表現（EIMs）與自體免疫共病關聯**：
  - **發炎平行型（活動度與腸道一致）**：周邊關節炎（非對稱、大關節、遊走型）、結節性紅斑（Erythema nodosum）、結膜炎/鞏膜外層炎、口瘡性潰瘍。
  - **發炎獨立型（與腸道活動度脫鉤）**：僵直性脊椎炎（AS，約 2/3 為 HLA-B27$^+$）、壞疽性膿皮症（Pyoderma gangrenosum，常與嚴重病變相關，禁用手術清創）、葡萄膜炎（Uveitis，需防視力受損）、原發性硬化性膽管炎（PSC）。
  - **代謝併發症**：小腸末端病變/切除導致膽鹽重吸收失敗，膽酸池耗竭引發**膽結石**；未吸收脂肪酸結合鈣質，使游離草酸吸收過度而引發高草酸尿症併發**草酸鈣腎結石**。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **功能性營養素/微量元素補充方針**：
  - **活性維生素 D (Vitamin D3)**：強效免疫調節劑，文獻指出其充足濃度對 CD 具有保護效應，並可減緩長期類固醇引發之骨質流失（建議追蹤 25-OH-D 並維護於最適機能水準）。
  - **水溶性葉酸 (Folic Acid)**：Sulfasalazine 會抑制葉酸吸收，常規給予葉酸補充以預防骨髓抑制與同半胱胺酸升高；MTX 使用者亦需配合調整。
  - **鐵劑補給（首選靜脈輸注）**：由於活動性發炎時腸道黏膜對口服鐵劑耐受不良、吸收率極低且容易加劇腸道發炎與菌相失衡，嚴重貧血患者應優先採用靜脈鐵劑注射。
  - **脂溶性維生素與微量礦物質**：廣泛小腸病變或短腸病患需每日補充綜合維生素、維生素 A、E、K、鈣，以及鋅（Zinc）、硒（Selenium）、銅（Copper）與鎂（Magnesium），以維持黏膜修復酵素機能。

- **飲食策略與腸道休息療法**：
  - **全腸道營養 (Exclusive Enteral Nutrition, EEN)**：活動性小腸型 CD 誘導緩解之一線非藥物選擇（尤其適用於兒童或避免全身性類固醇副作用之成年人），提供腸黏膜修復所需基質，降低抗原刺激。
  - **抗發炎飲食結構**：
    - *避開誘發因子*：嚴格限制飽和動物性脂肪、超加工食品、精緻糖類、甜味飲料、以及高比例 $\omega$-6 多元不飽和脂肪酸。
    - *保護性模式*：採用地中海飲食架構、特異碳水化合物飲食（SCD）或發炎性腸道疾病抗發炎飲食（IBD-AID），依個別腸道狹窄情況漸進攝取富含可溶性纖維的蔬果。
    - *小腸吸收障礙之限制*：若有草酸鈣結石病史，應採取**低草酸飲食**（避免濃茶、菠菜、堅果等過量），並隨餐攝取適量鈣質結合草酸。

- **環境毒素阻斷與生活型態調節**：
  - **抽菸之雙重性與戒菸指導**：抽菸顯著增加 CD 發病率（OR 1.76）及術後早期復發率，CD 患者**必須徹底戒菸**；雖然抽菸在 UC 呈現負相關（OR 0.58），但全面健康評估下仍不建議吸菸作為治療手段。
  - **避免腸黏膜毒性藥物**：全面停用非類固醇消炎止痛藥（NSAIDs），防止黏膜前列腺素合成受抑導致潰瘍破壞或誘發急性復發。
  - **壓力調節與腸腦軸支持**：神經內分泌壓力軸直接活化肥大細胞並改變腸道黏膜通透性，應整合規律生理時鐘睡眠與壓力釋放技巧。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實非侵入性發炎客觀監測**：對表現輕微腹瀉但懷疑發炎者，常規安排**糞便鈣衛蛋白（Fecal Calprotectin）**與 **CRP** 檢驗，精準鑑別是大腸激躁症（IBS）抑或 IBD 復發，避免過度依賴主觀症狀。
2. **啟動全方位營養與骨質篩檢防護網**：確診或長期追蹤之 IBD 患者，特別是有小腸受累、切除史或曾使用類固醇者，常規排檢 **DEXA 骨質密度**，並檢測**維生素 D、鐵蛋白（Ferritin）、葉酸、B12、鋅、鎂**，及時給予靜脈或標靶營養補充。
3. **高風險族群早期升階治療（Treat-to-Target）**：對於年齡 <30 歲、廣泛性侵犯、具深層潰瘍或瘻管型 CD 高危險群，及早評估抗 TNF（如 Infliximab/Adalimumab）、抗整合素（Vedolizumab）或抗 IL-12/23 等生物製劑合併免疫調節劑，以達到深度黏膜癒合。
4. **評估手術時機與落實癌症監測計畫**：患病病程超過 8–10 年的廣泛性結腸炎或合併原發性硬化性膽管炎（PSC）患者，每年或每 2 年應使用**色素內視鏡（Chromoendoscopy）**進行常規黏膜異生（Dysplasia）篩檢；對狹窄無法通過之病灶保持高度惡性警覺。
