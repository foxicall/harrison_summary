# 酸鹼平衡紊亂之病理生理、臨床評估與代謝調控全解析
- **主講人/來源**：Thomas D. DuBose, Jr. / 55 Acidosis and Alkalosis.pdf
- **核心主旨**：系統性剖析代謝性與呼吸性酸鹼紊亂之代償機制、陰離子隙（Anion Gap）與滲透壓隙評估，並將臨床急性處置延伸至功能醫學視角下之粒線體能量代謝、穀胱甘肽耗竭、電解質動態平衡與慢性酸負荷對骨骼與肌肉衰老的衝擊。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - 動脈血 pH 嚴格維持於 7.35～7.45，仰賴細胞內外化學緩衝、肺臟通氣調節（$Paco_2$）及腎臟排酸保鹼（$[HCO_3^-]$）之協同作用。
  - 當內生性有機酸生成過剩（乳酸、酮體）、外源性毒素累積、腎臟淨酸排泄受損或腸道/腎臟重碳酸鹽過度流失，即引發酸中毒；反之，胃酸/非揮發酸流失、細胞外液容積（ECFV）收縮合併低氯低鉀，或鹽皮質素自主性過量則維持鹼中毒。
  - **衰老與退化驅動**：慢性低度代謝性酸中毒（如慢性腎病 CKD 早期至晚期）會持續活化骨骼碳酸鈣緩衝系統，造成骨質嚴重流失（骨質疏鬆），並誘發肌肉蛋白分解與分解代謝加速（肌少症）。
- **演講亮點與臨床洞察**：
  - **白蛋白校正陰離子隙之必要性**：血清白蛋白是體內最重要的未測定陰離子，每下降 1.0 g/dL，實測 AG 需上修 2.5 mmol/L，避免低白蛋白血症掩蓋真實的高陰離子隙酸中毒。
  - **穀胱甘肽耗竭之隱形危機**：對乙醯胺酚（Acetaminophen）在營養不良或危重症患者體內會耗竭細胞內穀胱甘肽，引發焦麩胺酸（5-oxoproline / pyroglutamic acid）堆積，造成典型無滲透壓隙升高的 HAGMA。
  - **生理代償極限法則**：單純性酸鹼紊亂之生理代償「僅能使 pH 趨近、但絕不能完全回到正常值」；**慢性呼吸性鹼中毒**是臨床上「唯一」能藉由腎臟完全代償而使 pH 回復至正常範圍的特例。
  - **飲食內生性鹼負荷之長壽意涵**：在 CKD 3～4 期非陰離子隙酸中毒中，適度給予鹼劑或富含蔬果（有機檸檬酸鹽前驅物）之飲食，能顯著減緩腎功能衰退速度並保存肌肉骨骼量。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **動脈血氣分析 (pH / $Paco_2$ / $HCO_3^-$)** | 評估即時酸鹼狀態、通氣驅動及原發/代償軸向 | pH: 7.35～7.45<br>$Paco_2$: ~40 mmHg<br>血清 $[HCO_3^-]$: 24～26 mmol/L |
| **血清陰離子隙 (Serum Anion Gap, AG)** | 區分高陰離子隙（HAGMA）與正常陰離子隙（NAGMA）代謝性酸中毒 | 正常值基準約 10 mmol/L（範圍 6～12 mmol/L）<br>公式：$Na^+ - (Cl^- + HCO_3^-)$ |
| **校正陰離子隙 (Corrected AG)** | 排除低白蛋白血症造成的假性正常 AG | 若白蛋白 <4.5 g/dL：<br>校正 AG = 實測 AG + $2.5 \times (4.5 - \text{Albumin})$ |
| **滲透壓隙 (Osmolar Gap)** | 篩檢未測定的外源性小分子溶質（毒性醇類中毒） | 正常差值 <10～15 mOsm/kg $H_2O$<br>計算值：$2Na^+ + \frac{Glu}{18} + \frac{BUN}{2.8}$ |
| **$\Delta\text{AG} / \Delta\text{HCO}_3^-$ ($\Delta/\Delta$ 比值)** | 鑑別隱匿性混合型代謝性障礙（共存代謝性鹼中毒或非隙酸中毒） | $\Delta\text{AG} = \text{實測 AG} - 10$<br>$\Delta\text{HCO}_3^- = 25 - \text{實測 } [HCO_3^-]$<br>$\Delta\text{AG} \gg \Delta\text{HCO}_3^-$ 提示共存代謝性鹼中毒 |
| **尿陰離子隙 (Urine Anion Gap, UAG)** | 間接評估腎臟排銨（$NH_4^+$）能力，鑑別腹瀉與腎小管酸中毒 (RTA) | 公式：$[Na^+ + K^+]_u - [Cl^-]_u$<br>負值：尿銨適當增加（腸道流失）<br>正值：尿銨排泄障礙（RTA） |
| **焦麩胺酸 (5-Oxoproline)** | 評估對乙醯胺酚誘發之穀胱甘肽耗竭與粒線體代謝阻斷 | 懷疑藥物毒性之不明原因 HAGMA 時檢測 |
| **尿氯濃度 ($[Cl^-]_u$)** | 鑑別代謝性鹼中毒之生理病因（反應型 vs 抗性型） | $<20\text{ meq/L}$：容積/氯反應型（嘔吐、利尿劑後）<br>$>20\text{ meq/L}$：容積擴張/醛固酮過量型 |

## 三、 關鍵機制詳解與投影片重點筆記

- **機制 1：代償反應公式與混合型酸鹼障礙之精準辨識**
  - **代謝性酸中毒之呼吸代償（Winter's Equation）**：
    $$\text{預期 } Paco_2 = (1.5 \times [HCO_3^-]) + 8 \pm 2$$
    若實測 $Paco_2$ 低於預期值，代表合併原發性呼吸性鹼中毒（如敗血症早期、水楊酸中毒）；若高於預期值，則代表合併呼吸性酸中毒（如 COPD 呼吸肌疲勞）。
  - **代謝性鹼中毒代償**：$[HCO_3^-]$ 每增加 1 mmol/L，$Paco_2$ 上升約 0.75 mmHg（或每 10 mmol/L 上升 6 mmHg）。
  - **呼吸性障礙的急慢性分水嶺**：
    - *急性呼吸性酸/鹼中毒*：細胞內非碳酸氫鹽緩衝主導，每改變 10 mmHg $Paco_2$，$HCO_3^-$ 僅相應同向變動 1～2 mmol/L。
    - *慢性呼吸性酸/鹼中毒（>24～72小時）*：腎臟近端與遠端腎小管進行重吸收/排泄代償，$Paco_2$ 每改變 10 mmHg，$HCO_3^-$ 變動可達 4～5 mmol/L。
  - **反向變動即為混合型**：若 $Paco_2$ 與 $[HCO_3^-]$ 呈現一升一降之反向變動，必然存在混合型酸鹼失衡。

- **機制 2：高陰離子隙酸中毒（HAGMA）與粒線體/細胞氧化還原障礙**
  - **L-型乳酸中毒（Type A vs Type B）**：
    - *Type A*：組織缺氧與嚴重灌流不足（休克、心衰竭、腸道缺血）。
    - *Type B*：無組織缺氧之需氧代謝障礙。見於惡性腫瘤、粒線體呼吸鏈缺陷、抗反轉錄病毒藥物（NRTIs）、硫胺素（Thiamine, $B_1$）缺乏（丙酮酸無法進入 TCA 循環），以及雙胍類藥物或毒性醇類抑制粒線體功能。
  - **穀胱甘肽耗竭性酸中毒**：對乙醯胺酚在危重或營養不良病患體內耗竭 Glutathione，使 $\gamma$-麩胺醯循環失衡，5-oxoproline 大量生成堆積，引起無滲透壓隙增高之高 AG 代謝性酸中毒。
  - **毒性醇類動態轉化**：乙二醇（Ethylene glycol）與甲醇（Methanol）中毒初期以「滲透壓隙（Osmolar Gap）」為主；隨醇去氫酶（ADH）將其轉化為乙醇酸（Glycolate）、草酸（Oxalate）或甲酸（Formate）後，滲透壓隙下降，轉而表現為顯著的「陰離子隙（AG）」。異丙醇（Isopropanol）則僅代謝為丙酮，通常只引起高滲透壓隙與低血糖，不引起 HAGMA。

- **機制 3：正常陰離子隙酸中毒（NAGMA）與慢性格局對長壽機能之損耗**
  - **成因**：胃腸道鹼流失（腹瀉）或腎臟排酸障礙（腎小管酸中毒 RTA Types 1, 2, 4）。高氯離子會代償性上升，使 AG 維持正常（Hyperchloremic acidosis）。
  - **骨骼與肌肉的代償性代價（The Skeletal-Muscle Trade-off）**：
    - 在 CKD 3～4 期，每日高達 20 mmol 之滯留酸無法排出，體內血清 $[HCO_3^-]$ 雖可因骨骼緩衝而維持穩定，但代價是骨骼中碳酸鈣（$\text{CaCO}_3$）不斷被解離釋出，造成進行性**骨礦物質流失與腎性骨病變**。
    - 慢性酸血症直接激活泛素-蛋白酶體途徑（Ubiquitin-Proteasome System），促使骨骼肌大量分解，導致**慢性肌少症、惡病質與代謝耐受力退化**。

- **機制 4：代謝性鹼中毒的「維持因子」與電解質惡性循環**
  - 產鹼（嘔吐流失 HCl）僅為「生成階段（Generation）」，鹼中毒得以「維持（Maintenance）」關鍵在於腎臟無法有效排泄過剩之 $HCO_3^-$。
  - **維持三要素**：有效循環血量不足（ECFV contraction）、低氯血症（缺少流經皮質集尿管的氯離子以交換重碳酸根）與低鉀血症（刺激近端腎小管保鹼並促使遠端泌氫）。
  - **低鉀與泌氫**：細胞內缺鉀促使氫離子移入細胞內以維持電中性，引發細胞內酸中毒，進一步刺激集尿管上皮之 $H^+/K^+$-ATPase 活性，造成反常性酸尿（Paradoxical aciduria）並惡化全身性鹼中毒。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **功能性營養素/植化素補充**：
  - **有機檸檬酸鹽（Citrate 前驅物）**：
    - *處方/建議*：檸檬酸鉀（Potassium Citrate）或檸檬酸鈉/鉀口服液（如 Shohl 氏溶液），目標使血清 $[HCO_3^-] > 22\text{～}24\text{ mmol/L}$。
    - *機轉*：檸檬酸根在肝臟被完全代謝轉化為碳酸氫鹽，能中和內生性酸負荷、抑制骨質解離，並提升尿中檸檬酸濃度以預防草酸鈣結石形成。
  - **硫胺素（Thiamine, 活性維生素 $B_1$）**：
    - *劑量*：100～200 mg/day IV 或口服。
    - *機轉*：作為丙酮酸去氫酶（PDH）之關鍵輔酶，加速丙酮酸進入三羧酸循環（TCA Cycle），切斷 Type B 乳酸中毒途徑，特別針對長期酗酒、慢性營養不良或高代謝需求病患。
  - **N-乙醯半胱胺酸 (NAC)**：
    - *機轉*：提供半胱胺酸前驅物以重建細胞內還原型穀胱甘肽（GSH）儲存池，終止對乙醯胺酚所引發的 5-oxoproline 異常蓄積。
  - **吡哆醇（Pyridoxine, 維生素 $B_6$）**：
    - *劑量*：50～100 mg/day，用於乙二醇中毒之輔助支持，引導有毒代謝物轉化為無毒之甘胺酸（Glycine）。

- **飲食與禁食策略**：
  - **高植化素/高鹼性灰分飲食（Plant-rich / Alkaline-ash Diet）**：
    - 降低富含產酸硫代胺基酸（甲硫胺酸、半胱胺酸）的精緻動物蛋白比例，大幅提升深綠色蔬菜、低糖水果（富含有機鉀鹽與檸檬酸鹽）之攝取。文獻證實可降低淨內生性產酸率（NEAP），減緩腎小球過濾率（eGFR）下降並維持骨質密度。
  - **生酮飲食與 SGLT2 抑制劑之代謝安全監控**：
    - SGLT2 抑制劑使用者若合併低碳水或禁食，易誘發非高血糖性酮酸中毒（Euglycemic DKA）；需衛教病患維持充足水分，監測血中 $\beta$-羥基丁酸（$\beta$-HB），而非僅仰賴尿糖或尿酮試紙（硝普酸反應無法檢測 $\beta$-HB）。

- **環境毒素阻斷/代謝排毒/生活型態**：
  - **外源性醇類代謝阻斷**：
    - 懷疑乙二醇或甲醇中毒時，即刻使用 Fomepizole（4-methylpyrazole，首劑 15 mg/kg IV，隨後每 12 小時 10 mg/kg）以競爭性抑制醇去氫酶（ADH），防止高毒性酸性代謝物生成。
  - **醫源性擴容酸中毒（Expansion Acidosis）之預防**：
    - 避免過度、無節制輸注大量生理食鹽水（0.9% NaCl），高濃度的氯離子會引發高氯性非陰離子隙代謝性酸中毒；需評估動態血流動力學，並適時採用平衡性晶體液（Balanced crystalloids）。
  - **水楊酸毒性排毒**：
    - 給予碳酸氫鈉鹼化尿液（維持尿 pH > 7.5），可使水楊酸在集尿管解離為離子態而阻斷再吸收，清除率可提升 5 倍以上。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實動靜脈檢驗同步化與白蛋白校正**：
   - 評估酸鹼時，必須「同時」採集動脈血氣（ABG）與血清生化電解質。判讀陰離子隙（AG）前，務必檢視血清白蛋白數值，套用校正公式（每降 1 g/dL 補 2.5 mmol/L），以免漏診危及生命的隱匿性高 AG 酸中毒。
2. **掌握 Winter 公式與 $\Delta/\Delta$ 判別混合障礙**：
   - 對於任何代謝性酸中毒，即刻計算 Winter 公式預估 $Paco_2$；若存在高 AG，接續比對 $\Delta\text{AG}$ 與 $\Delta[HCO_3^-]$。若 $\Delta\text{AG} \gg \Delta[HCO_3^-]$，代表患者背後潛藏嘔吐、利尿劑使用或鼻胃管引流所致的代謝性鹼中毒。
3. **重視慢性低度酸中毒對抗衰老的長遠破壞**：
   - 關注慢性退化性疾病與 CKD 病患的血清 $[HCO_3^-]$，目標維持在 $\ge 22\text{ mmol/L}$。藉由功能性檸檬酸鹽或鹼性蔬果飲食介入中和淨酸，是阻斷「骨質流失—肌少症—腎機能退化」惡性循環的核心抗老防線。
4. **不明原因 HAGMA 須排查穀胱甘肽耗竭**：
   - 面對重症、衰弱或營養不良且 AG 顯著升高但無高血糖、無高乳酸、滲透壓隙正常的病患，應立即回顧乙醯胺酚使用史，警惕 5-oxoproline 酸中毒，及早停藥並介入抗氧化與前驅物支持。
5. **嚴守重碳酸鈉輸注之安全邊界**：
   - 除非極度嚴重酸血症（pH < 7.00）或合併血流動力學崩潰，切忌盲目快速推注 $\text{NaHCO}_3$。過激補鹼會引發細胞內矛盾性酸中毒、低血鉀、抽搐、高血鈉及組織氧釋放障礙（Bohr 效應左移）；目標僅需平穩提升 pH 至 7.20 或 $[HCO_3^-]$ 達 10～12 mmol/L 即可。
