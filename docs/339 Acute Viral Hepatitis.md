# 急性病毒性肝炎的分子機制、臨床診斷與全人整合管理指南
- **主講人/來源**：339 Acute Viral Hepatitis.pdf（Harrison's Principles of Internal Medicine, 21e, Chap. 339, Jules L. Dienstag, MD）
- **核心主旨**：急性病毒性肝炎主要由 HAV、HBV、HCV、HDV 與 HEV 引起；其肝臟組織損傷絕非單純病毒直接細胞病變，而是宿主免疫反應、微環境發炎瀑布與代謝交互作用共同驅動的病理過程，臨床需掌握精準血清學分型與代謝/免疫支持策略。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **非直接細胞致病性（Non-cytopathic Nature）**：在常規狀態下，肝炎病毒本身對肝細胞不具直接毒性。肝細胞的壞死、凋亡與「網狀架構塌陷」本質上是由抗原特異性 CD8+ 毒殺型 T 細胞（CTL）、NK 細胞過度活化，以及促發炎細胞因子（TNF-α、IFN-γ）引發的免疫清除反應。
  - **免疫耐受與 T 細胞耗竭**：新生兒/垂直感染 HBV 會因在子宮內接觸可穿過胎盤的 HBeAg 而誘發深度的 T 細胞耐受；成人期慢性化（如 HCV、部分 HBV）則涉及 CD4+ 輔助細胞增殖缺陷、抑制性受體上調及抗原變異引發的免疫逃逸。
  - **代謝重塑與病毒偽裝（Lipoviroparticles）**：HCV 利用肝細胞極低密度脂蛋白（VLDL/LDL）組裝與分泌途徑，偽裝成微脂粒包裹的病毒顆粒（lipoviroparticles），直接干擾宿主葡萄糖與脂質代謝，導致粒線體氧化壓力加劇、胰島素阻抗與肝脂肪變性（Steatosis）。
- **演講亮點與臨床洞察**：
  - **診斷窗口期（Window Period）之真諦**：急性 HBV 感染早期或 HBsAg 消失而 anti-HBs 尚未出現時，**IgM anti-HBc** 是唯一可靠的急性期血清標記；且高抗體力價的 IgM anti-HBc 亦可能於慢性 B 肝急性發作（Reactivation）時重現。
  - **HCV 治療典範轉移**：過去干擾素時代建議等待 3~6 個月觀察自發性清除；在當代高治癒率（95~100%）之直接抗病毒藥物（DAA）時代，急性 HCV 確診後建議儘早啟動全口服 DAA 標準療程（8~12 週），不宜消極等待。
  - **特殊族群致命警訊**：HEV（基因型 1、2 型）在孕婦感染時，猛爆性肝衰竭致死率高達 10~20%；慢性 B 肝患者若重疊感染 HDV（Superinfection），其轉化為猛爆性肝炎與肝硬化（年發生率 ~4%）之風險急遽上升。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **AST / ALT** | 反映急性肝細胞壞死程度與細胞膜完整性；數值高低與肝損傷嚴重度/預後無絕對線性相關 | 急性期典型峰值介於 400 ~ 4000+ IU/L；重症壞死時若「酵素驟降但膽紅素急升」為肝竭警訊 |
| **凝血酶原時間 (PT / INR)** | 評估肝臟蛋白質合成功能最敏感的指標；肝細胞廣泛壞死時最先異常 | **延長為嚴重肝竭與不良預後的關鍵指標**；臨床強烈警訊 |
| **總膽紅素 (Total Bilirubin)** | 評估膽汁鬱積與排泄障礙；高膽紅素血症常在黃疸期持續上升 | 典型黃疸 >43 μmol/L (2.5 mg/dL)；**>340 μmol/L (20 mg/dL) 且持續延長提示重症** |
| **IgM anti-HAV** | 急性甲型肝炎之確診金標準 | 陽性代表急性 HAV 感染（可維持約 3~6 個月） |
| **HBsAg / IgM anti-HBc** | 鑑別 B 型肝炎為急性期、空窗期或慢性感染 | HBsAg(+) 伴 IgM anti-HBc(+) 確立急性 HBV；單純 IgM anti-HBc(+) 提示空窗期 |
| **HBeAg / HBV DNA 定量** | 評估 HBV 病毒複製活性、傳染力及發炎驅動強度 | HBV DNA 敏感度 PCR 達 5~10 IU/mL；活動期多 >10⁵ IU/mL，非複製期通常 ≤10³ virions/mL |
| **HCV RNA 定量 (RT-PCR)** | HCV 感染的黃金標準，早於抗體出現；評估活動性感染或治癒狀態 | 下限 10~25 IU/mL；治癒標準為完治後持續病毒學反應（SVR） |
| **血清白蛋白 (Albumin)** | 評估肝臟慢性合成功能儲備；急性單純性肝炎通常正常 | 若急性期顯著下降提示廣泛性實質壞死或原有潛在慢性肝病 |
| **代謝評估：空腹血糖 / 胰島素 (HOMA-IR)** | 評估由 HCV 或發炎細胞因子引發的繼發性胰島素阻抗與代謝異常 | 密切監控，因胰島素阻抗會加速肝纖維化進程 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 肝炎病毒之基因組構型與複製策略
- **HBV（Hepadnavirus，嗜肝 DNA 病毒）**：
  - 基因組極為緊湊（3.2 kb 部分雙股環狀 DNA），具 4 個重疊開放閱讀框（S、C、P、X）。
  - **逆轉錄複製循環**：進入宿主核後轉化為共價閉合環狀 DNA（cccDNA），作為轉錄 mRNA 及 pregenomic RNA（pgRNA）的模板；由病毒 P 蛋白（具逆轉錄酶與 DNA 聚合酶活性）反轉錄出負鏈 DNA。
  - **Pre-core 突變（G1896A 終止密碼子突變）**：使病毒無法合成可溶性 HBeAg，但仍具備活躍複製能力及毒性，易導致臨床上「HBeAg 陰性但 HBV DNA 高量」的侵襲性肝病。
  - **表面抗原逃逸突變（G145R）**：位於 HBsAg 之 *a* 決定基，導致中和抗體無法結合，對疫苗預防造成潛在威脅。
- **HCV（Hepacivirus，單股正鏈 RNA 病毒）**：
  - 長度約 9600 nt，轉譯出約 3000 個胺基酸的多聚蛋白，經宿主及病毒蛋白酶（NS2-3、NS3-4A）裂解為 10 種結構與非結構蛋白（Core, E1, E2, p7, NS2, NS3, NS4A, NS4B, NS5A, NS5B）。
  - **高變異性與 Quasispecies**：缺少校對機制的高複製率（每日產生 $10^{12}$ 病毒體，半衰期僅 2.7 小時），E2 區超變異區（HVR）頻繁突變，使中和抗體難以持久維持保護力。
  - **宿主依賴因子**：高度依賴微小核糖核酸 miR-122 與親環素 A（Cyclophilin A）進行穩定複製。

### 2. 免疫致病性與肝外免疫複合物疾患
- **細胞毒性 T 細胞反應雙面刃**：
  - 急性肝炎之肝細胞壞死、氣球樣變性（Ballooning）、嗜酸性凋亡小體（Councilman bodies）形成，均為 CD8+ CTL 辨識肝細胞膜上微量核心抗原（HBcAg 等）與 HLA Class I 複合物後的攻擊結果。
  - 當先天免疫（NK 細胞、IFN-λ）與適應性免疫反應適度且多株協同（Polyclonal）時，病毒被廓清；若宿主免疫不全、T 細胞耗竭（Exhaustion）或逃逸突變，則轉入慢性持續性感染。
- **循環免疫複合物（Type III 過敏反應）之肝外表徵**：
  - **急性前驅期血清病樣症候群**：5~10% 的急性 HBV 患者在黃疸出現前，因 HBsAg-anti-HBs 免疫複合物沉積於血管壁，啟動補體級聯反應，導致關節痛/關節炎、蕁麻疹、血管神經性水腫與蛋白尿。
  - **慢性期血管與腎臟病變**：
    - **結節性多動脈炎（PAN）**：20~30% 的 PAN 患者具 HBsAg 陽性，中小型動脈壁可見免疫球蛋白與補體沉積。
    - **混合型冷凝球蛋白血症（Essential Mixed Cryoglobulinemia, EMC）**：強烈與慢性 HCV 感染相關，循環免疫複合物含 HCV RNA，臨床表現為紫斑症（Palpable purpura）、關節痛及膜性增生性腎絲球腎炎（MPGN）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 傳統醫療介入與藥物治療時機
- **急性 HAV / HEV**：以支持性療法為主。重症/急性加慢性肝衰竭（ACLF）之 HEV 患者可考慮 Ribavirin（600 mg BID），但**孕婦絕對禁用（具致畸胎性）**。
- **急性 HBV**：
  - 95~99% 健康成人可自發痊癒，常規不需抗病毒藥。
  - **嚴重型（Severe）或具肝衰竭傾向者**：強烈建議早期使用強效、低抗藥性之核苷酸類似物（如 **Entecavir 0.5 mg/day** 或 **Tenofovir disoproxil fumarate 300 mg/day / TAF 25 mg/day**），持續治療至 HBsAg 血清轉換後 3 個月，或 HBeAg 轉換後 6 個月。
- **急性 HCV**：不再等待自發清除，直接使用第一線全口服 DAA 組合（如 Sofosbuvir/Velpatasvir 或 Glecaprevir/Pibrentasvir）治療 8~12 週。
- **猛爆性肝衰竭支持**：早期轉診加護病房，限制蛋白質攝取、給予乳果糖（Lactulose）降氨、嚴密監控腦水腫；評估緊急肝臟移植（急診唯一挽救生命的根治手段）。

### 2. 功能性營養素與肝臟排毒途徑支援
- **肝臟第 II 相解毒與抗氧化儲備（粒線體保護）**：
  - **N-乙醯半胱氨酸 (NAC)**：作為穀胱甘肽（GSH）的前驅物，顯著減緩自由基對肝細胞膜的過氧化損傷，對於非對乙醯氨基酚引起的急性肝衰竭亦具微循環改善與抗氧化效益。
  - **S-腺苷甲硫氨酸 (SAMe)**：促進轉硫途徑（Transsulfuration），維持肝內甲基化狀態，協助膽汁酸代謝排泄，緩解膽汁鬱積型肝炎之搔癢與膽紅素滯留。
  - **水飛薊素（Silymarin / Silybin 複合物）**：具備膜穩定作用、抑制脂質過氧化、阻斷發炎核轉錄因子 NF-κB，並促進肝細胞核糖體 RNA 合成與再生。
- **膽汁流動（Choleretic）與脂溶性毒素排除**：
  - 若伴隨膽汁鬱積性黃疸與嚴重搔癢，傳統可短期使用消膽胺（Cholestyramine 4g BID~TID），功能醫學層面可補充牛磺酸（Taurine）與水溶性膳食纖維，協助結合次級膽汁酸並阻斷腸肝循環。
  - **脂溶性維生素監測與補充**：長程膽汁鬱積易導致維生素 A、D、E、K 吸收不良，凝血時間延長者應即時評估維生素 K1 靜脈或皮下支持。

### 3. 臨床飲食與能量代謝策略
- **晝夜節律飲食（能量集中於早晨）**：
  - 急性肝炎患者常有「晨輕暮重」的噁心感及嗅覺/味覺改變。臨床應採取**高熱量、優質碳水化合物為主、低刺激性的早餐與早午餐**，確保全日主要熱量於上午順利攝入。
  - 避免強迫進食大量高油脂食物，以減輕肝膽系統負擔。
- **維持肝醣儲備以防低血糖**：
  - 受損的肝細胞糖質新生（Gluconeogenesis）與肝醣分解能力劇降，極易發生重症低血糖。急性期需少量多餐攝取複合碳水化合物，必要時給予靜脈葡萄糖輸注維持血糖平穩。
- **嚴格代謝減負**：
  - **禁絕外源性肝毒素**：絕對戒酒；嚴格停用非必要之藥物（特別是高肝臟首渡代謝藥物、NSAIDs、Acetaminophen）。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **急性肝炎精準血清學「四聯篩檢」常規化**：
   - 任何急性肝炎臨床疑似患者，立即檢驗：**HBsAg、IgM anti-HAV、IgM anti-HBc、Anti-HCV**。若高度懷疑急性 C 肝或處於免疫功能低下狀態，務必加驗 **HCV RNA**，以防抗體偽陰性。
2. **高度警惕猛爆性肝衰竭的「生化分離現象」**：
   - 若追蹤檢驗顯示 **AST/ALT 迅速回落，但總膽紅素急遽上升、凝血酶原時間（PT/INR）顯著延長**，切勿誤判為病情好轉，此乃肝細胞大面積壞死（Massive Hepatic Necrosis）的重症警訊，應即刻安排轉入 ICU 並啟動肝移植評估。
3. **終身防護網：主動免疫與接觸後預防（PEP）執行**：
   - **HBV 暴露**：未接種疫苗者發生經皮/黏膜高風險暴露（如針扎、母嬰），應於 12~24 小時內施打 **HBIG (0.06 mL/kg 或新生兒 0.5 mL)** 並於不同部位同步啟動 B 肝疫苗常規注射。
   - **HAV 暴露**：年齡 ≥12 個月之接觸者優先給予 HAV 疫苗單劑；免疫不全、慢性肝病患者或年齡 >40 歲高風險者，建議同時給予 HAV 疫苗與免疫球蛋白（IG 0.1 mL/kg）。
4. **HCV 與代謝症候群的雙向共病管理**：
   - 慢性 HCV 感染患者應被視為心血管代謝高風險群，除儘早予以 DAA 根除病毒外，臨床應系統性監控脂肪肝、胰島素阻抗及冷凝球蛋白血症相關之血管/腎臟損害，提供全人抗發炎與代謝修復計畫。
