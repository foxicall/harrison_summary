# 肝臟功能評估與肝膽生化標記解析（Evaluation of Liver Function）
- **主講人/來源**：337 Evaluation of Liver Function.pdf (Emily D. Bethea, Daniel S. Pratt / *Harrison's Principles of Internal Medicine*)
- **核心主旨**：肝臟生化檢驗（LFTs）本質上為肝細胞膜受損、膽汁淤積或合成受損之複合指針，臨床應透過成套檢案（Battery tests）並辨識酵素比例與動力學變化，以精準定位肝膽病理分型、評估纖維化風險並指導整體代謝排毒機能。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **細胞膜通透性改變與壞死釋出**：轉氨酶（AST/ALT）升高反映的是肝細胞膜穩定性受損導致的酵素漏出，而非僅直接對應不可逆的細胞壞死，其數值絕對值與急性肝損傷預後無絕對線性關係。
  - **解毒限速步驟障礙與微膽管停滯**：膽紅素代謝中，結合型膽紅素跨過膽毛細管膜的排泄是限速步驟（Rate-limiting step），任何發炎或膽汁酸代謝淤積均會優先抑制排泄端，導致結合型膽紅素反流入血。
  - **腸肝循環破損與免疫發炎級聯**：慢性肝病與肝硬化患者因腸黏膜屏障受損、肝臟網狀內皮系統清除細菌抗原能力下降，大量腸道內毒素與抗原進入體循環，誘發 B 細胞代償性過度活化產生多株球蛋白（Hypergammaglobulinemia）。
- **演講亮點與臨床洞察**：
  - **酵素比值背後的微量營養素缺陷**：酒精性肝病中經典的 AST:ALT > 2:1（或 > 3:1），生化關鍵在於長期酗酒導致輔酶 **Pyridoxal 5'-phosphate（維生素 B6 活性型）** 嚴重耗竭，使得高度依賴 B6 的 ALT 合成受到抑制，導致血中 ALT 假性偏低。
  - **合成指標之時間軸差異**：白蛋白半衰期長達 18–20 天，無法及時反映急性功能缺損；反之，依賴維生素 K 的凝血因子（如 Factor VII 半衰期僅 6 小時）所呈現之凝血酶原時間（PT/INR），方為急性肝實質合成功能的金標準指標。
  - **器官交互作用與解毒分工**：人體血氨清除非肝臟獨佔，骨骼肌在肌球蛋白合成麩醯胺酸（Glutamine）的氨緩衝中扮演要角；晚期肝病患者之肌少症（Sarcopenia）會顯著削弱肌肉解氨能力，急遽加劇高血氨血症。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **總膽紅素 (Total Bilirubin)** | 評估溶血、肝細胞排泄及膽道阻塞；MELD 評分之核心指標 | 正常值約 0.2–0.9 mg/dL（群體 95%），上限一般為 1.0–1.5 mg/dL |
| **直接/結合型膽紅素 (Direct Bilirubin)** | 區分肝前性溶血與肝性/膽道病變；直接膽紅素 >15% 代表肝膽排泄受阻 | 正常上限通常為 0.3 mg/dL；<15% 視為純間接膽紅素血症 |
| **ALT (丙胺酸轉氨酶)** | 肝細胞質特異性受損標記，對發炎敏感性高 | 臨床常規參考區間：10–40 IU/L（功能醫學關注低度發炎者宜 <25 IU/L） |
| **AST (天門冬胺酸轉氨酶)** | 分布於肝臟、心肌、骨骼肌及腎臟；反映細胞與粒線體損傷 | 常規參考區間：10–40 IU/L；AST/ALT 比值具分型意義 |
| **AST:ALT 比值** | 鑑別病毒性肝炎、脂肪肝、肝纖維化進展與酒精性肝病 | 典型病毒/NAFLD <1；進展至肝硬化 >1；酒精性肝炎常 >2:1（甚至 >3:1） |
| **極度轉氨酶升高 (>1000 IU/L)** | 反映廣泛急性肝細胞缺血或壞死 | 常見於：(1)缺血性肝損傷 (2)急性病毒性肝炎 (3)毒物/藥物肝損傷 (4)膽石過境暫態 |
| **ALP (鹼性磷酸酶)** | 膽毛細管膜酵素；評估膽汁淤積、浸潤性肝病（腫瘤/肉芽腫）及骨病變 | >4× 正常上限強烈提示膽汁淤積、浸潤病變（如澱粉樣變性）或骨 Paget 病 |
| **GGT 與 5'-Nucleotidase** | 輔助確認 ALP 來源；GGT 亦反映肝臟第二階段排毒壓力與微粒體誘導 | 5'-NT 或 GGT 升高確認 ALP 來源為肝膽而非骨骼；GGT 對酒精暴露敏感 |
| **血清白蛋白 (Albumin)** | 評估肝臟長期合成機能、發炎消耗與蛋白質營養狀態 | 正常 3.5–5.0 g/dL；急性期不易變動，肝炎病患 <3.0 g/dL 警示慢性化或肝硬化 |
| **凝血酶原時間 / INR (PT/INR)** | 快速評估急性肝實質合成能力（凝血因子 II, V, VII, X） | 延長 >5 秒且 Vit K 無法校正者為急性肝壞死不良預後指針 |
| **血清免疫球蛋白 (IgG, IgM, IgA)** | 反映肝臟過濾腸道抗原失能及自體免疫反應驅動 | IgG 升高 >100% 提示自體免疫性肝炎；IgM 升高提示 PBC；IgA 升高提示酒精性肝病 |
| **非侵入性纖維化檢測 (FibroTest / TE / MRE)** | 取代或輔助肝切片，早期評估肝實質硬度與纖維化分期 | 綜合 Haptoglobin、ApoA-1、$\alpha_2$-Macroglobulin、Bilirubin、GGT；TE (FibroScan) |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 肝臟排毒與代謝受損的生化分型路徑
- **肝細胞損傷模式（Hepatocellular Pattern）**：
  - 轉氨酶釋放機轉：肝細胞缺氧、發炎介質攻擊或毒性代謝物累積破壞細胞膜流動性與完整性，膜通透性增加即導致細胞質酵素溢漏至細胞外液。
  - 當轉氨酶 $>1000\text{ IU/L}$ 時，應迅速排查三大關鍵危症：
    1. **缺血性肝損傷（Ischemic Hepatitis / Shock Liver）**：常伴隨嚴重低血壓或急性心衰竭。
    2. **急性中毒或藥物損傷**：如乙醯胺酚（Acetaminophen）過量引發之穀胱甘肽耗竭與毒性代謝物 NAPQI 蓄積。
    3. **暴發性急性病毒性肝炎**。
    *(例外：膽結石通過總膽管造成急性暫時性嵌頓嵌塞，亦可引發 AST/ALT 短暫飆升至 1000–2000 IU/L，但隨後迅速陡降並轉向膽汁淤積圖譜)*。
- **膽汁淤積與浸潤模式（Cholestatic / Infiltrative Pattern）**：
  - ALP 與 5'-Nucleotidase 緊密固著於膽小管微絨毛質膜。當膽汁酸滯留（Detergent effect）或微管內壓上升時，刺激膽管細胞代償合成並促使酵素裂解進入血流。
  - **診斷分流邏輯**：孤立性 ALP 升高應先確認組織來源（檢查 GGT 或 5'-Nucleotidase）。若為肝源性且超音波未見膽管擴張，需檢測**抗粒線體抗體（AMA）**排除原發性膽汁性膽管炎（PBC），或考慮浸潤性肉芽腫/腫瘤病變。

### 2. 蛋白質合成、發炎交互調控與腸-肝軸失衡
- **負向急性期蛋白與白蛋白合成抑制**：
  - 白蛋白的下降在慢性肝病中雖然反映肝實質喪失，但在全身性慢性發炎中，促發炎細胞因子（如 **IL-1、TNF-$\alpha$**）會直接在轉錄層次抑制肝臟合成白蛋白，同時使其在微血管滲透性增加，導致功能性低白蛋白血症。
- **門脈高壓、腸漏（Leaky Gut）與免疫球蛋白激增**：
  - 門靜脈高壓及微循環阻力增加促使腸道靜脈淤血，導致腸黏膜屏障破壞，大量細菌抗原、內毒素（LPS）經門脈系統進入體循環。
  - 正常情況下，肝臟 Kupffer 細胞可清除這些抗原；肝硬化時因門脈側支分流與巨噬細胞機能衰退，抗原大量刺激全身 B 淋巴細胞，形成顯著的多株高丙種球蛋白血症（Hypergammaglobulinemia）。

### 3. 解毒代償與血氨代謝網絡
- 氨的清除依賴兩大生理軸線：
  1. **肝臟尿素循環（Urea Cycle）**：消耗 ATP 將氨轉換為尿素經腎臟排出。
  2. **周邊骨骼肌的麩醯胺酸合成酶（Glutamine Synthetase）路徑**：將氨與麩胺酸（Glutamate）結合為麩醯胺酸。
- 當慢性肝損傷發展至末期，伴隨肌肉萎縮與蛋白質消耗，人體喪失關鍵的周邊解氨緩衝體積，大幅增加肝性腦病變的風險。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素/植化素補充支持
- **粒線體與第二階段解毒路徑支持（针对 ALT/AST 異常升高）**：
  - **N-乙醯半胱胺酸 (NAC)**：每日 600–1800 mg，補充細胞內半胱胺酸庫存，促進還原型穀胱甘肽（GSH）合成，阻斷親電子基質與自由基對肝細胞膜的過氧化損傷。
  - **活性維生素 B 群（特別是 P-5-P / 活性 B6）**：每日 25–50 mg，修復轉氨酶輔基缺乏，改善高同半胱胺酸與蛋白質轉氨代謝障礙（尤其具飲酒習慣者）。
- **膽汁流動與微膽管膜保護（针对 ALP/GGT 膽汁淤積型）**：
  - **牛磺酸 (Taurine)**：每日 500–1500 mg，促進初級膽汁酸結合為親水性牛磺膽酸，降低疏水性膽汁酸對膽小管細胞的膜溶解毒性。
  - **水飛薊素 (Silymarin / Silybin)**：每日 140–420 mg（高生物利用度磷脂複合物型態），具備膜穩定、抗微小管發炎與促進膽汁分泌（Choleretic）之功效。

### 2. 飲食與代謝調控策略
- **逆轉肝細胞脂肪變性與發炎之飲食原則**：
  - 採取**高多酚地中海飲食**，巨量營養素控制在低精緻碳水化合物（特別是極限減少高果糖玉米糖漿），以減輕肝臟新生脂肪生成（De Novo Lipogenesis, DNL）造成的游離脂肪酸毒性。
  - **植物性蛋白質與適度支鏈胺基酸（BCAA）配置**：晚期慢性肝病患者應確保足量優質蛋白質（1.2–1.5 g/kg/day），並可提高植物性蛋白質比例以減少腸道產氨菌負擔；補充 BCAA 有助維持骨骼肌質量，強化周邊血氨解毒庫存。

### 3. 環境毒素阻斷與生活型態介入
- **完全代謝排毒支持與藥物警戒**：
  - 戒絕乙醇攝入（酒精為粒線體毒素，直接加劇細胞質 NADH/NAD+ 失衡與脂肪堆積）。
  - 全面審視病患用藥清單（Review Drug List），暫停非必要之後設肝代謝藥物、草藥補品或可能造成藥物誘導性肝損傷（DILI）的成藥。
- **腸道屏障修復與腸肝軸優化**：
  - 補充益生元與可溶性膳食纖維，酸化結腸環境促進氨離子化（形成不被吸收的 $\text{NH}_4^+$ 隨糞便排出），改善腸道黏膜緊密連接，切斷內毒素入血造成的微炎症級聯。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **成套檢查代替單一指標**：臨床切忌僅憑單一 ALT/AST 判定肝功能，必須組合評估 **ALT、AST、ALP、Bilirubin（結合/未結合）、Albumin 及 PT/INR**，才能區分細胞損害、排泄障礙與實際合成衰竭。
2. **警覺 AST:ALT 比值倒置**：NAFLD 或慢性肝炎患者若觀察到 AST/ALT 比值由 $<1$ 逐漸上升至 $>1$，高度暗示疾病已跨越單純發炎階段，正進展至進行性纖維化或肝硬化；比值 $>2:1$ 則應重點追問酒精暴露史與 B6 缺乏。
3. **區別 ALP 來源的標準化流程**：若遇孤立性 ALP 升高，第一步應檢測 **GGT 或 5'-Nucleotidase**。確認為肝源性後，首選**腹部超音波**評估膽管直徑：若膽管擴張行 MRCP/ERCP；膽管未擴張則檢測 **AMA** 排除自體免疫膽道疾病。
4. **急性監控認準凝血指標**：面對嚴重急性肝炎，白蛋白無預後指導意義；必須動態追蹤 **PT/INR**。若 PT 延長超過對照組 5 秒以上且經注射維生素 K 後無法逆轉，提示大範圍肝壞死與潛在急性肝衰竭風險。
5. **整合非侵入性纖維化評估**：對慢性肝病患者，應善用非侵入性工具（如 FibroTest、FibroScan 暫態彈性造影或 MRE），及早介入抗氧化與抗纖維化方案，避免延宕至失代償期。
