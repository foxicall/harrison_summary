# 脂蛋白代謝異常與血脂障礙的全方位臨床剖析 (Disorders of Lipoprotein Metabolism)
- **主講人/來源**：407 Disorders of Lipoprotein Metabolism.pdf / Daniel J. Rader (*Harrison's Principles of Internal Medicine*)
- **核心主旨**：深入剖析外源性與內源性脂質運送、逆向膽固醇轉運之分子病理生理機制，結合單基因遺傳缺陷與代謝環境因子（胰島素阻抗、飲食、甲狀腺異常等）的交互作用，建立預防動脈粥狀硬化心血管疾病（ASCVD）與急性胰臟炎的精準檢測、生活型態與現代多靶點藥理介入體系。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **脂質廓清與水解障礙**：脂蛋白脂肪酶（LPL）活性受損或其輔因子（ApoC-II、ApoA-V）與轉運蛋白（GPIHBP1、LMF1）缺陷，導致乳糜微粒（Chylomicrons）與極低密度脂蛋白（VLDL）等富含三酸甘油酯脂蛋白（TRLs）嚴重滯留，引發高三酸甘油酯血症（HTG）與胰臟微循環缺血性發炎。
  - **受體介導胞吞異常**：低密度脂蛋白受體（LDLR）功能缺陷、ApoB-100 結合域突變、LDLRAP1 轉運障礙或 PCSK9 介導的受體過度降解，使 LDL-C 清除受阻；巨噬細胞攝取氧化修飾之 ApoB 顆粒形成泡沫細胞，驅動血管壁發炎與動脈粥狀硬化。
  - **逆向膽固醇轉運（RCT）衰退**：ABCA1、LCAT 功能不全或 HDL 重構異常，阻礙周邊細胞多餘未酯化膽固醇返回肝臟排泄。
- **演講亮點與臨床洞察**：
  - **致動脈硬化顆粒數的真正代表**：ApoB 存在於每個致動脈硬化顆粒（VLDL、IDL、LDL、Lp(a)）上且每個顆粒僅有一分子 ApoB，評估 ASCVD 風險時優於 LDL-C 與 Non-HDL-C。
  - **嚴重高三酸甘油酯血症（TG >500 mg/dL）首要目標是預防急性胰臟炎**；而中度 HTG（150–500 mg/dL）的核心臨床考量則是降低心血管剩餘風險（Residual ASCVD Risk）。
  - **Lp(a) 具高度遺傳性且為獨立的 ASCVD 致病因子**；針對難治型或特殊型血脂異常，臨床需辨識出罕見的單基因病變（如家族性高膽固醇血症 FH、第 III 型高脂蛋白血症 FDBL、植物固醇血症 Sitosterolemia、溶酶體酸性脂肪酶缺乏症 LALD 等）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **空腹三酸甘油酯 (Fasting TG)** | 評估富含 TG 脂蛋白滯留程度；高值提示急性胰臟炎或代謝症候群風險 | **<150 mg/dL** 為理想；**>500 mg/dL** 為重度（胰臟炎極高危）；**>1000 mg/dL** 強烈懷疑 FCS/FPLD |
| **LDL-C (低密度脂蛋白膽固醇)** | 評估 ASCVD 主要致病因子（若 TG >400 mg/dL 或 FDBL 則 Friedewald 公式失效，需直接測定） | 依 ASCVD 風險分層，高危個案目標值常需 **<70 mg/dL**；未經治療 **>190 mg/dL** 需高度懷疑單基因 FH |
| **Non-HDL-C (非高密度脂蛋白膽固醇)** | 計算公式為 `TC - HDL-C`；綜合評估 LDL、IDL、VLDL 所攜帶之總致動脈硬化膽固醇 | 一般建議目標為 **LDL-C 目標值 + 30 mg/dL**（正常空腹參考上限約 **<130 mg/dL**） |
| **Apolipoprotein B (ApoB)** | 致動脈硬化性脂蛋白顆粒總數之精準定量；不受顆粒大小或膽固醇含量變異影響 | 臨床風險評估重要標記，特別在混合型血脂異常、代謝症候群或糖尿病患者中顯著升高 |
| **Lipoprotein(a) [Lp(a)]** | 具高度遺傳性的獨立致動脈硬化與致血栓因子；肝臟生成，含 Apo(a) 及 ApoB-100 | 終身檢測至少一次以進行精準 ASCVD 風險分層；數值顯著升高時需更積極降低 LDL-C |
| **HDL-C 與 Apolipoprotein A-I** | 評估逆向膽固醇轉運潛力與代謝發炎指標（強烈的逆向心血管風險標記，非單純升降靶點） | 男性 **>40 mg/dL**，女性 **>50 mg/dL**；**<20 mg/dL** 需排除 Tangier 病、LCAT 缺乏或嚴重 ApoA-I 突變 |
| **促甲狀腺激素 (TSH)** | 排除甲狀腺功能低下導致之肝臟 LDLR 下調與次發性高膽固醇血症 | 常規篩檢項目（特別是未明原因 LDL-C 突然上升時） |
| **空腹血糖 / HbA1c / 胰島素** | 評估胰島素阻抗與糖尿病；胰島素缺乏/阻抗抑制 LPL 並刺激肝臟 VLDL 分泌 | 排除代謝症候群及次發性嚴重高三酸甘油酯血症 |
| **冠狀動脈鈣化積分 (CAC) / hs-CRP** | 輔助心血管風險邊緣（Borderline Risk）族群之動態風險分層，決定是否啟動積極藥物 | CAC > 0 或 hs-CRP 升高提示亞臨床動脈硬化或血管慢性低度發炎 |
| **血漿植物固醇 (Sitosterol/Campesterol)** | 鑑別診斷 ABCG5/ABCG8 基因突變之植物固醇血症（對 Statin 反應差者） | 懷疑 Sitosterolemia、合併溶血性貧血與肌腱黃色瘤時測定 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 外源性與內源性脂蛋白代謝途徑（Exogenous & Endogenous Pathways）
- **外源性途徑（膳食脂質與乳糜微粒）**：
  - 腸道水解脂質後乳化形成微膠粒（Micelles），近端小腸吸收游離脂肪酸、膽固醇與脂溶性維生素。
  - 腸黏膜細胞透過 **微粒體三酸甘油酯轉運蛋白 (MTP)** 將甘油三酯、膽固醇酯與 **ApoB-48** 組裝為新生乳糜微粒（Nascent Chylomicrons），經乳糜管、胸導管入體循環。
  - 微血管內皮細胞表面的 **脂蛋白脂肪酶 (LPL)** 進行 TG 水解，需要 **ApoC-II**（輔因子）活化，並由 **ApoA-V** 促進活性；LPL 的內皮轉運錨定依賴 **GPIHPB1**，其正確折疊需 **LMF1** 協助。
  - TG 降解為游離脂肪酸（供肌細胞氧化或脂肪細胞儲存），顆粒縮小並脫落表面成分至 HDL，形成乳糜微粒殘粒（Remnants）。因 ApoB-48 缺乏 LDLR 結合域，殘粒必須依賴 **ApoE** 作為配體，經肝臟 LDLR/LRP 受體胞吞清除。
- **內源性途徑（肝臟 VLDL、IDL 與 LDL 代謝軸）**：
  - 空腹時，脂肪組織釋放脂肪酸入肝，肝臟合成 TG 並透過 MTP 將其與 **ApoB-100** 組裝成 VLDL 分泌至血漿。
  - VLDL 受 LPL 水解形成中密度脂蛋白（IDL）。約 40–60% 的 IDL 藉由 ApoE 媒介被肝臟受體吸收，其餘部分經 **肝脂酶 (Hepatic Lipase, HL)** 進一步水解磷脂與 TG，脫去其他載脂蛋白，僅保留 ApoB-100，重塑形成 LDL。
  - LDL 主要藉由 ApoB-100 結合肝臟 LDLR 被清除。若 LDLR 數量或活性下降，LDL 停留時間延長，易氧化修飾並被血管內皮巨噬細胞攝取。

```
【外源性】膳食脂肪 ➔ 腸道 (MTP + ApoB-48) ➔ 乳糜微粒 ➔ LPL水解 (ApoC-II/ApoA-V/GPIHPB1) ➔ 殘粒 ➔ 肝臟清除 (ApoE)
【內源性】肝臟游離脂肪酸 ➔ (MTP + ApoB-100) ➔ VLDL ➔ LPL水解 ➔ IDL ➔ HL重塑 ➔ LDL ➔ 肝臟清除 (ApoB-100 - LDLR)
```

### 2. 逆向膽固醇轉運（Reverse Cholesterol Transport, RCT）與 HDL 動態循環
- **新生盤狀 HDL 的形成**：肝臟與小腸分泌新生 **ApoA-I**，透過細胞膜轉運蛋白 **ABCA1** 與周邊巨噬細胞作用，獲取磷脂與未酯化膽固醇，生成新生盤狀 HDL。
- **成熟與酯化（LCAT 軸）**：HDL 表面之 **卵磷脂-膽固醇醯基轉移酶 (LCAT)** 被 ApoA-I 活化，催化膽固醇轉化為疏水性膽固醇酯（CE），CE 移動至顆粒核心，使 HDL 轉變為成熟球狀顆粒。
- **肝臟清除與轉運**：
  - **SR-B1 途徑**：肝臟表面清道夫受體 B1 (SR-B1) 專一性攝取 HDL 核心的 CE，顆粒不被降解而是脫脂後“回收再利用”。
  - **CETP 途徑**：膽固醇酯轉運蛋白（CETP）促進 HDL 的 CE 與含 ApoB 脂蛋白（VLDL/LDL）的 TG 進行雙向交換，再藉由 LDLR 途徑清除。
  - **排泄途徑**：肝內膽固醇經膽汁酸轉化或原形排入膽汁，亦有部分直接透過跨腸道膽固醇排泄（TICE）排出體外。

### 3. 重點單基因遺傳血脂障礙鑑別診斷
- **家族性高乳糜微粒血症候群 (FCS)**：體染色體隱性（AR），*LPL, APOC2, APOA5, GPIHBP1, LMF1* 雙等位基因功能喪失（LoF）。空腹血漿呈乳白色牛奶樣（上浮奶油層），TG 常常 >1000 mg/dL，伴隨反覆胰臟炎、發疹性黃色瘤、視網膜脂血症、肝脾腫大，但非典型的早發 ASCVD。
- **家族性高膽固醇血症 (FH)**：體染色體顯性（AD），*LDLR* (LoF)、*APOB* (LoF 結合域)、*PCSK9* (GoF 功能增強)。極高 LDL-C、肌腱黃色瘤（特別是跟腱與手背）、早發性冠心病。若為雙等位純合子（HoFH），LDL-C 可達 400–1000 mg/dL，幼年即可能出現主動脈瓣上狹窄及心肌梗塞。
- **自體隱性高膽固醇血症 (ARH)**：*LDLRAP1* 雙等位突變，LDLR 胞內段轉運轉接蛋白缺失，LDL-LDLR 複合體無法內吞。臨床表現如同 FH，但對 Statin 治療有部分反應。
- **植物固醇血症 (Sitosterolemia)**：*ABCG5* 或 *ABCG8* 突變（AR），腸道與膽道無法排出植物固醇。高膽固醇血症、肌腱黃色瘤，伴隨**大血小板症、溶血性貧血**。對 Statin 反應極差，但對 Ezetimibe 反應極佳。
- **第 III 型高脂蛋白血症 (FDBL / 家族性異常乙型脂蛋白血症)**：ApoE2/E2 同型合子加上“第二次打擊”（肥胖、DM、甲減等）。殘粒（IDL/乳糜微粒殘粒）清除障礙，TC 與 TG 等比例升高（1:1），出現**手掌紋路黃色瘤 (Xanthomata striata palmaris)** 與結節發疹性黃色瘤，早發 ASCVD 及周邊血管疾病。
- **低脂蛋白血症**：
  - *MTTP* 突變導致無乙型脂蛋白血症（Abetalipoproteinemia）：缺乏 ApoB 脂蛋白，重度脂肪瀉、神經性共濟失調、色素性視網膜病變、棘紅細胞。
  - *PCSK9* 或 *ANGPTL3* 失去功能突變：血脂低下，但對心血管具有終生保護作用。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素/特定植化素補充與藥理協同
- **純化 Omega-3 脂肪酸 (n-3 PUFAs)**：
  - **劑量**：3~4 g/天。
  - **機轉**：抑制肝臟 VLDL 合成，促進 TG 分解代謝，可降低血漿 TG 約 30%。
  - **臨床應用**：高純度 EPA（如 Icosapent ethyl 4 g/d）已被證實具顯著心血管保護效益且不升高 LDL-C；一般含 DHA 配方在高 TG 族群中可能微幅拉高 LDL-C。
- **高劑量脂溶性維生素補充（針對吸收不良型遺傳病）**：
  - 在 Abetalipoproteinemia 或嚴重 FCS 嚴格限脂患者中，必須早期且持續補充大劑量**維生素 E（α-tocopherol）**、維生素 A、K，以阻斷脊髓小腦變性與神經視網膜退化。
- **特定血脂異常禁用/慎用成分**：
  - **植物固醇（Plant Sterols）**：常規心血管保健常用於競爭膽固醇吸收，但**嚴禁**用於已確診或疑似 **植物固醇血症 (Sitosterolemia)** 之病患。

### 2. 精準飲食與代謝管理策略
- **嚴重高三酸甘油酯血症 (TG >500 mg/dL，特別是 FCS/FPLD)**：
  - **極低脂肪飲食**：每日總脂肪嚴格限制在 **15 g/天**（或佔總熱量 <10–15%），以切斷外源性乳糜微粒的生成路徑。
  - **嚴格禁酒**：酒精可抑制游離脂肪酸氧化，加劇肝臟 TG 合成與 VLDL 分泌。
  - **嚴控精緻碳水化合物與果糖**：高果糖與高醣飲食會強烈刺激肝臟從頭脂肪生成（*De novo lipogenesis*）。
- **高膽固醇血症 (Elevated LDL-C)**：
  - **飽和脂肪與反式脂肪阻斷**：飽和脂肪會下調肝臟 LDLR 表現；臨床需將飽和脂肪攝取量控制在總熱量 5–6% 以下，全面排除工業反式脂肪。
  - **地中海型抗發炎飲食**：提高單元不飽和脂肪酸（MUFA，如特級初榨橄欖油）與水溶性膳食纖維攝取，促進膽汁酸排出。
- **體重控制與減重手術**：
  - 肥胖與代謝症候群患者，減輕體重 5–10% 可顯著降低 VLDL 分泌並改善周邊 LPL 活性；重度病患可評估代謝減重手術，顯著扭轉代謝紊亂。

### 3. 現行臨床降脂藥理學指引（整合最新標靶）

```
【第一線基石】
Statin (HMG-CoA 還原酶抑制劑) ➔ 阻斷膽固醇合成 ➔ 上調肝臟 LDLR (降低 LDL-C 30–55%)
       │
       ▼ (未達標或不耐受)
【第二線聯用】
Ezetimibe (NPC1L1 抑制劑) ➔ 抑制腸道膽固醇吸收 ➔ 加幅降低 LDL-C ~18% (具心血管試驗終點證據)
       │
       ▼ (高危/FH/未達標)
【第三線標靶】
PCSK9 抑制劑 ➔ 單株抗體 (Evolocumab / Alirocumab, 降低 ~60%) 或 siRNA (Inclisiran, 半年一次)
Bempedoic Acid (ACL 抑制劑) ➔ 肝臟專一活化 (無肌肉痠痛)，降低 LDL-C 15–25% (注意尿酸/痛風)
       │
       ▼ (純合子 HoFH / 極端難治型)
【特殊標靶】
Lomitapide (MTP抑制劑) / Mipomersen (ApoB反義寡核苷酸) / Evinacumab (ANGPTL3抗體) / LDL血漿置換
```

- **高三酸甘油酯專一藥物**：
  - **Fibrates（纖維酸類，如 Fenofibrate）**：PPARα 激動劑，活化 LPL、下調 ApoC-III、促進脂肪酸 β 氧化；降低 TG ~30–50%（與 Statin 併用時避免選用 Gemfibrozil 以防橫紋肌溶解）。
  - **Volanesorsen**：APOC3 反義寡核苷酸（ASO），歐洲已批准用於 FCS，降 TG 效果顯著（需嚴密監測血小板低下）。

### 4. 環境代謝阻斷與續發因子管理
- **甲狀腺功能優先評估**：任何無法解釋的 LDL-C 升高，應優先檢測並校正甲狀腺低下（甲狀腺素為維持 LDLR 表現之必要荷爾蒙）。
- **醫源性與環境干擾排除**：
  - 檢視會加重 HTG 的藥物：雌激素（口服避孕藥/荷爾蒙替代）、全身性皮質類固醇、異維A酸（Isotretinoin）、Bexarotene、乙型阻斷劑（Beta-blockers）、免疫抑制劑（Cyclosporine、Sirolimus）。
  - 若高 TG 族群需使用膽汁酸結合樹脂（Colesevelam 等），需格外小心，因樹脂可能代償性誘發肝臟 VLDL 分泌而惡化 HTG。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **即刻風險分層與雙重目標設定**：
   - 面對 **TG >500 mg/dL** 患者，首要任務是防範急性胰臟炎，即刻實施「極低脂飲食（<15 g/d）+ 戒酒 + 高劑量 Omega-3/Fibrate」；
   - 面對 **TG 150–500 mg/dL** 患者，臨床核心是全面評估與遏止 ASCVD 風險（以 Statin 為基石，搭配生活型態調整）。
2. **超越傳統 LDL-C：導入 ApoB 與 Lp(a) 深度評估**：
   - 在糖尿病、代謝症候群、肥胖及混合型血脂異常患者中，常規檢測 **ApoB** 以掌握實際致動脈硬化顆粒暴露劑量；
   - 建議所有成年人一生至少檢測一次 **Lp(a)**，針對高值族群採取更激進的動脈硬化防治策略。
3. **系統性鑑別並排除次發性病因**：
   - 在診斷原發性高脂血症前，務必常規抽血確認：**TSH（甲狀腺）、空腹血糖/HbA1c（糖尿病）、肝腎功能與尿蛋白（腎病症候群/膽汁淤積）**，並詳細回顧酒精與致脂質異常藥物史。
4. **警惕單基因遺傳特徵並推動瀑布式家族篩檢（Cascade Screening）**：
   - 凡成年人未治療 LDL-C >190 mg/dL、幼童 >160 mg/dL、或有明顯早發心血管家族史、肌腱/手掌黃色瘤者，積極安排基因檢測並為一等親屬進行級聯篩檢，早期阻斷遺傳性高血脂的致死風險。
5. **階梯式多靶點降脂處方精準整合**：
   - LDL-C 嚴重超標或 Statin 無法完全達標之高危患者，不盲目過度追加 Statin 劑量（避免倍增劑量僅獲 6% 降幅及潛在肌痛副作用），應迅速聯用 **Ezetimibe**，必要時提早啟動 **PCSK9 單株抗體/siRNA** 或 **Bempedoic acid** 進行多靶點協同阻斷。
