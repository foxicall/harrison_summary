# 前庭神經系統評估與眩暈全方位臨床鑑別診斷指引
- **主講人/來源**：22 Dizziness and Vertigo.pdf（摘自 *Harrison's Principles of Internal Medicine*, 21st Edition, Chapter 22 by Mark F. Walker & Robert B. Daroff）
- **核心主旨**：頭暈與眩暈的精準診療核心不在於患者主觀模糊的詞彙描述，而在於發作時間軸、誘發因子及神經眼動學檢查（如 Head Impulse、眼震特徵）；臨床應跳脫盲目使用前庭抑制劑的舊思維，著重於排除危急中樞病變並促發神經可塑性代償與代謝修復。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **前庭神經輸入不對稱性**：急性單側迷路或前庭神經受損（如前庭神經炎、缺血）破壞兩側對稱的前庭靜止放電率，大腦皮質誤判為持續性旋轉運動，伴隨嚴重自主神經興奮（噁心、嘔吐）。
  - **生物力學與內耳微循環異常**：包括耳石自橢圓囊斑脫落進入半規管引發的重力流體力學刺激（BPPV）、內淋巴液吸收回流障礙引發的「內淋巴水腫」（梅尼爾氏症），以及偏頭痛引發的皮質擴散性抑制與腦血管舒縮不穩（前庭偏頭痛）。
  - **神經退化與中毒性凋亡**：雙側前庭功能低下常源自粒線體/內耳受損（如胺基糖苷類抗生素 ototoxicity）、神經退化疾病或自體免疫發炎。
  - **中樞神經迴路調控失靈**：後循環缺血（腦幹/小腦中風）、脫髓鞘病變，或前庭神經炎後大腦重塑障礙進展為慢性「持續性姿勢-知覺性頭暈」（PPPD）。
- **演講亮點與臨床洞察**：
  - **典範轉移（Paradigm Shift）**：停止過度依賴「頭暈（Dizziness）vs 旋轉性眩暈（Vertigo）」的病患主訴分類，改以「發作持續時間（秒、分、時、日）」與「觸發條件（姿勢變換、靜態旋轉）」為首要診斷階層。
  - **中樞 vs 週邊的黃金鑑別（HINTS 核心思維）**：急性持續性眩暈中，「正常的 Head Impulse Test（無矯正跳視）」高度暗示中樞性病變（如後循環中風）；方向變換型眼震、無法被固視抑制的純垂直或純扭轉眼震均為紅色警訊（Red Flags）。
  - **用藥禁忌警訊**：抗組織胺或鎮靜劑等前庭抑制藥物（Vestibular Suppressants）僅限於急性期最初數天使用，長期使用會抑制中樞神經代償（Central Compensation），導致慢性平衡失調。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 理學神經評估 | 臨床意義與評估目標 | 判讀標準與異常警訊 |
| :--- | :--- | :--- |
| **頭部甩動測試 (Head Impulse Test, HIT)** | 評估前庭動眼反射（VOR）完整性；鑑別急性單側前庭損傷與中樞中風 | • **異常（Catch-up Saccade 矯正跳視）**：多為週邊前庭缺損（轉向患側時出現代償性跳視）。<br>• **正常（無跳視）但伴急性持續性眩暈**：高度懷疑**中樞性病變（如小腦或腦幹梗塞）**。 |
| **Dix-Hallpike 誘發試驗** | 誘發後半規管耳石流動，確認良性陣發性姿勢性眩暈（BPPV） | 誘發具潛伏期（15–20秒）、短暫性（<1分鐘）且具疲勞性的**上轉扭轉性眼震（Upbeating-torsional nystagmus）**；眼球上極朝向下側患耳。 |
| **動態視力檢查 (Dynamic Visual Acuity, DVA)** | 評估頭部運動時的前庭眼動穩定功能（防禦振盪幻視 Oscillopsia） | 頭部以 1–2 Hz 旋轉時，視力表清晰度**下降超過 1 行（Snellen chart）**即屬異常，提示前庭功能低下。 |
| **純音聽力檢查 (Audiometry)** | 區分內耳傳導與感音神經性損傷 | • **低頻感音神經性聽損**：梅尼爾氏症（Ménière's disease）之特徵。<br>• **單側進行性感音聽損**：需懷疑前庭神經鞘瘤（Vestibular Schwannoma）。 |
| **腦部與內聽道 MRI (含釓造影 Gadolinium)** | 排除小腦/腦幹缺血、出血、脫髓鞘疾病或橋腦小腦角腫瘤 | 單側不明原因前庭缺損、不對稱聽損、純垂直眼震或具中樞神經徵象時必做。 |
| **前庭功能儀器檢查 (vHIT / VNG / Caloric / VEMP)** | 全面評估 6 條半規管與耳石器官（球囊、橢圓囊）各自的神經傳導完整度 | 溫差試驗（Caloric test）水平半規管反應降低；vHIT 呈現半規管增益下降；前庭誘發肌電位（VEMP）異常評估耳石反射。 |

## 三、 關鍵機制詳解與重點筆記

### 1. 眼動學與中樞 vs 週邊前庭徵象鑑別（Table 22-1 核心剖析）
- **眼震（Nystagmus）特性解析**：
  - **週邊型眼震**：單向性（Unidirectional）、水平扭轉性，快相（Fast phase）永遠朝向**健側**（遠離患側病灶），且藉由凝視固定（Visual fixation）可被明顯**抑制**（使用 Frenzel 透鏡或紅外線眼動儀消除固視後會大幅加劇）。
  - **中樞型眼震**：常為方向變換型凝視誘發眼震（Gaze-evoked nystagmus）、純垂直向下（Downbeat nystagmus）或純扭轉性（Pure torsional）；**無法被固視抑制**。
- **神經眼動軌跡（Pursuit & Saccades）**：
  - 平滑追隨運動（Smooth pursuit）斷續或跳視化、掃視過衝/不足（Dysmetric saccades），直接指向小腦或腦幹迴路異常。
  - 遮眼交替覆蓋測試（Cover test）若出現垂直錯位（Skew deviation），為小腦腦幹前庭通路受損之典型體徵。

### 2. 四大常見前庭疾患之病理與特徵
- **良性陣發性姿勢性眩暈（BPPV）**：
  - *機轉*：碳酸鈣耳石（Otoconia）自橢圓囊斑脫落進入半規管（最常見為後半規管 Posterior canal），頭部轉動時重力帶動耳石滾動推擠內淋巴與頂膜。
  - *臨床特徵*：極為短暫（<1分鐘，通常15–20秒），滾床、抬頭望高處時誘發。
- **前庭神經炎（Vestibular Neuritis）**：
  - *機轉*：多推測為病毒感染或血管微循環缺血引發前庭神經急性去神經化。
  - *臨床特徵*：急性、持續數天至數週的劇烈眩暈、噁心嘔吐與步態不穩；無耳蝸症狀（無新發聽損）；頭部晃動時振盪幻視。
- **梅尼爾氏症（Ménière’s Disease）**：
  - *機轉*：內淋巴囊再吸收衰退導致內淋巴水腫（Endolymphatic hydrops），膜迷路週期性破裂或受壓。
  - *臨床特徵*：眩暈發作持續數小時，合併**波動性低頻聽力損失、耳悶脹感（Aural fullness）與新發耳鳴**。
- **前庭偏頭痛（Vestibular Migraine）**：
  - *機轉*：三叉神經血管系統活化、皮質擴散性去極化擴展至前庭皮質神經核。
  - *臨床特徵*：發作可為數分鐘至數小時（甚至伴隨數天之不平衡感）；常不伴隨頭痛，但具備畏光、怕吵、視覺預兆或對運動視覺敏感。

### 3. 雙側前庭低下與功能性頭暈（PPPD）
- **雙側前庭功能低下（Bilateral Vestibular Hypofunction）**：
  - *機轉*：胺基糖苷類藥物（Gentamicin）耳毒性、自體免疫發炎、退化性共濟失調等。
  - *特點*：**通常完全不出現旋轉性眩暈（Vertigo）**（因兩側前庭神經無輸入不對稱性），主要表現為暗處嚴重失衡、行動時嚴重視野晃動（Oscillopsia），雙側 HIT 皆異常。
- **持續性姿勢-知覺性頭暈（PPPD）**：
  - *機轉*：多由急性眩暈事件（如前庭神經炎、驚恐發作）觸發後，中樞神經前庭調控失調、過度依賴視覺刺激，大腦威脅警報迴路慢性過載。
  - *特點*：症狀持續 $\ge 3$ 個月，站立與複雜視覺刺激（如大賣場貨架、觀看移動影像）時大幅惡化。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

```
[急性眩暈患者初診]
       │
       ├─ (1) 危急中樞徵象評估 (HINTS、腦神經/小腦徵象) ──[有異常/純垂直眼震/HIT正常]──> 急診神經科 / 腦部 MRI
       │
       ├─ (2) 發作時間 < 1 分鐘且姿勢誘發 ──[Dix-Hallpike 陽性]──> 執行 Epley 耳石復位術
       │
       ├─ (3) 發作數小時 + 低頻聽損/耳悶 ──> 梅尼爾氏症處置 (低鈉、利尿、水鹽平衡)
       │
       └─ (4) 急性單側持續眩暈 (前庭神經炎) ──> 早期短期症狀控制 -> 盡早停用鎮靜劑 -> 啟動前庭復健 (VRT)
```

### 1. 物理手法與復健處方
- **耳石復位手法（Canalith Repositioning Maneuvers）**：
  - **後半規管 BPPV**：首選 **Epley Maneuver（艾普利氏復位術）**。透過 5 步驟依序轉動頭部 45 度、仰臥頭後仰 20 度（維持 30 秒至眼震消失）、旋轉 90 度轉向健側、側臥轉頭面部朝下 45 度，最後坐起，利用重力將耳石倒回橢圓囊。
- **前庭復健治療（Vestibular Rehabilitation Therapy, VRT）**：
  - 適用於前庭神經炎後恢復期、雙側前庭功能低下、慢性失衡及 PPPD。
  - 核心為**凝視穩定度訓練（Gaze Stabilization Exercises）**、習服訓練（Habituation）及平衡再適應步態訓練，藉由本體感覺與視覺重塑中樞神經代償。

### 2. 功能性營養與微營養素介入（針對前庭神經修復與偏頭痛機制）
- **前庭偏頭痛神經安定配方**：
  - **鎂離子（Magnesium Glycinate / L-Threonate）**：400–600 mg/day，調控 NMDA 受體與腦血管平滑肌張力。
  - **核黃素（Riboflavin, Vitamin B2）**：200–400 mg/day，支持腦神經粒線體電子傳遞鏈代謝。
  - **輔酶 Q10（Coenzyme Q10）**：100–300 mg/day，減輕神經元氧化壓力。
- **內耳微循環與水鹽代謝支持（梅尼爾氏症）**：
  - **飲食鈉限制**：每日鈉攝取嚴格控制於 1,500–2,000 mg 以下，避免內耳淋巴滲透壓震盪。
  - **銀杏葉萃取物（EGb 761）**：輔助改善微末梢循環與毛細血管灌流。

### 3. 環境與神經可塑性生活型態
- **禁用長期前庭抑制劑（Critical Warning）**：
  - Dimenhydrinate、Meclizine、Diazepam 等僅限急性期發作**最初 48–72 小時**使用，一旦嘔吐控制應立即停藥；延遲停藥會阻礙大腦突觸修復與代償機制的建立。
- **感官漸進暴露法（PPPD 管理）**：
  - 針對複雜視覺環境敏感者，實施階梯式環境視覺暴露，搭配自主神經調節（腹式呼吸、心率變異度 HRV 訓練）與認知行為治療（CBT），降低下視丘-腦下垂體-腎上腺（HPA）軸的過度警覺。
- **避免耳毒性物質暴露**：
  - 審慎評估 aminoglycoside 類抗生素、特定白金類化療藥與高劑量環利尿劑，保護前庭毛細胞粒線體。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **落實 HINTS 評估三部曲**：面對急性持續性眩暈（AVS），務必精確執行 Head Impulse Test、觀察眼震是否方向變換、執行 Cover Test 排除垂直偏位，切勿僅因「沒有肢體無力」就排除後循環中風。
2. **位置性發作首重 Epley 復位**：對於短暫姿勢改變誘發之眩暈，優先以 Dix-Hallpike 確認病灶並實施 Epley maneuver，耳石復位成功率極高，切忌開立止暈藥敷衍了事。
3. **前庭神經炎的黃金康復期**：急性前庭神經炎在噁心劇烈期過後（$\le 3$ 天），應強烈衛教病患「越早動、好越快」，立即停用止暈藥並啟動 VRT 前庭注視穩定訓練。
4. **警惕單側進行性聽損**：凡伴隨單側不對稱感音神經聽力下降或單側耳鳴的眩暈患者，務必轉診安排含顯影劑之內聽道 MRI，排除前庭神經鞘瘤。
5. **梅尼爾氏症的生活醫學處方**：落實限鈉（<2g/天）、規律補水、戒除咖啡因與高精緻糖飲食，以穩定內耳內淋巴液恆定性。
