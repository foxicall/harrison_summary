# 光敏感性與陽光引起的皮膚病理反應（Photosensitivity and Other Reactions to Sunlight）

- **主講人/來源**：Alexander G. Marneros, David R. Bickers / *Harrison's Principles of Internal Medicine*, Chapter 61 (61 Photosensitivity and Other Reactions to Sunlight.pdf)
- **核心主旨**：陽光紫外線與可見光透過光生物化學與光免疫學反應驅動皮膚光老化、DNA 突變、免疫抑制與多樣性光敏感疾病；臨床需精準辨識致病光譜、光毒性/光過敏機轉與紫質代謝異常，並建立整合物理阻隔、細胞抗氧化與代謝調節的個人化防護策略。

---

## 一、 核心要點精華（Executive Clinical Summary）

### 核心病理生理機制
1. **DNA 直接突變與光致癌（UV-B 途徑）**：UV-B（290–320 nm）直接被表皮 DNA 吸收，誘導相鄰嘧啶鹼基形成環丁烷嘧啶二聚體（Cyclobutane Pyrimidine Dimers, CPD）與 6,4-光產物（6,4-Photoproducts），導致具特異性的 UV 標記突變（$C \to T$ 及 $CC \to TT$），好發於 *p53* 與 *NOTCH1* 基因，驅動鱗狀細胞癌（SCC）與基底細胞癌（BCC）。
2. **氧化壓力與光老化（UV-A 途徑）**：UV-A（320–400 nm）穿透至真皮層，激發內源性發色團產生活性氧物質（ROS），活化基質金屬蛋白酶（MMP-1、MMP-3），分解細胞外基質膠原蛋白，並抑制第一型原膠原蛋白（Type I procollagen）mRNA 合成，導致異常彈性纖維沉積（日光性彈性纖維變性，Solar elastosis）。
3. **神經內分泌與成癮軸線**：角質形成細胞受 UV 照射後，藉由 p53 活化促阿片黑素細胞皮質素（POMC）轉錄，裂解為 $\alpha$-黑素細胞刺激素（$\alpha$-MSH）與 $\beta$-腦內啡（$\beta$-endorphin）；後者進入體循環被認為是誘發「曬太陽尋求行為」與「日曬成癮」的生物學基礎。
4. **光免疫抑制（Photoimmunology）**：UV 輻射造成表皮蘭格罕氏細胞（Langerhans cells）空洞化耗竭，並使角質層的 *反式*-尿刊酸（*trans*-urocanic acid）異構化為 *順式*-尿刊酸（*cis*-urocanic acid），誘導 IL-10、IL-4 分泌與調節性 T 細胞（Tregs）增殖，全身性抑制抗原呈現與抗腫瘤免疫監控。

### 演講亮點與臨床洞察
- **黑素亞型決定抗氧化與促癌風險**：優黑素（Eumelanin，黑/棕）能有效阻隔 UV；褐黑素（Pheomelanin，紅/黃）含半胱胺酸結構，光防護力極差，甚至可藉由非 UV 依賴性與 UV-A 激發之 ROS 途徑加劇黑素瘤形成。
- **光致癌三階段中 UV-B 的完整致癌性**：UV-B 同時具備起始劑（Initiator，誘導無可逆突變）與促進劑（Promoter，促進純系擴增形成日光性角化症 Actinic Keratosis）的雙重角色，被定義為完整致癌物（Complete Carcinogen）。
- **光毒性 vs. 光過敏的關鍵分水嶺**：光毒性為非免疫性、劑量依賴性的直接組織損傷（外觀似嚴重曬傷，易脫屑水泡）；光過敏為遲發性第 IV 型超敏反應（需經由光活化形成半抗原抗原複合物，表現為劇烈搔癢的濕疹化病灶）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 臨床判讀與標準參考 |
| :--- | :--- | :--- |
| **最小致紅斑劑量 (MED) 測定** | 評估皮膚對 UV-A/UV-B 之紅斑反應閾值；於服藥前後比對以確立光毒性診斷。 | 暴露於 UV-A/UV-B 後 24 小時讀取；持續性光反應（PLR）患者對 UV-B 的 MED 顯著下降。 |
| **光貼布試驗 (Photopatch Testing)** | 診斷遲發性光過敏反應（Photoallergy），鑑別外源性光致敏原（如防曬劑、外用藥、香精）。 | 雙側背部貼敷過敏原，一側照射亞紅斑劑量 UV-A；僅照射側出現濕疹樣反應為陽性。 |
| **血漿/尿液紫質分析 (Porphyrin Screen)** | 鑑別慢性水泡性光敏感疾病（如遲發性皮膚紫質症 PCT）與急性非水泡性病變。 | PCT 患者尿液中尿紫質（Uroporphyrin）大幅上升；血漿紫質螢光光譜於 615–620 nm 出現發射峰。 |
| **紅血球原紫質 (Erythrocyte PROTO)** | 評估紅血球生成性原紫質症（EPP）與 X 染色體原紫質症（XLP）。 | 游離原紫質顯著升高；需注意金屬螯合原紫質（如鉛中毒、缺鐵性貧血）不具光致敏活性。 |
| **自體抗體譜 (ANA, Anti-Ro/SSA, Anti-La/SSB)** | 鑑別光加劇性自體免疫疾病（紅斑性狼瘡 SLE、亞急性皮膚紅斑狼瘡 SCLE、皮肌炎）。 | 陽性反應需優先考慮自體免疫性光敏感，排除單純多形性日光疹（PMLE）。 |
| **血清鐵蛋白與轉鐵蛋白飽和度** | 評估 PCT 病患之肝臟鐵過載狀態；作為治療（放血）監控指標。 | PCT 病患常伴隨肝鐵沉積與 *HFE* 基因突變（血色病相關），治療目標為耗竭多餘鐵儲存。 |
| **血清 25-羥基維生素 D [25(OH)D]** | 評估嚴格防曬或年長族群之維生素 D 生物合成狀態。 | 理想功能醫學範圍建議維持於 40–60 ng/mL；不足時建議經口補充，而非刻意曬傷日曬。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 光生物學作用光譜與組織穿透深度
- **UV-B（290–320 nm）**：主要被角質層與表皮層吸收，僅約 3% 穿透至基底細胞層。光子能量最高，為引起曬傷紅斑（Sunburn Spectrum）最高效波段（比 UV-A 高約 1000 倍）。
- **UV-A（320–400 nm）**：穿透力深達真皮網狀層，超過 20% 能穿透表皮。雖然引起急性紅斑效率低，但在正午陽光中通量遠高於 UV-B，是造成慢性光老化、真皮膠原降解與多數光過敏/光毒性反應的主要光譜。
- **可見光（400–700 nm）與 Soret 帶（400–410 nm）**：在缺乏光敏劑時不傷人體；但若體內沉積過量紫質（Porphyrins），紫質會在 400–410 nm（Soret 帶）及 580–660 nm（紅光區）強烈吸收光子，引發第 II 型光動力反應，產生單線態氧（$^1\text{O}_2$）與超氧陰離子，攻擊微血管與組織。

```
[陽光光譜] ───┬── UV-B (290-320nm)  ──> 表皮角質細胞/DNA ──> 嘧啶二聚體/p53突變 ──> SCC/BCC
              ├── UV-A (320-400nm)  ──> 真皮纖維母細胞 ────> ROS/MMP-1,3活化 ─────> 光老化/彈性纖維變性
              └── 可見光 (400-700nm) ──> (需外源/內源光敏劑) ─> 紫質活化/ROS生成 ──────> 組織壞死/水泡
```

### 2. 黑素生化合成與 Fitzpatrick 皮膚分型機制
- **MC1R 訊息傳導途徑**：角質形成細胞受 UV 照射後，釋放 $\alpha$-MSH 結合至黑素細胞的 G 蛋白偶聯受體 MC1R $\to$ 活化腺苷酸環化酶，使細胞內 cAMP 上升 $\to$ 活化蛋白激酶 A（PKA） $\to$ 上調小眼畸形相關轉錄因子（MITF） $\to$ 驅動酪胺酸酶（Tyrosinase）活性，促進黑色素生成並轉移至黑素小體（Melanosomes）。
- **Fitzpatrick 分型與致癌風險**：
  - **Type I/II（紅髮、白皙、極易曬傷、不易曬黑）**：常帶有 *MC1R* 功能缺失突變，主要合成紅/黃色的褐黑素（Pheomelanin），屏蔽 UV 效果差且易產生內源性自由基，罹患黑素瘤及 NMSC 之風險最高。
  - **Type IV–VI（深膚色、極易曬黑、不易曬傷）**：優黑素（Eumelanin）比例高，提供強大的天然光防護網。

```
UV 輻射 ──> 表皮角質細胞 (p53 活化) ──> POMC 裂解 ──┬──> β-Endorphin ──> 中樞成癮/日曬尋求行為
                                                   └──> α-MSH ──> 結合黑素細胞 MC1R 
                                                                    │
                                                                 (cAMP ↑ / PKA)
                                                                    │
                                                                    ▼
                                                               MITF 轉錄增加
                                                                    │
                                                                    ▼
                                                     酪胺酸酶活化 ──> 黑色素生成 (優黑素 vs 褐黑素)
```

### 3. 光毒性（Phototoxicity）與光過敏（Photoallergy）的病理生理區分

```
                   ┌── 光毒性 (Phototoxic)：非免疫性、化學物質直接吸光產生 ROS ──> 曬傷樣水泡/脫屑
[藥物/化學物光敏感] ┤
                   └── 光過敏 (Photoallergic)：免疫性 (第 IV 型)、光活化形成半抗原 ─────> 劇癢濕疹樣病灶
```

- **光毒性（Phototoxicity）**：
  - **機轉**：藥物吸收光能進入激發態，直接轉移能量給周邊分子或氧分子，產生 ROS 與自由基，引起直接細胞壞死。
  - **常見致病藥物**：Amiodarone、四環黴素類（Tetracyclines，如 Doxycycline）、氟喹諾酮類（Fluoroquinolones）、Thiazide 類利尿劑、Furosemide、NSAIDs、磺胺類、Psoralens。
  - **特殊表現**：植物日光性皮膚炎（Phytophotodermatitis，接觸傘形科植物中的呋喃香豆素 furocoumarins 經 UV-A 誘發）。
- **光過敏（Photoallergy）**：
  - **機轉**：光能將光敏原轉化為高活性游離基半抗原，與皮膚大分子載體蛋白共價結合形成全抗原，致敏 T 淋巴細胞，引發遲發型超敏反應（Type IV delayed hypersensitivity）。
  - **臨床特點**：常擴散至非日曬部位，病灶呈急性或亞急性濕疹；少數病患在停藥後仍演變為「持續性光反應（Persistent light reaction）」或「慢性光化性皮炎（CAD）」。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 內源性抗氧化劑與功能性營養補充
- **$\beta$-胡蘿蔔素（$\beta$-Carotene）**：
  - **適應症**：原紫質症（EPP）與重度光過敏病患。
  - **機制**：作為強效物理與化學單線態氧猝滅劑（Singlet oxygen quencher），清除光致激發態分子，改善患者對陽光的耐受閾值。
- **維生素 D3 經口最佳化補充**：
  - **策略**：光敏感病患及嚴格防曬者體內光合作用受阻，應直接經口補充維生素 D3（建議每日 2000–5000 IU，依血清 25(OH)D 數值調整），避免藉由未受保護之日曬獲取維生素 D。
- **NSAIDs 早期抗發炎干預**：
  - **機制**：UV 輻射可強烈活化磷脂酶 $\text{A}_2$（$\text{PLA}_2$）生成前列腺素 $\text{E}_2$（$\text{PGE}_2$）；於曬傷急性期（4–12 小時內）早期給予 NSAIDs 可有效抑制花生四烯酸發炎瀑布，緩解紅斑與血管舒張。

### 2. 代謝與標靶處方介入
- **遲發性皮膚紫質症（PCT）代謝阻斷處方**：
  - **重複性靜脈放血（Phlebotomy）**：每 1–2 週放血一次，持續至血清鐵蛋白降至低正常值，以耗竭肝臟過量鐵沉積，解除其對尿紫質原去羧酶（UROD）的抑制。
  - **超低劑量羥氯喹（Hydroxychloroquine）**：每週兩次、低劑量口服（100–200 mg，不可使用標準狼瘡劑量以免誘發猛爆性肝毒性），可增加水溶性紫質由肝臟釋出並自尿液排除。
- **新型神經內分泌胜肽模擬物（Afamelanotide）**：
  - **適應症**：FDA 核准用於紅血球生成性原紫質症（EPP）。
  - **機制**：合成型 $\alpha$-MSH 類似物皮下植入劑，能繞過 UV 光刺激直接活化 MC1R 誘導優黑素生成，提供內源性物理屏障，使病患免於灼痛並大幅延長耐曬時間。

### 3. 全光譜物理阻斷與環境毒素管理
- **防曬劑科學配方選擇**：
  - **廣色域光防護（Broad-Spectrum SPF $\ge 30$）**：SPF 僅反映 UV-B 防護比率，必須併用廣譜 UV-A 吸收劑。
  - **物理型礦物阻斷劑（首選）**：氧化鋅（Zinc Oxide, ZnO）與二氧化鈦（Titanium Dioxide, $\text{TiO}_2$），能同時反射與吸收 UV-B、UV-A 及部分短波可見光，安全性最高且極少引起光過敏。
  - **化學型成分辨識**：防護 UV-B（水楊酸酯類 Salicylates、肉桂酸酯類 Cinnamates）；防護 UV-A（Avobenzone、Ecamsule/Mexoryl SX）。
- **光致硬化預防療法（Photohardening）**：
  - 針對多形性日光疹（PMLE）患者，於春季初開始，預防性給予微量遞增的窄頻 UV-B（NB-UVB）或 PUVA（補骨脂素加 UV-A）治療約 4 週，誘導角質層增厚、黑素沉著與局部免疫適應，預防夏季大爆發。
- **代謝毒素阻斷**：
  - 嚴格禁絕激發 PCT 表現的誘發因子：完全戒酒（Ethanol）、停用外源性雌激素（Estrogens）、積極治療慢性 C 型肝炎病毒（HCV）感染。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **藥物史排查為光敏感評估第一步**：遇到日曬區突發性皮疹，立即檢視當前用藥清單（特別是降血壓藥 Thiazides、抗生素 Fluoroquinolones/Doxycycline、心律不整藥 Amiodarone 與降血糖藥 Sulfonylureas），確認是否為光毒性反應。
2. **區分水泡病灶：慢性水泡必驗紫質**：手背、前臂伸側出現易碎性水泡、出血性糜爛、紫斑伴隨多毛症者，應即刻安排尿液與血漿紫質測定，確立遲發性皮膚紫質症（PCT）並檢驗鐵代謝與 HCV。
3. **推動健康維生素 D 獲取途徑**：明確告知病患，防曬乳使用並不會在現實生活中造成顯著的維生素 D 缺乏；應鼓勵透過口服營養補充達標，而非承擔 UV-B 誘導 *p53* 突變與光老化的風險進行「美黑」或刻意過度日曬。
4. **高危險族群落實廣譜物理防護**：器官移植長期使用免疫抑制劑者（SCC 風險飆升）、Fitzpatrick Type I/II 族群，應處方 SPF $\ge 30$ 且含高比例 Zinc Oxide 之廣譜抗水型物理防曬，並配合 UPF 認證抗 UV 緊密編織衣物與闊邊遮陽帽。
5. **多形性日光疹（PMLE）之超前部署**：對於每年春夏之交反覆發作劇癢丘疹的 PMLE 病患，於早春及早安排 NB-UVB 脫敏硬化療程（Hardening），能顯著改善其夏季生活品質並減少外用強效類固醇的使用頻率。
