# 凝血與血栓形成的生理病理、臨床評估與整合醫學洞察（Bleeding and Thrombosis）
- **主講人/來源**：65 Bleeding and Thrombosis.pdf（Barbara A. Konkle, MD / 《哈里遜內科學》第 65 章）
- **核心主旨**：人體止血系統是促凝、抗凝與纖溶機制高度協調的動態平衡；臨床上評估出血與血栓風險時，必須結合精確病史（如 ISTH 評分）、實驗室篩檢演算法，並嚴密審視生活型態、內源性慢性發炎及高劑量營養補充品／草本植物對血小板與凝血路徑的調控作用。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **初級與次級止血的動態協同**：血管內皮損傷暴露組織因子（TF）與皮下膠原，經 von Willebrand 因子（vWF）媒介血小板黏附及活化（釋放 ADP、TXA2、Serotonin），誘發 Gp IIb/IIIa 受體構型改變形成血小板血栓；隨後經由 TF-FVIIa 複合物啟動凝血，並藉由凝血酶（Thrombin, FIIa）正回饋活化 FXI、FVIII 與 FV 進行訊號放大，終至纖維蛋白原轉化為不溶性交聯纖維蛋白網（經 FXIIIa 穩定）。
  - **內源性抗凝與纖溶保護罩**：健康內皮細胞恆常分泌前列環素（$\text{PGI}_2$）、一氧化氮（NO）、CD39（ectoADPase）抑制血小板聚集；抗凝血酶（AT-III）、蛋白質 C/S 系統（經 Thrombomodulin 及 EPCR 活化）與組織因子途徑抑制劑（TFPI）負責侷限凝血反應；纖溶系統（tPA/uPA-纖溶酶）及調控蛋白（PAI-1、TAFI、$\alpha_2$-antiplasmin）負責適時溶解血栓並促進組織修復。
  - **多重因子血栓累積模型（Multicausal Model）**：血栓形成並非單一因素所致，而是內源性基因易感性（如 Factor V Leiden、Prothrombin G20210A）疊加年齡老化、內皮發炎、荷爾蒙暴露（OCP/HRT）、肥胖及手術或固定不動等觸發因子，跨越臨床血栓閾值而爆發。
- **演講亮點與臨床洞察**：
  - **病史勝於常規實驗室篩檢**：常規術前凝血篩檢（aPTT/PT）對無出血史患者的出血風險預測力極差；臨床上標準化的出血評估工具（如 ISTH-BAT）能有效排除輕微出血疾患，避免不必要的侵入性檢驗。
  - **功能性補充品與草本植物的止血干擾**：高劑量 Omega-3 脂肪酸透過轉化生成抑制性更強的 $\text{PGI}_3$ 與弱促凝活性的 $\text{TXA}_3$ 抑制血小板功能；維生素 E 藉由抑制蛋白激酶 C（PKC）及影響 NO 釋放干擾凝集；多種常見草本（銀杏、大蒜、薑黃、人參、白三葉草等）具抗血小板或含香豆素活性，在整合醫療門診中是造成不明瘀青或術中出血的隱形推手。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **血小板計數 (Platelet Count)** | 評估骨髓生成、周邊破壞或脾臟隔離；判斷自發性出血與侵入性處置安全界限 | 正常範圍：$150,000\sim 450,000/\mu\text{L}$。<br>多數侵入性手術安全門檻：$\ge 50,000/\mu\text{L}$；自發性出血高危險：$<10,000\sim 20,000/\mu\text{L}$ |
| **凝血酶原時間 / 國際標準化比值 (PT/INR)** | 評估外在路徑與共同路徑（因子 I, II, V, VII, X）及維生素 K 依賴性凝血因子合成功能 | INR 正常約 $0.8\sim 1.2$。<br>對輕度肝功能異常者可能高估出血風險；評估 DOAC（特別是 Apixaban）敏感度受限 |
| **活化部分凝血活酶時間 (aPTT)** | 評估內在路徑與共同路徑（因子 XII, HMWK, PK, XI, IX, VIII, X, V, II, I）及肝素監測 | 因子活性降至正常的 $30\%\sim 50\%$ 時呈現延長；易受試劑磷脂質成分與抗磷脂抗體干擾 |
| **血漿混合試驗 (Mixing Studies, 1:1)** | 鑑別 aPTT 或 PT 延長是因「凝血因子缺乏」或存在「病理性抑制物」 | **因子缺乏**：即刻與 $37^\circ\text{C}$ 溫育後皆能校正。<br>**狼瘡抗凝物 (LA)**：即刻與溫育均不校正。<br>**FVIII 抑制物**：即刻可能暫時校正，但溫育 $30\sim 120$ 分鐘後再度延長 |
| **D-二聚體 (D-dimer)** | 反映經 FXIIIa 交聯之纖維蛋白被纖溶酶完全降解的特異性產物，評估活動性血栓與纖溶 | 臨床常用於排除 DVT/PE；隨年齡遞增，高齡患者使用傳統臨界值易造成偽陽性 |
| **抗凝血因子 Xa 活性 (Anti-Factor Xa Assay)** | 監測低分子量肝素（LMWH）、未分餾肝素（UFH）或直接口服 Factor Xa 抑制劑活性 | 透過專一性發色受質水解抑制曲線進行定量分析 |
| **稀釋羅素蛇毒時間 (dRVVT) / LA 評估** | 檢測依賴磷脂質的抗磷脂抗體（狼瘡抗凝物）；透過降低試劑磷脂質濃度提升敏感度 | 篩檢延長＋混合不校正＋添加過量血小板磷脂質後時間縮短（確認陽性） |
| **ISTH 止血評估工具 (ISTH-BAT)** | 客觀量化自發性或創傷性出血症狀（如月經過多、鼻衄、拔牙後出血）之臨床評分 | 藉由結構化問卷量化出血表現，能有效篩檢或排除 Type 1 vWD 及輕度出血疾患 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 初級止血：內皮損傷與血小板栓子形成（Platelet Plug Formation）
- **黏附（Adhesion）**：高流速/高剪切力小動脈環境下，血管內皮破損暴露膠原纖維，血漿與內皮下基質中的 **von Willebrand 因子（vWF）** 扮演「分子膠水」，鍵結內皮下膠原與血小板膜上的 **Gp Ib-IX-V 複合物**；血小板表面亦具有直接結合膠原之受體。
- **活化與分泌（Activation & Secretion）**：結合引發胞內訊息傳遞，血小板脫顆粒釋放濃染顆粒（ADP、Serotonin、鈣離子）與 $\alpha$ 顆粒（vWF、Fibrinogen、Factor V 等），並活化 COX-1 催化生成血栓素 $\text{A}_2$（$\text{TXA}_2$）。
- **聚集（Aggregation）**：血小板活化誘導最豐富的表面受體 **Gp IIb/IIIa（$\alpha_{\text{IIb}}\beta_3$）** 發生立體結構轉化，轉為高親和力狀態，與血漿中的**纖維蛋白原（Fibrinogen）**及 vWF 結合，透過雙價交聯橋樑迅速形成緻密的血小板栓子網絡。

```
[血管內皮損傷 / 膠原暴露]
        │
        ├─► vWF 結合內皮下膠原 ──► 抓取血小板 Gp Ib-IX-V 受體（初級黏附）
        │
        └─► 血小板活化 (釋放 ADP, TXA2, 5-HT) ──► Gp IIb/IIIa 受體活化
                                                        │
                                                        ▼
                                          纖維蛋白原橋接相鄰血小板
                                                        │
                                                        ▼
                                              【初期血小板血栓形成】
```

### 2. 次級止血：凝血瀑布的現代觀點（TF 啟動與內在途徑放大網絡）
傳統將凝血區分為各自獨立的「外在」與「內在」路徑，現代凝血生物學則證實兩者密不可分：
- **啟動階段（Initiation）**：血管壁平滑肌與成纖維細胞表面微粒子持續表達的 **組織因子（TF）** 暴露於血流，與活化型第七因子（FVIIa）結合形成 **TF/FVIIa 複合物**，直接活化少量 FX 為 FXa，亦同步將 FIX 活化為 FIXa。
- **限制與轉換（Inhibition by TFPI）**：新生之 FXa 與 TF/FVIIa 迅速被內源性 **組織因子途徑抑制劑（TFPI）** 阻斷，使得外在啟動機制暫停。
- **傳播與放大階段（Propagation & Amplification）**：初始生成的微量凝血酶（Thrombin, FIIa）回饋活化 **FXI $\to$ FXIa**、**FVIII $\to$ FVIIIa** 以及 **FV $\to$ FVa**。
  - **Tenase 複合物**：FIXa 結合輔因子 FVIIIa，於活化血小板酸性磷脂質表面以極高效率裂解活化 FX。
  - **Prothrombinase 複合物**：FXa 結合輔因子 FVa，爆發性催化凝血酶原（Prothrombin, FII）轉化為凝血酶（Thrombin）。
- **血纖維蛋白形成與交聯**：凝血酶水解纖維蛋白原的 A/B 肽段生成纖維蛋白單體，自發聚合成原纖維；凝血酶同時活化 **FXIII $\to$ FXIIIa**，催化纖維蛋白 D-domain 間形成共價交聯胜肽鍵，構築不可溶性抗剪切力血纖維蛋白網（見下圖原理）。

```
      【啟動 Initiation】                 【放大 Propagation】
   Vessel Injury ──► TF 暴露                 Thrombin (IIa) 正回饋
                        │                            │
             FVIIa ──► TF/FVIIa 複合物         ┌─────┼─────┐
                        │                     ▼     ▼     ▼
             ┌──────────┴──────────┐        FXIa  FVIIIa FVa
             ▼                     ▼          │     │     │
         FX ──► FXa            FIX ──► FIXa ──┴─────┘     │
                 │                       │                │
                 │ (受 TFPI 抑制)          ▼                │
                 │                 [FIXa/FVIIIa 複合物]   │
                 │                       │                │
                 └───────────────────────┼──► FX ──► FXa  │
                                         │            │   │
                                         ▼            ▼   ▼
                                        【FXa/FVa 凝血酶原酶複合物】
                                                      │
                                                      ▼
                                       Prothrombin (II) ──► Thrombin (IIa)
                                                                │
                                          Fibrinogen ──► Fibrin Mesh (FXIIIa 交聯)
```

### 3. 內源性抗凝與纖維蛋白溶解調控系統
- **抗凝血酶（Antithrombin, AT）**：血漿中主要的絲胺酸蛋白酶抑制劑，直接中和 Thrombin、FXa、FIXa 等；血管內皮表面的硫酸乙醯肝素（Heparan sulfate）可使其抑制速率暴增數千倍。
- **蛋白質 C 與 S 系統（Protein C/S Pathway）**：
  - 凝血酶結合內皮表面 **Thrombomodulin（TM）** 後喪失促凝活性，轉而專一活化結合在 **EPCR（內皮蛋白質 C 受體）** 上的蛋白質 C。
  - 活化型蛋白質 C（APC）在輔因子 **游離蛋白質 S** 協同下，蛋白水解失活 FVIIIa 與 FVa，形成負回饋煞車。
  - *臨床變異*：Factor V Leiden（FVa 裂解位點突變）產生 APC 抗性，為遺傳性血栓形成關鍵成因。
- **纖溶機制（Fibrinolysis）**：
  - 內皮細胞釋放 **tPA** 與 **uPA**，特異性切割結合於纖維蛋白離胺酸（Lysine）殘基上的纖溶酶原（Plasminogen）形成 **纖溶酶（Plasmin）**。
  - 纖溶酶水解交聯纖維蛋白生成 **D-二聚體（D-dimer）**。
  - *纖溶抑制機制*：**PAI-1**（抑制 tPA/uPA）、**TAFI**（凝血酶活化纖溶抑制物，切除纖維蛋白 C-端離胺酸阻斷 tPA 結合）、**$\alpha_2$-antiplasmin**（快速中和血漿中游離纖溶酶）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素與植化素調控（抗血栓 vs 出血風險雙向評估）
- **高純度 Omega-3 多元不飽和脂肪酸（EPA / DHA）**：
  - **生化機轉**：競爭性置換血小板膜磷脂質上的花生四烯酸（AA），引導 COX-1 與 TX 裂解酶生成活性微弱的血栓素 $\text{A}_3$（$\text{TXA}_3$），並促使內皮生成強效抗聚集前列環素 $\text{PGI}_3$。
  - **臨床應用與警戒**：心血管抗發炎保護劑；若日常攝取劑量 $>3\sim 4\text{ g/day}$，可能顯著延長出血時間，進行重大手術前 7~10 天宜評估暫停或減量。
- **維生素 E（$\alpha$-生育酚）**：
  - **生化機轉**：抑制血小板內蛋白激酶 C（PKC）訊息路徑，降低細胞骨架重組與顆粒釋放；調節內皮 eNOS 活性促進 NO 釋放。
  - **臨床劑量監控**：超高劑量（$>800\sim 1200\text{ IU/day}$）可能拮抗維生素 K 依賴性羧化作用並抑制血小板功能，合併抗凝劑時具出血風險。
- **具顯著抗血小板活性的草本萃取物（Herbs with Antiplatelet Activity）**：
  - **銀杏（Ginkgo biloba）**：拮抗血小板活化因子（PAF 受體）。
  - **大蒜素（Garlic / Allium sativum）**：抑制血小板內鈣離子內流與 TXA2 合成。
  - **薑黃素（Curcuma longa）**：抑制 AA 代謝路徑中之 COX 與 LOX 途徑。
  - **其他**：小白菊（Feverfew）、薑（Ginger）、當歸（Dong quai）、西洋參／高麗參（Panax ginseng）等。
- **含天然香豆素（Coumarin-Containing）草本**：
  - **草本品項**：黃花草木樨、母草（Motherwort）、洋甘菊（Chamomile）、歐洲七葉樹（Horse chestnut）、紅三葉草（Red clover）、胡蘆巴（Fenugreek）。
  - **臨床意義**：含香豆素衍生物，具潛在競爭性抑制維生素 K 環氧化物還原酶之風險，禁止與 Warfarin 或 DOAC 未經監控下合併重疊使用。

### 2. 代謝與發炎驅動血栓之生活型態干預策略
- **逆轉高凝血狀態的代謝核心（Targeting PAI-1 & Chronic Inflammation）**：
  - 內臟脂肪組織為 **PAI-1（纖溶酶原活化劑抑制物-1）** 的主要病理性分泌來源，胰島素阻抗與內臟肥胖會大幅壓制內源性纖溶能力，誘發低度發炎性血栓倾向。
  - **間歇性斷食與低升糖抗發炎飲食**：透過降低胰島素濃度、下調 NF-$\kappa$B 轉錄路徑，抑制內皮黏附分子（ICAM-1、VCAM-1）表達，減少血管內皮微粒子釋放。
- **內皮一氧化氮合酶（eNOS）支持與血管通透保護**：
  - **飲食型態**：地中海型飲食結構，富含天然多酚、無機硝酸鹽（甜菜根、深綠色蔬菜），促進血管舒張因子 NO 與 $\text{PGI}_2$ 之合成。
  - **規律阻力與有氧運動**：提供血管週期性生理剪切力（Fluid Shear Stress），上調內皮 KLF2 轉錄因子，促進 Thrombomodulin 及 TFPI 表達，同時抑制組織因子（TF）的病理性暴露。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **結構化落實出血病史詢問**：在門診中面對主訴易瘀青、經血過多（血塊 $>1$ 英吋、每小時需更換護墊、合併缺鐵性貧血）之患者，優先使用標準化出血評估量表（如 ISTH-BAT）評估，避免無指徵地開立常規 aPTT/PT 篩檢。
2. **精確解讀凝血篩檢與混血試驗（Mixing Study）**：
   - 面對單純 aPTT 延長：優先確認採血是否抗凝劑比例錯誤（真空採血未達 $90\%$ 或 Hct $>55\%$）。
   - 執行 1:1 混血試驗：立即與溫育後均校正為「凝血因子缺乏」；溫育後再度延長須高度懷疑「後天性凝血因子抑制物（如 Acquired FVIII inhibitor）」；皆不校正則需進行 dRVVT 檢驗排查「抗磷脂抗體／狼瘡抗凝物」。
3. **整合性藥物與營養補充品審查（Supplement Reconciliation）**：
   - 臨床遇不明皮下出血、反覆鼻衄或術前評估時，嚴格排查是否合併使用高劑量魚油、維生素 E，以及銀杏、大蒜素、薑黃素、當歸、洋甘菊等草本配方。
   - 預定重大侵入性手術前，建議於術前 7~14 天有計劃地暫停具有強抗血小板/抗凝活性之保健食品。
4. **多維度評估靜脈血栓（VTE）復發風險**：針對初次深層靜脈血栓（DVT）患者，務必區分「突發特發性（Unprovoked）」或「誘發性（Provoked）」，特發性是預測復發的最強危險因子；評估肥胖、高齡及荷爾蒙製劑暴露，審慎制定長期抗凝時程。
