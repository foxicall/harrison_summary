# 主動脈瓣逆流之病理生理、臨床表徵與手術介入精準決策（Aortic Regurgitation: Pathophysiology, Clinical Manifestations, and Management）
- **主講人/來源**：Patrick T. O’Gara, Joseph Loscalzo / 262 Aortic Regurgitation.pdf (Harrison's Principles of Internal Medicine)
- **核心主旨**：深入剖析主動脈瓣逆流（AR）從代償期（離心性肥厚與前/後負荷雙重增加）至心肌失代償的血流動力學演變，確立以「收縮末期維度（LVESD）」與「射出分率（LVEF）」為核心的黃金手術介入時機，並提供急慢性病況的精準醫療與生活型態管理方針。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **前負荷與後負荷雙重加載**：逆流量造成左心室舒張末期容積（LVEDV）大幅增加引發代償性離心性肥厚；依據拉普拉斯定律（Laplace's Law），心室擴張顯著增加收縮期室壁張力（Afterload），最終導致心肌細胞纖維化與收縮衰竭。
  - **心肌灌流壓差失衡與內皮微循環缺血**：主動脈舒張壓顯著驟降（冠狀動脈灌注壓降低）合併心室重塑導致心肌氧耗劇增，即使無心外膜冠狀動脈疾病（CAD），患者仍會發生嚴重的內皮與心內膜下心肌缺血。
- **演講亮點與臨床洞察**：
  - **無症狀假象與不可逆損傷時間窗**：慢性嚴重 AR 可維持長達 10～15 年的無症狀代償期。若延誤治療超過左心室功能障礙出現或症狀爆發後 1 年，術後心室結構與功能將無法完全恢復。
  - **治療禁忌與血流動力學陷阱**：急性重度 AR **嚴格禁忌主動脈內氣球幫浦（IABP）**（會加劇逆流）及 **β 受體阻斷劑**（延長心室舒張期將增加反流量並惡化心輸出量）；慢性無症狀且血壓正常者，預防性使用血管擴張劑無法延緩手術時機。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 介入臨界數值標準 |
| :--- | :--- | :--- |
| **超音波：Vena Contracta (VC)** | 評估瓣膜逆流狹頸部寬度，定義逆流嚴重度 | **>0.6 cm**（代表 Severe AR） |
| **逆流容積（RVol）與逆流分率（RF）** | 評估左心室逆流血流動力學負荷總量 | **RVol ≥60 mL/beat**；**RF ≥50%** |
| **有效逆流孔面積（ERO）** | 定量逆流孔徑結構缺損嚴重度 | **ERO ≥0.3 cm²** |
| **左心室射出分率（LVEF）** | 評估左心室收縮功能代償狀態（Stage C1 vs C2） | **LVEF ≤55%** 即為手術絕對適應症（Class 1） |
| **左心室收縮末期內徑（LVESD / LVESDi）** | 心室不可逆心肌重塑與心肌纖維化風險指標 | **LVESD >50 mm** 或 **LVESDi >25 mm/m²**（體型較小者考量 ≥20 mm/m²） |
| **左心室舒張末期內徑（LVEDD）** | 評估心室前負荷擴張程度與進展速度 | **LVEDD >65 mm**（連續追蹤 ≥3 次進展且低手術風險者可考慮 AVR） |
| **心臟磁振造影（CMR）與 LGE** | 精準評估主動脈根部尺寸、逆流容積與心肌纖維化（遲發性釓增強） | 無 LGE 顯影；主動脈根部/升主動脈直徑維持在安全監控範圍內 |
| **血壓量測（脈搏壓與 Phase IV 音）** | 評估大動脈回跳性與動脈僵硬度（高收縮壓合併低舒張壓） | 監測柯氏音第 IV 期（聲音變沉悶點）作為真實舒張壓指標；維持 SBP <140 mmHg |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 急性 vs. 慢性主動脈瓣逆流之血流動力學分歧
- **急性重度 AR（Infective Endocarditis, Dissection, Trauma）**：
  - 左心室無預警承受大量返流血量，心室無法即時擴張代償（心室順應性正常或偏低）。
  - 左心室舒張末期壓力（LVEDP）急遽飆升至 >40 mmHg，導致舒張末期左室壓迅速超越左房壓，引發**二尖瓣過早關閉（Premature closure of mitral valve）**。
  - 臨床表現為低心輸出量、代償性心搏過速、肺水腫與心因性休克；脈搏壓通常**不寬**，雜音短促輕微。
- **慢性重度 AR（Bicuspid Aortic Valve, Rheumatic, Root Dilation）**：
  - 心室呈現離心性肥厚，心室腔極度擴大（心臟重量有時 >1000 g，Cor Bovinum）。
  - 主動脈根部舒張早期壓力差大、晚期快速下降，呈現典型的「**遞減型舒張期雜音（Decrescendo diastolic murmur）**」。

### 2. 特異性周邊血管徵象與聽診物理診斷
- **外周血管血流動力學標誌**：
  - **Corrigan’s Pulse（水錘脈）**：收縮期迅速衝起、舒張期驟然塌陷。
  - **Quincke’s Pulse**：輕壓甲床可見毛細血管微搏動與紅白交替。
  - **Traube’s Sign**：股動脈聽診出現如槍擊般之巨響（Pistol-shot sound）。
  - **Duroziez’s Sign**：輕壓股動脈聽診出現收縮期與舒張期雙向雜音（To-and-fro murmur）。
- **心臟聽診重點**：
  - 主動脈瓣第二心音（A2）通常減弱或消失。
  - **Austin Flint 雜音**：逆流噴流衝擊二尖瓣前葉導致舒張中晚期低頻滾動樣雜音（非器質性二尖瓣狹窄）。
  - **雜音傳導鑑別**：左胸骨緣較大提示原發性瓣膜病變；**右胸骨緣較大**則強烈提示主動脈根部擴張動脈瘤。

### 3. 外科介入時機與術式抉擇矩陣
- **有症狀患者（Stage D）**：不論 LVEF 為何，皆具備**第 1 類手術適應症（AVR Class 1）**。
- **無症狀患者（Stage C）之手術指徵**：
  - **LVEF ≤55%（Stage C2）** $\rightarrow$ AVR (Class 1)
  - **LVEF >55% 但 LVESD >50 mm 或 LVESDi >25 mm/m²** $\rightarrow$ AVR (Class 2a)
  - 進行其他心臟外科手術時合併嚴重 AR $\rightarrow$ AVR (Class 2a)
  - 連續 ≥3 次檢查呈現進行性擴張（EF 55–60%, EDD >65 mm）且手術風險低 $\rightarrow$ AVR (Class 2b)
- **經導管介入與保留自體瓣膜根部重建**：
  - **TAVI 限制**：由於純 AR 患者多伴隨主動脈環極度擴張且缺乏鈣化錨定點，TAVI 併發症高，**非手術候選者之常規首選**。
  - **David 手術（Valve-Sparing Root Reconstruction）**：針對主動脈根部動脈瘤（如 Marfan 症候群），切除病變主動脈竇並將冠狀動脈鈕（Coronary buttons）再植入人造血管，保留自體瓣膜（Fig. 262-2）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 內科藥物治療與血流動力學優化
- **急性發作緊急穩定**：
  - 靜脈滴注血管擴張劑（如 Sodium Nitroprusside）與利尿劑以降低後負荷與微血管靜水壓；**24 小時內緊急外科手術**。
  - **禁忌**：絕對禁用 IABP；避免常規給予 β 阻斷劑以防止舒張充盈時間拉長。
- **慢性 AR 之血壓與神經內分泌調控**：
  - 嚴格控制收縮壓（目標 SBP <140 mmHg）：首選 Dihydropyridine 類鈣離子阻斷劑（CCB）、ACEI 或 ARB，減輕左心室後負荷。
  - **主動脈根部擴張（如 Marfan 症候群）**：臨床試驗顯示 **Losartan** 與 **Atenolol** 在減緩主動脈根部擴張速度上具同等療效，可優先選用以延緩主動脈瘤變。

### 2. 血管彈性、抗氧化與心肌代謝支持（功能醫學思維整合）
- **大動脈順應性與血管內皮保護**：
  - 由於脈搏壓極大，主動脈壁承受極高剪切應力，需著重降低全身性低度慢性發炎（Systemic low-grade inflammation）以減緩主動脈中層退化（Medial degeneration）。
  - 著重抗氧化壓力與一氧化氮（NO）生合成途徑，維護血管內皮完整性。
- **心肌細胞能量代謝支持**：
  - 離心性肥厚心肌對氧氣與 ATP 需求激增，應確保粒線體輔因子（如輔酶 Q10、鎂離子）維持於充足水平，預防心肌能量衰竭。

### 3. 生活型態與活動安全指引
- **運動處方禁忌**：
  - 嚴重主動脈瓣逆流及合併主動脈擴張/主動脈病變（Aortopathy）者，**嚴格禁止等長收縮運動（Isometric exercises，如重度阻力訓練、搬運重物、推舉）**，避免周邊血管阻力驟升造成左心室後負荷過載及主動脈夾層破裂風險。
  - 建議採低強度至中等強度動態有氧運動（如步行、輕快走），並定期進行運動心電圖耐受度評估。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **掌握手術黃金時間窗**：無症狀嚴重 AR 病患應每 6～12 個月接受臨床與心臟超音波追蹤，緊盯三大關鍵數值：**LVEF ≤55%**、**LVESD >50 mm** 或 **LVESDi >25 mm/m²**，一旦跨過門檻即刻轉介外科評估，切勿等待心室衰竭症狀顯現。
2. **急性 AR 臨床決策紅線**：面對急性嚴重 AR（如心內膜炎、A 型主動脈剝離），切記**禁用 IABP 及 β 阻斷劑**，應立即聯絡心臟外科，爭取在 24 小時內實施急診手術。
3. **外周徵象敏銳度培養**：聽診時遇舒張期雜音，應同時檢視水錘脈（Corrigan's）、指甲微血管搏動（Quincke's）及量測血壓脈搏壓差；雜音偏向右側胸骨緣時務必高度警惕主動脈根部動脈瘤。
4. **根部病變精準影像定位**：若超音波音窗不佳或懷疑主動脈病變，應及早安排心臟磁振造影（CMR）或電腦斷層血管攝影（CTA），精確丈量主動脈竇與升主動脈管徑，以評估是否適合實施保留自體瓣膜的 David 術式。
