# 血管炎症候群的臨床病理剖析與整合醫學觀點 (The Vasculitis Syndromes)
- **主講人/來源**：Carol A. Langford, Anthony S. Fauci / *Harrison's Principles of Internal Medicine* (363 The Vasculitis Syndromes.pdf)
- **核心主旨**：血管炎是由多種免疫機制驅動血管內皮發炎、管腔閉塞與組織缺血的異質性疾病譜系；臨床需精準辨識免疫複合體、ANCA 媒介與 T 細胞肉芽腫反應三大病理軸線，在傳統免疫抑制搶救器官的同時，整合抗氧化、排毒代謝支持與藥物毒性防護，以達到血管長期修復與長壽健康目標。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **內皮發炎與缺血級聯反應**：血管內皮在細胞因子（TNF-α、IL-1、IFN-γ）活化下表達黏附分子（ELAM-1、VCAM-1），導致白血球浸潤、管壁壞死（如類纖維蛋白壞死）、血栓形成及管腔閉塞，引發遠端組織缺血壞死。
  - **三大免疫致病驅動路徑**：
    1. *致病性免疫複合體沉積*：抗原-抗體複合體激活補體 C5a，趨化嗜中性球釋放溶酶體酵素造成管壁損傷（如 IgA 血管炎、冷凍球蛋白血症血管炎、HBV/HCV 相關血管炎）。
    2. *ANCA 介導的嗜中性球爆發*：前驅細胞因子（TNF-α/IL-1）促使嗜中性球的 PR3 或 MPO 易位至細胞膜，與 ANCA 結合後引發細胞除顆粒反應、釋放活性氧物質（ROS）並直接毒殺血管內皮（GPA、MPA、EGPA）。
    3. *T 細胞免疫反應與肉芽腫生成*：HLA class II 分子活化促使 CD4+ T 細胞向 TH1（IFN-γ）與 TH17（IL-17）分化，活化巨噬細胞並形成多核巨細胞與肉芽腫（巨細胞動脈炎、高安氏動脈炎、GPA）。
- **演講亮點與臨床洞察**：
  - **ANCA 滴度與疾病活動度脫鉤**：臨床緩解期患者體內 ANCA 陽性可持續數年；前瞻性研究顯示僅 43% ANCA 滴度上升者在 1 年內復發，**不可僅憑 ANCA 滴度上升而盲目重啟或增強免疫抑制劑**。
  - **標靶補體受體新範式**：C5a 受體抑制劑 Avacopan 在隨機對照試驗中展現了顯著的類固醇減量（Steroid-sparing）潛力，打破過去必須依賴超生理劑量類固醇誘導緩解的舊常規。
  - **嚴密監測擬態疾病（Mimics）**：在給予猛烈免疫抑制前，必須排除感染（如心內膜炎）、高凝血狀態、以及外源性毒素（如摻雜 Levamisole 的古柯鹼引起之網狀青斑與 ANCA 陽性血管炎樣壞死）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **cANCA / PR3-ANCA** | GPA（肉芽腫性多血管炎）的核心診斷標記，具高特異性 | 活動期 >90% 陽性；緩解期敏感度降至 60–70% |
| **pANCA / MPO-ANCA** | 主要見於 MPA、EGPA 及壞死性新月體腎絲球腎炎 | MPA 陽性率約 75%；EGPA 約 48% |
| **ESR / 高敏 C-反應蛋白 (hs-CRP)** | 全身性血管發炎指標；監控 GCA/PMR 治療反應（注意：使用 Tocilizumab 時會被人工壓制至極低） | 臨床追求維持於 baseline 正常範圍，但減藥時微幅上升若無症狀無需立即加藥 |
| **血清補體 (C3, C4)** | 免疫複合體消耗評估；特別是冷凍球蛋白血症血管炎 | 冷凍球蛋白血症中 90% 伴隨低補體血症 |
| **冷凍球蛋白 (Cryoglobulins) & RF** | 評估冷沉澱性免疫球蛋白；類風濕因子（RF）常呈強陽性 | 鑑別 HCV 相關血管炎；陰性時需複查 |
| **尿液沈渣與鏡檢 (U/A & Microscopy)** | 早期發現無症狀性腎絲球腎炎（蛋白尿、鏡檢血尿、紅血球圓柱體 RBC casts） | 任何出現 RBC casts 均提示活動性小血管炎腎損傷 |
| **TPMT (硫嘌呤甲基轉移酶) 酵素/基因檢測** | 使用 Azathioprine 前的藥物基因學檢測，預防嚴重骨髓抑制 | 酵素活性低下或突變型禁用標準劑量 |
| **嗜酸性球絕對計數 (AEC)** | 評估 EGPA (Churg-Strauss) 的特異發炎驅動指標 | >1000 cells/μL（>80% 患者符合） |
| **肝炎病毒標記 (HBsAg, Anti-HCV, HCV RNA)** | 排除繼發性血管炎（PAN 常與 HBV 相關；冷凍球蛋白血症與 HCV 高度相關） | 確診後須優先抗病毒治療而非純免疫抑制 |
| **白血球/嗜中性球絕對計數 (WBC / ANC)** | 監控 Cyclophosphamide 及其他免疫抑制劑的骨髓抑制毒性 | 維持 WBC >3000/μL，ANC >1500/μL 以免致死性感染 |

## 三、 關鍵機制詳解與投影片重點筆記

- **機制 1：嗜中性球引爆與微血管發炎壞死（ANCA-Associated Small-Vessel Vasculitis）**
  - **抗原易位與活化**：正常休眠狀態下，PR3 與 MPO 隱藏於嗜中性球初級嗜天青顆粒（azurophilic granules）及單核球溶酶體中。當體內存在慢性發炎環境，促炎細胞因子（TNF-α、IL-1）刺激嗜中性球「前驅化（priming）」，使 PR3/MPO 移位暴露至細胞表面。
  - **呼吸爆發與微血管滲漏**：細胞外的 ANCA 與突出的 PR3/MPO 結合，引發嗜中性球過度脫顆粒、釋放毒性氧自由基（ROS）與水解酵素，穿透血管基底膜，導致內皮細胞裂解凋亡。
  - **惡性發炎循環**：受活化的嗜中性球進一步分泌 IL-1 與 IL-8，趨化更多白血球並誘發白細胞碎裂（Leukocytoclasis），在腎絲球形成寡免疫性壞死性新月體腎炎（Pauci-immune crescentic GN），在肺部引起微血管炎與肺泡出血。

- **機制 2：大中血管的透壁性肉芽腫發炎與纖維化（Large-Vessel Vasculitis: GCA & Takayasu）**
  - **外膜啟動（Inside-out hypothesis）**：巨細胞動脈炎與高安氏動脈炎的發炎過程通常始於血管外膜（Adventitia）。樹突細胞捕捉未知的動脈壁抗原後，招募 CD4+ T 細胞通過滋養血管（vasa vasorum）進入血管壁。
  - **雙重 T 細胞軸線**：
    - *TH1 路徑*：分泌高濃度 IFN-γ，驅動單核球轉化為活化巨噬細胞，形成多核巨細胞（Giant cells），釋放基質金屬蛋白酶（MMPs）破壞血管內彈性層（internal elastic lamina）。此軸線對皮質類固醇反應相對遲鈍。
    - *TH17 路徑*：依賴 IL-6/IL-23 軸線分化，分泌 IL-17 造成全身性急性發炎反應（發燒、高 ESR/CRP、PMR 症狀），對類固醇及抗 IL-6 受體標靶藥物（Tocilizumab）反應極佳。
  - **內膜重塑與缺血**：中膜（Media）平滑肌細胞增生並向內膜遷移，引起廣泛的內膜纖維化與管腔狹窄閉塞，導致遠端組織缺血（如 GCA 引起的缺血性視神經病變、失明；高安氏動脈炎引起的脈搏減弱與肢體跛行）。

- **機制 3：免疫複合體沈積與補體活化（Immune Complex-Mediated Vasculitis）**
  - **抗原過量與滲透性增加**：在抗原過量（如持續病毒血症或外源性異種蛋白）狀態下，抗原抗體形成中等大小的可溶性免疫複合體。血小板或肥大細胞經 IgE 途徑釋放組織胺、緩激肽、白三烯，造成微血管通透性上升。
  - **C5a 驅動之白細胞碎裂性血管炎**：複合體嵌頓於真皮微血管與腎小球基底膜後，活化經典補體途徑，產生強烈趨化因子 C5a。嗜中性球吞噬複合體後核崩裂，形成典型的核塵（nuclear debris / leukocytoclasis），常見於 IgA 血管炎與 C 型肝炎相關冷凍球蛋白血症。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

*傳統醫學治療血管炎側重以大劑量類固醇配合 Rituximab 或 Cyclophosphamide 誘導緩解；功能醫學與整合醫學則聚焦於**降低藥物醫源性損傷、修復內皮完整性、中和過量自由基與調節自體免疫耐受性**。*

- **功能性營養素/植化素補充（輔助常規治療與解毒）**：
  - **類固醇骨質與代謝保護網絡**：
    - *維生素 D3 (3000–5000 IU/d) + 維生素 K2 (MK-7 100–200 mcg/d)*：促進鈣質正確沉積於骨基質，防止類固醇誘導性骨質疏鬆與血管鈣化。
    - *鈣質 (檸檬酸鈣/海藻鈣 800–1000 mg/d) 與鎂 (甘胺酸鎂 300–400 mg/d)*：平衡骨代謝與神經肌肉興奮性。
    - *小檗鹼 (Berberine 500 mg bid) / 硫辛酸 (ALA 300–600 mg/d)*：對抗高劑量類固醇引發之胰島素阻抗與高血糖。
  - **抗葉酸劑（Methotrexate）專屬修復處方**：
    - *活性葉酸 (5-MTHF 1–2 mg/d 或 Folinic Acid)*：降低 MTX 之骨髓抑制、胃腸道不耐與口腔黏膜潰瘍，且不減低抗發炎療效。
  - **環磷醯胺（Cyclophosphamide）毒性防護**：
    - *N-乙醯半胱氨酸 (NAC 600–1200 mg/d)*：補充細胞內穀胱甘肽（GSH），保護膀胱黏膜上皮免受丙烯醛（Acrolein）毒性氧化損害，並減輕肝臟代謝解毒負擔。
  - **血管內皮生物力學修復與抗發炎支持**：
    - *高純度 Omega-3 脂肪酸 (EPA/DHA 3–4 g/d)*：降低花生四烯酸代謝產物，減少內皮黏附分子表達，改善微循環血流變學。
    - *薑黃素 (優化生物利用度配方 500–1000 mg/d) 與白藜蘆醇 (200–500 mg/d)*：抑制 NF-κB 轉錄路徑，阻斷 TNF-α 與 IL-6 釋放，修復血管內皮細胞屏障。

- **飲食與禁食策略**：
  - **嚴格全食物低抗原抗發炎飲食**：
    - 採取地中海式或自體免疫性抗發炎飲食（AIP 概念），全面戒除精製糖、高果糖漿、超加工食品與反式脂肪，避免引起內皮糖化終產物（AGEs）堆積與微血管內膜刺激。
    - 消除飲食（Elimination Diet）：檢測並暫停潛在促發免疫反應之食物過敏原（如麩質、酪蛋白、某些凝集素），以降低腸道通透性（Leaky Gut）及全身性免疫複合體生成。
  - **微間歇斷食（Time-Restricted Eating, 14:10 或 16:8）**：
    - 在非急性重症期且營養狀態允許下進行，利用自噬作用（Autophagy）清除受損細胞殘骸與粒線體，增強抗氧化防禦基因（Nrf2）表達；但需在充足熱量與優質蛋白質攝取下執行，避免加重肌肉流失。

- **環境毒素阻斷/代謝排毒/生活型態**：
  - **環境抗原與外源毒素徹底阻斷**：
    - 嚴禁吸菸、被動吸菸及任何非法物質接觸（高度警惕摻有 Levamisole 之古柯鹼引起的致死性血管閉塞與皮膚壞死）。
    - 評估居家與工作環境重金屬（如砷、鉛）及黴菌毒素（Mycotoxins），減少持續啟動免疫系統外源觸發源。
  - **微生物菌相管理（Microbiome Modulation）**：
    - GPA 患者上呼吸道常慢性定殖金黃色葡萄球菌（*S. aureus*），文獻提示其與復發相關；應落實鼻腔局部溫和沖洗與保濕，必要時配合抗生素或精油抗菌策略維護黏膜屏障。
  - **排毒與微循環賦活**：
    - 水分攝取每日維持 2500–3000 mL（特別是使用 Cyclophosphamide 期間，需晨間大劑量水化並頻繁排尿以預防出血性膀胱炎與膀胱癌）。
    - 輕度被動式微循環促進：在無活動性大血管動脈瘤或破裂風險前提下，紅外線溫熱療法或溫和步行有助於擴張微血管、降低組織缺血壞死風險。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **排除擬態疾病是第一天條**：面對可疑血管炎（紫斑、發燒、多發性單神經炎、不明缺血），必須先排除感染（如感染性心內膜炎、敗血症）、血栓性微血管病變及藥物毒性，切忌在感染未明前冒進給予強效脈衝類固醇或生物製劑。
2. **組織切片遵循「有症狀才切」原則**：避免盲目無效切片。肺部切片對 GPA 確診率最高；皮膚紫斑切片需取邊緣新鮮病灶；GCA 顳動脈切片至少需 3–5 cm 長度並作連續切片以避開「跳躍性病灶（skip lesions）」。
3. **藥物安全三防線務必落實**：
   - *預防感染*：凡長期併用日劑量類固醇與第二種免疫抑制劑者，必須常規處方 TMP-SMX 預防肺囊蟲肺炎（PJP）。
   - *藥物基因*：開立 Azathioprine 前務必檢測 TPMT 酵素/基因型，預防致死性骨髓抑制。
   - *肝炎防線*：給予 Rituximab 耗竭 B 細胞前，必須全面清查 B/C 肝炎抗原抗體，防止 B 肝致死性再活化。
4. **精準區分「活動性發炎」與「慢性結構損傷」**：慢性鼻竇炎黏膜乾燥需仰賴濕潤護理；GPA 聲門下狹窄多為纖維化瘢痕，應優先考慮機械性擴張與局部類固醇注射，而非盲目調高全身性免疫抑制劑劑量。
5. **落實抗發炎營養支持與類固醇減量計畫**：全程建立「維生素 D3/K2 + 鈣鎂 + 活性葉酸 + 血管抗氧化抗發炎營養素」防護網，積極結合 C5a 受體抑制劑（Avacopan）或抗 IL-6（Tocilizumab）等新型標靶，以最短時間將類固醇降至安全劑量，守護患者長期心血管與代謝壽命。
