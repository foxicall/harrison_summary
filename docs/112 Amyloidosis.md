# 澱粉樣變性病（Amyloidosis）：蛋白質錯誤折疊、老化與系統性沉積的臨床診斷與前沿治療
- **主講人/來源**：John L. Berk, Vaishali Sanchorawala / 112 Amyloidosis.pdf (Harrison's Principles of Internal Medicine 21e, Chap. 112)
- **核心主旨**：澱粉樣變性病源自蛋白質體穩態（Proteostasis）失衡與未折疊蛋白反應（UPR）衰退，不溶性反平行 $\beta$-摺疊原纖維沈積於細胞外間質，臨床需早期藉由組織切片、生物標記與精準分型（質譜/基因），及早啟動前驅蛋白抑制、原纖維穩定化或基因沉默等精準靶向治療。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **蛋白質穩態失衡與錯誤折疊**：細胞內伴護蛋白（Chaperone）與降解機制無法負荷變異或過度分泌的蛋白質，導致其轉變為具豐富反平行 $\beta$-摺疊（antiparallel $\beta$-pleated sheet）的構型。
  - **寡聚體毒性（Oligomer Toxicity）**：病理過程中的寡聚體中間產物（Oligomeric intermediates）比大型成熟原纖維具有更高的細胞毒性，會引發細胞膜不穩定、活性氧（ROS）生成激增及細胞壓力訊息傳導。
  - **多重驅動病因**：包括單株漿細胞異常增生產生過量輕鏈（AL 型）、慢性全身性發炎驅動血清澱粉樣蛋白 A（AA 型）、遺傳性基因突變或細胞衰老導致之轉甲狀腺素蛋白（TTR）不穩定（ATTRm / ATTRwt 型）。
- **演講亮點與臨床洞察**：
  - **老化與野生型 ATTR（ATTRwt）的爆發**：80 歲以上長者屍檢中有高達 25% 心臟存在 ATTRwt 沈積，揭示老化過程中「未折疊蛋白反應（UPR）」品質控管機制衰退，是全球高齡男性心衰竭的重要退化性病因。
  - **心臟澱粉樣變性的用藥陷阱**：在澱粉樣心肌病變中，**洋地黃（Digitalis）、鈣離子阻斷劑（CCB）與乙型阻斷劑（Beta-blockers）相對禁忌**，因其會與原纖維交互作用，誘發嚴重房室傳導阻滯並惡化心衰竭。
  - **神經缺失逆轉的臨床里程碑**：TTR 基因沉默劑（RNAi / ASO）不僅能抑制疾病進展，在 35–60% 的遺傳性患者中甚至能逆轉感覺神經功能障礙。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **腹部皮下脂肪抽吸 Congo Red 染色** | 非侵入性組織病理檢查，偏光顯微鏡下觀察澱粉樣原纖維的特異性「蘋果綠雙折射光（Apple-green birefringence）」。 | 陽性即代表有澱粉樣沉積（全身性患者陽性率 >80%）。 |
| **游離輕鏈差值 (dFLC)** | 評估 AL 型骨髓單株漿細胞負荷與預後分期（Mayo 2012 系統）。 | **dFLC < 50 mg/L** 預後與存活率顯著較佳。 |
| **血清/尿液免疫固定電泳 (SIFE / UIFE)** | 篩檢單株免疫球蛋白或游離輕鏈；傳統 SPEP 敏感度不足，常呈偽陰性。 | 異常單株條帶出現即屬警訊（AL 型陽性率 >90%）。 |
| **心臟生物標記 (NT-proBNP / BNP / Troponin)** | 評估心肌受累程度、疾病分期、活動度監控（Mayo 2004/2012、Boston 分期）。注意腎功能不全會偽陽性升高。 | 數值顯著升高提示同心性心室肥厚與舒張功能障礙。 |
| **24小時尿蛋白定量 & eGFR** | 評估腎臟澱粉樣病變程度，並預測 2 年內進展至透析之風險。 | 蛋白尿常達腎病症候群範圍（>3.5 g/day）；血清白蛋白常 <2 g/dL。 |
| **血清鹼性磷酸酶 (ALP)** | 評估肝臟浸潤；典型表現為顯著膽汁淤積（Cholestasis），轉氨酶（AST/ALT）與合成功能多維持正常。 | 孤立性 ALP 顯著上升提示肝臟澱粉樣浸潤。 |
| **質譜分析 (Laser Capture Microdissection + Tandem MS)** | 鑑定澱粉樣沉積物之前驅蛋白生物化學型態之黃金標準。 | 明確鑑別 AL、AA、ATTR 或其他罕見遺傳亞型。 |
| **TTR 基因定序** | 鑑別突變型（hATTR，如 V122I、V30M）與野生型（ATTRwt），指引標靶治療與家系篩檢。 | 檢出致病單核苷酸變異（SNV）。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 蛋白質折疊失序與寡聚體毒性路徑（Protein Misfolding & Oligomer Cascade）
- **發病假說**：正常生理狀態下，分子伴護蛋白（Molecular Chaperones）維持三級結構，不合規蛋白質則由 UPR 及蛋白酶體系統清除。當基因突變、轉譯後修飾異常、慢性過量生成或衰老導致 UPR 失靈時，可溶性前驅蛋白展開（Unfolding），形成具高穩定性、交錯的 $\beta$-摺疊結構。
- **毒性本質**：病理過程產生的可溶性**前驅寡聚體（Oligomers）**具有高度親脂性與膜干擾活性，能穿透細胞膜誘導 ROS 暴增、破壞線粒體功能、啟動內質網壓力與凋亡訊號。成熟原纖維（Fibrils，直徑約 10 nm）沉積於細胞外基質，合併 Serum Amyloid P (SAP)、ApoE、黏多醣（GAGs）等輔助分子，進一步破壞組織物理架構與器官功能。

```
[前驅蛋白] (過量/突變/衰老) 
       │
       ▼ (折疊失常)
[不穩定中間單體]
       │
       ▼ (寡聚化)
[可溶性寡聚體] ────► 誘導 ROS 生成、細胞毒性、內質網壓力
       │
       ▼ (聚合)
[原纖維 (Fibrils)] ──► 結合 SAP/GAGs ──► 細胞外基質沉積 ──► 組織物理破壞與器官衰竭
```

### 2. 系統性澱粉樣變性病之主要亞型臨床剖析
- **AL 澱粉樣變性病（輕鏈型）**：
  - **病源**：漿細胞或 B 細胞單株增生異常，分泌過量單株輕鏈（$\lambda$ 佔優勢，尤其 $\lambda 6$ 具高度腎臟趨向性）。
  - **臨床特徵**：進展極快。70–80% 累及腎臟（重度腎病症候群）；50–60% 累及心臟（同心性心室肥厚、舒張功能障礙、心電圖呈現**肢導極低電壓**與假性心肌梗塞圖形）；**巨舌症（Macroglossia）**與**眼眶周圍紫斑（"Raccoon-eye"）**為具特異性之病徵。
  - **血液異常**：部分患者伴隨第 X 凝血因子被澱粉樣原纖維特異性吸附，導致凝血功能異常與嚴重出血傾向。
- **AA 澱粉樣變性病（反應型/繼發型）**：
  - **病源**：長期慢性感染（結核、骨髓炎）或慢性發炎性自體免疫疾病（類風濕性關節炎、發炎性腸道疾病、家族性地中海熱 FMF）。
  - **機制**：發炎細胞因子（TNF-$\alpha$、IL-1、IL-6）刺激肝臟持續合成急性期蛋白 Serum Amyloid A (SAA)；SAA 經巨噬細胞異常蛋白裂解形成 8-kDa 原纖維。
- **ATTR 澱粉樣變性病（轉甲狀腺素蛋白型）**：
  - **遺傳型 (hATTR)**：常染色體顯性遺傳。V122I 突變盛行於非裔族群（約 4%），以晚發型心肌病變為主；V30M 突變常表現為自律神經與小纖維周邊神經病變。
  - **野生型 (ATTRwt / 舊稱老年全身性)**：見於高齡族群（男性為主）。軟組織病變（雙側腕隧道症候群、脊椎狹窄、肱二頭肌腱自發性斷裂）通常比心臟症狀早 10–20 年出現。

### 3. 診斷路徑與臨床陷阱（Diagnostic Algorithm）
- **懷疑線索**：不明原因心臟衰竭伴隨射血分數保留（HFpEF）但心電圖呈低電壓、非糖尿病腎病症候群、周邊小纖維/自律神經失調、反覆性肌腱斷裂或腕隧道症候群。
- **處置流程**：
  1. 首選非侵入性檢查：**腹部皮下脂肪墊針吸切片（Fat pad aspiration）+ Congo red 染色**。
  2. 若陰性但高度懷疑：針對受累器官（心內膜、腎臟、肝臟、神經）進行侵入性組織活檢。
  3. 確診後之分型：必須依賴**質譜儀分析（LC-MS/MS）**或免疫電鏡，避免抗體非特異性結合導致誤診；若懷疑 ATTR 需進行基因定序鑑別野生型或突變型。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 現代精準醫學與標靶藥物介入
- **AL 澱粉樣變性病（抑制漿細胞複本）**：
  - **一線治療**：自體周邊血幹細胞移植（HDM/SCT）適合 20–30% 體能佳之患者。
  - **不適合移植者**：Bortezomib（蛋白酶體抑制劑）併用 Melphalan + Dexamethasone (MDex)。新興標靶包含抗 CD38 單株抗體（Daratumumab）及口服蛋白酶體抑制劑（Ixazomib）。
- **AA 澱粉樣變性病（阻斷發炎驅動鏈）**：
  - **家族性地中海熱 (FMF)**：Colchicine（秋水仙素）每日 1.2–1.8 mg，可有效預防發作及澱粉樣沉積。
  - **其他發炎性疾病**：使用生物製劑阻斷發炎訊號（TNF-$\alpha$、IL-1、IL-6 拮抗劑），降低血清 SAA 濃度至正常區間。
- **ATTR 澱粉樣變性病（四聚體穩定化與基因沉默）**：
  - **TTR 四聚體穩定劑**：**Tafamidis**（專利甲狀腺素擬似物）結合於 TTR 甲狀腺素結合位，防止四聚體解離為單體，顯著延長存活率並減緩心肺衰退；**Diflunisal**（非類固醇抗發炎藥）亦有類似穩定效果。
  - **TTR 基因沉默療法**：**RNA 干擾劑（Patisiran）**或**反義寡核苷酸（Inotersen）**，能阻斷肝臟 TTR mRNA 轉譯，大幅降低血清 TTR 濃度，顯著改善周邊感覺神經功能與心室重塑。
  - **器官移植**：原位肝臟移植（OLT）僅限於特定早期 hATTR（如 V30M），非 V30M 突變患者在換肝後，野生型 TTR 仍常沉積於原有病灶，故效益有限。

### 2. 心血管與自主神經支持性處方
- **心衰竭症狀管理**：
  - 主要依賴**利尿劑（Diuretics）**調節前負荷。
  - **絕對用藥安全禁忌**：嚴格避免使用 Digitalis、Verapamil/Diltiazem 等 CCB，以及謹慎使用 Beta-blockers，以防引發重度傳導阻滯與心因性休克。
  - 由於心房機械性收縮力喪失，即使心電圖維持竇性節律，亦具高度心房血栓形成與中風風險，應評估早期**抗凝血治療（Anticoagulation）**。
- **自律神經與直立性低血壓管理**：
  - 使用 $\alpha_1$ 受體激動劑（如 **Midodrine**）維持血管張力；胃腸運動機能失調可配合促進腸道動力藥物。

### 3. 功能醫學、代謝排毒與抗衰老整合思維
- **減輕內質網壓力與支持 UPR 途徑**：
  - 減少代謝毒素、終末糖化產物（AGEs）與超加工食品的攝入，降低全身性氧化壓力與分子伴護蛋白系統之過度負載。
  - 嚴格控制血糖與胰島素阻抗，避免高胰島素血症干擾自噬作用（Autophagy）與蛋白酵素清除異常沉積物的效率。
- **低慢性發炎環境維護**：
  - 定期監控全身發炎反應（hs-CRP、SAA、發炎細胞因子），藉由抗發炎飲食型態（高多酚、優質 Omega-3 脂肪酸平衡）抑制巨噬細胞異常活化與急性期反應。
- **肝腎代謝通道支持**：
  - 重度低白蛋白血症患者（血清白蛋白 <2 g/dL）需藉由靜脈白蛋白支持提升膠體滲透壓，搭配彈性襪減少下肢水腫；維持腸道黏膜屏障完整性，避免腸漏誘發二次菌毒血症，加重原纖維誘發的全身性發炎。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **建立臨床警覺性**：遇到「原因不明之同心性心室肥厚伴隨心衰竭（尤其心電圖呈現非相稱性低電壓）」、「非糖尿病引起的嚴重腎病症候群」或「腕隧道症候群伴隨自發性肌腱斷裂」的患者，應立即將澱粉樣變性病列入鑑別診斷。
2. **早期非侵入性篩檢**：優先安排**腹部皮下脂肪針吸 Congo red 染色**，並同步檢驗**血清/尿液免疫固定電泳（SIFE/UIFE）**與**血清游離輕鏈（sFLC）**，以利在器官不可逆衰竭前阻斷病程。
3. **避免常規心衰竭用藥毒性**：若懷疑或確診為心臟澱粉樣變性病，**停用或避免開立鈣離子阻斷劑、洋地黃及乙型阻斷劑**，預防致死性傳導阻滯與血液動力學崩潰。
4. **精準型態學與基因確認**：活檢標本必須以**雷射捕捉顯微切割結合串聯質譜儀（LC-MS/MS）**定型；ATTR 確診者應強制進行 **TTR 基因定序**，以區分 ATTRwt 與 hATTR，並為家族成員提供遺傳諮詢。
5. **早期介入標靶與基因治療**：hATTR 或 ATTR-CM 患者應及早評估啟動 TTR 四聚體穩定劑（Tafamidis）或基因沉默藥物（Patisiran / Inotersen）；AL 型患者應儘速轉介血液腫瘤專科評估蛋白酶體抑制劑或免疫化療。
