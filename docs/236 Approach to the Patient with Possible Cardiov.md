# 心血管疾病患者的系統性臨床評估與早期預防架構
- **主講人/來源**：Joseph Loscalzo / 236 Approach to the Patient with Possible Cardiov.pdf
- **核心主旨**：心血管疾病（CVD）具備高度隱匿性與高致死率；臨床上應超越單純的急性症狀處置，透過病因、解剖、生理及功能四維度診斷框架，並緊密結合發炎、胰島素阻抗與代謝異常等根源性驅動因子，在不可逆事件發生前啟動早期預防與精準介入。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **代謝與發炎驅動動脈粥狀硬化**：肥胖、第 2 型糖尿病與代謝症候群引發的慢性全身性低度發炎（Inflammation），正抵消過去數十年在冠心病死亡率上的改善趨勢。
  - **性別特異性病理機轉**：女性心血管疾病死亡人數持續上升；相較於男性，發炎與代謝異常在女性冠狀動脈粥狀硬化中扮演更主導的角色，且女性更常表現為**冠狀動脈微血管功能障礙（Microvascular Dysfunction）**，導致傳統運動心電圖對心外膜大血管阻塞的診斷準確度偏低。
  - **心肌氧供需失衡與泵血障礙**：心肌缺血源自氧氣供需失衡（表現為胸痛）；心臟泵血衰退導致心室上游充血性壓力升高，引發周邊水腫與肺鬱血氣促。
- **演講亮點與臨床洞察**：
  - **自然病程的隱匿性**：約 25% 的心血管死亡為猝死，許多急性心肌梗塞或心肌病變患者首次發病即是災難性事件（猝死、中風）。然而，其動脈粥狀硬化與代謝危險因子往往已存在數年，具備長期的「可預防黃金期」。
  - **症狀與運動的生理關聯**：心血管功能不全的特徵是「**活動時加劇、休息時緩解**」（若休息時出現但運動時減輕，通常非典型心因性）。臨床問診必須深入量化「誘發症狀的運動強度與速度變更」，並評估其在過去 6 個月至 1 年內的動態退化趨勢。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及或常規臨床指引） |
| :--- | :--- | :--- |
| **高敏度 C-反應蛋白 (hs-CRP)** | 血管內皮發炎與全身微發炎狀態標記，用於無症狀個體的冠心病（CAD）全域風險分層 | 臨床無症狀族群建議 `< 1.0 mg/L`（降低發炎性動脈粥狀硬化風險） |
| **完整血脂分析 (Lipid Fractions)** | 總膽固醇、LDL-C、HDL-C 及三酸甘油酯等亞型分佈，評估致動脈粥狀硬化顆粒負荷 | 結合心血管整體風險評估，極高危險群宜嚴格控制非-HDL 與致動脈粥狀硬化脂蛋白 |
| **B 型利鈉肽 (BNP / NT-proBNP)** | 反映心室容量過載與心室壁張力變化，鑑別呼吸困難是否源於心衰竭（泵血衰竭） | 依年齡與腎功能設定排除/診斷切點，顯著升高提示心室擴張與心衰充血 |
| **安靜與運動心電圖 (ECG / Exercise ECG)** | 評估心律不整、傳導異常、心室肥厚、缺血與 QT 間期延長；女性需注意其偽陰性偏高 | 運動試驗中出現 ST 段壓低、QTc 異常延長（預警心因性猝死風險） |
| **經胸心臟超音波 (Echocardiography)** | 雜音評估核心工具；評估心室壁厚度、腔室大小、射血分數（EF）、瓣膜狹窄/逆流程度 | 瓣膜心雜音（≥ III 級、全收縮期/舒張期雜音）之必要確診檢查 |
| **單基因遺傳基因檢測 (Genetic Testing)** | 篩檢單基因致病變異，如肥厚型心肌病變（HCM）、馬凡氏症候群、長 QT 症候群 | 針對具家族猝死史、早發性心臟病患者進行針對性基因分型 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 紐約心臟學會 (NYHA) 完整四維度心臟診斷體系
確立正確診斷需系統性涵蓋以下四項要素，缺一不可：
1. **潛在病因（Etiology）**：先天性、高血壓性、缺血性或發炎/感染性。
2. **解剖構造異常（Anatomic abnormalities）**：涉及腔室（肥厚、擴張）、瓣膜（逆流、狹窄）、心包病變或心肌梗塞後疤痕。
3. **生理紊亂（Physiologic disturbances）**：是否存在心律不整、充血性心衰竭、心肌缺血，或加重供需失衡的次發因素（如嚴重貧血、甲狀腺毒症、上室性心搏過速）。
4. **功能受損程度（Functional disability - NYHA Class I-IV）**：
   - **Class I**：日常活動不受限，常規體力活動不引起症狀。
   - **Class II**：輕度受限，常規體力活動即引起疲倦、心悸或氣促。
   - **Class III**：顯著受限，低於常規活動即引發症狀，僅在休息時無症狀。
   - **Class IV**：無法執行任何體力活動，甚至在靜態休息時即有症狀。

### 2. 心雜音的臨床決策樹（Evaluation of Heart Murmur）
依據物理檢查雜音屬性進行分流處置（對應 Fig. 236-1）：
- **舒張期雜音（Diastolic）或 連續性雜音（Continuous）**：
  - 均屬於病理性，**一律直接安排心臟超音波（Echocardiography）**評估並轉診心臟專科。
- **收縮期雜音（Systolic Murmur）**：
  - **Grade III 以上、全收縮期（Holosystolic）或收縮晚期（Late systolic）雜音**：建議安排心臟超音波。
  - **Grade I～II 中收縮期雜音（Midsystolic）**：
    - 若**無症狀且無其他心血管體徵**，且心電圖與胸部 X 光正常 $\rightarrow$ **無需進一步處置，追蹤觀察**。
    - 若伴隨其他心臟症狀/體徵，或心電圖/胸部 X 光異常 $\rightarrow$ **安排心臟超音波檢查**。

### 3. 多基因體質與家族聚集性交互作用
- **單基因（Mendelian）心臟病**：如肥厚型心肌病變（HCM）、馬凡氏症候群（Marfan's）、先天性長 QT 症候群，呈現單一基因孟德爾遺傳，常以猝死為初發表現。
- **多基因（Polygenic）心血管病**：早發性冠心病、原發性高血壓、第 2 型糖尿病與高血脂症。家族聚集性不僅來自多基因遺傳背景，往往與**家庭共享的生活型態與環境毒素暴露**（高鈉飲食、高熱量精緻飲食、抽菸習慣）產生高度表觀遺傳與後天交互作用。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **功能性營養素/植化素補充**：
  - **血管內皮與粒線體能量支持**：針對心肌缺血與能量代謝障礙，建議補充還原型輔酶 Q10（Ubiquinol）、左旋肉鹼（L-Carnitine）與 D-核糖（D-Ribose），改善心肌細胞 ATP 生成並減輕氧化壓力。
  - **微血管循環與一氧化氮（NO）促進**：針對女性常見的微血管功能異常，補充精胺酸/瓜胺酸（L-Arginine / L-Citrulline）、甜菜根萃取物與富含多酚之原花青素（Pycnogenol），修復內皮型一氧化氮合酶（eNOS）路徑。
  - **發炎路徑調控**：高純度 Omega-3 脂肪酸（高 EPA 比例，2–4 g/天），下調全身慢性發炎，降低 hs-CRP 與內皮細胞黏附分子表現。
- **飲食與禁食策略**：
  - **抗發炎與心血管代謝重塑飲食**：採用富含抗氧化劑的地中海飲食架構，嚴格限制超加工食品、精緻碳水化合物與反式脂肪，改善胰島素敏感度並遏止代謝症候群進展。
  - **精準鈉/鉀離子平衡**：針對高血壓與家族性水鈉滯留傾象，限制加工食品中的隱形高鈉攝取，同步增加未精製蔬菜水果中的天然鉀、鎂離子攝取以穩定血管平滑肌張力。
- **環境毒素阻斷/代謝排毒/生活型態**：
  - **菸害與環境毒素阻斷**：嚴格戒菸（包括二手菸與電子煙），消除香菸燃燒產物對血管內皮的一氧化氮耗竭與急性脂質過氧化損傷。
  - **分級運動訓練（Exercise Prescription）**：依據 NYHA 功能分級設計漸進式有氧與阻力訓練；評估患者從平地步行至爬樓梯的自覺用力係數（RPE），避免運動誘發的心肌氧需耗竭，逐步提升心肺耐受度。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實無症狀高風險族群的「主動預警評估」**：針對看似健康的成年人，常規進行全身發炎指標（hs-CRP）、脂質亞型與代謝症候群篩檢，及早阻斷無症狀期邁向急性心肌梗塞或猝死的病程。
2. **建立高度警覺的女性特異性心血管思維**：面對女性患者的主訴（即使運動心電圖陰性），若具備肥胖、糖尿病或代謝異常，應高度懷疑「微血管功能障礙」，及早導入影像檢查與內皮修復策略。
3. **精準執行心雜音聽診分流流程**：遇舒張期/連續性雜音或 $\ge$ Grade III 收縮期雜音，果斷安排心臟超音波檢查；Grade I-II 輕微雜音則須結合胸部 X 光、ECG 與症狀進行綜合把關。
4. **深入採集功能受損進展史（Tempo of progression）**：問診時具體詢問「半年前或一年前能輕鬆完成、現在卻引發氣促或胸悶的特定體力活動」，以動態量化疾病惡化速度並校正治療強度。
