# 鮑氏不動桿菌（*Acinetobacter baumannii*）感染症：病理機轉、抗藥性演化與綜合臨床防治策略
- **主講人/來源**：162 Acinetobacter Infections.pdf（*Harrison's Principles of Internal Medicine*, 21st Edition, Chapter 162, by Rossana Rosa, L. Silvia Munoz-Price）
- **核心主旨**：深入剖析多重抗藥性鮑氏不動桿菌（MDR-AB）之泛基因體可塑性、環境存活機制與毒力分泌系統，並結合抗微生物藥物精準處方與感控束狀防護策略，以克服高致死率之重症與院內感染威脅。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **極限環境存活與生物膜形成**：透過修飾膜上 **Lipid A** 結構降低對宿主陽離子抗菌胜肽（AMPs）與抗生素之感受性；利用 ***abaI* 自動誘導合成酶** 驅動群體感應（quorum-sensing），在醫療器材（人工氣道、導尿管、CVC）及組織表面形成緻密生物膜（biofilm）。
  - **多重分泌系統與組織侵襲**：表現第二型（T2SS，分泌 LipA 脂酶）、第五型（T5SS，三聚體自轉運蛋白結合胞外基質膠原蛋白）與第六型分泌系統（T6SS，分泌抗菌毒素以排擠共生菌叢）；釋放 **磷脂酶 C 與 D（PLC/PLD）** 毒殺上皮細胞並加速組織穿透。
  - **鐵離子掠奪系統**：分泌高親和力 **載鐵蛋白（siderophores）**，在宿主低游離鐵的防禦環境中強行奪取鐵質以維持增殖。
  - **基因體可塑性與外來抗藥島**：泛基因體由「小型核心基因組」與「大型附屬/可支配基因組」構成，毒力基因深植核心，而大量抗藥基因座落於跳躍子與外來島嶼（alien islands），驅使國際複製株（ICL I/II）快速席捲全球。
- **演講亮點與臨床洞察**：
  - **次抑菌濃度抗生素誘發超毒力（Hypervirulence）**：暴露於低於抑菌濃度的抗生素時，該菌會代償性急遽增加胞外莢膜生成，顯著增強逃避宿主補體殺傷（complement-mediated killing）之能力。
  - **「糞便銅綠層（Fecal Patina）」傳播模型**：定植患者直腸與周邊皮膚被帶菌層覆蓋，呈同心圓向病室環境擴散，造成病床周邊高頻接觸點、醫護人員手部及穿戴設備的持續交叉污染。
  - **菌血症休克與 DIC 風險極高**：*A. baumannii* 菌血症患者中，高達 **25–30%** 於發病初期即迅速併發 **感染性休克** 及 **瀰漫性血管內凝血（DIC）**；碳青黴烯抗藥株（CRAB）之粗死亡率可高達 **70%**。
  - **腦脊髓液抹片鑑別陷阱**：在腦脊髓液（CSF）革蘭氏染色下，其呈成對的革蘭氏陰性球桿菌，極易被誤判為腦膜炎雙球菌（*Neisseria meningitidis*）。

## 二、 核心評估指標與臨床檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 關注標準 / 臨床判讀指引 |
| :--- | :--- | :--- |
| **MALDI-TOF-MS 與 qPCR** | 表型特徵難以區分不動桿菌種別；需依賴質譜儀與核酸定量精準鑑別致病力最強之 *A. baumannii* | 確定是否為 *A. baumannii* 核心臨床致病種 |
| **直腸拭子主動篩檢 (Rectal Surveillance)** | 偵測高危險病患（ICU、長照轉入）是否定植 CRAB，評估「糞便銅綠層」擴散與後續伺機感染風險 | 陽性即代表為高傳播風險帶菌者，需立即啟動接觸隔離 |
| **CSF 革蘭氏鏡檢與培養** | 評估外傷、神經外科手術或外引流管相關之中樞神經感染 | 呈現成對革蘭氏陰性球桿菌（需與 *N. meningitidis* 進行分子或質譜鑑別） |
| **分子型別分析 (PFGE / rep-PCR / MLST)** | 用於突發性群聚感染之院內感控流行病學調查，辨識爆發株與環境非爆發株 | 追蹤是否為單株（Monoclonal）或寡株（Oligoclonal）快速蔓延 |
| **OXA 碳青黴烯酶基因與藥敏試驗 (AST)** | 評估 Ambler Class D 內生型（OXA-51）與獲得型（OXA-23, 24, 58）抗藥基因及 MIC 表現 | 確立 Carbapenem 抗藥性，指導是否升級至多黏菌素或新型頭孢菌素 |
| **凝血指標 (Platelets, PT/INR, D-dimer)** | 監控全身性菌血症併發微血管栓塞與消耗性凝血病變 | 血小板驟降、PT/APTT 延長、D-dimer 飆升反映 DIC 發生（盛行率達 25–30%） |

## 三、 關鍵機制詳解與重點筆記

### 1. 多重抗藥機制（MDR Phenotype）的分子防線
- **外膜通透性下降與主動外排**：
  - 下調外膜孔道蛋白（Porins）表現，阻止 $\beta$-內醯胺類抗生素進入周質間隙（periplasmic space）。
  - 過度表現多底物外排泵（Efflux Pumps），主動將氟喹諾酮類、四環素類、氯黴素、消毒劑與替加環素（Tigecycline）泵出菌體。
- **$\beta$-內醯胺酶全方位武裝**：
  - **染色體內源 AmpC 活化**：全菌株皆帶有 AmpC 頭孢菌素酶，當基因上游插入轉位序列 **ISAba1** 時，會導致啟動子過度活化，直接瓦解第三、四代頭孢菌素。
  - **Ambler Class D 碳青黴烯水解酶（OXA-type）**：包括內源性的 OXA-51-like，以及由質體/染色體獲得的 OXA-23-like、OXA-24/40-like、OXA-58-like、OXA-143 與 OXA-235；此外亦可獲得金屬 $\beta$-內醯胺酶（NDM、IMP）。

### 2. 致病性與組織侵襲驅動網絡
- **外膜囊泡（Outer-Membrane Vesicles, OMVs）**：
  - 菌體主動出芽釋放富含外膜蛋白 A（OmpA）、各類蛋白酶與磷脂酶的囊泡。
  - OMVs 會刺激宿主巨噬細胞與上皮細胞釋放過量促發炎細胞因子，引發細胞凋亡與全身性發炎瀑布反應；目前動物模型亦將其作為無細胞疫苗之候選標靶。
- **宿主微環境奪鐵與脂質利用**：
  - 依賴 **T2SS 分泌的 LipA 脂酶**，使細菌能在缺乏游離葡萄糖的組織中以宿主脂質作為唯一碳源生長（LipA 缺損株於嗜中性球低下菌血症模型中無法生存）。
  - 藉由分泌 siderophores 奪取轉鐵蛋白結合之鐵離子，突破人體的「營養免疫（Nutritional Immunity）」防線。

## 四、 臨床介入處方與抗微生物策略（Therapeutic Strategies）

### 1. 常用抗生素治療方案與臨床考量（依據 Table 162-1）

```
[MDR A. baumannii 感染] ──┬── 基礎線 (藥敏敏感) ──> 傳統高劑量 β-Lactams
                          ├── 核心主力 ─────────> Sulbactam (單獨具內源活性)
                          ├── 碳青黴烯耐藥 (CRAB) ─> Cefiderocol 或 Colistin / Polymyxin B
                          └── 輔助/協同用藥 ────> Minocycline, Tigecycline, Eravacycline, Fosfomycin
```

- **Sulbactam（舒巴坦）**：
  - **機制與地位**：具備針對 *A. baumannii* 的直接殺菌活性（非單純抑制劑），療效不遜於碳青黴烯類與多黏菌素。
  - **劑量**：3–9 g/d（若使用 Ampicillin-Sulbactam 複方，劑量需調高至 9–27 g/d IV）。
- **Cefiderocol（新型鐵載體頭孢菌素）**：
  - **機制**：利用細菌鐵攝取途徑穿透外膜，對 ESBL、AmpC、OXA-23/40/58 及 NDM/IMP 具極佳體外穩定性。
  - **劑量**：2 g q8h IV（建議延長輸注時間至 3 小時）。
- **Polymyxins（Colistin 多黏菌素 E / Polymyxin B）**：
  - **機制**：破壞外膜滲透壓之陽離子清潔劑，體外對 CRAB 活性最強，但具高腎毒性與神經毒性。
  - **劑量**：Colistin 負荷劑量 5 mg/kg，接續 2.5–5.0 mg/kg/d（分 2–4 次投予）；Polymyxin B 1.5–3 mg/kg q12h。
  - **臨床限制**：RCT 顯示「Colistin 為基礎之合併療法」臨床存活率並未優於「單藥治療」；肺部感染可評估合併**吸入劑型**輔助治療。
- **四環素類衍生物（Minocycline, Tigecycline, Eravacycline）**：
  - **Minocycline**：100 mg q12h IV（可給予 200 mg 負荷劑量），具抑菌活性，與 Colistin 或 Carbapenem 具體外協同殺菌潛力。
  - **Tigecycline**：負荷劑量 100 mg，後續 50 mg q12h IV；**血清濃度極低，嚴禁單用於菌血症**，治療中易快速產生抗藥性。
  - **Eravacycline**：1 mg/kg q12h IV，核准用於複雜腹腔感染，但在複雜泌尿道感染試驗中劣於對照組。
- **輔助協同藥物**：
  - **Fosfomycin**（4 g q12h PO/IV）：無直接殺菌力，但與 Colistin 或 Sulbactam 具體外協同作用，可提高微生物清除率。
  - **噬菌體療法（Bacteriophage Therapy）**：作為難治性 MDR 感染之同情用藥，臨床劑量與療程尚未標準化，需留意治療期間突發之抗藥性。

### 2. 環境阻斷與感控防護策略（束狀防護 Bundle）

```
[帶菌病患 (Rectum/Skin)] ──(Fecal Patina)──> [周遭環境 / 醫療設備]
        │                                           │
  (未嚴格手部衛生)                           (未落實設備清消)
        ▼                                           ▼
[醫護人員雙手 / 隔離衣] ──────────────────────> [未感染病患 (ICU/病房)]
```

- **消滅皮膚「糞便銅綠層」**：針對定植與重症患者每日執行 **氯己定（Chlorhexidine, CHG）藥浴**，減少皮膚表面向環境脫落菌落。
- **徹底切斷水平傳播鏈**：
  - 確診/帶菌者實施接觸隔離與分區照護（Cohorting）。
  - 加強高頻接觸表面與設備之終末消毒（Terminal Disinfection），嚴禁共用呼吸治療器材、便盆及血壓計。
- **抗微生物藥物管理（Antimicrobial Stewardship）**：
  - 前期過度使用第三代頭孢菌素、氟喹諾酮或碳青黴烯類是菌群定植與突破感染的最強危險因子；嚴格限縮廣效廣譜碳青黴烯類之經驗性過度投藥。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實抗生素降階與精準處方**：
   - 避免非必要的長期廣效抗生素（尤其是 Carbapenems 與第 3 代 Cephalosporins）暴露，以保護宿主正常共生菌叢並阻斷耐藥株定植。
2. **謹慎解讀呼吸道分離培養**：
   - 氣切或長期呼吸器患者呼吸道常有 *A. baumannii* 定植；應結合發燒、膿痰增加、白血球升高及新浸潤陰影綜合判斷，避免將「單純定植」誤當「肺炎」而濫用抗生素。
3. **優化高危菌血症經驗用藥結構**：
   - 在高抗藥盛行區，懷疑 CRAB 菌血症併發敗血性休克時，應及早給予含足量 **高劑量 Sulbactam** 或 **Polymyxin/Cefiderocol** 之經驗治療；**切忌單獨使用 Tigecycline 治療血管內或菌血症感染**。
4. **警惕 CSF 鏡檢陷阱**：
   - 神經外科術後或留置腦室外引流管（EVD）患者出現中樞神經感染時，CSF 抹片見「成對革蘭氏陰性球菌」不可僅考慮腦膜炎雙球菌，必須將 *A. baumannii* 列入首要鑑別並同步送驗 PCR/MALDI-TOF。
5. **啟動感控整合束狀措施（Bundled Care）**：
   - 病房一旦發現陽性個案，立即實施主動直腸監測、單室隔離/同病種集中照護、嚴格手部衛生查核及病室環境終末清消，防止形成地方性院內群聚（Endemic strains）。
