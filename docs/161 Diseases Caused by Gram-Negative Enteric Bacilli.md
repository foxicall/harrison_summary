# 腸道革蘭氏陰性桿菌感染症與抗藥性危機：從微生物病原學到腸屏障與宿主防禦的臨床洞察
- **主講人/來源**：161 Diseases Caused by Gram-Negative Enteric Bacilli.pdf (Harrison's Principles of Internal Medicine, 21e / Thomas A. Russo, James R. Johnson)
- **核心主旨**：隨著後抗生素時代來臨，腸道革蘭氏陰性桿菌（GNB）憑藉內毒素（LPS）、毒力質體與多元抗藥機制威脅生命；臨床思維必須超越單純「殺菌」，從病原精準診治、破除細菌生物膜、阻斷感染源（Source Control）到修復腸道微生態與宿主黏膜屏障進行全方位介入。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **內毒素血症與促炎風暴**：GNB 外膜脂多醣（LPS）之 Lipid A  moiety 作為病原相關分子模式（PAMPs），活化宿主 TLR 等受體引發細胞因子瀑布，過度活化導致敗血性休克及組織損傷釋放 DAMPs（如 HMGB1）。
  - **營養競爭與鐵螯合（Iron Stealing）**：致病菌透過分泌高親和力鐵載體（Siderophores）掠奪宿主鐵質，在宿主防禦缺損（如糖尿病、肝硬化、血鐵沉積）時迅速增殖並侵襲組織。
  - **黏膜定殖、生物膜與移位（Translocation）**：共生菌群失調（Dysbiosis）與腸道/泌尿道黏膜屏障破損是腸外致病性大腸桿菌（ExPEC）及克雷伯氏菌等侵入無菌組織的關鍵限速步驟。
  - **抗藥性遺傳元件水平轉移**：接合質體與轉座子廣泛散播 ESBL、AmpC 與碳青黴烯酶（Carbapenemases），摧毀一線 β-lactam 類藥物防線。
- **演講亮點與臨床洞察**：
  - **進入「後抗生素時代」**：CRE（抗碳青黴烯腸道菌）已被 CDC/WHO 列為「極緊急（Urgent）」最高威脅；全球已出現真正泛耐藥（Pan-resistant）菌株。
  - **高毒力肺炎克雷伯菌（hvKp）新典範**：不同於傳統醫院內感染菌株，hvKp 具強大轉移侵襲力，好發於亞洲人及糖尿病患，常以**社區型單菌性化膿性肝膿瘍**表現，並伴隨眼內炎（可致盲）或腦膜炎。
  - **STEC/EHEC 腹瀉的抗生素禁忌**：產志賀毒素大腸桿菌（STEC）引發血便時，**切忌使用抗生素**，否則會刺激前噬菌體大量釋放志賀毒素（Stx），顯著增加溶血性尿毒症候群（HUS）發生率。
  - **變形桿菌屬（Proteeae）的代謝特性**：具強大尿素酶（Urease）活性，鹼化尿液並形成磷酸銨鎂（Struvite）鹿角狀結石與生物膜；且天生對多黏菌素（Colistin）、替加環素（Tigecycline）及亞胺培南（Imipenem）具內因性抗藥。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **hvKp 毒力基因群 (iucA, iroB, peg-344, rmpA, rmpA2)** | 鑑別高毒力肺炎克雷伯菌（hvKp）之黃金分子標準，評估轉移性膿瘍風險 | 陽性即代表高毒力侵襲性株（準確度高於拉絲試驗） |
| **拉絲試驗 (String Test)** | 評估克雷伯氏菌之高黏液表型（Hypermucoviscous phenotype） | 接種環沾取菌落拉出黏液絲 **>5 mm** 為陽性（敏感/特異度中等） |
| **碳青黴烯酶檢測 (mCIM / Carba NP / PCR)** | 鑑定 CRE 之酵素型別：Class A (KPC), Class B (NDM/VIM), Class D (OXA-48) | 陽性提示極高抗藥性，需個別化選用新一代抑酶劑複方或頭孢地爾 |
| **志賀毒素檢測 (Stx1/Stx2 基因或 EIA 毒素)** | 篩檢 STEC/EHEC，評估急性腎衰竭與血栓性微血管病變（HUS）風險 | 任何社區型腹瀉（無論有無血便）皆建議同步糞便培養與毒素篩檢 |
| **尿液 pH 值分析** | 評估泌尿道是否有產尿素酶菌（Proteus, Providencia, Morganella）生長 | **pH > 7.0~8.0** 提示尿素水解產生氨，高度懷疑感染性結石形成 |
| **糞便發炎標記 (Fecal Leukocytes / Lactoferrin / Calprotectin)** | 鑑別發炎性（侵襲性細菌）與非發炎性（分泌性毒素）腹瀉 | 發炎標記陽性見於 STEC, EIEC 等；ETEC, EAEC, EPEC 通常為陰性 |
| **血糖/糖化血色素 (HbA1c) & 血清鐵/鐵蛋白** | 宿主代謝與微量元素環境評估：高血糖及鐵過載顯著加劇 hvKp 與 *Edwardsiella* 易感性 | HbA1c < 6.5%；排除未監控的血鐵過載與嚴重代謝紊亂 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 腸外致病性大腸桿菌（ExPEC）之宿主-病原體交互作用博弈
- **宿主屏障與細菌突圍策略（表 161-1）**：
  - *尿流與黏液纖毛沖刷* $\rightarrow$ 細菌利用 P 菌毛（P pili）、Type 1 菌毛牢固黏附尿道/膀胱上皮。
  - *宿主鐵扣押（Lactoferrin/Transferrin 貧鐵環境）* $\rightarrow$ 細菌合成多種 Siderophores（鐵載體）逆向搶奪鐵質；利用溶血素（Hemolysin）溶解細胞釋出養分。
  - *體液與先天免疫殺傷（補體、抗菌胜肽）* $\rightarrow$ 細菌進化出特殊莢膜多醣（如 K1 莢膜導致新生兒腦膜炎）與 LPS O-抗原結構逃避吞噬。
  - *組織屏障限制* $\rightarrow$ 釋放細胞毒素造成組織壞死，甚至穿透血腦屏障內皮細胞。

### 2. 致病性大腸桿菌（E. coli）分型與臨床特徵（表 161-3）
- **腸外致病菌（ExPEC）**：多數源於自體腸道定殖移位，為非複雜性膀胱炎（佔 80–90%）、急性腎盂腎炎、腹腔內膿瘍及敗血症最主要病原。
- **腸道致病菌（Intestinal Pathogenic E. coli）**：
  - **STEC/EHEC（如 O157:H7）**：反芻動物為保菌宿主。低感染劑量（$<10^2$ CFU）即可致病。釋放 Stx 毒素切斷 28S rRNA 腺嘌呤，終止蛋白質合成。典型病程：水瀉 $\rightarrow$ 劇烈腹痛伴隨無熱性鮮血便 $\rightarrow$ 2~14 天後可能併發 HUS。
  - **ETEC（產毒性）**：旅行者腹瀉（佔 25–75%）主因。分泌 LT（活化 Adenylate cyclase，類似霍亂毒素）與 STa（活化 Guanylate cyclase C），導致大量分泌性水瀉，無黏液血便、無發燒。
  - **EPEC（致病性）**：發展中國家嬰幼兒水瀉主因，具 LEE 致病島，造成小腸微絨毛「附著與抹平（Attaching and effacing）」病變。
  - **EIEC（侵襲性）**：機轉同志賀氏菌，侵入大腸黏膜細胞內繁殖擴散，引發發燒、裡急後重及黏液膿血便。
  - **EAEC（凝集性）**：展現「疊磚狀（stacked-brick）」黏附，分泌黏液並形成生物膜，引發持久性水瀉。

### 3. 特殊菌種之臨床表現與病理特性
- **高毒力肺炎克雷伯菌 (hvKp)**：
  - 常見於亞洲人及糖尿病族群，具強大血行性播散能力。除典型單菌性肝膿瘍外，極易轉移至眼睛（眼內炎，視力受損）、中樞神經系統（腦膜炎/腦膿瘍）及壞死性筋膜炎。
- **變形桿菌屬 (Proteus spp.)**：
  - 常見於長期導尿患者。尿素酶將尿素分解為氨，使尿液顯著鹼化，導致磷酸銨鎂（Struvite）結晶析出，包覆細菌形成導管生物膜與巨大鹿角狀腎結石，抗生素難以滲透。
- **阪崎克羅諾桿菌 (*Cronobacter sakazakii*)**：
  - 易污染乾燥嬰兒配方奶粉，引起新生兒及早產兒壞死性小腸結腸炎、敗血症與伴隨腦膿瘍的致命性腦膜炎。
- **遲緩愛德華氏菌 (*Edwardsiella tarda*)**：
  - 與淡水、海水生物接觸或食用未熟水產相關；好發於肝硬化、血鐵過載（Iron overload）或糖尿病患，壞死性軟組織感染及菌血症死亡率高達 40%。

### 4. 關鍵抗藥性機轉與處方陷阱（表 161-2）
- **ESBLs (超廣效 β-內醯胺酶)**：以 CTX-M 最普遍，水解 3 代頭孢菌素及 Aztreonam。**首選為碳青黴烯類**（MERINO 試驗證實 Piperacillin-tazobactam 治療 ESBL 菌血症失敗率較高）。
- **AmpC β-內醯胺酶**：常見於 *Enterobacter cloacae*, *Klebsiella aerogenes*, *Citrobacter freundii*, *Serratia*。暴露於 3 代頭孢菌素易誘發「去抑制突變（Derepression）」而產生抗藥性。治療首選碳青黴烯；若排除 ESBL 且具感染源控制，可審慎使用 Cefepime。
- **碳青黴烯酶（CRE）分型應對**：
  - *Class A (KPC)*：可選用 Ceftazidime-avibactam 或 Meropenem-vaborbactam。
  - *Class B Metallo-β-lactamase (NDM-1)*：核心具鋅離子，上述新抑酶劑無效！需採用 **Ceftazidime-avibactam + Aztreonam 聯合療法**（Avibactam 保護 Aztreonam 不被共存的 ESBL/AmpC 水解），或使用新型鐵載體頭孢菌素 **Cefiderocol**。
  - *Class D (OXA-48-like)*：Ceftazidime-avibactam 有效；但 Vaborbactam 與 Relebactam 無效。
- **內因性抗藥性紅線（絕對無效藥物）**：
  - **Proteeae (*Proteus*, *Morganella*, *Providencia*)**：對 **Polymyxins (Colistin)**、**Tigecycline**、**Nitrofurantoin**、**Imipenem** 天然抗藥。
  - **Serratia**：對 **Polymyxins** 及 **Tigecycline** 具天然抗藥性。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 宿主防禦、黏膜屏障與功能性輔助支持
- **阻斷細菌黏附與生物膜管理**：
  - **D-甘露糖（D-Mannose）與高濃度蔓越莓前花青素（PACs）**：競爭性結合 ExPEC 之 Type 1 菌毛及 P 菌毛，阻斷細菌附著於膀胱與腸道上皮，輔助預防復發性 UTI。
  - **N-乙醯半胱氨酸（NAC）與生物膜溶解酵素**：針對慢性導尿管相關菌群（如 *Proteus*），有助破壞生物膜多醣基質，提升抗生素及宿主免疫清除率。
- **腸道黏膜修復與防禦（防範菌群移位）**：
  - **L-麩醯胺酸（L-Glutamine）與鋅肌肽（Zinc Carnosine）**：促進腸上皮緊密連接（Tight junctions）蛋白修復，減少危重症、化療後或肝硬化患者因腸漏引起的 GNB 菌血症。
  - **宿主鐵代謝監控**：避免在未受控的細菌感染活動期盲目補充高劑量靜脈鐵劑，以免「餵養」高度依賴鐵載體的致病菌（如 hvKp, *E. tarda*）。

### 2. 抗微生物製劑精準使用原則
- **抗生素管理與減壓（Antimicrobial Stewardship）**：
  - **杜絕無症狀菌尿症（ASB）治療**：除孕婦及即將接受泌尿道黏膜侵入性手術者外，其餘無症狀菌尿（包括長期留置導尿管者）**切勿給予抗生素**，避免篩選出 ESBL 及 CRE。
  - **感染源控制（Source Control）**：抗生素無法取代引流。膿瘍必須引流、受感染移植物/導尿管必須拔除、產尿素酶菌引發之鹿角狀結石必須外科碎石取出。
  - **及時降階治療（De-escalation）**：依藥敏試驗結果儘速將碳青黴烯降階為窄效藥物，一般非重症且感染源控制良好患者，**7 天療程**多數已足夠。

### 3. 食安防線與環境暴露阻斷
- **高危病原飲食阻斷**：
  - **STEC 預防**：碎牛肉/漢堡肉必須徹底煮熟（肉心溫度達標）；生菜沙拉、未消毒蔬果芽菜具高度污染風險，應嚴格清洗殺菌。
  - **嬰兒配方奶沖泡指引（WHO 標準）**：為殺滅潛在污染之 *Cronobacter sakazakii*，沖泡奶粉之水溫**必須 $>70^\circ\text{C}$**，沖泡後若未立即飲用應存放於 $<5^\circ\text{C}$ 冷藏並儘速食用。
- **創傷與水體暴露管理**：
  - 肝膽疾病、糖尿病或血鐵沉積症患者，嚴禁帶有皮膚傷口接觸淡海水環境或生食水產，降低 *Edwardsiella tarda* 敗血症風險。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **嚴守無熱血便處方紅線**：臨床遇劇烈腹痛伴隨血便但「無發燒」者，高度懷疑 STEC 感染，**嚴格禁用抗生素及抗腸道蠕動藥物（如 Loperamide）**，給予積極等張輸液擴容以保護腎功能，防範 HUS。
2. **糖尿病患高毒力克雷伯菌警覺**：亞裔糖尿病患者若出現不明原因發燒或單菌性肝膿瘍，必須高度警惕 hvKp，常規安排**眼底鏡檢查**排查轉移性眼內炎，避免不可逆失明。
3. **長期導尿管異狀處置標準**：若見尿液 pH 呈強鹼性或出現「紫尿袋症候群」，指向 *Proteus* 或 *Providencia* 感染；首要行動是**拔除/更換導尿管**並評估是否有鹿角狀結石，單用抗生素無法根除生物膜。
4. **謹記 Proteeae 的天然抗藥陷阱**：面對 *Proteus*, *Morganella*, *Providencia* 嚴重感染，**絕對不可選用多黏菌素（Colistin）或替加環素（Tigecycline）**，重症應優先選用敏感之碳青黴烯（除 Imipenem 外）、Amikacin 或新一代頭孢抑酶劑複方。
5. **落實抗生素降階與腸道黏膜防護**：非重症感染於感染源完全控制後，避免非必要長療程抗生素，搭配黏膜修復支持，保護腸道微生態對外來抗藥性 GNB 的定殖抗性（Colonization resistance）。
