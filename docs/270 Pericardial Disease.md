# 心包膜疾病全解析：從急性心包膜炎、心包填塞到縮窄性心包膜炎的病理與臨床處置
- **主講人/來源**：*Harrison's Principles of Internal Medicine*, 21st Edition, Chapter 270 Pericardial Disease (Joseph Loscalzo)
- **核心主旨**：系統化解析心包膜疾病（急性發炎、心包積液/填塞、慢性纖維化縮窄）的血流動力學與免疫病理機制，確立精準鑑別診斷架構（如區分 AMI、肝硬化與限制型心肌病），並制定結合標準抗發炎階梯藥物與全身性發炎微環境調控的整合性處置策略。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **急性發炎與免疫失衡**：病毒感染、自體免疫反應（如 SLE、Postcardiac injury/Dressler's syndrome）或代謝毒素（尿毒症）刺激心包膜臟層與壁層，引發微血管通透性增加、嗜中性球浸潤與介白素（特別是 IL-1 途徑）活化，產生漿液性或纖維蛋白性滲出液。
  - **血流動力學受限與心室相互依賴性（Ventricular Interdependence）**：當積液急性增加（心包填塞）或慢性壁層增厚鈣化（縮窄性心包膜炎）時，堅硬的心包膜限制舒張期心室充盈。由於心包容積固定，吸氣時右心充盈受限迫使室間隔向左心室側凸，導致左心搏出量與體循環動脈壓劇降（奇脈機轉）。
  - **慢性纖維化與組織重塑**：急性發炎未完全消退轉為肉芽組織與緻密瘢痕，阻斷中晚期舒張心室擴張，導致靜脈壓顯著升高及多器官鬱血（如心因性肝硬化）。

- **演講亮點與臨床洞察**：
  - **酵素與 ECG 的「病理脫節」（Dissociation）**：心包膜炎引起心外膜發炎（Epi-myocarditis）時，Troponin 及 CK-MB 僅呈現輕度升高，這與其心電圖大範圍廣泛的 ST 段上升不成比例；此特徵為鑑別急性心肌梗塞（AMI）的關鍵。
  - **秋水仙素（Colchicine）的核心抗復發角色**：藉由抑制嗜中性球微管蛋白聚合與趨化性，秋水仙素為減少急性心包膜炎復發（發生率約 25%）的基礎用藥（建議使用 3 個月），且能顯著提升 NSAIDs 之治療療效。
  - **類固醇的雙面刃陷阱**：系統性類固醇（Prednisone）雖能迅速壓制臨床發炎症狀，但已被證實是日後「疾病復發」的獨立危險因子，故僅保留給對 NSAIDs/Colchicine 無反應或禁忌者，且須在 2~4 天後迅速漸減。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **心肌酵素 (Troponin / CK-MB)** | 評估是否合併心外膜心肌炎（Epi-myocarditis）或鑑別急性心肌梗塞 (AMI)。 | 心包炎時僅輕度升高，與廣泛 ST 上升不成比例；若顯著極高則強烈懷疑 AMI。 |
| **發炎指標 (CRP / WBC)** | 評估全身性免疫發炎程度與監控抗發炎治療之療效終點。 | 治療期間持續追蹤至 CRP 完全恢復正常，方可進行藥物遞減。 |
| **心電圖 (12-Lead ECG)** | 監控疾病四階段變化；偵測 PR 段下陷、廣泛凹面向上 ST 上升、低電壓與電氣交替。 | **Stage 1**: 廣泛凹面向上 ST 上升 + PR 段下陷（aVR 鏡像上升）；**Stage 2**: 正常化；**Stage 3**: T波倒置；**Stage 4**: 完全恢復正常。 |
| **奇脈 (Pulsus Paradoxus)** | 評估心包填塞之血流動力學受損程度（心室相互依賴現象）。 | 吸氣時收縮壓下降 **>10 mmHg** 即具臨床病理意義（心包填塞時為 `+++`）。 |
| **都卜勒超音波流速呼吸變異** | 評估經房室瓣血流隨呼吸變異程度，鑑別縮窄性心包膜炎與限制型心肌病。 | 吸氣時三尖瓣流速大幅上升，二尖瓣與肺靜脈流速大幅下降（縮窄性與填塞特徵）。 |
| **頸靜脈波形 (JVP tracing)** | 鑑別心包填塞與縮窄性心包膜炎的舒張期充盈障礙類型。 | **填塞**：x 降波顯著，**y 降波消失/變平**；**縮窄**：x 與 **y 降波極度陡峭** (M型/W型)。 |
| **心包積液 PCR / 組織細胞學** | 鑑別結核分枝桿菌（MTB-DNA）、惡性腫瘤轉移或化膿性細菌感染。 | 陰性為正常；陽性可明確特定病因，指導抗結核或腫瘤標靶處置。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 急性心包膜炎的診斷四大核心與臨床鑑別
- **胸痛特徵**：常為劇烈、胸骨後或左側心前區疼痛，常放射至斜方肌脊（Trapezius ridge，因膈神經支配受刺激），具明顯「肋膜性痛」特質（深呼吸、咳嗽加重）；**特異性緩解姿勢為身體坐起並前傾（Sitting up and leaning forward）**，平躺（Supine）則顯著加重。
- **心包摩擦音（Pericardial Friction Rub）**：約 85% 病患可聽診發現，含多達三個音成分（心房收縮、心室收縮、心室舒張早期快速充盈），音質呈抓刮樣（scratching/grating），在病患前傾且吐氣末（end-expiration）聽診最清晰。
- **心電圖分期與鑑別**：
  - **Stage 1**：廣泛導程（I, II, aVF, V2–V6）呈現向下凹陷型（upward concavity）ST 段上升，伴隨心房受損誘發的 PR 段下陷（aVR 出現 PR 上升與 ST 下陷）。
  - **與 AMI 之鑑別**：AMI 呈現凸面向上（convexity）ST 上升，伴隨嚴格解剖血管分佈的鏡像變化（reciprocal depression）、快速出現病理性 Q 波與 R 波高度喪失；心包炎則無 Q 波，且 T 波倒置是在 ST 段回到基準線後（Stage 3）才會出現。

```
[急性心包膜炎 ECG 演進四階段]
Stage 1: 廣泛 ST 凹面向上上升 + PR 段下陷 (aVR 鏡像相反)
   ↓ (數天後)
Stage 2: ST 段回歸等電位線 (Isoelectric)，PR 回復
   ↓
Stage 3: T 波轉為對稱性倒置 (Inverted T waves)
   ↓ (數週至數月)
Stage 4: ECG 完全恢復正常基準線
```

- **心包積液與周邊壓迫徵象**：大體積積液可壓迫左肺底部，引發左肩胛下角叩診濁音、語音震顫增加及羊鳴音（**Ewart's sign**）；X 光呈現「燒瓶心/水壺心（water bottle sign）」。

---

### 2. 心包填塞（Cardiac Tamponade）的急重症病理
- **Beck’s Triad（貝克氏三病徵）**：
  1. 低血壓（Hypotension，心輸出量劇減）。
  2. 心音遙遠/微弱（Soft or absent heart sounds）。
  3. 頸靜脈怒張（JVD），伴隨顯著的 $x$ 降波但 **$y$ 降波完全消失**（因心包腔高壓導致舒張早期心室無法快速充盈）。
- **容積-壓力曲線非線性關係**：急驟發生的積液（如主動脈剝離出血、心臟穿孔），僅需 200 mL 即引發腔內壓飆升致死；慢性積液經心包延展，可累積 >2000 mL 始出現填塞。
- **心電圖特徵**：QRS 低電壓（Low voltage）與心臟在積液中擺動導致的**電氣交替（Electrical alternans）**（P、QRS、T 波振幅隨心跳逐跳交替變化）。
- **超音波關鍵徵象**：右心室自由壁與右心房舒張末期塌陷（Diastolic collapse），都卜勒顯示吸氣時三尖瓣流速劇增、二尖瓣流速劇降。

---

### 3. 縮窄性心包膜炎（Constrictive Pericarditis）與鑑別診斷
- **舒張受阻機制**：與填塞（全舒張期均受限）不同，縮窄性心包炎在**舒張極早期充盈不受阻**，但當充盈到達心包硬化外殼極限時突然中斷。心室壓力波形呈現典型的**「平方根徵（Square root sign）」**或下陷-平台型（dip-and-plateau）。
- **臨床表徵**：
  - **Kussmaul's sign（庫斯莫爾氏徵）**：吸氣時頸靜脈壓反常不降反升（因右心無法吸納回流血量）。
  - **心包敲擊音（Pericardial knock）**：舒張早期充盈驟然停止時產生的額外心音（早於一般 S3）。
  - **Broadbent's sign**：收縮期心尖搏動回縮。
  - **假性肝硬化陷阱**：顯著腹水、肝腫大、黃疸與惡質病（Cachexia），若忽略檢查頸靜脈怒張，常被誤診為原發性肝硬化。
- **與限制型心肌病（Restrictive CM）的關鍵鑑別**：
  - 縮窄性心包炎的兩心室舒張末期壓力呈現**均等化（Equalization within 5 mmHg）**。
  - 都卜勒超音波具顯著的呼吸血流流速變異（Respiratory variation >25%），且影像學（CT/MRI）可見心包顯著增厚（>3–4 mm）與鈣化；限制型心肌病則無顯著呼吸依賴性，心包厚度正常。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

```
[急性心包膜炎階梯治療流程]
一線處方: 高劑量 NSAIDs/Aspirin + Colchicine (3個月) + 胃黏膜保護 (PPI)
   ↓ (療效不佳或無法耐受)
二線處方: 短程低-中劑量全身性類固醇 (Prednisone 1 mg/kg/d，2-4天後速減)
   ↓ (難治型、反覆發作 >2年)
三線處方: IL-1β 受體拮抗劑 (Anakinra) / 免疫抑制劑 (Azathioprine) / 心包剝離術
```

### 1. 標準抗發炎與免疫階梯處方
- **第一線基礎治療（NSAIDs + Colchicine 協同處方）**：
  - **Aspirin**：2–4 g/天，或 **Ibuprofen**：600–800 mg tid，或 **Indomethacin**：25–50 mg tid；持續 1–2 週至症狀緩解後，耗時數週漸進式減量（Tapering）。
  - **胃黏膜屏障保護**：強制合併質子幫浦抑制劑（PPI，如 Omeprazole 20 mg/d）以防止高劑量 NSAID 誘發之消化道出血與潰瘍。
  - **Colchicine（抗微管蛋白與發炎體調節）**：
    - 體重 $<70\text{ kg}$：0.5 mg qd。
    - 體重 $\ge 70\text{ kg}$：0.5 mg bid。
    - **療程規範**：初發患者至少給予 **3 個月**；復發型患者至少給予 6 個月以上。禁忌於嚴重肝腎功能不全患者。
- **難治型或自體免疫型進階處方**：
  - **全身性皮質類固醇（Prednisone）**：1 mg/kg/d，僅在 NSAIDs 及秋水仙素無效或禁忌時介入。為避免日後復發率上升，全劑量僅能維持 2~4 天，確認症狀壓制後即刻逐步緩慢減量。
  - **標靶抗發炎生物製劑**：難治、復發超過 2 年者，可採用 **Anakinra（IL-1β 受體拮抗劑）** 或 **Azathioprine** 抑制全身自體免疫路徑。
  - **嚴格禁忌**：急性期應**避免使用抗凝血劑（Anticoagulants）**，防止心包滲血誘發致命性心包填塞。

### 2. 急重症介入處方
- **心包填塞之緊急心包穿刺引流術（Pericardiocentesis）**：
  - 若出現血流動力學不穩，應立即經劍突下（Subxiphoid）、心尖或胸骨旁進針引流。
  - 準備期間可給予生理食鹽水靜脈輸液維持前負荷，但**不可延遲穿刺引流**。
  - 留置多孔導管持續引流，必要時施行心包切開造窗術（Pericardial window）。
- **縮窄性心包炎之外科根治**：
  - **完全心包剝離切除術（Pericardial resection/decortication）** 為唯一根治手段。年齡 $>50$ 歲患者術前應常規進行冠狀動脈攝影，以排除潛在缺血性心臟病。

### 3. 生活型態管理與全身發炎微環境優化
- **急性期活動限制（Bed Rest）**：
  - 急性心包炎期間應嚴格**臥床休息**，避免競技運動及中高強度勞動，直至發炎症狀緩解、發炎指數（CRP）及 ECG 恢復正常，以防止心肌耗氧量增加及代謝壓力誘發心肌發炎壞死。
- **降低全身發炎負荷飲食原則**：
  - 攝取高抗氧化、富含多酚與 Omega-3 脂肪酸的地中海飲食模式，降低促發炎介質（如前列腺素 E2、TXA2）之基線濃度。
  - 縮窄性心包炎或充血性心臟衰竭階段，嚴格限制鈉鹽（$<2\text{ g/day}$）與水分攝取，以減輕頸靜脈壓迫、腹水與下肢水腫。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **辨識典型胸痛姿位特徵並即刻安排心電圖**：若遇吸氣、平躺加重，坐起前傾緩解之胸痛，立即描記 ECG。尋找廣泛性凹面向上 ST 上升與 PR 段下陷，並檢測心肌酵素；若 ST 廣泛變化但 Troponin 僅微量上升，應優先診斷急性心包炎而非 AMI。
2. **急性發炎期首選「雙重抗發炎搭橋」，拒絕常規過早使用類固醇**：處方充足劑量 NSAIDs（如 Ibuprofen 600~800 mg tid）加上 Colchicine（0.5 mg qd/bid 維持 3 個月），同步合併 PPI 保護腸道；除非必要，避免常規開立類固醇以防復發循環。
3. **血流動力學危象快速排查（警惕 Beck 三聯徵與奇脈）**：遇低血壓合併頸靜脈怒張患者，床邊觸診或血壓計量測吸氣期收縮壓是否下降 $>10\text{ mmHg}$，並觀察頸靜脈 $y$ 降波是否消失；若超音波確認右心塌陷與填塞，應即刻進行床邊心包穿刺術。
4. **難治型腹水患者切勿遺漏「頸靜脈視診」**：面臨頑固性腹水、黃疸與肝腫大但缺乏顯著心臟雜音者，務必抬高床頭檢視頸靜脈壓（有無 Kussmaul 徵象或深深陡峭的 y 降波）；若頸靜脈顯著充盈，應安排胸部 CT/MRI 與心臟超音波排除縮窄性心包炎，避免誤診為肝硬化而錯失心包剝離手術良機。
