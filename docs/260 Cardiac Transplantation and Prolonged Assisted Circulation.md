# 心臟移植與長期心室輔助循環：晚期心臟衰竭的外科終極策略與代謝血流動力學生態

- **主講人/來源**：Mandeep R. Mehra / 260 Cardiac Transplantation and Prolonged Assisted Circulation.pdf (*Harrison's Principles of Internal Medicine*, 21st ed., Chapter 260)
- **核心主旨**：針對神經荷爾蒙藥物治療頑固之晚期心臟衰竭，心臟移植與左心室輔助裝置（LVAS）為重建血流動力學與延長存活的關鍵外科手段；臨床成功取決於移植免疫排斥調控、同種異體移植物血管病變（CAV）之代謝血管防護，以及機械循環裝置引發之剪切應力與血液相容性（Hemocompatibility）平衡。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **代謝與血流動力學崩潰**：晚期心衰竭伴隨顯著之心腎症候群（Cardiorenal syndrome）、心臟儲備耗竭與神經荷爾蒙拮抗劑耐受不良，核心機制由心肌張力異常與灌流不足轉向全身微血管內皮發炎與終末器官衰竭。
  - **移植物血管病變（CAV）之發炎-代謝驅動**：腦死誘發之發炎風暴、缺血再灌流損傷（Ischemia-Reperfusion Injury）、同種異體免疫反應，疊加術後長期的神經鈣蛋白抑制劑（CNI）所致之高血壓、血脂異常及高血糖，共同誘發瀰漫性冠狀動脈內皮炎與內膜纖維增生。
  - **機械循環輔助之血液相容性三聯症**：LVAS 高剪切應力（Shear stress）造成獲得性溫韋伯氏疾病（Acquired von Willebrand Disease, 降解高分子量 vWF 多聚體）與紅血球溶血；低搏動性血流（Diminished pulsatility）引發腸道動靜脈畸形（AVMs），與抗凝治療交織形成「血栓-出血」兩難天平。

- **演講亮點與臨床洞察**：
  - **去神經化心臟的自主調節失調**：Bi-caval 術式保留受者右心房部分解剖，但移植心臟喪失交感與副交感神經支配，術後急性心搏過緩對阿托品（Atropine）無效，必須使用異丙腎上腺素（Isoproterenol）或心臟節律器。
  - **裝置技術的典範轉移（Paradigm Shift）**：從早期巨型脈衝式幫浦（REMATCH 試驗），進展至軸流式（HeartMate II），再到磁懸浮離心式（HeartMate 3, MOMENTUM 3 試驗）。全磁懸浮技術透過加大血流通道與人造搏動脈衝（30 bpm），大幅降低剪切破壞，近乎根除幫浦血栓並顯著降低中風風險。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **心肺運動耐量（Peak $\text{VO}_2$）** | 評估心衰竭患者有氧代謝極限與心臟儲備，作為列入移植名單之客觀標準 | $\text{VO}_2 < 14\text{ mL/kg/min}$（若使用 $\beta$-blocker 則 $<12$）；或預測值 $<50\%$ |
| **肺血管阻力（PVR）與跨肺壓差** | 評估右心後負荷；固定型肺高壓將導致移植後供心急性右心衰竭 | PVR $>3\text{ Wood units}$、TPG $>15\text{ mmHg}$、PASP $>50\text{ mmHg}$ 為移植相對禁忌症（除非對血管擴張劑有反應） |
| **同種異體抗體 / 虛擬交叉配對（Virtual Crossmatch）** | 預防超急性排斥及抗體媒介性排斥（AMR）；評估致敏受者之抗 HLA 抗體 | 致敏受者必須進行預期或虛擬交叉配對陰性始可接受供心 |
| **都卜勒平均動脈壓（Doppler MAP）** | 評估連續流 LVAS 之左室卸載阻抗，防止後負荷過高誘發中風與幫浦功能不良 | 目標維持 $\text{MAP} \le 90\text{ mmHg}$（以都卜勒超音波測量開啟壓） |
| **乳酸脫氫酶（LDH）** | 連續流血流剪切應力下微血管病性溶血指標，預警早期幫浦血栓形成 | 異常升高提示亞臨床溶血或即將發生的 LVAD 血栓（伴隨裝置功率 Power 上升） |
| **凝血酶原時間國際標準化比值（INR）** | LVAS 植入後的血液相容性監測，權衡動脈血栓與消化道出血風險 | 標靶區間設定為 $\text{INR } 2.0 \sim 3.0$（合併 Aspirin $81 \sim 325\text{ mg/day}$） |
| **血管內超音波（IVUS）** | 早期偵測同種異體移植物血管病變（CAV）之冠狀動脈內膜瀰漫性增厚 | 診斷敏感度顯著高於傳統侵入性冠狀動脈造影（CAG） |
| **持續性估計腎絲球過濾率（eGFR）** | 評估心腎症候群之可逆性及全身血管病變嚴重度 | $\text{eGFR} < 30\text{ mL/min/1.73 m}^2$（若為持續不可逆狀態）為心臟移植相對禁忌症 |

## 三、 關鍵機制詳解與重點筆記

### 1. 免疫排斥雙路徑：細胞媒介（ACR） vs. 抗體媒介（AMR）
- **急性細胞媒介性排斥（ACR）**：
  - **發病機轉**：T 細胞受體辨識供體同種異體抗原，活化並浸潤心肌。初期侷限於靜脈周圍（Mild），嚴重時侵入心肌間質並招募巨噬細胞、嗜中性球及嗜酸性球，導致心肌細胞壞死、心肌間質出血與血液動力學衰竭。
  - **臨床處理**：亞臨床輕度 ACR 可密切觀察或給予高劑量類固醇脈衝治療（Corticosteroid pulses）；併發血液動力學障礙時需合併多株抗體（如 ATG）進行挽救治療。
- **抗體媒介性排斥（AMR）**：
  - **發病機轉**：由供體特異性抗體（Donor-specific antibodies, DSA）引導之體液免疫。抗體沉積於微血管內皮並活化補體系統（C4d 沉積），引發內皮細胞腫脹、間質水腫及心肌小動脈炎。
  - **不良預後**：相較於 ACR，AMR 更易引發同種異體移植物功能不全、大幅加速心臟異體移植物血管病變（CAV）的進展，死亡率更高。
  - **標靶治療**：移除循環抗體與阻斷 B 細胞/補體路徑——血漿置換（Plasmapheresis）、Rituximab（抗 CD20 單株抗體）、Bortezomib（蛋白酶體抑制劑）、Eculizumab（終端補體 C5 抑制劑）。

### 2. 異體移植物血管病變（CAV）：免疫-代謝交織的血管老化
- **病理生理網絡**：
  - **發起期**：供體腦死引發之全身細胞激素風暴、冷缺血時間（通常需限制於 4 小時內）與再灌流微血管內皮氧化損傷，構成初期內皮炎（Endothelialitis）。
  - **推進期（代謝撞擊）**：術後長期使用免疫抑制劑（尤其 Calcineurin Inhibitors）誘發高血壓、代謝症候群、胰島素阻抗與高三酸甘油酯血症。
  - **表現特徵**：全冠狀動脈樹呈現瀰漫性、進行性管腔同心圓纖維內膜增生，與傳統粥狀動脈硬化的局部偏心斑塊截然不同。因心臟神經切斷，病患多無典型心絞痛症狀（靜默性缺血）。經皮冠狀動脈介入（PCI）或繞道手術（CABG）僅能緩解局部病灶，無法改善長期存活；**再次心臟移植是晚期 CAV 的唯一根治手段**。

### 3. 機械循環輔助裝置（LVAS）的血流動力學與併發症生態
- **血液相容性三聯併發症（Hemocompatibility Complex）**：
  - **腸道血管發育不良出血**：連續非搏動血流 $\to$ 血管壁切應力異常 $\to$ 黏膜缺氧與血管新生失調 $\to$ 消化道動靜脈畸形（AVMs）；疊加高剪切應力切割大分子 vWF 多聚體，引發消耗性止血功能缺陷與頑固缺鐵性貧血。
  - **幫浦血栓與溶血**：舊型軸流式（HeartMate II）具機械軸承，容易產生血液滯留區與高溫摩擦；血栓形成時伴隨裝置功率異常驟升與血清 LDH 飆升。內科溶栓常因高出血風險而受限，需行高風險換機手術（Perioperative mortality ~6.5%）。
  - **神經系統事件**：微血栓栓塞引發缺血性中風，抗凝與微血管壁脆性增加引發腦出血（尤其在 MAP 未良好控制於 $\le 90\text{ mmHg}$ 時）。
- **右心室功能失調（RV-Pulmonary Uncoupling）**：
  - LVAD 大幅抽吸左室血液致使室間隔左偏，減弱右心室收縮力學效率；伴隨左心排血增加導致靜脈回流（右心前負荷）暴增，易迅速誘發急性右心擴張衰竭。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素與代謝防護支持
- **鐵代謝與造血修復**：
  - **機轉**：連續流 LVAS 患者因獲得性 vWF 缺乏合併腸道 AVMs，長期微量失血極易併發重度缺鐵性貧血；全人工心臟（TAH）機械瓣膜亦會造成機械性溶血與異常紅血球生成。
  - **臨床處方**：定期監控鐵蛋白（Ferritin）與運鐵蛋白飽和度（TSAT），常規進行靜脈鐵劑補充（優於口服鐵劑，因口服吸收受心衰竭腸壁水腫及發炎性 Hepcidin 抑制），維持血紅素穩定以減輕右心高輸出負荷。
- **神經鈣蛋白抑制劑（CNI）抗代謝毒性防護**：
  - **抗氧化與粒線體保護**：CNI（Tacrolimus, Cyclosporine）會引發入球小動脈收縮與腎小管間質纖維化，並損傷胰島 $\beta$ 細胞誘發糖尿病。臨床可評估輔酶 Q10、高純度 Omega-3 脂肪酸（EPA/DHA $2 \sim 4\text{ g/day}$）以降低三酸甘油酯並提供血管內皮發炎防護。
- **mTOR 抑制劑併發症之營養對策**：
  - 使用 Sirolimus 或 Everolimus 時，常伴隨高三酸甘油酯血症、口腔炎與傷口癒合延遲；需強化高抗氧化植化素（如薑黃素複合物）減輕發炎反應，並嚴格監控血脂輪廓。

### 2. 心臟代謝與飲食調控策略
- **嚴格血管內皮保護型飲食**：
  - 移植後與 LVAS 病患需執行低升糖指數、富含多元不飽和脂肪酸的抗發炎地中海型飲食，藉由阻斷動脈粥狀硬化與代謝症候群進程，減緩 CAV 發展。
  - **血壓與水分穩態**：LVAS 術後嚴格控制鈉鹽攝取（$<2\text{ g/day}$），將目標維持於 Doppler MAP $\le 90\text{ mmHg}$，預防主動脈逆流、降低後負荷並防止腦中風。

### 3. 環境防護、排毒與感染阻斷機制
- **紫外光暴露阻斷（皮膚惡性腫瘤防護）**：
  - **機制**：長期使用三聯免疫抑制劑（CNI + 類固醇 + 抗代謝藥物）導致免疫監視功能低下，鱗狀細胞癌（SCC）與基底細胞癌（BCC）風險劇烈上升。
  - **處方**：落實全年每日廣譜防曬（SPF 50+、高 PA 值防曬乳），避免紫外線誘導之 DNA 突變，並每 6~12 個月進行全身體表皮膚鏡檢。
- **經皮傳輸線（Driveline）微生態與發炎阻斷**：
  - **臨床問題**：LVAS 的外接導線穿透人體皮膚屏障，感染率高達 20%（1/5），感染引發之全身發炎會進一步破壞血液相容性並提高中風風險。
  - **管理**：嚴格無菌傷口護理、固定導線防止微小撕裂傷、避免局部潮濕與生物膜（Biofilm）形成。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **嚴格落實心衰竭器械治療轉介時機**：
   - 當頑固性心衰竭病患出現最大攝氧量 $\text{Peak } \text{VO}_2 < 14\text{ mL/kg/min}$（用 $\beta$-blocker 者 $<12\text{ mL/kg/min}$）、無法耐受神經荷爾蒙抑制劑、或開始依賴連續強心劑輸注時，應立即啟動進階機械循環輔助（LVAS）或心臟移植評估，切勿拖延至不可逆心腎衰竭。

2. **精準把關心臟移植列名禁忌症**：
   - 術前必須完成右心導管評估：若固定型肺血管阻力 $\text{PVR} > 3\text{ Wood units}$ 且對血管擴張劑無反應、持續性 $\text{eGFR} < 30\text{ mL/min/1.73 m}^2$、活躍性物質濫用或戒菸未滿 6 個月者，應視為手術相對禁忌，應先透過 LVAS 進行「決策橋接（Bridge to decision）」以爭取終末器官逆轉機會。

3. **掌握去神經化移植心臟急症處置原則**：
   - 遭遇心臟移植術後急性心搏過緩時，**嚴禁仰賴阿托品（Atropine，無副交感神經通路可拮抗）**；首選藥物為直接刺激 $\beta$ 受體之異丙腎上腺素（Isoproterenol）或採取暫時性心臟電擊節律（Pacing）。

4. **全面監測連續流 LVAS 之血液相容性指標**：
   - 門診隨訪須以都卜勒超音波常規測量並將平均動脈壓壓制在 $\text{MAP} \le 90\text{ mmHg}$；密切追蹤血清 LDH 變化（溶血與幫浦血栓之敏感早期標記）；定期篩檢糞便潛血與鐵蛋白，早期阻斷腸道動靜脈畸形伴隨之消耗性貧血。

5. **實施全方位移植後代謝與腫瘤防禦措施**：
   - 將移植後 CAV 防治視為全身性血管抗老化工程，早期導入 Statin 類藥物、優先選用具抗內膜增生優勢的免疫抑制劑（如 Mycophenolate Mofetil 或 mTOR 抑制劑），並對患者進行徹底的防曬教育與皮膚癌定期篩檢。
