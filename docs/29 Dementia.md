# 認知退化與失智症之神經網絡病理、精準鑑別與整合性醫學評估全策
- **主講人/來源**：William W. Seeley, Gil D. Rabinovici, Bruce L. Miller / 《哈里遜內科學》（Harrison's Principles of Internal Medicine, 21e）第 29 章 Dementia
- **核心主旨**：失智症並非單一疾病，而是多重神經網絡中斷與異常蛋白質沉積（蛋白質病變）所導致的症候群；臨床首要任務在於釐清可逆病因、區分特定神經退化亞型，並及早透過血管代謝管理、神經發炎阻斷與生活型態介入，減緩神經元衰亡進程。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **大規模神經網絡破壞（Large-Scale Network Disruption）**：認知缺損取決於受損神經網絡的解剖位置與突觸丟失程度。膽鹼能神經系統（支配注意力與記憶）與單胺類系統（去甲腎上腺素、血清素、多巴胺，調節情緒與行為）的失衡共同塑造臨床表型。
  - **異常蛋白質聚集病變（Proteinopathies）**：各型神經退化症本質為特定蛋白質錯誤折疊沉積——阿茲海默症（AD: Aβ42 與過度磷酸化 Tau 蛋白）、路易氏體失智症（DLB: α-synuclein）、額顳葉失智症（FTD: Tau、TDP-43 或 FET 蛋白家族）、狂牛症/庫賈氏病（CJD: 異常普丁蛋白 $\text{PrP}^{\text{Sc}}$）、以及高齡者海馬體萎縮常見的 LATE（TDP-43）。
  - **血管代謝與微循環障礙**：慢性腦血管灌流不足、廣泛白質病變（Binswanger 病變）與多發微梗塞，破壞網絡節點連結，常與 AD 混合並存。
- **演講亮點與臨床洞察**：
  - **可逆性與共存因子佔比極高**：記憶門診研究顯示，高達 19% 的患者具有潛在「可逆病因」，23% 具有加重病情的「可逆共病」。臨床不可直觀將記憶衰退視為不可逆退化，必須積極排查抑鬱、常壓性水腦症（NPH）、酒精與藥物毒性。
  - **「良性老化忘性」與主觀/輕度認知障礙分界**：85 歲個體學習回憶能力約為 18 歲時的一半；若自覺退化但客觀測試正常屬「主觀認知下降（SCD）」；若客觀受損但日常生活能力（ADL）維持則為「輕度認知障礙（MCI）」，後者合併 ApoE ε4、海馬體萎縮或 CSF Aβ/Tau 異常時，高比例轉化為 AD。
  - **BPSD 行為精神症狀的根本原因追溯**：躁動、譫妄或精神症狀往往由「生理不適」觸發（如便秘、尿路感染、疼痛、電解質紊亂或抗膽鹼藥物毒性），應以環境調整與生理根因治療為第一線，而非逕行使用抗精神病藥物（此類藥物增加失智患者死亡率）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **腦脊髓液（CSF）生物標記**<br>$\text{A}\beta_{42}$、總 Tau、磷酸化 Tau | 反映腦部類澱粉沉積與神經纖維纏結；CSF 中 $\text{A}\beta_{42}$ 降低（或 $\text{A}\beta_{42}/\text{A}\beta_{40}$ 降低）、t-tau 輕中度升高、p-tau（Thr181 或 Thr217）顯著升高為 AD 特異標誌 | 出現「低 $\text{A}\beta_{42}$ ＋ 高 p-tau」組合具極高 AD 診斷價值；血液檢測亦正快速發展中 |
| **維生素 $\text{B}_{12}$ 與同半胱胺酸（Homocysteine）** | 評估甲基化代謝、髓鞘生成健全性；缺乏可導致亞急性合併退化症（SCD）、腦白質缺損及失智 | 臨床常規必檢；偏低之 $\text{B}_{12}$ 數值或高同半胱胺酸（代謝血管毒性）應立即積極介入 |
| **維生素 $\text{B}_1$（Thiamine）狀態** | 預防/評估魏尼凱腦病變（Wernicke's encephalopathy）；常發生於酒精濫用、營養不良、吸收障礙 | 懷疑酒精依賴、吸收不良或胃手術患者必備；預防不可逆失憶-虛談症候群（Korsakoff） |
| **甲狀腺功能（TSH、Free T4）** | 排除內分泌紊亂引起的代謝性與假性失智（甲狀腺功能低下典型表現為嗜睡、水腫、乾皮、心搏過緩） | 臨床標準篩檢項目，維持 TSH 於正常區間 |
| **梅毒與感染篩檢（RPR / VDRL、HIV）** | 排除中樞神經慢性感染性失智症（神經性梅毒、愛滋相關失智症候群） | 具高風險行為或非典型快速進展者列為必要檢測 |
| **結構性神經影像（MRI / CT）** | 鑑別可逆性構造異常（硬腦膜下血腫、腦腫瘤、NPH 水腦症）與腦血管白質高訊號病變（FLAIR Hyperintensities） | 評估海馬體萎縮、頂葉萎縮（AD）、額顳葉萎縮（FTD）或腦室顯著擴大伴頂葉壓迫（NPH） |
| **分子神經影像（Amyloid-PET / Tau-PET / FDG-PET）** | 類澱粉蛋白與 Tau 纖維在體標記；FDG/SPECT 評估腦區代謝低灌流模式 | 陰性 Amyloid-PET 可高度排除 AD；Tau-PET 分布與認知缺損及疾病分期高度一致 |
| **神經認知篩檢（MMSE / MoCA）** | 客觀量化定向力、注意力、短期記憶、語言與視覺建構功能 | 滿分 30 分；MCI 階段常規 MMSE 常表現假陰性，需更敏感之神經心理測試（如記憶延遲回憶、動物流暢度） |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 神經迴路解剖與臨床神經心理表型（Functional Anatomy）
- **內側顳葉-邊緣系統網絡（AD 起源）**：
  - 退化起始於內嗅皮質（Entorhinal cortex）與海馬體，繼而擴展至基底顳葉、外側及後頂葉皮質。臨床最早表現為**情節記憶（Episodic memory）**缺損，晚期合併失語、失行與失認。
- **額葉-紋狀體迴路（Frontal-Striatal Circuits）及其病變表徵**：
  - **背外側前額葉皮質（DLPFC）- 尾狀核中心帶**：損傷導致**執行功能障礙**（計畫、組織力下降、工作記憶喪失）。
  - **外側眼眶額葉皮質（LOFC）- 腹內側尾狀核**：損傷引發**去抑制行為（Disinhibition）**、衝動控制缺失、注意力渙散。
  - **前扣帶回（ACC）/ 內側前額葉 - 伏隔核（Nucleus Accumbens）**：損傷造成**淡漠（Apathy）**、言語貧乏、情感遲鈍，極端表現為運動不能性不語（Akinetic mutism）。

```
[前額葉-紋狀體三大路徑]
DLPFC  ──> 尾狀核中心帶 ──────> 執行功能缺損 (無計畫/工作記憶差)
LOFC   ──> 腹內側尾狀核 ──────> 行為去抑制 (衝動/失序/過度口慾)
ACC    ──> 伏隔核 (Accumbens) ──> 淡漠症候群 (缺乏動機/情感淡漠)
```

### 2. 蛋白質病變分子基礎與基因易感性（Proteinopathies & Genetics）
- **阿茲海默症（AD）**：因 $A\beta_{42}$ 寡聚體/類澱粉斑塊與過度磷酸化 Tau 神經纖維纏結堆積；致病突變見於 *APP*、*PSEN1*、*PSEN2*；最強環境易感基因為 **ApoE $\varepsilon4$**。
- **額顳葉失智症（FTD）**：以人格改變、淡漠、脫抑制或原發性進行性失語為早期表現；病理涵蓋 Tau 蛋白（*MAPT* 突變）、TDP-43（*GRN*、*C9ORF72* 擴增突變）或 FET 家族蛋白。
- **路易氏體失智症（DLB）**：以 $\alpha$-synuclein 沉積為標誌；臨床以早發性生動視幻覺、認知與警覺度波動、巴金森症候群、**REM 睡眠行為障礙（RBD）**及對抗精神病藥物極度敏感為特徵。
- **快速進展型失智（Rapidly Progressive Dementia, RPD）**：一年內急遽惡化。經典為 CJD（普丁蛋白致病，伴肌陣攣與擴散加權 MRI 皮質帶徵象 Cortical ribboning），但臨床上更常見由侵襲性神經退化症或**自體免疫/副腫瘤性腦炎**（抗 LGI1、Caspr2、NMDA、AMPA 受體抗體）引起。

### 3. 可逆性病因深度鑑別（Reversible Dementias）
- **常壓性水腦症（Normal Pressure Hydrocephalus, NPH）**：典型臨床三聯徵為步態步幅減小/失用、尿失禁、認知障礙。MRI 關鍵為側腦室擴大、胼胝體受拉扯向上膨脹、第三腦室底凹陷、大腦裂（Sylvian fissures）擴張合併高位頂葉腦溝受壓迫密合（Vertex effacement），引流分流手術具高恢復率。
- **內分泌與代謝障礙**：慢性腎衰竭、肝性腦病、嚴重甲狀腺低下、腎上腺皮質功能異常（Cushing's 或 Addison's）。
- **慢性中毒與藥物蓄積**：重金屬接觸、酒精慢性神經毒性、鎮靜劑、抗膽鹼類抗組織胺、類鴉片止痛藥等長期蓄積。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性微量營養素與代謝修復
- **甲基化代謝與同半胱胺酸清除**：高同半胱胺酸具內皮毒性與神經毒性，若篩檢發現不足或偏高，應立即補充活化型甲基輔酶（Methylcobalamin $\text{B}_{12}$、5-MTHF 活性葉酸、Pyridoxal-5-Phosphate $\text{B}_6$），修復單碳循環與髓鞘穩定度。
- **粒線體能量代謝與神經突觸支持**：
  - 補充維生素 $\text{B}_1$（尤其酒精暴露、胃腸吸收不良個體），維護丙酮酸脫氫酶及三羧酸循環運作。
  - 針對粒線體病變或腦萎縮高風險者，評估輔酶 Q10、乙醯左旋肉鹼（ALCAR）、PQQ 等協同支持粒線體呼吸鏈。

### 2. 血管代謝優化與抗發炎飲食架構
- **代謝血管危險因子嚴格管理**：控制中年期高血壓、高膽固醇、第 2 型糖尿病與肥胖，直接阻斷血管性失智微梗塞及類澱粉清除途徑受損。
- **腦血管內皮修復型飲食**：
  - 採用地中海-心智飲食（MIND Diet）模式：強調富含多酚之深色莓果類、深綠色蔬菜、富含 Omega-3（DHA/EPA）的深海魚類與優質單元不飽和脂肪酸（初榨橄欖油）。
  - 控制高精緻碳水化合物與反式脂肪，降低晚期糖化終產物（AGEs）堆積與微血管內皮硬化。

### 3. 環境毒素阻斷、排毒管道與生活節律整合
- **清理認知干擾性藥物負擔**：全面盤點用藥，撤除抗膽鹼藥物（如第一代抗組織胺 Diphenhydramine、三環抗憂鬱劑）、長效苯二氮平類（BZD）、巴比妥鹽類與高鎮靜性精神藥物。
- **睡眠品質與腦部淋巴系統（Glymphatic System）排毒**：
  - 重視 REM 睡眠障礙（RBD）與睡眠呼吸中止症（OSA）的篩檢與矯正。
  - 確保充足深層慢波睡眠，促進腦部膠淋巴系統清除日間累積之代謝廢物與蛋白質（$A\beta$、Tau 碎片）。
- **感知覺刺激與運動神經防護**：
  - **聽力障礙早期矯正**：聽力減退是晚年失智的高風險危險因子，早期驗配助聽器可避免聽覺皮質去傳入化導致的認知衰退。
  - **規律有氧運動與肌力訓練**：促進腦衍生神經滋養因子（BDNF）釋放，改善腦血流灌注，顯著降低認知退化發生率。
  - **環境毒素隔離**：避免空氣污染（PM2.5）、重金屬暴露（鉛、汞、蓄電池工廠毒素）、二手菸與慢性酒精過量。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **全面清查可逆致病因子**：對新診斷認知障礙患者，常規執行全套生化、甲狀腺功能（TSH）、維生素 $\text{B}_{12}$/葉酸/同半胱胺酸、電解質、鈣離子、梅毒血清試驗與腦部結構性 MRI，切勿預設為「無藥可救之阿茲海默症」。
2. **快速惡化失智（RPD）啟動急症處理路徑**：病程於一年以內迅速衰退者，除 Prion（CJD）外，應優先排查**自體免疫性腦炎（如抗 LGI1、NMDA 抗體）**、副腫瘤症候群與中樞慢性感染，即早給予免疫調節治療可扭轉神經缺損。
3. **BPSD 症狀以「生理根因搜索」取代「立即藥物壓制」**：面對失智患者出現突發性幻覺、胡言亂語或攻擊行為，首要排除便秘、尿滯留、尿路感染、骨折扭傷痛楚、急性脫水電解質紊亂或藥物中毒；嚴禁直接盲目加開鎮靜安眠藥或過量抗精神病藥物。
4. **貫徹中壯年期「血管-代謝因子」源頭攔截**：積極監控並改善胰島素阻抗、肥胖、高血壓、吸菸與缺乏運動，搭配聽力保護及腦力激盪社交，落實神經保護與延緩失智的長壽策略。
