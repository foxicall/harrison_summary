# 二尖瓣逆流（Mitral Regurgitation, MR）之病理生理、臨床評估與全人整合管理指南
- **主講人/來源**：264 Mitral Regurgitation.pdf（出處：*Harrison's Principles of Internal Medicine*, Patrick T. O’Gara, Joseph Loscalzo）
- **核心主旨**：深入剖析原發性（退化性）與次發性（功能性）二尖瓣逆流之血流動力學演變、超音波量化指標與精準手術時機，並結合功能醫學與心肌代謝支持，建立兼顧急性血液動力學穩定與慢性心室重塑逆轉的整合診療策略。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **容量負荷過載與代償極限**：左心室（LV）射血至低阻抗的左心房（LA），初期後負荷（afterload）假性降低，引發代償性完全排空；隨著時間推移，LV 與 LA 進行性擴大，心室舒張末期容積增加並導致心肌順應性下降與收縮功能衰退。
  - **惡性循環「MR begets MR」**：LA 與 LV 擴大導致二尖瓣環擴張、後葉受牽拉（tethering）及乳頭肌幾何結構移位，加重瓣膜閉合不全，形成結構性退化的正回饋。
  - **老化、發炎與異位鈣化機制**：二尖瓣環鈣化（Mitral Annular Calcification, MAC）常好發於高齡女性、慢性腎病變（CKD）及代謝症候群患者，涉及基質金屬蛋白酶（MMPs）活化、纖維母細胞向成骨細胞樣細胞轉化（osteogenic transdifferentiation）、粒線體氧化壓力與發炎浸潤。
- **演講亮點與臨床洞察**：
  - **射血分數（LVEF）的「假性正常」陷阱**：在嚴重 MR 中，因 LV 排血阻力降低，正常生理狀態下 EF 應偏高。因此，當 LVEF 下降至 **<60%** 或心室收縮末期內徑（LVESD）達到 **≥40 mm** 時，即代表心肌已有顯著內在收縮功能不全（Stage C2），不可忽視。
  - **修補（Repair）優於置換（Replacement）**：二尖瓣修補術（MVRp）的手術死亡率（1.2%）顯著低於瓣膜置換術（MVR, 4.5%）；保留下瓣葉與腱索結構能完整維持 LV 幾何構型與長期收縮效能。
  - **運動禁忌關鍵提示**：無症狀之嚴重 MR 患者應嚴格避免**等長收縮阻力運動（Isometric exercise）**，因其會急遽增加周邊血管阻力與 LV 後負荷，惡化逆流量並誘發急性代償失調。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **超音波：有效逆流孔面積（EROA）** | 評估瓣膜逆流開口嚴重度的核心解剖血流指標 | 嚴重 MR：**$\ge 0.40\text{ cm}^2$** |
| **超音波：逆流量（Regurgitant Volume, RVol）** | 單次心搏漏回左心房的絕對血液量 | 嚴重 MR：**$\ge 60\text{ mL/beat}$** |
| **超音波：逆流分率（Regurgitant Fraction, RF）** | 評估逆流量佔心室總搏出量的比例 | 嚴重 MR：**$\ge 50\%$** |
| **超音波：縮流頸寬度（Vena Contracta, VC）** | 逆流射流最狹窄處寬度，反映逆流嚴重度 | 嚴重 MR：**$\ge 0.7\text{ cm}$** |
| **左心室收縮末期內徑（LVESD）** | 評估 LV 離心性重塑程度與無症狀手術介入臨界點 | 手術觸發點：**$\ge 40\text{ mm}$**（次發性 TEER 條件：$\le 70\text{ mm}$） |
| **左心室射血分數（LVEF）** | 評估心室實質收縮功能（需校正後負荷假性降低） | 心肌失代償臨界：**$\le 60\%$**（次發性 TEER 條件：$20\%\sim 50\%$） |
| **肺動脈收縮壓（PASP）** | 評估後微血管性肺高壓及右心受累程度 | 靜止時 $>50\text{ mmHg}$，運動時 $>60\text{ mmHg}$ 提示不良預後 |
| **心房利鈉肽/腦利鈉肽（NT-proBNP/BNP）** | 反映心房擴張與心室容積負荷壁張力（Wall Stress） | 追蹤容積過載進程，作為早期心肌代償失調警訊 |
| **高敏感度 C 反應蛋白（hs-CRP）與發炎指標** | 評估心血管內皮微發炎與瓣膜基質重塑活性 | 臨床目標：$<1.0\text{ mg/L}$，監控全身低度慢性發炎 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 原發性（Degenerative）vs. 次發性（Functional）二尖瓣逆流的機制分型
- **原發性 MR（Primary MR）**：
  - 病變原發於瓣膜複合結構本身（瓣葉、腱索）。
  - 主要病因包括黏液樣退化（Myxomatous degeneration / Mitral Valve Prolapse / Barlow’s disease）、感染性心內膜炎（穿孔或穿透）、風濕熱、外傷破裂或胸部鈍傷。
  - 急性腱索斷裂可導致「急性加重於慢性（Acute-on-chronic）」之嚴重逆流。
- **次發性 MR（Secondary/Functional MR）**：
  - 瓣葉與腱索結構多屬正常（稱為「無辜旁觀者」Innocent bystanders）。
  - 驅動機制為**左心室擴大與整體幾何重塑**（如缺血性心肌病變、擴張型心肌病變）或**心房擴大與瓣環擴張**（如長期持續性心房顫動引起的 Atrial functional MR）。
  - 當 LV 舒張末期內徑達 $\ge 6\text{ cm}$ 時，乳頭肌往外向下位移引發後葉牽拉（tethering），導致瓣葉接合不良。

### 2. 急性 vs. 慢性嚴重二尖瓣逆流的左心房順應性與血流動力學
- **急性嚴重 MR（Normal LA Compliance）**：
  - 左心房尚未代償擴大，心房順應性正常或偏低。
  - 大量逆流血液湧入容積固定的左心房，造成心房壓劇烈飆升，形成高聳的 **$v$ 波**。
  - 逆流壓力階差在收縮中晚期迅速縮小，心雜音呈現**早期遞減型（Early decrescendo systolic murmur）**，甚至在 $S_2$ 前即消失；臨床極易迅速爆發急性肺水腫與心因性休克。
- **慢性嚴重 MR（Increased LA Compliance）**：
  - 左心房經歷長期容積負荷，顯著擴張且心房順應性大幅提高。
  - 心房內壓與肺靜脈壓上升較平緩，$v$ 波相對不明顯。
  - 雜音為典型的**全收縮期高頻平原狀雜音（Holosystolic plateau murmur）**，心尖部最清晰並常傳導至腋下。患者早期常以低心輸出量症狀（疲勞、運動耐力下降）為主，肺水腫症狀出現相對較晚。

### 3. 外科手術指引決策樹剖析（ACC/AHA Guidelines）
- **原發性 MR 手術決策**：
  - **Stage D（有症狀）**：一律建議二尖瓣手術（Class 1），強烈優先選擇二尖瓣修補術（MVRp）。若屬極高或無法承擔手術風險者，解剖結構適宜時考慮經導管瓣膜邊對邊修補術（TEER, Class 2a）。
  - **Stage C2（無症狀但出現 LV 收縮障礙）**：若 LVEF $\le 60\%$ 或 LVESD $\ge 40\text{ mm}$，即建議進行手術介入（Class 1）。
  - **Stage C1（無症狀且 LV 結構正常）**：若由經驗豐富的綜合心臟瓣膜中心（CVC）評估，手術死亡率 $<1\%$ 且長期修補成功率 $>95\%$，可考慮提早進行修補術（Class 2a）。
- **次發性 MR 處置階梯**：
  - **基石治療**：心衰竭專科醫師主導之最高耐受劑量**指引導向藥物治療（GDMT）**（Class 1）。
  - **介入時機**：若最佳 GDMT 與心律控制後仍持續有症狀，且符合 LVEF $20\%\sim 50\%$、LVESD $\le 70\text{ mm}$、PASP $\le 70\text{ mmHg}$，推薦行 TEER（Class 2a）。若合併需進行冠狀動脈旁路移植術（CABG），則同步行二尖瓣手術（Class 2a）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 常規心臟科藥物與指引介入（GDMT）
- **心衰竭標準四部曲（HFrEF 次發性 MR）**：
  - **ARNI / ACEI / ARB**：降低周邊血管阻力，減少左心室向主動脈射血的阻抗，從而減少向後逆流至左心房的容積。
  - **實證乙型阻斷劑（Carvedilol / Metoprolol succinate / Bisoprolol）**：抑制交感神經過度興奮，減緩心室擴張重塑。
  - **鹽皮質激素受體拮抗劑（MRA, Spironolactone/Eplerenone）**：阻斷醛固酮引起的心肌纖維化與膠原沉積。
  - **SGLT2 抑制劑（Dapagliflozin / Empagliflozin）**：改善心肌代謝能量利用，促進滲透性利尿與後負荷減輕。
- **抗凝血管理**：併發心房顫動（AF）時，依 $\text{CHA}_2\text{DS}_2\text{-VASc}$ 評分使用抗凝劑（Warfarin 或 DOACs 如 Apixaban、Rivaroxaban）。*注意：若合併中重度風濕性二尖瓣狹窄或機械瓣膜，嚴格禁用 DOACs。*

### 2. 功能醫學、代謝優化與微營養素支持
- **粒線體生物能量學支持（針對心肌重塑與疲勞）**：
  - **輔酶 Q10（CoQ10 / 泛醇 Ubiquinol）**：$100\sim 300\text{ mg/day}$，提升心肌細胞 ATP 製造，減少過載心肌的氧化壓力。
  - **左旋肉鹼（L-Carnitine / Acetyl-L-Carnitine）**：$1,000\sim 2,000\text{ mg/day}$，促進長鏈脂肪酸進入粒線體 $\beta$-氧化，優化缺血或衰竭心肌之基質代謝利用率。
  - **牛磺酸（Taurine）**：$1,000\sim 3,000\text{ mg/day}$，調節心肌細胞鈣離子恆定，增強心肌收縮力並輔助滲透壓調節。
  - **甘胺酸鎂 / 蘋果酸鎂（Magnesium Glycinate/Malate）**：元素鎂 $300\sim 500\text{ mg/day}$，維持心肌電氣穩定性、改善周邊血管張力、降低房性心律不整（AF）易感性。
- **抗瓣膜環異位鈣化策略（針對 MAC 患者）**：
  - **維生素 K2（MK-7 形式）**：$100\sim 200\text{ mcg/day}$，活化基質 Gla 蛋白（MGP），抑制血管及瓣膜環平滑肌細胞向成骨細胞分化，預防異位鈣化沉積（*若患者使用 Warfarin 則需嚴格避開或在醫師嚴密監控下調整*）。
  - **維生素 D3**：維持血清 25(OH)D 於 $40\sim 60\text{ ng/mL}$，調節鈣磷代謝與副甲狀腺素（PTH）恆定。

### 3. 飲食、抗發炎與生活型態處方
- **抗發炎與代謝重置飲食**：
  - 採取富含多酚、抗氧化物的地中海型飲食（深海魚、冷壓初榨橄欖油、深綠色蔬菜、多色植化素），抑制低度全身性慢性發炎與纖維化路徑。
  - 嚴格限制鈉鹽攝取（每日鈉離子 $<2,000\text{ mg}$），防止血容量膨脹加重左心房與左心室舒張期壁張力。
- **運動與心血管負荷指引**：
  - **禁忌**：嚴禁**高強度阻力/等長收縮運動**（如極限推舉、長時間平板支撐、握力對抗），因其會反射性引起周邊阻力飆升，驟增 LV 後負荷而加劇逆流。
  - **建議**：無症狀且心功能代償良好者，建議進行中低強度規律有氧運動（如快走、定速自行車），維持外周血管順應性與骨骼肌氧化代謝能力。
- **自主神經平衡與睡眠修復**：
  - 積極篩檢與矯治阻塞型睡眠呼吸中止症（OSA），防止夜間低血氧與胸腔內負壓驟變誘發交感神經風暴、血壓飆升及心房顫動發作。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **破除 LVEF 正常迷思，嚴抓無症狀轉折點**：
   - 嚴重 MR 患者若超音波報告顯示 LVEF $\le 60\%$ 或 LVESD $\ge 40\text{ mm}$，即使患者自述完全無症狀，亦不可延誤，應即刻轉診心臟外科團隊評估瓣膜修補手術。
2. **確立修補為先策略，早期轉診高量能中心**：
   - 原發性 MR 優先選擇瓣膜修補術（死亡率僅 1.2% vs. 置換術 4.5%）；若患者解剖構造複雜，應轉介至修補成功率 $>95\%$ 且手術死亡率 $<1\%$ 的整合型瓣膜中心（CVC）。
3. **嚴密衛教運動模式，杜絕閉氣等長用力**：
   - 告誡無症狀中重度 MR 患者，切忌從事提搬重物、負重深蹲等會引發 Valsalva 動作或強烈等長收縮之活動，避免外周阻力暴增誘發急性腱索破裂或急性左心衰竭。
4. **次發性 MR 實施四重奏 GDMT 並追蹤幾何結構**：
   - 針對心肌病變引起的次發性 MR，首先強化包含 ARNI、Beta-blocker、MRA、SGLT2i 在內之完整抗心衰藥物；若優化治療後仍有症狀且符合標準，積極評估經導管邊對邊修補（TEER/MitraClip）。
5. **整合營養素代謝支持，防範瓣環退化鈣化**：
   - 針對高齡、高血壓及腎功能不全的高危險群，加強鎂、輔酶 Q10 與心肌代謝基質補充；在未使用 Warfarin 的前提下，適度補充維生素 K2（MK-7），保護心臟瓣膜結構減緩退化性鈣化進程。
