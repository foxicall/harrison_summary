# 腹部膨脹與腹水之病理生理、診斷路徑與臨床處置精粹（Abdominal Swelling and Ascites）
- **主講人/來源**：50 Abdominal Swelling and Ascites.pdf (Lawrence S. Friedman / Harrison's Principles of Internal Medicine)
- **核心主旨**：腹部膨脹是多種全身性病理機制的交會表徵；臨床上必須精準區分結構性/功能性氣體蓄積、內臟肥胖與真性腹水，並透過血清-腹水白蛋白梯度（SAAG）與腹水蛋白總量剖析門脈血流動力學與竇狀隙通透性，採取標靶性減鹽利尿、血管張力調節及腸-肝軸防護策略。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **肝硬化腹水之血流動力學悖論**：肝纖維化與星狀細胞活化阻礙門脈血流，伴隨肝內內皮型一氧化氮合酶（eNOS）下調導致肝內血管劇烈收縮；然而在內臟血循環中，NO、VEGF 及 TNF-α 大量釋放誘發內臟動脈過度擴張。此一「肝內高阻力、內臟低阻力」導致大量血液滯留於內臟床，引發有效循環動脈血量（ECAV）不足，啟動抗利尿激素（ADH）、交感神經系統（SNS）與腎素-血管張力素-醛固酮系統（RAAS），造成嚴重的腎臟鈉水滯留。
  - **腸黏膜屏障崩解與細菌移位**：腸道長期鬱血水腫導致屏障功能受損，腸內革蘭氏陰性桿菌（如 *E. coli*、*Klebsiella*）穿透腸壁移位至腹腔與腸系膜淋巴結，在腹水調理素（Opsonins）活性不足時迅速誘發自發性細菌性腹膜炎（SBP）。
- **演講亮點與臨床洞察**：
  - **功能性腹脹（Bloating）與腹圍擴大（Distention）的本質差異**：功能性腹部膨脹往往非單純氣體體積增加，而是源於「橫膈-腹壁肌肉運動不協調（Abdomino-thoracic dyssynergia）」（橫膈異常收縮下壓搭配腹壁不自主鬆弛），可藉由生理回饋（Biofeedback）與腸道微生態調節逆轉。
  - **診斷點範式轉移（SAAG vs. 滲出/漏出液傳統分類）**：徹底淘汰以單純滲出/漏出液為標準的分類法，改以體現史達林定律（Starling forces）的 **SAAG $\ge 1.1\text{ g/dL}$** 作為辨識門脈高壓的絕對基準。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **SAAG (血清-腹水白蛋白梯度)** | 評估門脈高壓（反映肝竇內靜水壓與膠體滲透壓差） | **$\ge 1.1\text{ g/dL}$**：門脈高壓性；**$<1.1\text{ g/dL}$**：非門脈高壓性 |
| **腹水總蛋白 (Ascitic Total Protein)** | 評估肝竇狀隙結構完整性與通透性（在高 SAAG 族群中分流） | **$\ge 2.5\text{ g/dL}$**：肝竇正常（如心衰竭）；**$<2.5\text{ g/dL}$**：肝竇疤痕化破壞（肝硬化） |
| **腹水 PMN 絕對計數** | 診斷自發性細菌性腹膜炎（SBP）之黃金生化指標 | **$\ge 250/\mu\text{L}$**（需立即啟動經驗性抗生素治療） |
| **腹水三酸甘油酯 (Triglycerides)** | 評估淋巴管破裂、受損或淋巴回流受阻（乳糜性腹水） | **$>200\text{ mg/dL}$**（常規多數 $>1000\text{ mg/dL}$） |
| **腹水澱粉酶 (Amylase)** | 鑑別胰臟發炎、假性囊腫破裂或胰管破裂漏液 | **$>1000\text{ U/L}$**（高度提示胰源性腹水） |
| **腹水腺苷去胺酶 (ADA)** | 評估非硬化性患者之結核性腹膜炎（Tuberculous peritonitis） | **$>30 \sim 45\text{ U/L}$**（敏感度 $>90\%$） |
| **血清 BNP / Pro-BNP** | 鑑別高 SAAG、高蛋白腹水是否源於心因性（心衰竭/收縮性心包炎） | 顯著上升提示心室壁牽張與體循環充血 |
| **呼氣氫氣與甲烷測試 (Breath Test)** | 評估碳水化合物（乳糖）吸收不良及小腸菌叢過度增生（SIBO） | 呼氣中氫氣或甲烷濃度異常提早飆升 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 腹脹病因鑑別架構：六個「F」與橫膈協調失衡
- **經典六 F 鑑別**：Flatus（腸氣）、Fat（脂肪）、Fluid（腹水）、Fetus（胎兒）、Feces（糞便）、Fatal growth（腫瘤或內臟腫大）。
- **腸道氣體動力學與生化代謝**：
  - 腸道內正常氣體量約 $200\text{ mL}$。$\text{N}_2$ 與 $\text{O}_2$ 來自吞嚥空氣（Aerophagia）；$\text{CO}_2$、$\text{H}_2$ 與 $\text{CH}_4$ 則完全源自腸道微生物發酵未吸收之寡糖或乳糖。
  - **功能性腹脹新機轉**：腸躁症患者自覺膨脹常非「氣體總量增加」，而是「氣體運輸排空受損」與「神經肌肉失調（Abdomino-thoracic dyssynergia）」，亦即進食後橫膈反常下降而前腹壁肌肉失弛緩。

### 2. 腹水成因二分法：SAAG 診斷演算法解析
```
                    [ 腹水穿刺抽液分析 ]
                              │
                    計算 SAAG (血清 - 腹水 Alb)
             ┌────────────────┴────────────────┐
     [ SAAG ≥ 1.1 g/dL ]               [ SAAG < 1.1 g/dL ]
      (存在門脈高壓狀態)                 (無門脈高壓狀態)
             │                                 │
     檢查腹水總蛋白濃度                 鑑別診斷包括：
      ┌──────┴──────┐                   • 腹膜癌病變 (Carcinomatosis)
      │             │                   • 結核性腹膜炎 (Tuberculous)
[ < 2.5 g/dL ]  [ ≥ 2.5 g/dL ]          • 胰臟炎/胰性腹水 (Pancreatitis)
• 肝硬化         • 心臟衰竭/心包炎       • 腎病症候群 (Nephrotic syn.)
• 晚期 Budd-     • 早期 Budd-Chiari     • 膽汁外漏 (Biliary leak)
  Chiari 症候群  • 下腔靜脈阻塞 (IVC)
• 瀰漫性肝轉移   • 竇狀隙阻塞症候群
```
- **生化力學意涵**：
  - **SAAG $\ge 1.1\text{ g/dL}$**：反映肝竇靜水壓升高，體液因微血管靜水壓差濾出至腹腔；
  - **蛋白質量 $\ge 2.5\text{ g/dL}$**：代表肝竇內皮窗孔（Fenestrae）仍健全，高蛋白血漿濾液完好滲出（如心因性充血）；若 **$< 2.5\text{ g/dL}$** 則顯示肝竇結構已疤痕化破壞，阻隔蛋白質通透（如典型肝硬化）。

### 3. 頑固性腹水（Refractory Ascites）與全身血管調控
- **定義**：對嚴格限鈉與大劑量利尿劑（Spironolactone $400\text{ mg/d}$ + Furosemide $160\text{ mg/d}$）無反應，或因出現電解質紊亂/氮質血症等副作用而無法耐受。
- **血管活性藥物機制**：
  - 內臟擴張使有效循環血量崩解，使用 $\alpha_1$ 受體促效劑（Midodrine）或 $\alpha_2$ 受體促效劑（Clonidine），誘發內臟血管收縮，提升回心血量並抑制亢進的 RAAS 系統。
  - **臨床警訊**：頑固性腹水患者使用 $\beta$-blockers 可能與存活率下降相關，臨床上需高度警戒並重新評估。

### 4. 自發性細菌性腹膜炎（SBP）的微生態與免疫病理
- **隱匿性特徵**：僅約 $40\%$ 患者出現局部腹部壓痛，反彈痛極罕見；臨床上多以腹圍增加、低度發燒、無法解釋的肝性腦病變或急性腎損傷（HRS 前兆）為首發表現。
- **病原學**：單一菌株感染為主（$E. coli$、$Klebsiella$、鏈球菌）；若腹水出現多種菌株（Polymicrobial）且併發高 PMN，必須高度懷疑次發性腸道穿孔或膿瘍（Secondary peritonitis）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素/生化與分子支持
- **血清白蛋白標靶輸注（Oncotic Support）**：
  - 於大量腹水穿刺放液（LVP $>5\text{ L}$）時，每抽除 $1\text{ L}$ 腹水需常規靜脈回補 **$6 \sim 8\text{ g}$ 人體白蛋白**，防止放液後循環功能障礙（Postparacentesis Circulatory Dysfunction, PICD）引發急性腎衰竭與死亡。
- **腸道黏膜與微生態調理**：
  - 功能性腹脹患者，介入**特定益生菌菌株**與**消化酵素**，減少未消化的寡糖在大腸內快速發酵產氣。
  - 針對小腸菌叢過度增生（SIBO），評估非吸收性抗生素（如 Rifaximin）或天然植化抑菌素（牛至油、黃連素）以降低呼氣氫/甲烷產生。

### 2. 飲食與水鹽代謝策略
- **嚴格鈉離子限制**：
  - 每日鈉攝取量嚴格限制於 **$2\text{ g/day}$（約 $88\text{ mmol/day}$，相當於 $5\text{ g}$ 食鹽）**。單純限鈉即可使部分輕度硬化性腹水患者達成負鈉平衡。
- **低 FODMAP 飲食導入**：
  - 針對以氣體滯留為主的腹脹，短期採用低 FODMAP 飲食，限制果糖、果聚糖、多元醇等高發酵性醣類，顯著減輕腸道擴張感。
- **液體攝取調節**：
  - 常規腹水患者不需限制飲水；僅在**血清鈉離子 $< 120 \sim 125\text{ mmol/L}$** 出現高稀釋性低血鈉時，方嚴格限制水分攝取（通常 $< 1000 \sim 1500\text{ mL/day}$）。

### 3. 生活型態、神經調節與引流處置
- **橫膈-腹壁運動生理回饋（Biofeedback）**：
  - 針對 Abdomino-thoracic dyssynergia 引發的腹脹，進行專門的呼吸與骨盆腹壁肌肉放鬆訓練，糾正異常的橫膈下壓反射。
- **標準利尿處方階梯**：
  - 結合留鉀利尿劑（Spironolactone）與環利尿劑（Furosemide），維持 **100 mg : 40 mg** 之黃金比例協同給藥（維持正常血鉀平衡），最高滴定至 $400\text{ mg} : 160\text{ mg}$。
  - 若男性出現乳房疼痛與女乳化，以 **Amiloride（$5 \sim 40\text{ mg/d}$）** 取代 Spironolactone。
- **介入性分流處置**：
  - 藥物無效之頑固性腹水可考慮經頸靜脈肝內門體分流術（TIPS）或 Alfapump 系統，但 TIPS 術後需高度監測肝性腦病變風險。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **急診與住院時效性處置**：
   - 肝硬化合併腹水患者住院時，務必於 **12 小時內完成診斷性腹水穿刺（Diagnostic Paracentesis）**，早期篩檢 SBP，文獻證實可顯著降低院內死亡率。
2. **第一線穿刺分析標準作業**：
   - 同步採集「周邊血液白蛋白」與「腹水白蛋白」，精準計算 **SAAG**；同時將腹水在床邊直接注入血瓶培養，並測定細胞分類計數（PMN）。
3. **SBP 辨識與預防介入**：
   - 腹水 PMN $\ge 250/\mu\text{L}$ 即刻給予三代頭孢菌素（如 Cefotaxime）治療 5 天；針對高危險群（腹水總蛋白 $<1.0\text{ g/dL}$、有 SBP 病史或急性消化道出血者），常規給予 Ciprofloxacin 或 Norfloxacin 進行初級/次級預防性投藥。
4. **大量放液安全防線**：
   - 執行大容量穿刺（LVP）時，穿刺量若超過 $5\text{ L}$，必須按每抽取 $1\text{ L}$ 回補 **$6 \sim 8\text{ g}$ 白蛋白**之標準程序執行，杜絕 PICD 誘發心腎衰竭。
5. **鑑別診斷防錯原則**：
   - 叩診呈鼓音（Tympanic）為氣體；實音（Dull）需達 $1500\text{ mL}$ 以上液體方能於理學檢查查覺。超音波為最敏銳篩檢工具（可偵測低至 $100\text{ mL}$ 腹水），切勿單憑理學檢查排除腹水。
