# 中樞神經局限性化膿感染與發炎性病灶：腦膿瘍、硬腦膜下積膿與顱內靜脈竇炎之全方位臨床指引

- **主講人/來源**：140 Brain Abscess and Empyema.pdf（*Harrison's Principles of Internal Medicine*, 第 140 章，Karen L. Roos & Kenneth L. Tyler）
- **核心主旨**：腦部化膿性病灶（腦膿瘍、硬腦膜下積膿、硬腦膜外膿瘍）為高致死率與高致殘率的神經感染急症，其發生多以組織缺血缺氧為病理溫床；臨床決策核心在於早期影像定位、禁忌腰椎穿刺以防腦疝、外科立體定位引流與標靶抗生素介入，並在穩態後結合系統醫學全面修復血腦屏障、神經膠質發炎與微生態失衡。

---

## 一、 核心要點精華（Executive Clinical Summary）

### 核心病理生理機制
- **組織缺血缺氧與血管內皮受損**：正常的腦實質對細菌入侵具有高度抵抗力；腦膿瘍的形成**必須以預先存在或伴隨的局部組織缺血、壞死或低氧（Hypoxemia）為先決條件**。
- **病程演進之四階段**：
  1. *早期腦炎期（Early cerebritis, Days 1–3）*：血管周圍炎性細胞浸潤、中央凝固性壞死、周圍廣泛水腫。
  2. *晚期腦炎期（Late cerebritis, Days 4–9）*：壞死中心擴大化膿，巨噬細胞與纖維母細胞聚集，微血管增生。
  3. *早期包膜期（Early capsule, Days 10–13）*：纖維包膜形成（皮質側血供豐富故包膜厚於腦室側），影像開始呈現典型「環狀顯影（Ring enhancement）」。
  4. *晚期包膜期（Late capsule, Day 14+）*：緻密膠原包膜形成，但外圍膠質增生（Reactive astrogliosis）顯著，為日後**次發性頑固性癲癇（Seizure sequelae）的永久病理基質**。
- **解剖通道與無瓣膜靜脈系統擴散**：
  - *硬腦膜下腔（Subdural space）*：為一大無解剖障礙的潛在空間，鼻竇炎可經黏膜靜脈逆行性血栓靜脈炎擴散，感染蔓延極為迅猛。
  - *顱內靜脈竇與板障靜脈（Diploic veins）*：缺乏靜脈瓣膜，允許雙向血流，使表淺感染（中耳、乳突、顏面皮膚）得以直接向顱內蔓延，引發化膿性靜脈血栓（Suppurative thrombophlebitis）與出血性皮質梗塞。

### 臨床洞察與 Paradigm Shift
- **古典三聯徵（頭痛、發燒、局部神經缺損）出現率低於 50%**：最常見症狀為頭痛（>75%），發燒在初診時僅佔 50%，**臨床切勿因病患無發燒而排除腦膿瘍**。
- **腰椎穿刺（Lumbar Puncture, LP）為絕對禁忌**：對於已知或疑似局限性顱內感染（膿瘍或 SDE），LP 對診斷無益，且極度增加天幕裂孔疝或枕骨大孔疝（Brain Herniation）之致死風險。
- **MRI-DWI 的鑑別價值**：彌散加權影像（DWI）呈現強烈高訊號、ADC 呈低訊號（水分子的布朗運動受黏稠膿液受限），能迅速將腦膿瘍與壞死性多形性膠質母細胞瘤（GBM）或轉移癌明確區分。
- **類固醇使用的雙面刃**：地塞米松（Dexamethasone）會阻礙膠原蛋白合成與血管包膜化，**嚴禁常規使用**；僅限於周圍水腫引發嚴重中線偏移或腦壓過高有腦疝危機時，短暫使用並迅速漸進減量（Tapering）。

| :--- | :--- | :--- |
| **MRI - T1 + C / T2 / DWI / ADC** | **黃金診斷標準**。評估包膜厚度、中心液化壞死、DWI 受限擴散、水腫範圍及中線偏移。 | 鑑別壞死腫瘤與膿瘍；監測包膜薄弱側（腦室側）防破裂 |
| **CT-Guided 立體定位抽吸培養** | 取得膿液進行革蘭氏/抗酸性染色、需氧/厭氧菌培養、真菌與分子 PCR。 | 明確病原菌；引流兼具降壓治療與標靶給藥指引 |
| **C-反應蛋白 (CRP) 與 ESR** | 反映急性全身性及顱內化膿性發炎反應程度（腦膿瘍患者陽性率分別為 80% 與 60%）。 | CRP > 10 mg/L、ESR 顯著上升提示感染活動；治療追蹤指標 |
| **血液培養 (Blood Cultures)** | 評估血源性播散源（如心內膜炎、肺部化膿病灶）；*Listeria* 膿瘍陽性率可達 >85%。 | 至少抽 2 套（需氧+厭氧），一般腦膿瘍陽性率僅 ~10% |
| **抗磷脂抗體 / 凝血因子篩檢** | 評估化膿性靜脈血栓（Septic Thrombophlebitis）背後的易栓體質（Hypercoagulable state）。 | Lupus anticoagulant, Anticardiolipin IgG/IgM 陰性 |
| **腦電圖 (EEG)** | 膿瘍周圍神經膠質疤痕增生（Gliosis）引發之致癇病灶（Epileptogenic focus）追蹤。 | 抗癲癇藥停藥前必測；需達到無癲癇波且維持至少 3 個月正常 |
| **腸道微生態與毒素分析 (功能醫學)** | 評估 6–8 週超廣效抗生素使用後之菌相失衡、艱難梭菌感染風險及腸漏狀況。 | 恢復腸道共生菌（*Bifidobacteria*, *Lactobacillus*）與 SCFA 分泌 |

## 三、 關鍵機制詳解與重點筆記

### 1. 腦膿瘍（Brain Abscess）之病源學與解剖病理對應
- **鄰近蔓延（Contiguous Spread, 佔多數）**：
  - *額竇/篩竇炎* $\rightarrow$ 額葉膿瘍（常見鏈球菌如 *Streptococcus milleri*、厭氧菌、*Staphylococcus aureus*）。好發於 10–30 歲年輕男性。
  - *中耳炎/乳突炎（常合併膽脂瘤）* $\rightarrow$ 顳葉（55–75%）與小腦（20–30%）。常見變形桿菌、綠膿桿菌、腸桿菌科及厭氧菌。
  - *齒源性感染（Dental infections）* $\rightarrow$ 額葉，佔隱源性（Cryptogenic）膿瘍之大宗（常見鏈球菌、梭桿菌 *Fusobacterium*）。
- **血源性播散（Hematogenous, 佔 ~25%）**：
  - 特徵：**常為多發性（佔 50%）**，好發於**中大腦動脈（MCA）血流終末區之皮質與白質交界處（Gray-white matter junction）**，包膜通常較薄且脆弱。
  - 驅動病因：感染性心內膜炎（草綠色鏈球菌、金黃色葡萄球菌）、肺膿瘍/支氣管擴張症、**發紺型先天性心臟病（右向左分流，使細菌繞過肺泡巨噬細胞過濾網，且紅血球增多症造成微血管缺血栓塞作為感染巢穴）**。
- **神經外科手術或穿透傷**：
  - 常見抗藥性金黃色葡萄球菌（MRSA）、表皮葡萄球菌（*S. epidermidis*）、綠膿桿菌、腸桿菌科。

### 2. 硬腦膜下積膿（Subdural Empyema, SDE）與硬腦膜外膿瘍（Epidural Abscess）
- **硬腦膜下積膿（SDE）**：
  - **極危急之神經外科急症**：因硬腦膜下腔無解剖隔板，化膿物可沿大腦半球表面迅猛擴散。
  - 臨床表現為高燒、劇烈頭痛、快速惡化之對側偏癱（Hemiplegia）、局部皮質癲癇、頸部僵硬（Nuchal rigidity），並伴隨廣泛大腦皮質靜脈栓塞及腦梗塞。
  - **處置**：刻不容緩的急診開顱去骨瓣減壓排膿（Craniotomy），死亡率與神經殘障率極高。
- **顱內硬腦膜外膿瘍（Epidural Abscess）**：
  - 局限於顱骨內板與硬腦膜之間（潛在腔隙），硬腦膜緊貼骨壁，病灶呈雙凸透鏡狀（Lentiform），擴展緩慢、甚少引發大範圍中線偏移。
  - 常伴隨額骨骨髓炎及局部軟組織水腫，臨床稱為 **Pott’s puffy tumor**。

### 3. 非細菌性局部中樞感染：腦囊蟲病與弓形蟲病
- **腦囊蟲病（Neurocysticercosis, *Taenia solium*）**：
  - 全球最常見寄生蟲性中樞神經疾病，攝入豬肉絛蟲卵所致。
  - **病理分期與處置原則**：
    1. *囊泡期（Vesicular）*：具活性幼蟲，囊內可見頭節（Scolex），無顯著發炎水腫 $\rightarrow$ 需抗寄生蟲治療。
    2. *膠狀期（Colloidal）*：幼蟲退化死亡，囊壁不規則增厚、周圍強烈血管水腫 $\rightarrow$ 需抗寄生蟲藥物，**治療前必須給予類固醇預防強烈發炎惡化**。
    3. *肉芽腫期（Granulonodular）*：結節狀均勻顯影，周圍無水腫 $\rightarrow$ 爭議性治療。
    4. *結節鈣化期（Nodular-calcified）*：寄生蟲已死，CT 或 SWI 可見點狀鈣化點 $\rightarrow$ **嚴禁使用抗寄生蟲藥**，僅需抗癲癇治療。
- **中樞神經弓形蟲病（Toxoplasmosis, *Toxoplasma gondii*）**：
  - 見於嚴重免疫低下（尤其是 HIV/AIDS，CD4 < 100/$\mu$L）。
  - MRI 呈現基底核與皮質白質交界處之「多發性環狀或結節狀顯影病灶」。

## 四、 臨床介入處方與系統性整合策略（Therapeutic Strategies）

### 1. 急性期常規核心醫療方案（Conventional Standards）
- **手術介入**：
  - 首選：CT / 立體定位引流導管抽吸（Stereotactic aspiration），兼具降壓與病原培養。
  - 開顱切除術（Craniotomy）：保留給多房性（Multiloculated）膿瘍、氣性壞疽菌感染或立體定位失敗者。
- **經驗性靜脈抗生素處方（療程至少 6–8 週）**：
  - *社區型免疫健全者*：第三/四代頭孢菌素（Ceftriaxone 2g q12h 或 Cefepime 2g q8h）+ 甲硝唑（Metronidazole 500mg q6-8h，穿透膿瘍包膜能力強且具強效抗厭氧菌力）。
  - *神經外科術後 / 創傷後*：Ceftazidime（抗綠膿桿菌）+ Vancomycin（涵蓋 MRSA）；或高階降階療法：Meropenem + Vancomycin。
  - *腦弓形蟲病*：Sulfadiazine + Pyrimethamine + 亞葉酸（Folinic acid，預防骨髓抑制巨球性貧血）。
- **癲癇預防（Seizure Prophylaxis）**：
  - 腦膿瘍患者癲癇風險高達 35%，**常規給予預防性抗癲癇藥物至少 3 個月**；需經臨床評估無發作且 **EEG 正常** 方可漸進減藥。

### 2. 恢復期功能醫學與神經抗衰老修復策略
當病患度過急性神經外科危急期、轉入慢性抗生素療程與組織修復期時，應同步啟動功能醫學介入：

- **血腦屏障（BBB）與微血管內皮保護**：
  - 膿瘍周圍微血管內皮嚴重受損，需提供血管抗氧化基質以防長期的微出血與神經元凋亡。
  - 處方支持：**乙醯半胱氨酸（NAC 600–1200 mg/day）**，提供穀胱甘肽合成原料，清除膿性壞死所釋放的大量活性氧（ROS）；**白藜蘆醇（Resveratrol）或反式紫檀芪**，透過活化 SIRT1 途徑保護腦微血管內皮。
- **神經元抗癲癇閾值調節與代謝支持**：
  - 長期膠質增生（Astrogliosis）會下調星狀膠質細胞對細胞外麩胺酸（Glutamate）的重吸收，導致興奮毒性（Excitotoxicity）。
  - **高吸收率甘胺酸鎂或牛磺酸鎂（Magnesium Glycinate / Taurate 300–500 mg/day）**：阻斷 NMDA 受體過度活化，提升癲癇發作閾值。
  - **活化型維生素 B 群（含 Pyridoxal-5-Phosphate, P5P）**：作為 GAD 酵素合成抑制性神經傳導物質 GABA 的關鍵輔因子。
  - **溫和生酮代謝支持（Mild Ketogenic Diet / Exogenous Ketones）**：於復原期提供 $\beta$-羥基丁酸（$\beta$HB），能作為大腦粒線體的高效乾淨燃料，抑制 NLRP3 發炎小體，改善神經細胞發炎反應。
- **微生態修復與排毒路徑重建（Microbiome & Detox Support）**：
  - 長達 6–8 週的廣效高劑量靜脈抗生素會對腸道微生態造成毀滅性破壞，破壞腸-腦軸（Gut-Brain Axis）。
  - **布拉酵母菌（*Saccharomyces boulardii* 500–1000 mg/day）**：抗生素使用期間同步口服，顯著降低艱難梭菌（*C. diff*）感染風險與抗生素相關性腹瀉。
  - **泥炭萃取富里酸/腐植酸（Fulvic/Humic Minerals）與多種孢子型益生菌（Spore Probiotics）**：抗生素療程結束後立即啟動，修復腸道屏障密合蛋白（Zonulin 恆定），阻斷腸道發炎毒素（LPS）逆流惡化大腦發炎。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **破除臨床發燒迷思**：面對不明原因漸進性鈍性頭痛、突發神經缺損或新發作癲癇病患，**即使無發燒或白血球正常，亦應高度懷疑顱內局限性化膿性感染**，立即安排含顯影劑之腦部 MRI（必含 DWI 與 ADC 序列）。
2. **謹守腰椎穿刺安全底線**：懷疑腦膿瘍或硬腦膜下積膿者，**切勿執行腰椎穿刺**；其 CSF 檢測缺乏特異性，卻承受誘發致命天幕腦疝（Transtentorial herniation）的極高醫療風險。
3. **早期立體定位介入與精準投藥**：在未取得病原前不宜盲目僅作內科保守治療（除非病灶 <2 cm 或純粹為早發性腦炎期）。應由神經外科於立體定位導航下抽吸化膿物送檢，並即刻啟用三代頭孢菌素 + Metronidazole（若懷疑院內感染/創傷則用 Meropenem + Vancomycin）。
4. **理性管制皮質類固醇**：切勿將 Dexamethasone 列為腦膿瘍常規輔助用藥，因其延緩包膜生成及減低抗生素組織穿透；僅在影像顯示顯著中線偏移、水腫危及生命時短期救急，並儘速減量。
5. **長程神經與系統性微生態維護**：抗癲癇藥物預防投藥應維持至臨床康復後 3 個月並以 EEG 正常為停藥依據；全療程需協同給予布拉酵母菌預防偽膜性腸炎，並於急性期過後透過鎂離子、NAC 及粒線體代謝策略，積極消退神經膠質發炎與維持腦功能穩定。
