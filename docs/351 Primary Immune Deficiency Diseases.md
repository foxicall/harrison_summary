# 原發性免疫缺陷疾病（Primary Immune Deficiency Diseases）之病理機制、臨床評估與免疫調節指南
- **主講人/來源**：Alain Fischer / 351 Primary Immune Deficiency Diseases.pdf (Harrison's Principles of Internal Medicine)
- **核心主旨**：原發性免疫缺陷病（PID）本質為多重基因變異導致的免疫網絡失調；臨床表現已突破單純「感染易感性」的傳統框架，形成「伺機性感染、無菌性慢性發炎/自體免疫、過敏與惡性淋巴腫瘤」三位一體的複雜病理光譜。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  1. **先天免疫殺傷與趨化停滯**：骨髓顆粒球成熟阻斷（如 *ELANE*、*HAX1* 突變之 SCN）、整合素/選擇素缺乏導致的白血球黏附缺失（LAD）、以及 NADPH 氧化酶複合物突變導致活性氧（ROS）呼吸爆發障礙（CGD），阻礙病原體清除並誘發代償性無菌肉芽腫。
  2. **適應性免疫分化與基因重組缺陷**：共通 γ 鏈（$\gamma c$）/JAK3 訊號停滯、嘌呤代謝產物毒性累積（ADA 缺乏）或抗原受體 $V(D)J$ 基因重組障礙（*RAG1/2*、*Artemis*）引發嚴重複合型免疫缺乏症（SCID）；*BTK* 突變導致 B 細胞發育停滯於前 B 細胞階段（XLA）。
  3. **免疫耐受與恆定調節崩潰**：轉錄因子 *FOXP3* 缺失導致 $\text{CD4}^+\text{CD25}^+$ 調節性 T 細胞（Treg）匱乏（IPEX）；*Fas/FasL* 介導的活化誘導細胞凋亡（AICD）途徑受阻誘發雙陰性 T 細胞堆積（ALPS）；穿孔素（Perforin）與溶酶體胞吐機制缺損導致失控的巨噬細胞/CD8+ T 細胞活化風暴（HLH）。
- **演講亮點與臨床洞察**：
  - **診斷思維的範式轉移**：PID 絕非僅限於罕見的兒科致死性疾病。選擇性 IgA 缺乏症（發生率高達 1:600）與常見變異型免疫缺陷病（CVID，盛行率 1:20,000）多於成年期顯現，常以慢性自體免疫性腸炎、支氣管擴張及淋巴增生為首發表現。
  - **感染模式的逆向定錨**：感染微生物種類精準對應免疫缺損環節——莢膜細菌與呼吸道反覆感染提示體液免疫/補體缺損；深部組織膿瘍及真菌/過氧化氫酶陽性菌感染指向先天吞噬功能障礙；分枝桿菌（Mycobacteria）感染提示 IL-12/IFN-$\gamma$ 軸線受損；頑固性病毒、真菌與肺囊蟲（*P. jiroveci*）則強烈警示 T 細胞免疫缺陷。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注異常數值標準 |
| :--- | :--- | :--- |
| **絕對嗜中性球計數 (ANC)** | 評估骨髓顆粒球生成與外周消耗 | **< 500 /$\mu$L**：重度先天性嗜中性球低下 (SCN)；**> 30,000 /$\mu$L 伴隨感染無膿液**：高度懷疑 LAD |
| **絕對淋巴球計數 (ALC)** | 評估細胞免疫發育狀態，排除 SCID | **嬰幼兒 (<3個月) < 3000 /$\mu$L**；**成人 < 1500 /$\mu$L**：強烈警示 T 細胞免疫缺陷 |
| **嗜酸性球 (Eosinophils)** | 反映 Th2 偏位、免疫失衡或黏膜屏障崩解 | 異常顯著升高：提示 Wiskott-Aldrich (WAS)、高 IgE 症候群 (HIES)、Omenn 症候群 |
| **血清免疫球蛋白定量 (IgG, IgA, IgM, IgE)** | 評估體液免疫、類別轉換（CSR）功能 | **IgA < 7 mg/dL**：選擇性 IgA 缺乏；**IgG 補充治療目標**：谷濃度 (Trough level) 維持 **> 800 mg/dL**；IgE 顯著高於正常值（HIES） |
| **周邊血淋巴球免疫分型 (Flow Cytometry)** | 解析 CD3, CD4, CD8, CD19/20, CD16/56 及記憶 B 細胞（$\text{CD27}^+$）比例 | B 細胞 < 1%（XLA）；出現 **$\text{CD4}^-\text{CD8}^-\text{TCR}\alpha\beta^+$ 雙陰性 T 細胞佔 2–50%**（診斷 ALPS 關鍵指標） |
| **嗜中性球呼吸爆發分析 (DHR / NBT 試驗)** | 以二氫羅丹明 (DHR) 螢光或四唑氮藍評估吞噬細胞 ROS 產能 | 螢光無偏移或無還原反應：確診慢性肉芽腫病 (CGD) |
| **總補體溶血活性 (CH50 / AP50)** | 評估古典途徑、凝集素途徑（CH50）與旁路途徑（AP50）功能完整性 | 活性顯著降低或完全缺失：提示補體成分（C1-C9、Factor I/D/Properdin）先天缺損 |
| **T 細胞受體切除環 (TREC) 檢測** | 利用新生兒乾血紙片定量胸腺初始 T 細胞新生量 | 數值低下或缺失：新生兒 SCID 早期篩檢金標準 |
| **周邊血抹片與特殊標記** | 檢驗細胞形態學與細胞毒性功能 | 出現 **Howell-Jolly bodies**（脾功能缺失/無脾症）；**微小血小板**（WAS）；**CD107a 脫顆粒試驗異常**（HLH） |

## 三、 關鍵機制詳解與重點筆記

### 1. 先天免疫吞噬細胞與訊號傳導屏障（Innate Phagocytic Deficiencies）
- **顆粒球發育與趨化阻滯**：
  - **SCN**：多數因 *ELANE*（嗜中性球彈性蛋白酶）突變導致早幼粒細胞提早凋亡，骨髓生成停滯；臨床特徵為「缺乏膿液形成的嚴重組織壞死與菌血症」。
  - **LAD (Leukocyte Adhesion Deficiency)**：LAD-I 為 $\beta 2$ 整合素（CD18）編碼基因缺陷，導致嗜中性球無法自血管內皮黏附穿出；臨床表現為臍帶脫落延遲、無膿液感染及外周血極度顯著之嗜中性球增多症（$>30,000/\mu\text{L}$）。
- **氧依賴性殺傷破壞（CGD）**：
  - NADPH 氧化酶次單元（gp91phox、p22phox 等）失活，無法將分子氧還原為超氧陰離子與過氧化氫。
  - **病理矛盾**：缺乏 ROS 無法有效滅除過氧化氫酶陽性菌（如金黃色葡萄球菌、格蘭氏陰性沙雷氏菌、麴菌），但持續的抗原刺激引發巨噬細胞聚集，在肺、肝、消化道形成大範圍「無菌性肉芽腫」，誘發阻塞性病變與炎症性腸病。
- **IL-12 / IFN-$\gamma$ 軸缺陷（MSMD）**：
  - 專一性破壞巨噬細胞的細胞內病原體殺傷賦能路徑，導致對低毒性環境分枝桿菌（如卡介苗 BCG、非結核分枝桿菌）與沙門氏菌產生致命脆弱性。

### 2. 適應性免疫分化障礙與類別轉換缺陷（Adaptive Immune Deficiencies）
- **嚴重聯合免疫缺陷病（SCID）**：
  - **細胞激素訊號路徑**：$\gamma c$ 鏈或 *JAK3* 突變使 IL-2, 4, 7, 9, 15, 21 受體失效，造成典型 $\text{T}^-\text{B}^+\text{NK}^-$ 或 $\text{T}^-\text{B}^-\text{NK}^-$ 表型。
  - **嘌呤代謝毒性路徑**：*ADA* 缺乏導致腺苷（Ado）與去氧腺苷（dAdo）代謝物蓄積，抑制核苷酸還原酶，引發未成熟淋巴前驅細胞凋亡，常合併肋骨軟骨交界處異常與神經發育遲緩。
- **B 細胞分化阻斷與低丙種球蛋白血症**：
  - **XLA (Bruton's Agammaglobulinemia)**：*BTK* 酪氨酸激酶突變導致前 B 細胞受體（pre-BCR）訊號中斷，外周血成熟 B 細胞幾乎完全缺失（$<1\%$），極易遭受腸病毒（慢性腦膜腦炎）及包膜細菌侵襲。
  - **高 IgM 症候群（HIGM）**：最常見為 CD40 Ligand（T 細胞表面）或 CD40（B 細胞表面）突變，使生發中心之免疫球蛋白類別轉換重組（CSR）與體細胞超突變（SHM）完全停擺，表現為 IgM 正常或升高，但 IgG、IgA、IgE 極度匱乏，且兼具肺囊蟲（*P. jiroveci*）與隱孢子蟲（*Cryptosporidium*）之伺機感染風險。

### 3. 免疫耐受崩潰與調節性病變（Regulatory Defects & Autoimmunity）
- **IPEX 症候群與 Treg 失能**：
  - X 染色體轉錄因子 *FOXP3* 突變，直接摧毀 $\text{CD4}^+\text{CD25}^+\text{FOXP3}^+$ Treg 細胞的分化與抑制功能。
  - 臨床表現為極早發性的自體免疫破壞三聯徵：嚴重難治性自體免疫腸病（頑固腹瀉、嚴重絨毛萎縮）、1 型糖尿病及嚴重濕疹皮炎。
- **ALPS 與凋亡阻滯**：
  - *FAS*、*FASL* 或 *CASP10* 突變導致活化淋巴球無法啟動受體介導的細胞凋亡程序。
  - 自體反應性淋巴球異常蓄積，導致慢性無痛性淋巴結腫大、肝脾腫大，以及特征性的周邊血 TCR$\alpha\beta^+$ 雙陰性（$\text{CD4}^-\text{CD8}^-$）T 細胞異常增殖與溶血性貧血/血小板低下。
- **APECED（APS-1）與中樞耐受衰竭**：
  - 胸腺上皮細胞之 *AIRE* 基因缺陷，無法異位表達周邊組織專一性抗原（TSA），導致胸腺負向選汰機制失效，自體反應性 T 細胞大量流出，併發慢性皮膚黏膜念珠菌病（CMC）與多發性內分泌自體免疫疾病（副甲狀腺機能低下、腎上腺皮質機能不全）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素與免疫代謝輔助
- **維生素 A 與維生素 D3/K2 協同調理**：
  - **機制**：活化維生素 D 受體（VDR）以誘導抗微生物胜肽（Cathelicidin）表達，並引導樹突細胞促進黏膜型 Foxp3+ Treg 誘導；維生素 A（視網醇）調節分泌型 IgA 合成與上皮屏障修復。
  - **建議劑量**：維生素 D3 依血清 25(OH)D 目標濃度（建議維持於 50–70 ng/mL）校正使用（如 2000–5000 IU/日）；維生素 A（乳化型 Retinyl palmitate）5000–10000 IU/日，定期監測肝功能。
- **高純度鋅劑（Zinc Carnosine / Zinc Bisglycinate）**：
  - **機制**：維持胸腺素（Thymulin）生物活性，修復腸道上皮緊密連接（Tight junctions），改善先天免疫吞噬細胞之超氧化物生成力。
  - **建議劑量**：元素鋅 25–45 mg/日，長期使用需以 15:1 比例搭配銅（Copper 1–2 mg/日）。
- **黏膜抗炎與腸道屏障基質修復（L-Glutamine & Butyrate）**：
  - **機制**：針對 CVID、IPEX 或 IgA 缺乏伴隨的腸壁結構萎縮與吸收不良，提供腸上皮細胞能量來源，降低內毒素（LPS）移位引起的全身性慢性發炎。
  - **建議劑量**：左旋麩醯胺酸 5–10 g/日（沖水空腹飲用）；微膠囊化丁酸鹽 500–1000 mg/日。
- **細胞內抗氧化與氧化還原微調（NAC & 還原型穀胱甘肽）**：
  - **機制**：針對吞噬功能低下或慢性發炎個案，穩定線粒體膜電位，調節過度發炎引發的二次氧化組織損傷。
  - **建議劑量**：N-乙醯半胱胺酸（NAC）600 mg，每日 2 次；脂質體穀胱甘肽 250–500 mg/日。

### 2. 醫療介入與飲食防禦策略
- **免疫球蛋白替代治療（IVIG / SCIG）的臨床監控原則**：
  - 適用於 XLA、CVID、HIGM 等體液免疫缺陷。目標維持血清 IgG 谷濃度 **> 800 mg/dL**。
  - **特別警訊**：**絕對性 IgA 缺乏症患者體內可能含有抗 IgA 抗體（Anti-IgA Antibodies），常規輸注含微量 IgA 的 IgG 製劑可能引發嚴重過敏性休克（Anaphylaxis），必須選用超高純度「無 IgA 製劑（IgA-depleted IgG）」**。
- **低微生物抗原飲食（Neutropenic / Clean-source Diet）**：
  - 對於 ANC < 500/$\mu$L 或嚴重淋巴球缺乏個案，嚴禁攝取任何未經全熟加熱的食物（生生肉、生魚片、未殺菌生乳酪、生菜沙拉）。
  - 嚴格避開富含黴菌之陳年乳酪、發酵製品，減少黃麴毒素與伺機性真菌孢子之胃腸道暴露。
- **抗發炎 / 自身免疫草本排除飲食（Autoimmune Protocol, AIP）**：
  - 針對 CVID/ALPS 相關之發炎性腸道病變與關節炎，初期排除麩質、酪蛋白、茄科植物及精緻加工糖類，降低自律性抗原模仿反應與非特異性免疫活化。

### 3. 環境毒素阻斷、排毒通道與生活型態
- **環境生物毒素（黴菌/真菌孢子）極致防護**：
  - CGD 與吞噬細胞缺陷患者對環境黴菌（如 *Aspergillus* 麴菌屬）極度敏感，吸入微量孢子即可導致致命性肺壞死與肉芽腫。
  - 生活環境應配置醫療級 HEPA 過濾系統，維持室內濕度於 45–50% 之間，嚴禁接觸園藝土壤、堆肥、落葉堆及受潮發霉之建材。
- **嚴禁使用活性減毒疫苗（Live Attenuated Vaccines）**：
  - **絕對禁忌**：對於確診或疑似 T 細胞缺乏（如 SCID）、XLA 患者，**絕對禁止施打 BCG 卡介苗、口服小兒麻痺疫苗（OPV）、麻疹-腮腺炎-德國麻疹（MMR）、水痘及輪狀病毒疫苗**，否則將導致致命性疫苗株播散性感染。
- **口腔微生態與上皮屏障維護**：
  - SCN 與各類吞噬細胞低下患者最常以頑固性牙周炎、口腔潰瘍為早期表現。應建立無創牙周物理性清潔習慣，定期使用無酒精洗必泰（Chlorhexidine）漱口液，阻斷口腔黏膜菌群入血路徑。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實「頻繁感染」背後的警訊評估**：成人一年內發生 $\ge 2$ 次嚴重新竇炎/肺炎，或小兒出現生長遲緩合併頑固性鵝口瘡，首要步驟為開立 **CBC/DC + 血清 IgG/A/M/E** 篩檢，切忌僅以口服抗生素治標。
2. **警覺細胞計數臨界值**：周邊血常規若發現 **ANC < 500/$\mu$L**，或 3 個月內嬰兒 **ALC < 3000/$\mu$L**，必須視為臨床緊急狀況，暫緩所有活性減毒疫苗注射，並儘速轉介醫學中心進行 TREC、流式細胞分型或骨髓檢查。
3. **辨識「非感染性」免疫缺陷表型**：自體免疫性溶血、不明原因全血球減少、早發性難治型發炎性腸道疾病（IBD）或淋巴結異常增生，應將免疫調節缺陷（如 IPEX、ALPS、CVID）列入鑑別診斷。
4. **確診病患之個人化防護宣告**：針對選擇性 IgA 缺乏者，於病歷明確標註使用「無 IgA 製劑」並佩戴醫療示警手環；CGD 患者常規開立 TMP-SMX 及抗真菌藥（Itraconazole）預防性投藥，並遠離土壤與黴菌環境。
