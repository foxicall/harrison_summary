# 氣喘之精準醫學與免疫表型治療策略：從第二型/非第二型發炎機制、代謝介質到整合性階梯治療
- **主講人/來源**：Elliot Israel 醫師 / 287 Asthma.pdf (*Harrison's Principles of Internal Medicine*, 21st Edition)
- **核心主旨**：氣喘為高度異質性的慢性氣道疾病，其致病機轉涉及遺傳易感性、環境毒素暴露、氧化壓力與微菌叢失衡；臨床處置已由傳統表徵治療轉向辨識「第二型（Type 2）」與「非第二型（Non-Type 2）」發炎內型，並結合呼氣一氧化氮（FeNO）評估、ICS/Formoterol 早期緩解策略與標靶生物製劑之精準介入。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **氣道高反應性（AHR）與結構重塑**：包含平滑肌肥大增生、上皮下修復型膠原蛋白（Tenascin, Periostin, Fibronectin）沉積、基底膜增厚、微血管血管新生（Angiogenesis）與杯狀細胞化生（Goblet cell metaplasia）導致黏液栓塞。
  - **Type 2 免疫驅動**：由過敏原或環境刺激物誘發上皮細胞釋放警訊素（Alarmins：TSLP, IL-25, IL-33），激活 Th2 細胞與第 2 型先天淋巴細胞（ILC2），大量產生 IL-4（促使 B 細胞生成 IgE）、IL-5（調控嗜酸性球分化與存活）及 IL-13（引發 AHR 與黏液過度分泌）。
  - **Non-Type 2 免疫驅動**：由刺激物、病毒/非典型感染（如 *Mycoplasma*）或氧化壓力主導，經 Th1/Th17 細胞分泌 IL-6, IL-8, IL-17, TNF-α 及 IFN-γ，誘發嗜中性球浸潤；對傳統吸入型類固醇（ICS）反應不佳。
  - **發炎代謝失衡與氧化壓力**：花生四烯酸代謝產物（半胱胺醯白三烯 LTC4/LTD4/LTE4、PGD2）過度釋放，伴隨專一性促消退介質（SPMs：Resolvins, Lipoxins）缺乏；發炎細胞釋放大量活性氧（ROS）損害氣道黏膜。
- **演講亮點與臨床洞察**：
  - **治療典範轉移（Paradigm Shift）**：GINA 臨床指引重大變革——不再推薦單獨使用短效 $\beta_2$-促效劑（SABA）治療輕度氣喘（單獨使用 SABA 與死亡率及急性惡化增加相關），全面轉向以「低劑量 ICS/Formoterol」作為按需（PRN）抗發炎緩解劑（SMART/MART 策略）。
  - **精準生物製劑分層**：針對 Type 2 重度氣喘，依據血中嗜酸性球（$\ge 300\text{ cells}/\mu\text{L}$）、FeNO（$\ge 20\text{--}25\text{ ppb}$）及總 IgE，精準選用 Anti-IgE（Omalizumab）、Anti-IL-5/IL-5R（Mepolizumab, Reslizumab, Benralizumab）或 Anti-IL-4R$\alpha$（Dupilumab）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **FeNO（呼氣一氧化氮濃度）** | 反映氣道嗜酸性球發炎程度及 IL-13 活化狀態；評估對 ICS 的治療反應性與患者用藥順從性 | • 未治療者診斷閾值：$> 35\text{--}40\text{ ppb}$ 代表顯著嗜酸性發炎<br>• 接受中高劑量 ICS 者：$> 20\text{--}25\text{ ppb}$ 提示順從性差或存在持續性 Type 2 發炎 |
| **肺功能檢查（Spirometry）** | 評估氣流受限嚴重度及可逆性（Reversibility） | • 吸入支氣管擴張劑後，$\text{FEV}_1$ 增加 $\ge 12\%$ 且絕對值增加 $\ge 200\text{ mL}$<br>• 日間 PEF 變異率 $> 20\%$ |
| **氣道激發試驗（Methacholine Challenge）** | 評估氣道高反應性（AHR），適用於肺功能正常但疑似氣喘者 | • 激發劑量 $\text{PD}_{20} \le 400\ \mu\text{g}$（使 $\text{FEV}_1$ 下降 20% 之累積劑量）即屬陽性 |
| **運動/冷空氣激發試驗** | 評估運動型氣喘及滲透壓敏感度 | • 運動或冷空氣激發後，$\text{FEV}_1$ 較基準值下降 $\ge 10\%$ 為陽性 |
| **周邊血嗜酸性球計數（Blood Eosinophils）** | 評估系統性 Type 2 發炎活性，作為 IL-5/IL-4 標靶生物製劑反應之預測標記 | • $\ge 300\text{ cells}/\mu\text{L}$（提示對 Anti-IL-5 或 Dupilumab 反應良好）<br>• 顯著升高（如 $> 1000\text{ cells}/\mu\text{L}$）需排除 EGPA 或寄生蟲感染 |
| **血清總 IgE 與特定過敏原 IgE（RAST）/ 皮膚點刺** | 確認特應性（Atopy）體質，評估過敏性鼻炎與環境暴露源；作為 Omalizumab 劑量計算基礎 | • 總 $\text{IgE} \ge 30\text{ IU/mL}$ 伴隨常年過敏原陽性（適合 Anti-IgE 治療）<br>• $\text{IgE} > 1000\text{ IU/mL}$ 應高度警惕 ABPA（過敏性支氣管肺麴菌病） |
| **誘導痰液細胞學檢查（Sputum Cytology）** | 直接評估氣道腔內發炎表型（嗜酸性 vs. 嗜中性 vs. 寡肉芽腫性 pauci-granulocytic） | • 痰液嗜酸性球比例升高提示 Type 2 發炎；嗜中性球為主常提示感染、內毒素刺激或類固醇無反應性 |
| **汗液氯離子檢測（Sweat Chloride Test）** | 鑑別診斷慢性阻塞與氣喘表徵（排除囊腫纖維化 CF） | • 確診 CF：$\ge 60\text{ mmol/L}$<br>• 灰階/未確定區間（CFF 最新指引）：$30\text{--}50\text{ mmol/L}$（需結合基因檢測） |

## 三、 關鍵機制詳解與投影片重點筆記

- **Type 2 與 Non-Type 2 免疫網絡架構（圖 287-3）**：
  - **Type 2 途徑**：
    1. *上皮細胞損傷與警訊素釋放*：環境過敏原、真菌、病毒激活上皮細胞釋放 TSLP、IL-25 與 IL-33。
    2. *先天與後天免疫協同*：Alarmins 活化 ILC2 細胞，外源抗原經 APC 活化 Th2 細胞；兩者均表達 GATA3 轉錄因子，協同產生 IL-4、IL-5、IL-13。
    3. *效應細胞召集*：IL-5 驅動骨髓嗜酸性球生成、活化與氣道遷移；IL-4 驅動 B 細胞進行 IgE 類別轉換，IgE 結合肥大細胞表面 Fc$\varepsilon$RI；過敏原交聯促使肥大細胞去顆粒釋放組織胺、白三烯與 $\text{PGD}_2$。
    4. *組織效應*：IL-13 直接刺激杯狀細胞化生、黏液高分泌，並刺激平滑肌收縮；同時誘導上皮細胞產生一氧化氮（導致 FeNO 上升）。
  - **Non-Type 2 途徑**：
    1. 刺激物、空氣污染物、細菌毒素透過上皮細胞分泌 IL-6、TGF-$\beta$、IL-23，誘導 Th17 與 Th1 細胞分化。
    2. Th17 分泌 IL-17，Th1 分泌 IFN-$\gamma$ 與 TNF-$\alpha$，上皮細胞釋放 CXCL8（IL-8）與 GM-CSF。
    3. 強力趨化嗜中性球進入氣道，釋放髓過氧化物酶（MPO）、彈性蛋白酶（Elastase）及大量 ROS，造成組織廣泛壞死與無菌性發炎，對類固醇治療極具抗性。

- **發炎代謝介質、消退缺陷與氧化壓力**：
  - **半胱胺醯白三烯（CysLTs: $\text{LTC}_4, \text{LTD}_4, \text{LTE}_4$）**：由肥大細胞與嗜酸性球透過 5-脂氧合酶（5-LOX）途徑生成，其致支氣管收縮強度為組織胺的 100~1000 倍，並促進微血管滲漏、黏液分泌與平滑肌增生。
  - **前列腺素 $\text{D}_2$（$\text{PGD}_2$）與 CRTH2 受體**：肥大細胞分泌之 $\text{PGD}_2$ 結合於 Th2、ILC2 及嗜酸性球表面之 CRTH2（DP2）受體，放大 Type 2 發炎反應。
  - **發炎消退缺陷（Resolution Defect）**：內源性抗發炎與消退介質（專一性促消退脂質介質 SPMs，如 Resolvins、Lipoxins）合成不足，被證實是重度難治性氣喘發炎持續存在的核心生化異常。
  - **氧化壓力（ROS）**：浸潤的發炎細胞產生呼吸爆發（Respiratory burst），釋放超氧化物與過氧化氫，不僅直接破壞呼吸道上皮屏障（形成脫落性空洞），亦損害 $\beta_2$-受體敏感度，導致支氣管擴張劑抗藥性。

- **阿斯匹靈加重型呼吸道疾病（AERD）之生化分流機制**：
  - 約 5~10% 成人型氣喘合併鼻竇炎與鼻息肉。
  - 機制：病患體內微環境存在異常的白三烯合成過度活化；當使用阿斯匹靈或 NSAIDs 抑制 COX-1 時，促使花生四烯酸代謝流全數轉移至 5-LOX 途徑，同時因抑制具有保護作用的 $\text{PGE}_2$，解除對肥大細胞去顆粒的剎車機制，爆發致死性支氣管痙攣與鼻竇充血。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **功能性營養素/抗氧化與抗發炎代謝支持**：
  - **維生素 D3（最適血清濃度建議 $> 40\text{--}50\text{ ng/mL}$）**：文獻指出產前母體維生素 D 缺乏顯著增加子代氣喘風險。維生素 D 透過下調 Th2/Th17 促炎細胞因子、上調 IL-10 與調節型 T 細胞（Treg），可改善皮質類固醇抗藥性並減少急性惡化。
  - **抗氧化網絡支持（維生素 C、維生素 E、鋅）**：研究顯示產前/飲食補充抗氧化微量元素可對抗氣道氧化壓力、保護上皮細胞完整性並降低小兒氣喘發生率。
  - **長鏈 Omega-3 多元不飽和脂肪酸（EPA/DHA）**：提供 Resolvins（E系列、D系列）與 Protectins 前驅受質，競爭性抑制花生四烯酸代謝，減少 CysLTs 與 $\text{LTB}_4$ 生成，促進慢性氣道發炎消退。
  - **鎂離子（Magnesium）補充**：急性發作時靜脈輸注或日常適量口服補充，透過拮抗鈣離子通道舒緩支氣管平滑肌痙攣。

- **飲食策略與代謝優化**：
  - **抗發炎與低敏全食物飲食**：富含植物多酚與膳食纖維，藉由腸道菌生成短鏈脂肪酸（SCFAs）調節全身性發炎。
  - **減少高精緻糖分攝取**：觀察性研究指出，高糖攝取與高升糖負荷會加速 AGEs（晚期糖化終產物）堆積，並增加氣道發炎及子代氣喘發病風險。
  - **體重管理與代謝症候群矯治**：肥胖為氣喘難以控制的獨立危險因子。脂肪組織釋放促炎性脂肪激素（Adipokines）與 IL-6，造成 Non-Type 2 氣道微發炎與胸廓順應性下降；減重或減重代謝手術可顯著降低氣喘急性發作次數。

- **環境毒素阻斷、微菌叢建立與氣道防護**：
  - **氣道上皮屏障保護與環境除毒**：
    - 嚴格戒除菸草、二手菸與大麻燃燒煙霧（吸菸會直接鈍化 ICS 的抗發炎效果）。
    - 減少暴露於燃氣爐具、開放式明火所排放之二氧化氮（$\text{NO}_2$）與一氧化碳（CO），使用高效能 HEPA 空氣清淨系統。
    - 針對已致敏患者執行全方位過敏原清除：防蟎床包（需搭配多維度防護策略）、防黴去濕（維持環境濕度 40~50%）、撲滅蟑螂/害蟲。
  - **微菌叢（Microbiome）調控理念**：衛生假說之延伸——早期生命接觸多樣性農村環境微菌叢與益生菌產物，有助於引導免疫系統建立耐受機制，抑制過度 Atopy 偏向。
  - **運動誘發性氣喘（EIA）防護**：冷乾燥空氣會導致氣道上皮脫水、滲透壓升高並釋放收縮介質。運動前應充足熱身、寒冷天佩戴口罩預熱空氣；常規運動者可預防性使用白三烯調節劑（LTRA）或運動前吸入 SABA（或 ICS/Formoterol），避免單用 LABA 造成保護效應快速耐受（Tachyphylaxis）。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實精準免疫表型分類**：
   面對中重度或難治型氣喘，第一時間檢測 **FeNO**、**周邊血嗜酸性球計數** 及 **總/特異性 IgE**，迅速劃分 Type 2-high（嗜酸性/過敏性）或 Type 2-low（嗜中性/寡細胞性），精準對接後續用藥。
2. **貫徹 GINA 現代階梯治療（摒除單用 SABA）**：
   - Step 1~2：優先採用 **低劑量 ICS/Formoterol** 作為按需緩解用藥（PRN），從疾病初期即同步抗發炎與解痙。
   - Step 3~4：維持規律中/低劑量 ICS/Formoterol，並以同一吸入劑作為 PRN 緩解（MART 策略）。
   - Step 5~6：加用 LAMA（如 Tiotropium），或依表型加用標靶生物製劑（如 Dupilumab、Mepolizumab、Benralizumab、Omalizumab）。
3. **系統性排查並治療混淆共病（Mimics & Comorbidities）**：
   在將氣喘升級為重度前，務必徹底評估與處置 **胃食道逆流（GERD）**、**慢性鼻竇炎伴鼻息肉（CRSwNP）**、**肥胖**、**阻塞型睡眠呼吸中止症（OSA）** 及 **誘導性喉部功能障礙（Vocal Cord Dysfunction）**。
4. **特殊臨床亞型精準辨識**：
   - **AERD**：嚴禁常規 NSAIDs/Aspirin，首選白三烯調節劑（Montelukast, Zileuton）或抗 IL-4R$\alpha$（Dupilumab）生物製劑。
   - **重度急性發作危險徵候**：當呼吸窘迫患者動脈血氣分析出現「正常或偏高的 $\text{PaCO}_2$」，代表呼吸肌極度疲乏、瀕臨呼吸衰竭，須立即準備升級重症監護與氣道支持。
5. **整合性功能營養介入**：
   檢測並優化血清 **維生素 D3** 水平（維持於 $50\text{ ng/mL}$ 以上），開立醫療級 **Omega-3 脂肪酸** 以支持體內 SPMs 合成，並建立低抗原、低精緻糖、富含天然抗氧化劑的生活型態。
