# IgG4 相關疾病（IgG4-Related Disease, IgG4-RD）之系統性病理病程、鑑別診斷與臨床整合管理

- **主講人/來源**：John H. Stone, MD, MPH / 368 IgG4-Related Disease.pdf (*Harrison's Principles of Internal Medicine*)
- **核心主旨**：IgG4-RD 是一種以致密淋巴漿細胞浸潤、席紋狀纖維化與假性腫瘤形成為特徵的全身性慢性纖維發炎疾病；臨床上極易擬態為惡性腫瘤，需整合血清學、組織病理特徵（警惕檢測前帶效應與晚期纖維化假陰性）及跨器官微環境評估，以避免不可逆的器官硬化與衰竭。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **慢性抗原驅動與纖維化串聯**：局部以 CD4+ T 細胞為主導的瀰漫浸潤，協同 B 細胞生發中心分化之 IgG4+ 漿細胞釋放發炎訊號，驅動成纖維細胞異常增殖，形成具專一特異性的**席紋狀纖維化（Storiform fibrosis）**與**閉塞性靜脈炎（Obliterative phlebitis）**。
  - **代謝與外分泌耗竭**：高發於胰臟（第 1 型自體免疫性胰臟炎 AIP），常伴隨胰外分泌衰竭導致進行性體重下降，以及胰內分泌功能損傷導致急性糖耐量異常或新發糖尿病。
- **演講亮點與臨床洞察（Paradigm Shifts）**：
  - **惡性腫瘤高度擬態者（The Great Mimicker）**：常形成實質性假性腫瘤（Pseudotumors），臨床常見患者在未明確診斷前接受了大型切除手術（如 Whipple 手術或甲狀腺切除術）。
  - **非典型人口統計學特徵**：傳統自體免疫疾病多發於年輕女性，但 IgG4-RD（特別是 AIP、腹膜後纖維化及小管間質性腎炎）好發於**中老年男性**（男:女比例高達 3:1；僅頭頸部侵犯時性別比接近 1:1）。
  - **發炎指數的「沈默陷阱」**：即便處於多器官侵犯狀態，患者通常無發燒，且 **C-反應蛋白（CRP）多無顯著升高**，呈現亞急性隱匿進展，常導致診斷延誤直至器官發生不可逆硬化（如輸尿管嵌頓、腎萎縮、主動脈瘤或夾層）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **血清 IgG4 濃度 (Serum IgG4)** | 評估活動度與多器官受累；作為治療反應與臨床復發的監控指標（復發前常出現滴度回升）。 | 正常上限可達 **30～40 倍**（常提示多器官受累）；約 **30% 患者呈現假性正常**（見於單器官、晚期纖維化或前帶效應）。 |
| **前帶效應稀釋檢測 (Prozone Testing)** | 散射比濁法（Nephelometry）在極高抗原濃度下會因抗原過剩產生「偽低值」，延誤高危重症患者診斷。 | 高度懷疑但檢驗正常時，實驗室必須進行**血清樣本稀釋重測**。 |
| **組織 IgG4+/IgG 漿細胞比值** | 確診金標準；區分非特異性發炎反應與 IgG4-RD 專一性浸潤。 | 晚期低細胞、高纖維化切片中，**IgG4/IgG 比值及席紋狀架構**之重要性遠高於單純的高倍視野（HPF）計數。 |
| **補體水平 (C3, C4)** | 評估腎臟實質受累狀態（特別是小管間質性腎炎 TIN 或膜性腎病變 MN）。 | 腎臟侵犯時**強烈伴隨低補體血症（Hypocomplementemia）**。 |
| **嗜酸性粒細胞計數 (Eosinophils)** | 反映個體 Th2 免疫偏向、特應性體質（Atopy）與外周過敏性炎症活性。 | 常見**輕度至中度外周血嗜酸性粒細胞增多**，組織切片亦可見嗜酸性粒細胞浸潤。 |
| **外分泌與內分泌代謝指標 (HbA1c, 血糖, 糞便彈性蛋白酶)** | 評估第 1 型 AIP 導致之胰島 β 細胞損傷及外分泌酵素缺乏症狀。 | 20%～50% 患者出現**急性葡萄糖耐量不良**或新發糖尿病；常伴隨脂肪便與營養吸收不良性消瘦。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 病理組織學「三聯徵」與排他性特徵
- **三大陽性特徵**：
  1. **致密淋巴漿細胞浸潤**：生發中心富含 CD19+、CD138+ 及高比例 IgG4+ 漿細胞；周圍瀰漫分布大量 CD4+ T 細胞。
  2. **席紋狀纖維化（Storiform Fibrosis）**：呈現拉丁文 *storea*（編織草蓆狀）的渦流型膠原纖維增生，成纖維細胞密集圍繞腺管或病灶。
  3. **閉塞性靜脈炎（Obliterative Phlebitis）**：發炎細胞主動侵犯並閉塞靜脈管腔（動脈侵犯較少見，但可在肺部出現閉塞性動脈炎）。
- **關鍵排除特徵（若出現則高度質疑非 IgG4-RD）**：
  - 顯著的中性粒細胞浸潤（Neutrophilic infiltration）
  - 白血球碎裂性血管炎（Leukocytoclasis）
  - 肉芽腫性發炎（Granulomatous inflammation）
  - 多核巨細胞（Multinucleated giant cells）
  - 纖維蛋白樣壞死（Fibrinoid necrosis）

### 2. 多器官侵犯與惡性腫瘤擬態表現
- **頭頸部與五官**：
  - **米庫利茲病（Mikulicz's disease）**：雙側淚腺（Dacryoadenitis）與頜下腺/腮腺對稱性腫大。
  - **眼眶假瘤**：眼外肌增粗（肥大性肌炎）侵犯翼顎窩與三叉神經路徑。
  - **耳鼻竇**：過敏性鼻息肉、氣喘共病，偶見類似肉芽腫性多血管炎（GPA）的骨破壞病灶。
- **神經軸與大血管**：
  - **肥厚性硬腦膜炎（Hypertrophic Pachymeningitis）**：硬腦膜廣泛顯著增厚強化，引發顱神經麻痺或脊髓壓迫。
  - **淋巴漿細胞性主動脈炎（Aortitis）**：主動脈壁增厚，可進展為主動脈瘤、主動脈夾層或發炎性腹主動脈瘤。
- **腹膜後與消化系統**：
  - **第 1 型 AIP**：影像學可見胰臟呈現均勻瀰漫腫大，失去正常分葉，外觀呈典型**「香腸狀胰臟（Sausage-shaped pancreas）」**。
  - **硬化性膽管炎（IgG4-SC）**：引起阻塞性黃疸，極易與膽管癌（Cholangiocarcinoma）或原發性硬化性膽管炎（PSC）混淆。
  - **腹膜後纖維化（RPF）**：圍繞腹主動脈並向下蔓延至髂血管，包埋輸尿管引發腎後性水腎與無聲性腎萎縮。

### 3. IgG4 抗體分子的免疫悖論
- **Fab 端交換（Fab-arm exchange）**：IgG4 半分子具有解離並與其他特異性半分子重組的特性，呈現不對稱雙特異性，無法有效交聯抗原形成大分子免疫複合體，且活化經典補體途徑能力極弱。
- **非致病主因，而是發炎調控標記**：目前學界傾向認為血清 IgG4 升高是機體對持續慢性抗原刺激、Th2/Treg 細胞介導的消炎代償反應產物，而非直接導致組織破壞的原發效應分子。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

> *註：IgG4-RD 急性期多需依賴標準免疫抑制治療（如全身性糖皮質激素、B細胞清除療法 Rituximab）。功能醫學與整合策略旨在降調節慢性抗原驅動、抑制成纖維細胞活化、支持受損器官代謝修復並維持長期自護力。*

- **功能性營養素與植化素支持**：
  - **纖維化訊號調控（TGF-β/Smad 途徑調控）**：
    - **薑黃素（Curcumin / Phytosome 劑型）**：高生物利用度製劑，抑制 NF-κB 發炎轉錄，下調纖維化級聯反應。
    - **槲皮素（Quercetin）與木犀草素（Luteolin）**：穩定肥大細胞，抑制 Th2 細胞過度偏向及嗜酸性粒細胞活化，改善特應性與過敏共病。
  - **黏膜抗氧化與細胞修復**：
    - **N-乙醯半胱氨酸（NAC, 600–1200 mg/天）**：補充細胞內穀胱甘肽，減輕組織纖維發炎環境中的氧化壓力損傷。
    - **高純度 Omega-3 脂肪酸（EPA/DHA 2–4 g/天）**：產生特異性促消退介質（SPMs），加速局部無菌性發炎的消退。
  - **免疫微環境調節**：
    - **維生素 D3 + K2**：維持血清 25(OH)D 於 50–70 ng/mL，強化 Treg 細胞功能，調控過度活躍的生發中心 B 細胞反應。
- **代謝微環境與營養補充策略**：
  - **胰外分泌功能替代（PERT）**：針對第 1 型 AIP 出現體重減輕、脂肪便者，餐中給予足量消化酵素，防止脂溶性維生素（A、D、E、K）與蛋白質營養不良。
  - **抗自體免疫/低過敏原飲食模式（AIP Diet / Elimination Diet）**：
    - 排除潛在致敏原與慢性食物敏感物（如麩質、精緻加工糖、乳製品），降低腸道抗原通透性，減輕全身免疫監控系統的抗原負荷。
    - 穩定餐後血糖波動，避免因內分泌受損誘發的高血糖加劇組織糖化與纖維化。
- **環境毒素阻斷與器官排毒引流**：
  - **環境抗原截斷**：IgG4-RD 患者常具過敏體質，需嚴格清查環境黴菌（Mold/Mycotoxins）、職業性粉塵、揮發性有機物（VOCs）等隱性長期免疫刺激源。
  - **膽道與肝臟循環支持**：硬化性膽管受累患者需補充牛磺熊去氧膽酸（TUDCA）或水飛薊素，改善膽汁酸流動性，降低膽汁鬱積性肝損傷風險。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **面對非典型「腫瘤」時保持警覺**：
   臨床遇見無痛性淋巴腺腫、淚腺/唾液腺腫大、胰臟邊界消失之香腸狀腫脹或後腹膜軟組織包塊時，**在動刀施行毀滅性腫瘤切除前，務必將 IgG4-RD 列入鑑別診斷**。
2. **謹防「血清 IgG4 正常」之偽陰性陷阱**：
   切勿僅因血清 IgG4 數值正常就排除診斷。若臨床高度懷疑，**必須要求檢驗室執行「血清稀釋重測」以破解抗原過剩之前帶效應（Prozone effect）**；同時需知曉純纖維化晚期血清 IgG4 常回落至正常區間。
3. **重視切片質性架構勝於絕對計數**：
   病理判讀時，需綜合評估**席紋狀纖維化**與**閉塞性靜脈炎**；組織細胞稀少時，**IgG4/IgG 漿細胞比值**的臨床價值遠大於單純高倍視野下的 IgG4 絕對細胞數。
4. **例行性多器官隱匿篩檢**：
   確診單一器官病變時（如單純腮腺腫大），應主動評估腎功能、尿液常規、補體（C3/C4）、血糖代謝與胸腹部影像，及早揪出無症狀之主動脈炎、間質性腎炎或腹膜後纖維化。
5. **療效達標後的持續滴度追蹤**：
   臨床症狀緩解後，血清 IgG4 濃度若未完全正常化但維持平穩可密切追蹤；一旦**血清 IgG4 出現持續進行性爬升，往往預示著亞臨床復發（Flare）**，需提早評估重啟介入以阻斷新的纖維化進展。
