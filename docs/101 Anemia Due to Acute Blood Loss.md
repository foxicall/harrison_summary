# 急性失血性貧血與補體調控途徑的臨床機轉與應對策略
- **主講人/來源**：101 Anemia Due to Acute Blood Loss.pdf（出自 *Harrison's Principles of Internal Medicine*, Chap. 101, Dan L. Longo 著，並附錄補體標靶治療圖譜）
- **核心主旨**：系統性剖析急性大量失血引發的早期低血容量休克與代償病理，並結合補體過度活化路徑（溶血機制）之近端與末端標靶阻斷，建立組織灌流重建、溶血防護與造血原料修復之臨床整合全貌。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **急性失血（Acute Posthemorrhagic Anemia）**：初期以**低容積（Hypovolemia）**與循環衰竭為主導，而非傳統紅血球濃度改變；因全血等比例流失，血紅素濃度初期呈現「正常假象」，直至組織間液回補或輸液代償後才呈現真實貧血。高血流灌注器官（大腦、腎臟）首當其衝，易引發組織缺氧、急性腎損傷（AKI）與神經缺血。
  - **補體途徑失調（如陣發性夜間血紅素尿症 PNH）**：由古典途徑、凝集素途徑或替代途徑（Tick-over 機制）觸發 C3/C5 轉化酶，進一步形成膜攻擊複合物（MAC, C5b-9），造成紅血球血管內溶血；近端補體過度活化亦會誘發血管外調理作用與吞噬。
- **演講亮點與臨床洞察**：
  - **臨床診斷陷阱**：急性大出血患者的常規血球計數（CBC/Hb）**初期不會下降**，不可依賴 Hb 排除出血；應即時評估脈壓差變窄（Decreased pulse pressure）、心搏過速、皮膚濕冷斑駁與寡尿等休克前期徵象。
  - **補體標靶的典範轉移（Paradigm Shift）**：末端抑制劑（Anti-C5: Eculizumab, Ravulizumab）能阻斷 MAC 形成，但無法抑制上游 C3 轉化酶活化；近端抑制劑（Broad: Anti-C3 如 Pegcetacoplan；Alternative-specific: Anti-factor D/B 如 Danicopan, Iptacopan）能阻斷放大循環（Amplification loop），全面改善血管內與血管外溶血。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及或常規指引） |
| :--- | :--- | :--- |
| **即時生命徵象與脈壓**<br>(Pulse Pressure / Shock Index) | 評估有效循環血量與周邊血管阻力，評估急性內外出血之低容積威脅 | 脈壓差變窄（< 30-40 mmHg）、休克指數（HR/SBP）> 0.8-1.0 提示早期失代償 |
| **全血細胞計數與血容比**<br>(CBC / Hb / Hct) | 監測紅血球丟失程度（注意：急性出血初期會呈偽性正常，需每 2~4 小時連續監測） | 急性期動態監測斜率，評估血液稀釋後之實際貧血程度 |
| **尿量與腎動脈灌注指標**<br>(Urine Output / Scr / BUN) | 反映高耗氧器官（腎臟）之灌注不足與缺血性損傷 | 尿量應維持 > 0.5 mL/kg/h；出現寡尿提示腎實質缺氧風險 |
| **補體活性分析**<br>(C3, C4, CH50, AH50) | 評估補體活化途徑（替代路徑過度亢進或消耗）及標靶治療之反應 | 評估消耗狀態，指導抗補體藥物（如 C3/C5/Factor B 抑制劑）之應用 |
| **溶血與代償標記**<br>(Reticulocytes, LDH, Haptoglobin) | 鑑別失血性貧血與補體/自體免疫溶血性貧血；評估骨髓代償造血速率 | 網狀紅血球上升（代償性）；LDH 上升合併結合珠蛋白（Haptoglobin）耗盡提示血管內溶血 |
| **鐵質代謝全套**<br>(Ferritin, Serum Iron, TIBC, TSAT) | 鑑別慢性失血之儲存鐵耗竭與急性出血後造血基質需求 | 鐵蛋白（Ferritin）> 50-100 ng/mL，轉鐵蛋白飽和度（TSAT）20-30% |

## 三、 關鍵機制詳解與投影片重點筆記

- **急性出血的三階段病理生理學（Chapter 101 重點）**：
  - **第一階段（低容積期 Hypovolemic Phase）**：
    - 全血驟降導致心輸出量驟減。臨床以**交感神經代償**為主要表現：心搏過速（Tachycardia）、呼吸急促（Tachypnea）、脈壓變窄、外周血管收縮（冷、蒼白、斑駁皮膚）。
    - 此階段紅血球與血漿等比例減少，常規血液常規檢查（CBC）無法即時反映失血程度，極易被誤判。
    - **終端器官威脅**：腦（意識改變、暈厥）、腎（急性腎小管壞死、寡尿）。
  - **第二階段（血液稀釋與代償期 Hemodilution Phase）**：
    - 血管內間質液回吸與神經體液調節（RAAS、ADH 活化），血漿容積被稀釋，Hb/Hct 開始顯著下降，呈現真正貧血數據。
  - **第三階段（骨髓代償與造血期 Marrow Replacement Phase）**：
    - 紅血球生成素（EPO）大量分泌，骨髓網狀紅血球（Reticulocytes）於數日內顯著上升，開始加速修復紅血球赤字。

- **補體激活路徑與靶向阻斷機制（Figure 100-11 詳解）**：
  - **三條活化途徑匯聚**：
    - **Classical / Lectin Pathway**：透過 C1 複合物或 MBL-MASPs 裂解 C2/C4，生成 **C4b2a**（C3 轉化酶）。
    - **Alternative Pathway**：自發性 C3 滴答活化（Tick-over）水解形成 C3(H2O)Bb，在 Factor B (fB)、Factor D (fD) 與 Properdin (P) 催化下形成 **C3bBb**，驅動極具破壞性的**放大循環（Amplification loop）**。
  - **轉化酶與裂解效應**：
    - C3 轉化酶裂解 C3 產生 C3a（過敏毒素/發炎引發）與 C3b（調理素）。
    - C3b 進一步組裝成 C5 轉化酶（C4b2aC3b 或 C3bBbC3b），裂解 C5 產生 C5a（強烈化學趨化因子）與 C5b。
    - C5b 招募 C6、C7、C8、C9 聚合形成**膜攻擊複合物（MAC, C5b-9）**，導致細胞膜孔洞、穿孔與血管內溶血。
  - **抑制劑分類與治療策略**：
    1. **末端抑制劑（Terminal Inhibitors）**：如 Eculizumab, Ravulizumab, Crovalimab（Anti-C5 單株抗體），能阻止 MAC 形成，但無法抑制 C3b 沉積（患者紅血球仍可能在脾臟被調理破壞，導致殘留性血管外溶血）。
    2. **近端廣譜抑制劑（Proximal Broad Inhibitors）**：Anti-C3（Pegcetacoplan），直接截斷 C3 裂解，同步抑制 MAC 與 C3b 調理。
    3. **近端替代途徑專一性抑制劑（Alternative Pathway-Specific）**：Anti-Factor D（Danicopan）、Anti-Factor B（Iptacopan），精準阻斷自發放大迴路，保留部分古典免疫清除功能。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **功能性營養素/造血與修復補充**：
  - **高效生物利用度鐵劑與輔助因子**：
    - 急性出血穩定期後，血紅素合成需大量原料：推薦**甘胺酸亞鐵（Ferrous Bisglycinate）** 30–60 mg/day（腸胃刺激性低），協同維生素 C 500 mg 促進吸收。
    - 結合活性輔酶型 B 群：**L-甲基葉酸（L-5-MTHF）** 800–1000 mcg/day 與 **甲基鈷胺素（Methylcobalamin）** 1000 mcg/day，支持骨髓紅血球系快速成熟。
  - **微量元素協同**：
    - 雙甘胺酸銅（Copper Bisglycinate）2 mg/day（促進鐵藍蛋白 Ceruloplasmin 活化與鐵運輸）。
    - 鋅（Zinc Picolinate）15–30 mg/day（保護紅血球細胞膜穩定度，修復血管內皮）。
  - **抗氧化與粒線體修復（針對缺血再灌注與溶血性氧化壓力）**：
    - **N-乙醯半胱胺酸（NAC）** 600 mg bid 或 **還原型穀胱甘肽（Liposomal Glutathione）** 250–500 mg/day：中和游離血紅素造成的氧化自由基損傷。
    - **輔酶 CoQ10（Ubiquinol）** 100–200 mg/day：支援大腦與腎小管細胞於缺氧後的粒線體能量生成。

- **飲食與組織灌流營養支持**：
  - **血量與電解質平衡**：以等滲透壓液體、骨頭高湯（含豐富甘胺酸、膠原蛋白）與富含鉀、鎂、鈉之電解質飲品補充細胞外液。
  - **造血原料豐富飲食**：納入草飼動物肝臟、有機紅肉、深綠色蔬菜，提供血基質鐵（Heme iron）與多酚類物質。
  - **抗發炎保護原則**：急性期避免極端高脂肪負載（減少腸道內毒素 LPS 經門靜脈引發替代途徑補體活化），採取地中海式全食物飲食。

- **環境毒素阻斷/內皮支持與生活型態**：
  - **腎臟與微循環保護**：在血容量未完全補足前，**嚴格禁用 NSAIDs 類消炎止痛藥**與腎毒性藥物，避免腎入球小動脈過度收縮導致 AKI。
  - **淋巴回流與被動活動**：低容積糾正後，進行輕度被動肢體活動與呼吸訓練，改善胸腔負壓，輔助靜脈回流與器官微循環灌注。
  - **降低補體激活誘因**：避免急性低溫暴露（冷凝集素刺激）與隱性感染（Bacterial LPS 會強烈活化替代途徑），維持體溫恆定與黏膜屏障完整。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **破除檢驗盲點**：面對嚴重外傷、產後大出血、消化道潰瘍或異位妊娠破裂患者，**切記早期 CBC 正常不可排除失血**；必須依賴心率、血壓、脈壓差、周邊皮溫及尿量作為急症辨識黃金標準。
2. **守護關鍵器官灌流**：急性失血初期首要威脅為低容積休克，應在黃金時間內穩定血容積，優先保全大腦與腎臟，預防急性腎損傷（AKI）與神經缺血損傷。
3. **辨別溶血與補體機制**：若貧血伴隨非外傷性血管內破壞（如 PNH、非典型溶血性尿毒症候群 aHUS），應迅速評估補體活化途徑；末端 Anti-C5 抗體若無法完全控制溶血，需考慮轉向或合併近端 C3/Factor B 抑制劑治療。
4. **階梯式造血原料重建**：當急性出血源頭控制、生命徵象穩定後，應即刻啟動活性甲基葉酸、活性 B12、甘胺酸亞鐵與抗氧化營養素整合方案，支持骨髓網狀紅血球生成峰值。
5. **監測感染與內毒素觸發源**：腸道菌叢失調或菌血症（LPS）是引爆補體替代途徑與微血管血栓的催化劑，在臨床調控中應同步維護腸道黏膜屏障與免疫恆定。
