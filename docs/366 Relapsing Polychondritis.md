# 復發性多軟骨炎（Relapsing Polychondritis）之病理機制、臨床表徵與整合醫學全方位評估
- **主講人/來源**：366 Relapsing Polychondritis.pdf（*Harrison's Principles of Internal Medicine*, 21st Edition, Chapter 366 by Carol A. Langford）
- **核心主旨**：復發性多軟骨炎是一種罕見且嚴重的全身性免疫介導軟骨破壞疾病，主要侵犯耳、鼻、喉氣管支氣管樹與非軟骨組織（眼、心血管及關節）；臨床須以全人視角早期辨識軟骨基質降解與自體免疫風暴，並排查 VEXAS 等體細胞突變症候群以精準擬定介入策略。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **軟骨外基質（ECM）崩解與蛋白聚醣（Proteoglycan）耗竭**：組織學早期表徵為嗜鹼性染色（basophilic staining）消失，顯示軟骨基質內的蛋白聚醣流失，伴隨軟骨陷窩（lacunar）破裂及軟骨細胞壞死。
  - **體液與細胞免疫雙重攻擊**：患者體內產生對抗第 II 型、IX 型、XI 型膠原蛋白及基質蛋白-1（Matrilin-1）的自體抗體與免疫複合物沉積；活化的 CD4+ 與 CD8+ T 細胞浸潤軟骨邊緣，釋放發炎因子與蛋白分解酶，導致軟骨不可逆纖維化與鈣化。
  - **微血管發炎與自體發炎基因途徑**：約 25% 患者合併血管炎；新近發現男性患者常伴隨 *UBA1* 體細胞突變（VEXAS 症候群），連結泛素化功能失調、骨髓分化異常與難治型全身發炎。
- **演講亮點與臨床洞察**：
  - **「保留耳垂（Earlobes Sparing）」的黃金鑑別法則**：耳廓軟骨炎（發生率高達 85%）僅侵犯具軟骨構造之耳廓（Pinna），耳垂因無軟骨組織而完全不受侵犯，此為臨床與蜂窩性組織炎鑑別之關鍵珠璣。
  - **呼吸道侵犯為致死主因**：高達 50–55% 患者出現喉氣管支氣管病變，因氣管軟骨環軟化塌陷（Tracheobronchomalacia）與聲門下狹窄（Subglottic stenosis），易致急性氣道窒息，必須早期進行動態吸吐相 CT 篩檢。
  - **MAGIC 症候群與跨疾病重疊**：臨床呈現「口腔及生殖器潰瘍合併軟骨發炎（MAGIC syndrome）」時，代表本病與白塞氏病（Behçet's disease）之重疊表型；約 30% 患者會合併其他風濕免疫病（如血管炎、RA、SLE）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **ESR & 高敏 C-反應蛋白 (hs-CRP)** | 評估全身性自體免疫發炎活動度與治療反應指標 | 臨床活動期顯著上升；緩解期應追求 hs-CRP < 1.0 mg/L |
| **全血球計數 (CBC with diff)** | 評估正球性正色素性貧血、白血球增多及 10% 出現之嗜酸性粒細胞增多（Eosinophilia） | 嗜酸性粒細胞比例需維持於正常區間 (< 5%)，貧血程度常平行發炎嚴重度 |
| **抗第 II 型膠原蛋白抗體 & 抗 Matrilin-1 抗體** | 專一性自體抗體評估；Matrilin-1 抗體陽性（~13%）高度預測呼吸道與氣管軟骨受累（~70% 呼吸道症狀） | 陰性或未檢出（常規實驗室少見，研究性指標；陰性不可排除診斷） |
| **ANCA (抗中性球細胞質抗體) 譜** | 鑑別診斷；RP 患者可能出現非特異性 cANCA 或 pANCA，但極少出現抗 PR3 或抗 MPO 抗體 | PR3-ANCA 與 MPO-ANCA 應為陰性（若陽性需高度懷疑肉芽腫併多發性血管炎 GPA） |
| **動態吸氣/呼氣相 胸部高解析 CT (Dynamic CT)** | 評估呼氣時大氣道動態塌陷（氣管軟化）、聲門下狹窄及管壁增厚鈣化 | 呼氣相氣管內徑塌陷率應 < 50%；排除氣道結構性阻塞 |
| **心臟超音波 (Echocardiogram)** | 篩檢主動脈根部擴張、主動脈瓣/二尖瓣逆流（發生率約 5–10%）與心包膜炎 | 主動脈瓣逆流 0 級、主動脈根部內徑正常、無瓣葉結構破壞 |
| **骨髓切片細胞學與 UBA1 基因檢測** | 男性難治型發炎、合併骨髓分化不良症候群 (MDS)、發燒、靜脈血栓時，排除 VEXAS 症候群 | 骨髓前驅細胞無空泡化（Vacuoles）；無 *UBA1* 體細胞錯義突變 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 軟骨組織免疫特權崩解與 Matrilin-1 靶向破壞
- **病理生理進程**：
  - 軟骨組織在正常生理狀態下缺乏血管且具有免疫特權。當因環境觸發因子（如感染、外傷）或遺傳易感背景（HLA-DR4 顯著增加）導致軟骨基質受損時，微血管與發炎細胞侵入。
  - **Matrilin-1（軟骨基質蛋白-1）特異性**：Matrilin-1 為非膠原性蛋白，高濃度存在於**氣管軟骨環與鼻中膈**，但**不存在於關節透明軟骨**。動物實驗證實，以 Matrilin-1 免疫大鼠會專一性誘發嚴重的鼻中膈腫脹、軟骨侵蝕與吸氣性喘鳴（Stridor），而不侵犯耳或關節軟骨。這解釋了臨床上約 70% 具 anti-matrilin-1 抗體的患者會出現顯著氣道受累的分子表型。
  - **軟骨外基質破壞連鎖反應**：蛋白聚醣最先被外基質金屬蛋白酶（MMPs）耗竭，繼之軟骨細胞凋亡，周邊纖維母細胞與肉芽組織長入，最終造成軟骨支架塌陷（形成馬鞍鼻 Saddle nose、垂耳 Droopy ear）。

### 2. 多器官系統受累機制與臨床表徵矩陣
- **耳、鼻、關節與氣道特徵**：
  - **外耳與內耳**：雙側或單側突發紅、腫、熱、痛，色澤呈鮮紅或紫紅色（Beefy red/violaceous）。若內聽動脈（Internal auditory artery）或耳蝸分支血管發炎，可造成感音神經性聽力喪失、眩暈、共濟失調及噁心。
  - **非侵蝕性寡/多關節炎（72%）**：呈不對稱性發作，數天至數週內自行緩解，**不造成骨骼侵蝕或關節變形**；關節液分析多為非發炎性。但胸肋、胸骨柄及胸鎖軟骨的破壞，嚴重時可致漏斗胸（Pectus excavatum）甚至連枷胸（Flail chest）。
  - **眼部發炎（59%）**：上鞏膜炎（Episcleritis）、鞏膜炎（可致眼球穿孔）、葡萄膜炎，甚至視網膜血管炎。
  - **心血管病變（10–15%）**：主動脈根部擴張導致嚴重主動脈瓣逆流（Aortic regurgitation），亦可引發未受發炎直接波及之胸主動脈或腹主動脈瘤破裂。

### 3. VEXAS 症候群：自體發炎與自體免疫交會的新典範
- **定義與基因表型**：
  - **V**acuoles（骨髓前驅細胞空泡）、**E**1 enzyme（泛素活化酶異常）、**X**-linked（X染色體聯鎖，好發於男性）、**A**utoinflammatory（自體發炎）、**S**omatic mutation（骨髓細胞後天體細胞突變）。
  - 致病基因為 *UBA1* 突變，導致泛素-蛋白酶體系統崩潰，引發不受控的天然免疫（Innate immunity）活化。
- **臨床警訊**：對於老年男性表現出復發性多軟骨炎、併發大球性貧血/MDS、反覆不明原因發燒、靜脈血栓栓塞症（VTE）及對常規免疫抑制劑極度抗藥者，必須高度懷疑此症候群。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

*註：復發性多軟骨炎為嚴重的潛在致死性自體免疫疾病，急性期與重症期必須依常規風濕免疫科指引給予全身性皮質類固醇、免疫抑制劑（如 MTX、Azathioprine）或生物製劑/氣道支架處置。以下結合功能醫學、抗老與臨床營養觀點，提供輔助保護外基質與調控慢性發炎之整合策略：*

- **功能性營養素/植化素補充（輔助軟骨基質維護與發炎調節）**：
  - **外基質與軟骨保護前驅物**：
    - **非變性二型膠原蛋白 (UC-II) 探討**：在傳統關節炎具口服免疫耐受（Oral tolerance）機制，但在 RP 處於急性免疫攻擊時應審慎評估，避免觸發抗原免疫反應；維持期可考慮提供純化硫酸葡萄糖胺（Glucosamine Sulfate 1500 mg/d）與低分子玻尿酸，為結締組織修復提供受質。
  - **NF-κB 與發炎體阻斷植化素**：
    - **高生物利用度微脂體薑黃素 (Curcuminoids 1000–1500 mg/d)**：抑制 NF-κB、下調 TNF-α 與 MMP-9，減緩軟骨蛋白聚醣分解。
    - **高純度 Omega-3 脂肪酸 (EPA/DHA 3–4 g/d)**：優化前列腺素代謝，透過專門促發炎消退介質（SPMs, Resolvins）促進組織修復。
  - **粒線體與抗氧化防護網**：
    - **N-乙醯半胱胺酸 (NAC 1200–1800 mg/d) + 硫辛酸 (ALA 600 mg/d)**：補充細胞內穀胱甘肽庫存，緩解軟骨細胞因慢性缺血-再灌流與血管炎引起的氧化損傷。

- **飲食與腸道屏障修復策略**：
  - **自體免疫消除飲食法 (Autoimmune Protocol, AIP)**：嚴格剔除麩質、精緻糖、乳製品、茄科植物與加工食品，降低腸道通透性（Leaky Gut Syndrome），阻絕外來抗原分子模擬（Molecular Mimicry）對軟骨抗原的交叉激化。
  - **多酚抗氧化多樣化飲食**：攝取富含原花青素、槲皮素之深色漿果與綠葉蔬菜，抑制肥大細胞及嗜中性球過度脫顆粒釋放彈性蛋白酶。

- **環境毒素阻斷/生活型態醫學支持**：
  - **氣道微環境保護**：因氣道黏膜纖毛清除功能受損與軟骨軟化，患者必須嚴格禁菸（包含二手菸），避免接觸揮發性有機化合物（VOCs）、粉塵與高臭氧環境；居家建議使用 HEPA 醫療級空氣清淨機。
  - **低衝擊力有氧運動與呼吸訓練**：在關節與氣道非急性發炎期，進行非承重水中有氧運動或平地步行，避免對脆弱的肋軟骨及胸廓造成撞擊外傷；配合溫和的橫膈呼吸訓練，維持胸廓順應性與肺活量。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **查核耳廓發炎界線（The "Earlobe Test"）**：視診耳部紅腫病灶時，務必確認紅腫是否**完全避開耳垂**。若邊界清晰止於耳廓軟骨邊緣且耳垂正常，高度支持復發性多軟骨炎診斷。
2. **動態氣道與發聲評估**：門診常規詢問患者是否有聲音沙啞（Hoarseness）、非生產性刺激性乾咳或吸氣喘鳴；若有異常，立即安排**動態吸/呼氣相胸部 CT** 或肺功能流量-容積曲線（Flow-volume loops），切忌貿然進行侵入性支氣管鏡，以免誘發急性氣道水腫痙攣。
3. **心臟與主動脈基線篩檢**：無論患者有無心血管症狀，初診斷時必須安排心臟超音波與主動脈影像，嚴密監控主動脈瓣關閉不全及隱匿性胸/腹主動脈瘤。
4. **男性難治型病患排查 VEXAS**：遇 50 歲以上男性患者合併難治性軟骨炎、血球發育異常（貧血/血小板低下）或血栓病史，應建議轉介血液風濕專科進行骨髓穿刺及 *UBA1* 基因檢測。
5. **眼科跨科共同照護**：患者主訴眼睛發紅或疼痛時，切勿僅當成一般結膜炎，必須立即由眼科醫師使用裂隙燈評估有無壞死性鞏膜炎或葡萄膜炎，避免視力遭受不可逆損害。
