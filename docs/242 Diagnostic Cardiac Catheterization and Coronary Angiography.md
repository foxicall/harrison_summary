# 診斷性心導管檢查與冠狀動脈攝影之臨床生理學與精準評估
- **主講人/來源**：Jane A. Leopold, David P. Faxon / *Harrison's Principles of Internal Medicine* (Chapter 242)
- **核心主旨**：心導管與冠狀動脈攝影為評估心臟解剖構造與血流動力學的黃金標準；臨床醫師應結合生理學功能評估（FFR/iFR/CFR）與高解析腔內影像（IVUS/OCT），並於術前術後精準阻斷顯影劑腎毒性、血管併發症與發炎氧化壓力，落實全人血管健康管理。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **血管內皮損傷與斑塊易損性（Plaque Vulnerability）**：動脈粥狀硬化非單純管腔狹窄，而是由慢性低度全身性發炎、脂質浸潤（特別是富含脂質核心）及巨噬細胞活化所驅動；薄帽纖維粥樣斑塊（TCFA）破裂及血栓形成是急性冠心症（ACS）的終極發病機制。
  - **微血管功能障礙（Coronary Microvascular Dysfunction, CMD）**：無阻塞性冠狀動脈缺血（INOCA）常源於微血管內皮功能受損與血管舒張儲備下降（CFR < 2.0），代表微循環層面的代謝失衡與氧化壓力累積。
  - **對比劑誘發急性腎損傷（CI-AKI）**：高滲透壓顯影劑進入腎髓質造成嚴重血管收縮、自由基（ROS）爆發性增生、髓質缺氧及直接腎小管上皮細胞毒性。
  - **鐵過載之心肌毒性（Iron Overload Cardiomyopathy）**：如血色病（Hemochromatosis），過量游離鐵離子藉由芬頓反應（Fenton reaction）產生大量羥自由基（·OH），導致心肌粒線體膜電位崩解與纖維化（CMR T2* < 20 ms 提示重度沉積）。
- **演講亮點與臨床洞察**：
  - **解剖與功能的範式轉移**：冠狀動脈造影的「視覺狹窄度（% stenosis）」常高估病變嚴重度。生理學指標（FFR < 0.80 或 iFR < 0.89）方為決定血流重建（Revascularization）預後之關鍵準則。
  - **高解析度腔內影像之互補性**：IVUS 提供深度組織穿透力與全層血管結構評估；OCT 則以近紅外線提供 12–18 μm 極高解析度，能精準洞察易損斑塊之薄纖維帽、巨噬細胞浸潤與微血栓。
  - **顯影劑腎毒性之精準防禦**：N-乙醯半胱氨酸（NAC）在臨床試驗中效果不一致已不作常規推薦；嚴格落實術前 3–12 小時至術後 6–24 小時之 0.9% 等滲食鹽水（1.0–1.5 mL/kg/h）充分擴容，可降低 >50% CI-AKI 風險。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **冠狀動脈血流儲備分數 (FFR)** | 評估心肌缺血之功能性金標準（Adenosine 誘發最大充血） | **< 0.80** 具顯著血流動力學意義，建議介入處置 |
| **瞬時無波形比率 (iFR)** | 舒張晚期無波期血流儲備評估（無需 Adenosine，適合氣喘者） | **< 0.89** 判定為心肌缺血陽性 |
| **冠狀動脈血流儲備 (CFR)** | 評估心臟微血管內皮功能與微循環狀態（排除大血管阻塞後） | **< 2.0** 提示微血管功能障礙（CMD / INOCA） |
| **心肌/肝臟 T2* CMR** | 評估鐵沉積性心肌病變/氧化壓力（血色病篩檢） | 心肌 T2* **< 20 ms** 代表鐵沉積毒性；重度病變可低至 10 ms |
| **血清肌酸酐 (Serum Creatinine)** | CI-AKI 監測指標（造影後 48–72 小時評估） | 術後上升 **>0.5 mg/dL** 或高於基準值 **>25%** 即定義為 CI-AKI |
| **肺血管阻力 (PVR)** | 評估肺動脈高壓之血管張力與可逆性 | 正常值 **40–120 dyn·s/cm⁵**；需測試吸入 NO 或前列環素之反應 |
| **Gorlin / Hakki 瓣膜面積** | 評估主動脈瓣/二尖瓣狹窄之嚴重度 | 主動脈瓣 **<1.0 cm²** 且平均壓差 **>40 mmHg** 提示重度 AS |
| **分流率 (Qp/Qs)** | 評估先天性心臟病心內分流之血流動力學負荷 | ASD **> 1.5**、VSD **≥ 2.0**（伴隨 LV 容量過負荷）為強烈手術指徵 |

## 三、 關鍵機制詳解與投影片重點筆記

- **心導管血流動力學波形剖析與鑑別診斷**：
  - **主動脈狹窄 (AS) vs. 肥厚型阻塞性心肌病變 (HOCM)**：
    - AS 表現為固定之收縮期左心室-主動脈壓力差（LV-Ao Gradient）。
    - HOCM 表現為動態心室內壓力差，具有典型的 **Brockenbrough-Braunwald 徵象**：在心室早期收縮（PVC）後，心肌收縮力增強使流出道阻塞加劇，導致 LV-Ao 壓力差上升，但同時主動脈脈搏壓（Pulse Pressure）反而下降。
  - **心包填塞、縮窄性心包膜炎與限制型心肌病變鑑別**：
    - *心包填塞 (Tamponade)*：心包腔壓力升高，右房壓升高伴隨「x」降凹明顯，但「y」降凹變平或消失（舒張受限），各心室舒張末期壓力均等化。
    - *縮窄性心包膜炎 (Constrictive Pericarditis)*：右房壓升高伴隨深陡的「y」降凹；心室壓力波出現舒張早期快速充盈充血下降與平台期（**Dip and Plateau / Square root sign**）；吸氣時左右心室收縮壓呈現**心室不協調性（Ventricular Discordance）**（吸氣時 RV 壓力上升、LV 壓力下降，具高度特異性）。
    - *限制型心肌病變 (Restrictive Cardiomyopathy)*：RV 收縮壓通常 >60 mmHg，吸氣時左右心室壓力呈**同向協調性（Concordant）**，LV 與 RV 舒張末期壓差通常 ≥5 mmHg。

- **血管腔內影像與功能生理學（IVUS vs. OCT vs. FFR）**：
  - **IVUS（血管內超音波）**：穿透深度達 4–8 mm，適合評估血管總外徑、外彈性膜截面積（EEM）、斑塊負荷（Plaque Burden）與開口處（Ostial）病變。
  - **OCT（光學同調斷層掃描）**：利用波長 1300 nm 近紅外線，空間解析度高達 12–18 μm（約為 IVUS 的十倍）。能精準鑑別：
    - *纖維斑塊*：高訊號、均質均勻。
    - *脂質斑塊*：光線吸收強，邊界不規則之低訊號暗區；當纖維帽厚度 <65 μm 時定義為薄帽纖維粥樣斑塊（TCFA），屬於高度破裂風險斑塊。
    - *血栓形成*：突出於管腔之不規則團塊，紅血球血栓伴後方陰影，血小板血栓呈低衰減。
    - *支架貼壁不良（Malapposition）*：精確測量支架鋼樑與內皮間隙。

- **對比劑急性腎損傷（CI-AKI）與圍手術期風險管理**：
  - 高危險因子包括：糖尿病、CKD、失代償性心衰竭、高齡、貧血、STEMI 伴隨血流動力學不穩定。
  - **Metformin 併發乳酸中毒防範**：術前 24 小時停用，術後 48 小時確認腎功能穩定後方可恢復。
  - **抗凝與抗血小板停藥節奏**：Warfarin 術前 2–3 天停藥（目標 INR <1.7）；DOAC 需於術前 24–48 小時停藥；常規術前給予 Aspirin 325 mg 負荷，擬行 PCI 者即刻併用 P2Y12 抑制劑（Ticagrelor 或 Clopidogrel；Prasugrel 禁用於 TIA/中風史及 ≥75 歲高齡者）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **功能性營養素/植化素與腎臟保護處方**：
  - **內源性抗氧化儲備強化（針對顯影劑暴露）**：
    - *活性穀胱甘肽前驅物*：雖然口服 NAC 臨床試驗數據異質性高，但對於代謝症候群患者，藉由脂質體穀胱甘肽（Liposomal Glutathione, 500–1000 mg/d）或高生物利用度 S-乙醯穀胱甘肽，配合甘胺酸（Glycine 3–5 g/d），有助於降低粒線體 ROS 損傷。
    - *維生素 C 與 E*：術前短期高劑量水溶性維生素 C（2–3 g）可作為抗氧化輔助劑，保護腎小管內皮免受缺血再灌流傷害。
    - *CoQ10（泛醇型 Ubiquinol 200–400 mg/d）*：提升心肌與血管內皮細胞粒線體 ATP 生成效率，改善微循環血流。
  - **微血管內皮修復支持（針對 CFR < 2.0 之 INOCA 患者）**：
    - *一氧化氮（NO）途徑促進劑*：L-精胺酸（L-Arginine 3–6 g/d）或 L-瓜胺酸（L-Citrulline 3 g/d），搭配高濃度甜菜根萃取物與富含多酚之碧容健（Pycnogenol 100–200 mg/d），恢復微血管舒張儲備。

- **飲食與水合保護策略**：
  - **積極水合協議（Hydration Protocol）**：
    - 術前 3–12 小時至術後 6–24 小時，採用等滲透壓 0.9% 氯化鈉輸注（1.0–1.5 mL/kg/h）；門診低風險病患應鼓勵術後攝取足量水分（>2000–3000 mL/天），促進顯影劑滲透性利尿排泄。
  - **抗炎抗粥狀硬化飲食架構**：
    - 採用**低升糖、高植化素地中海-心血管保護飲食**：降低氧化型低密度脂蛋白（ox-LDL）與晚期糖化終產物（AGEs）。
    - 嚴格排除超加工食品、反式脂肪與高果糖玉米糖漿，保護微血管壁糖萼（Endothelial Glycocalyx）。

- **環境毒素阻斷/代謝排毒/生活型態**：
  - **重金屬與鐵過載清除**：
    - 針對鐵沉積（CMR 提示 T2* < 20 ms）患者，積極配合心臟科與血液科進行放血（Phlebotomy）或鐵螯合治療（如 Deferasirox）；功能醫學臨床應監測血清鐵蛋白（Ferritin）與運鐵蛋白飽和度（Transferrin Saturation），避免過度鐵沉澱引發自由基風暴。
  - **游離輻射防護與粒線體修復**：
    - 心導管檢查累積劑量 >2 Gy 需監測紅斑，>5 Gy 需於 1 個月內追蹤皮膚放射損傷。
    - 術後可藉由紅外線低能量光療（PBM）、富氫水（Hydrogen-rich water）及褪黑激素（Melatonin 10–20 mg 睡前），降低電離輻射引發之雙鏈 DNA 斷裂與系統性氧化壓力。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實經橈動脈途徑（Radial First）策略**：
   - 優先選擇橈動脈作為血管通路，術前必備異常篩檢（Barbeau 試驗或改良 Allen's 試驗），可顯著降低 1.5–2.0% 之穿刺部位大出血與後腹腔血腫風險，並縮短臥床時間至 2 小時。
2. **貫徹顯影劑減量與目標導向水合**：
   - 嚴格控制顯影劑總量 <50 mL（或對比劑體積/估算 GFR 比值 <3.7）；對高危險族群落實生理食鹽水 1.0–1.5 mL/kg/h 輸注，術前 24 小時確實停用 Metformin。
3. **跳脫純解剖狹窄迷思，整合微循環評估**：
   - 面對 40–70% 中度冠脈狹窄時，應常規使用 FFR/iFR 決定是否置放支架；若病患有明顯心絞痛但造影無阻塞，務必加測 CFR 與 IMR，精準捕捉微血管功能障礙（CMD）。
4. **精準用藥與凝血抗板管理**：
   - 根據年齡與病史精準選擇 P2Y12 抑制劑（高齡 ≥75 歲或有中風病史者停用 Prasugrel）；DOAC 依半衰期於術前 24–48 小時停藥，Warfarin 監測 INR 降至 <1.7 後方可穿刺。
