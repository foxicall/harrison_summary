# 非結核分枝桿菌（NTM）感染症：免疫路徑缺失、環境暴露與全人整合臨床策略
- **主講人/來源**：Steven M. Holland, MD（Harrison's Principles of Internal Medicine, 21st Edition, Chapter 180）/ 180 Nontuberculous Mycobacterial Infections.pdf
- **核心主旨**：非結核分枝桿菌（NTM）廣泛存在於自然與人造水土環境中；其致病關鍵非病原體之高毒力，而是宿主局部上皮屏障破損（如支氣管擴張症）或全身性細胞免疫軸線（特別是 IFN-γ / IL-12 / TNF-α 訊息傳遞路徑與自體抗體）的機能失調。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **先天與細胞免疫軸線崩解**：NTM 的胞內清除完全依賴「巨噬細胞—T細胞/NK細胞」的交互活化循環。巨噬細胞吞噬 NTM 後釋放 IL-12（p35/p40 異合體），經由 IL-12R（β1/β2）刺激 STAT4，誘發 IFN-γ 分泌；IFN-γ 結合 IFN-γR1/R2 後經 STAT1 磷酸化，活化巨噬細胞產生活性氧分子（ROI）、高親和力 Fc 受體與 TNF-α，形成強大殺菌肉芽腫。任何環節的先天突變（如 *IFNGR1/2*, *STAT1*, *IL12RB1*, *IKBKG/NEMO*, *CYBB* 等）或後天性抗 IFN-γ 中和抗體，皆會瓦解此防禦網絡，導致散播性致命感染。
  - **局部上皮屏障與纖毛清除障礙**：肺部感染極少發生於全身免疫正常者，但高度聚集於結構性肺病患者（如支氣管擴張症、囊球性纖維化、纖毛運動不能症）。結構異常導致黏液蓄積與局部微環境發炎，使 NTM 得以定植並形成「樹芽徵（Tree-in-bud）」與空洞性破壞。

- **演講亮點與臨床洞察**：
  - **溫德米爾夫人症候群（Lady Windermere Syndrome）**：臨床好發於體型瘦高、胸廓異常（漏斗胸、脊椎側彎）、無吸菸史的停經後女性，常合併二尖瓣脫垂；其病程極為隱匿，從咳嗽、清喉嚨至確診常延遲長達 5 年以上，常同時感染多種 MAC（*Mycobacterium avium* complex）菌株。
  - **成人發病型免疫缺陷（東亞女性特別好發）**：無 HIV 感染且無家族原發性免疫缺陷的東亞女性，若發生快速生長型分枝桿菌（如 *M. abscessus*）廣泛散播感染，需高度懷疑體內存在高力價「抗 IFN-γ 中和自體抗體」，此時常規 IGRA 檢驗會呈現未定（Indeterminate）偽陰性反應。
  - **鑑別帶菌與實質疾病**：呼吸道分離出 NTM（如 *M. gordonae* 常為環境共生菌）不等於需要長期抗生素治療，必須嚴格依據臨床、高解析度電腦斷層（HRCT）及至少兩次獨立痰液或支氣管洗液陽性培養標準。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **高解析度胸部 CT (HRCT)** | 評估小氣道浸潤、支氣管壁增厚、中葉/舌葉受累與空洞化 | 出現特徵性「樹芽徵 (Tree-in-bud)」及結節性支氣管擴張即具診斷意義 |
| **抗酸性染色與 NTM 分離培養** | 確定是否具活動性病原菌（需區分快速生長型 `<7天` 與慢速生長型 `≥7天`） | ATS 準則：至少 **2 次獨立陽性痰培養**，或 **1 次支氣管鏡肺泡灌洗液陽性** |
| **藥物感受性試驗 (AST)** | 評估有效抗生素標靶，避免單藥治療誘發抗藥性基因突變 | **MAC 必驗克拉黴素 (Clarithromycin)**；***M. kansasii* 必驗利福平 (Rifampin)** |
| **干擾素釋放試驗 (IGRA) 與 PPD** | 評估結核分枝桿菌共病或鑑別診斷 | *M. marinum* / *M. kansasii* / *M. szulgai* 具 ESAT-6/CFP-10 蛋白，可致 **IGRA 偽陽性**；PPD >15 mm 仍高度提示結核 |
| **中和性抗 IFN-γ 自體抗體檢測** | 評估無 HIV 背景之快速生長型或散播性 NTM 病患（常見於東亞成人女性） | 出現高力價中和抗體（常伴隨 IGRA 結果無法判讀/Indeterminate） |
| **全血 CD4+ T 淋巴球絕對計數** | 評估宿主後天免疫功能狀態（散播性 MAC 感染高危族群） | **CD4+ < 50/μL** 需立即啟動預防性投藥 |
| **免疫基因定序 (Mendelian Susceptibility)** | 評估兒童非醫源性多器官散播性感染或骨髓炎之先天缺陷 | 篩檢 *IFNGR1*, *IFNGR2*, *STAT1*, *IL12RB1*, *GATA2*, *IKBKG* 等基因變異 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 宿主防禦核心：IFN-γ / IL-12 / TNF-α 免疫反饋迴路（Figure 180-1 深度剖析）
- **巨噬細胞與 NK/T 細胞串聯**：
  - 巨噬細胞（MΦ）吞噬抗酸桿菌（AFB）後，透過 TLR/CD14 路徑及細胞內訊息活化，釋出異合體 IL-12（p35 + p40）。
  - IL-12 結合至 T/NK 細胞表面受體（IL-12Rβ1 + IL-12Rβ2/IL-23R），促使 **STAT4 磷酸化**，啟動同合體 **IFN-γ** 的大量轉錄與分泌。
  - IFN-γ 結合巨噬細胞的受體複合物（IFN-γR1 與 IFN-γR2），引發 **STAT1 磷酸化**，下游活化 IRF8、ISG15，促使細胞產生溶酶體酵素、ROI（NADPH 氧化酶複合物，由 *CYBB* 編碼之 gp91phox 參與）並向上調控 TNF-α 與 IL-12。
- **TNF-α 與 NF-κB 的協同殺菌**：
  - 同三聚體 TNF-α 結合至 TNFαR，藉由下游含 NEMO（由 *IKBKG* 編碼）的活化複合物觸發 NF-κB 核移位，驅動成熟肉芽腫之形成與維持。
  - **臨床警示（醫源性免疫抑制）**：生物製劑阻斷 TNF-α（如 Infliximab、Adalimumab、Certolizumab、Golimumab 或可溶性受體 Etanercept）會直接拆解肉芽腫結構，大幅釋放潛伏的 NTM 或真菌，引發猛爆性播散。

```
[巨噬細胞 MΦ 吞噬 NTM] 
         │
         ▼ (釋放 IL-12)
[T / NK 淋巴細胞] ──(STAT4 活化)──► [分泌 IFN-γ]
         ▲                               │
         │                               ▼ (結合 IFN-γR1/R2)
[釋放 TNF-α ──► NEMO/NF-κB 活化] ◄── [STAT1 磷酸化 (巨噬細胞殺菌/ROI/MHC)]
```

### 2. 環境暴露與器官特異性表現型
- **肺部表型（占歐美與工業化國家之絕大多數）**：
  - **MAC（鳥型分枝桿菌複合群）**：占北美肺部感染大宗，女性好發於 60 歲左右，結節性支氣管擴張型患者多同時攜帶多種不同 MAC 菌株，且隨病程變異；男性吸菸者則偏向上葉開洞型病灶，常為單一菌株終身帶菌。
  - ***M. kansasii* 感染**：臨床及影像極度類似典型肺結核（發燒、咳血、胸痛、開洞），對三合一藥物反應極佳，通常治癒率高。
  - ***M. abscessus* 感染**：快速生長型（<7天培養陽性），常與食道動力障礙（如賁門弛緩不能 Achalasia）導致的微量吸入相關，對傳統抗生素抗藥性極高，最難治癒。
- **非肺部與局部接觸型感染**：
  - **水浴池與美甲沙龍**：*M. fortuitum* 與 *M. abscessus* 常在腿部刮毛造成的微小創口後，經由足浴水缸侵入，造成疼痛、紅腫、化膿但無全身性發燒的皮下肉芽腫結節。
  - **水族箱肉芽腫（Fish-tank Granuloma）**：*M. marinum* 嗜低溫（30°C），經由接觸魚缸、水族生物或海鮮微外傷感染，可沿淋巴管呈孢子絲菌樣（Sporotrichoid spread）向上蔓延，常波及腕關節滑囊與肌腱。
  - **布魯里潰瘍（Buruli Ulcer）**：由 *M. ulcerans* 引起（熱帶/西非多見），菌體分泌具免疫抑制性的外毒素 **Mycolactone**，造成無痛性、大面積壞死潰瘍及骨髓炎。
  - **溫水浴肺（Hot-tub Lung）**：並非真正全身性侵入感染，而是因室內密閉熱水浴缸未適度氯化消毒，導致大量吸入 MAC 氣膠誘發的**肺部過敏性肺炎反應（Hypersensitivity pneumonitis）**。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 常規抗生素聯合治療原則（抗抗藥性黃金法則）
*特別聲明：NTM 嚴禁單藥治療，單一抗生素極易誘發不可逆抗藥性與治療失敗。*
- **肺部 MAC 感染**：
  - **三合一基礎處方**：巨環類抗生素（Azithromycin 500 mg 3次/週 或 Clarithromycin 1000 mg/天）+ Ethambutol（15 mg/kg）+ 利福黴素（Rifampin 600 mg 或 Rifabutin）。
  - **療程規範**：必須於**痰液培養轉陰後持續服用至少 12 個月**，總療程一般長達 18 至 24 個月以上。難治型或空洞性病變可評估吸入型阿米卡星（Inhaled Amikacin）或手術切除。
- ***M. kansasii* 感染**：
  - 處方：Isoniazid (300 mg/d) + Rifampin (600 mg/d) + Ethambutol (15 mg/kg/d)。治療直至培養轉陰滿 1 年。
- ***M. abscessus* 難治型感染**：
  - 需依藥敏測試，初期多併用靜脈注射藥物（Amikacin、Cefoxitin、Carbapenem、Tigecycline）與口服巨環類、Clofazimine、Linezolid、Omadacycline 等複合療程。

### 2. 功能性營養與藥物毒性阻斷策略
- **周邊神經保護與代謝支持**：
  - **吡哆醇（維生素 B6, Pyridoxine / P-5-P）**：長期使用 Ethambutol、Isoniazid 或 Linezolid 易破壞維生素 B6 代謝，導致嚴重視神經炎或周邊神經病變。常規建議每日補充 **Pyridoxine 50–100 mg** 作為神經保護性阻斷劑。
- **巨噬細胞吞噬與殺菌輔助營養素**：
  - **維生素 D3 與 維生素 A**：誘導巨噬細胞分泌抗菌胜肽（Cathelicidin / LL-37），促進吞噬泡與溶酶體融合。建議維持血清 25(OH)D 於 **50–80 ng/mL**。
  - **鋅（Zinc）與 硒（Selenium）**：NADPH 氧化酶（*CYBB* 產物）及抗氧化酵素之重要輔因子，協助維持吞噬細胞產生活性氧殺滅胞內菌之能力，同時減輕鄰近正常肺實質之二次氧化傷害。
- **長期抗生素下的腸道微生態重塑**：
  - 由於療程長達 1.5–2 年，強效抗生素將重創腸道菌相與屏障機能。應在抗生素服用間隔 2–4 小時補充經臨床驗證之高劑量多元益生菌（如 *Saccharomyces boulardii* 及乳酸桿菌屬），並監控腸漏症與黴菌過度生長現象。

### 3. 環境毒素阻斷與呼吸道物理防護
- **水質與氣膠暴露管制**：
  - 避免使用室內無適當通風與殺菌之加溫熱水按摩浴池（Hot tub），預防吸入性過敏性肺炎。
  - 清理水族箱、處理生鮮魚貝類或戶外園藝耕作時，必須配戴防水手套，預防皮膚微小傷口接觸 *M. marinum*。
  - 美容沙龍美甲、刮毛後避免立即泡入公共足浴池，嚴格杜絕非醫療無菌針劑或未消毒器械之注射。
- **呼吸道廓清與排痰工程**：
  - 針對支氣管擴張及纖毛運動障礙者，機械性清除分泌物是阻斷 NTM 定植之第一道防線。每日執行體位引流、震盪排痰閥（PEP device）及高張食鹽水（3%–7% Hypertonic saline）吸入化痰，減少黏液鬱積。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實診斷標準，切忌見菌就打**：  
   呼吸道檢體中若分離出 NTM（特別是 *M. gordonae*），先對照 ATS 診斷指引（症狀 + HRCT 影像 + 至少 2 套獨立陽性痰檢體）。切勿因單次培養陽性即貿然開立具毒性之長期抗生素。
2. **警覺特殊體型與族群表現（Lady Windermere 徵候群）**：  
   面對身材瘦高、停經後女性，伴隨慢性咳嗽、清喉嚨數月至數年未癒者，應主動安排胸部 HRCT 篩檢中葉/舌葉小氣道發炎（樹芽徵）及支氣管擴張，並採集晨痰送分枝桿菌專用培養。
3. **青年或兒童播散感染：必查 IFN-γ/IL-12 先天免疫缺陷**：  
   非 HIV 感染之年輕患者若出現多器官感染（如骨髓炎、多發性淋巴結腫大），必須進行全外顯子定序或免疫基因檢測（檢驗 *IFNGR1/2*, *STAT1*, *IL12RB1*, *GATA2* 等）。
4. **東亞成年女性猛爆感染：檢驗抗 IFN-γ 自體抗體**：  
   東亞成年患者若罹患嚴重或散播性快速生長型分枝桿菌（如 *M. abscessus*），且 IGRA 出現 Indeterminate，高度提示中和性抗 IFN-γ 抗體症候群，治療策略可能需合併免疫調節（如抗 B 細胞療法 Rituximab）。
5. **長程治療之藥物安全與毒性監控清單**：  
   MAC/NTM 療程長達 18 個月以上，使用 Ethambutol 期間需每月監控視力與色溫辨識（防視神經炎）；使用 Linezolid/Ethambutol 務必常規搭配維生素 B6 防護；合併 Macrolide 時定期追蹤心電圖 QTc 間期與聽力。
