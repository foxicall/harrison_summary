# 絛蟲感染症（Cestode Infections）：從分子病理、臨床神經影像至功能性腸腦軸重構之全方位臨床指引
- **主講人/來源**：A. Clinton White, Jr., Peter F. Weller / 235 Cestode Infections.pdf
- **核心主旨**：絛蟲感染跨越「腸道寄生」至「組織侵襲（神經囊蟲病、棘球蚴病）」兩大範疇；臨床需結合高解析神經影像分期、宿主免疫發炎調控（避免抗蟲引發致命發炎破壞）及關鍵微量營養素（特別是維生素 B12）之修復整合。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **宿主角色雙重性與組織侵犯**：人類可作為最終宿主（成蟲定植於腸黏膜，如 *T. saginata*、*D. latus*）或中間宿主（六鉤蚴穿透腸壁經血流散播至大腦、肝臟、肌肉形成囊尾蚴或棘球囊腫，如 *T. solium*、*Echinococcus* spp.）。
  - **抗原釋放引發之劇烈神經與全身發炎**：組織型囊腫（如神經囊蟲病、肝包蟲囊腫）破裂或在抗寄生蟲藥物治療期間釋放高抗原性囊液，會誘發 Th2/嗜酸性球激增、細胞因子風暴、嚴重大腦血管炎、蛛網膜炎或致死性過敏性休克（Anaphylaxis）。
  - **微生態破壞與微量營養素掠奪**：腸道型成蟲（如廣節裂頭絛蟲 *D. latus*）在迴腸競爭性掠奪大量維生素 B12，造成甲基化路徑中斷、同半胱胺酸堆積、惡性貧血及神經去髓鞘退化。
- **演講亮點與臨床洞察**：
  - **神經囊蟲病（Neurocysticercosis, NCC）治療的典範轉移**：治療核心並非立即「殺蟲」，而是**先評估顱內壓與控制癲癇**。在死蟲崩解誘發嚴重腦水腫的風險下，抗寄生蟲藥物（Albendazole/Praziquantel）**必須在全身性皮質類固醇掩護下使用**，且合併 Praziquantel 時應使用 Cimetidine 抑制類固醇加速的肝臟首渡代謝。
  - **超音波分期導向的包蟲囊腫精準介入（WHO Staging）**：對於 *E. granulosus* 囊腫，嚴格依據 CE1 至 CE5 分期決定是採取藥物、PAIR 術式（穿刺-抽吸-注入化滅劑-再抽吸）、根除手術或單純觀察。
  - **自體感染（Autoinfection）循環**：微小膜殼絛蟲（*H. nana*）不需中間宿主即可在人體內反覆自體孵化繁衍；有囊蟲病疑慮的豬肉絛蟲帶原者嚴禁自體糞口接觸，以防繼發致命性組織囊蟲病。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **高解析度腦部 MRI (FIESTA / 3D CISS) 與 CT** | 評估腦實質/腦室/蛛網膜下腔囊蟲數、囊壁狀態、頭節（Scolex）存在與否及鈣化結節（CT 對鈣化敏感度較佳） | 明確辨認囊內頭節（Scolex）為確診之絕對條件；腦室/蛛網膜囊腫需嚴防腦積水 |
| **血清酵素免疫轉印法 (EITB - Lentil Lectin)** | 檢測特異性抗囊蟲醣蛋白抗體；評估全身性免疫接觸與活動性感染（敏感度與特異度 >99%） | 陽性具高度診斷價值（註：單一顱內病灶或已鈣化陳舊病灶可能呈現偽陰性） |
| **血清/CSF 寄生蟲抗原檢測 (Monoclonal Ab ELISA)** | 區分活動性組織囊腫或死滅囊腫；作為治療後發炎與殘存病灶追蹤工具 | 治療後數值應顯著下降；持續陽性代表仍有活體囊腫存在 |
| **腹部超音波 / CT (WHO-IWGE 分期)** | 評估肝臟包蟲囊腫（CE1–CE5）之活動性、內生子囊（Daughter cysts）及包膜完整性 | CE1/CE2/CE3 為活動/過渡期；CE4/CE5 為凝固/厚鈣化之無活性病灶 |
| **血清維生素 B12、同半胱胺酸 (Hcy) 與 MMA** | 評估廣節裂頭絛蟲（*D. latus*）造成的嚴重維生素 B12 耗竭與甲基化代謝障礙 | 血清 B12 < 200 pg/mL；功能性評估 MMA 上升、Hcy > 10 μmol/L |
| **全血嗜酸性球計數 (AEC) & 總 IgE** | 評估組織侵襲期或囊液外漏誘發之第 2 型輔助 T 細胞（Th2）過敏性發炎反應 | 腸道成蟲感染常正常；組織侵入或囊腫破裂時嗜酸性球顯著上升 |
| **糞便常規檢查與顯微鏡檢（蟲卵/節片）** | 鑑別 *Taenia* 卵（厚棕色輻射紋理）、孕節子宮分支計數（*T. saginata* 15–30 支 vs *T. solium* 8–12 支） | 檢出蟲卵或節片以確立腸道成蟲定植診斷（必要時採用透明膠帶肛圍採樣） |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 組織型囊蟲病（Cysticercosis）與神經囊蟲病（NCC）之病理轉機
- **致病路徑**：人類攝入*豬肉絛蟲（Taenia solium）*的蟲卵（來自受污染水源、食物或自體肛門-口腔途徑），蟲卵在十二指腸釋出六鉤蚴（Oncosphere），穿透腸道基底膜經血液循環擴散至腦實質、腦室、蛛網膜下腔、骨骼肌或眼底（Subretinal space）。
- **神經破壞與發炎級聯**：
  - **活囊期（Viable cysts）**：幼蟲具免疫逃避機制，囊壁薄、周圍幾無免疫發炎反應，患者可長期無症狀。
  - **退化與死亡期（Degenerating cysts）**：幼蟲死亡導致抗原暴露，啟動宿主劇烈細胞免疫。組織病理表現為囊周大量淋巴球、嗜酸性球浸潤及肉芽腫形成，影像呈現環狀顯影（Ring enhancement）及血管性腦水腫，引發局灶性或全身性癲癇發作。
  - **鈣化期（Calcified nodules）**：發炎消退後留下鈣化病灶（CT 顯影極佳），但局部膠質瘢痕仍具致癲癇性。
  - **蛛網膜下腔與腦室病變**：巨大分葉狀囊腫（Racemose cysts）壓迫基底腦膜或阻塞第四腦室導水管，引發慢性無菌性腦膜炎、血管炎性腦中風與致命性阻塞性/交通性腦積水。

```
[攝入 T. solium 蟲卵]
       │
       ▼
[六鉤蚴侵入腸壁微血管] ──> 血液播散 (中樞神經系統、眼睛、骨骼肌)
       │
       ├──> [活囊期]: 免疫偽裝、無明顯周圍水腫
       │
       ├──> [自然退化 / 抗蟲藥物攻擊]: 釋放大量蟲體抗原
       │           │
       │           ▼
       │     [劇烈周圍發炎]: 腦水腫、血管炎、蜘蛛膜炎
       │           │
       │           ▼
       │     [臨床急症]: 頑固型癲癇、顱內壓增高 (ICP)、腦積水
       │
       └──> [終末鈣化結節]: 形成致癲癇永久膠質瘢痕
```

### 2. 棘球蚴病（包蟲病，Echinococcosis）之侵襲與囊腫動力學
- **單房性囊型包蟲（*E. granulosus*）**：
  - 幼蟲在肝臟（占 2/3）或肺部形成單房性液態囊腫。結構外層為宿主纖維包膜，中層為無細胞角質層（Laminated membrane），內層為發育出原頭節（Protoscolices）與育囊的生發層（Germinal layer）。
  - **棘球砂（Hydatid sand）**：囊液中脫落的原頭節、育囊及鉤環。囊腫破裂時，棘球砂可沿腹腔播散形成廣泛繼發性種植，並伴隨嚴重的第 1 型過敏性休克。
- **多房性泡型包蟲（*E. multilocularis*）**：
  - 表現具「腫瘤樣（Malignant-like）」浸潤特性，生發層缺乏完整角質包膜保護，以出芽生長方式侵蝕破壞肝實質、浸潤下腔靜脈、橫膈或遠端轉移至肺、腦，致死率高。

### 3. 腸道型絛蟲之代謝奪取：廣節裂頭絛蟲（*Dibothriocephalus latus*）與甲基化崩解
- **掠奪機制**：成蟲最長可達 25 公尺，寄生於迴腸，其表面微毛特異性吸附並消耗宿主食糜中高達 80% 至 100% 的維生素 B12，同時阻礙內在因子-B12 複合物與迴腸受體結合。
- **神經毒性與代謝表型**：
  - 導致嚴重的甲基丙二酸（MMA）累積，抑制脂肪酸合成，造成脊髓後角與側索亞急性聯合變性（SCD，去髓鞘病變）。
  - 巨幼紅血球性貧血（Megaloblastic anemia）伴隨高同半胱胺酸血症，抑制肝臟硫轉移解毒途徑，誘發血管內皮慢性發炎。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 現代醫學精準驅蟲與抗炎協同方案（Conventional & Integrative Protocols）

```
[神經囊蟲病 (NCC) 介入流程]
       │
       ├─ Step 1: 癲癇控制 (抗癲癇藥 AEDs) + 評估顱內壓 (降腦壓/引流)
       │
       ├─ Step 2: 免疫屏障防護 ──> 投予高劑量類固醇 (Dexamethasone/Prednisone)
       │                            (嚴防殺蟲引發腦水腫爆發)
       │
       └─ Step 3: 雙聯抗蟲治療 ──> Albendazole (15 mg/kg/d) + Praziquantel (50 mg/kg/d)
                                    + Cimetidine (阻斷類固醇引起的藥物代謝耗損)
```

- **神經囊蟲病（NCC）治療架構**：
  - **控制急性顱內發炎優先於殺蟲**：禁止在瀰漫性腦水腫、腦炎或未受控制的顱內高壓狀態下直接投予殺寄生蟲劑。
  - **皮質類固醇掩護**：治療初期必須全程給予高劑量 Dexamethasone 或 Prednisone，阻斷蟲體崩解時釋放抗原所造成的局部致命性腦炎。
  - **藥物代謝交互作用調控**：高劑量類固醇會大幅誘導細胞色素 P450，使 Praziquantel 的血中濃度銳減；臨床必須**協同併用 Cimetidine**（H2 受體拮抗劑）以抑制 Praziquantel 的肝臟第一首渡代謝，確保中樞藥效。
  - **雙聯驅蟲方案**：對於具 2 顆以上活動性囊腫之病患，併用 Albendazole（15 mg/kg/d，分兩次）+ Praziquantel（50 mg/kg/d，分三次）療效顯著優於單藥治療。
- **肝包蟲囊腫 PAIR 術式保護**：
  - 術前至少 2 天至術後 4 週持續投予 Albendazole（15 mg/kg/d），嚴防穿刺針路或腹膜腔溢漏造成繼發性二次種植。
  - 嚴格禁用於與膽道相通之囊腫（化滅劑注入可能誘發硬化性膽管炎）或表淺囊腫。

### 2. 營養醫學與微量元素深層重構（Functional Nutrition Repletion）
- **甲基化重建治療（針對 *D. latus* 感染後遺症）**：
  - **注射型甲鈷胺（Methylcobalamin）**：初期每日 1000 μg 肌注連續一至兩週，後續轉為每週一次，直到血液與神經功能穩定；避免純口服以繞過破損之迴腸吸收障礙。
  - **活性葉酸（5-MTHF）與膽鹼（Choline）協同**：提供 800–1000 μg 5-MTHF，搭配甜菜鹼（TMG）與磷脂醯膽鹼，修復神經鞘磷脂代謝，快速壓降發炎性同半胱胺酸。
- **腸道黏膜障壁與免疫修復矩陣**：
  - **L-麩醯胺酸（L-Glutamine）**：5–10 g/day，修復受絛蟲頭節吸盤（Suckers/Hooks）物理性破壞的腸絨毛微環境。
  - **肌肽鋅（Zinc Carnosine）**：75 mg bid，強化腸上皮細胞緊密連接（Tight junctions），封堵寄生蟲排泄分泌產物（ESPs）誘發的腸漏（Leaky gut）。
- **天然植物性驅蟲輔助與生物膜降解（非急性期功能支持）**：
  - **南瓜子萃取（Cucurbitine）**：使腸道吸盤麻痺放鬆，有利於常規驅蟲後的成蟲整體排出。
  - **黑核桃皮（Black Walnut Hull）與黃連素（Berberine）**：輔助抑制殘存小腸共生菌失衡（SIBO）與二次酵母菌過度增生。

### 3. 環境阻斷與生活型態醫學（Environmental & Exposure Controls）
- **生物熱力學殺菌標準**：
  - 牛肉與豬肉內部核心溫度必須加熱至 **56°C 以上維持 5 分鐘**；或經冷凍處理：**–10°C 至少冷凍 9 天**，方可徹底破壞肉質深處之囊尾蚴。
  - 淡水魚類（預防裂頭絛蟲）：烹煮加熱至 **54°C 以上維持 5 分鐘**，或於 **–18°C 冷凍 24 小時以上**。
- **神經炎症後的生活型態保護**：
  - NCC 或包蟲術後患者應實施神經保護性抗發炎飲食（如生酮飲食或低升糖地中海飲食），提高星形膠質細胞與粒線體修復能力，降低癲癇病灶誘發閾值。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **遇癲癇與不明局灶神經徵候，嚴格遵循 NCC 處方順序**：高流行區移民或接觸史患者，影像見環狀強化病灶時，**切勿盲目單獨給予驅蟲藥**；必須遵循「抗癲癇 + 降顱內壓 $\rightarrow$ 預先使用皮質類固醇 $\rightarrow$ 聯用 Albendazole/Praziquantel + Cimetidine」之金標準流程。
2. **巨幼紅血球性貧血合併周邊神經病變：必查飲食魚類史**：鑑別診斷惡性貧血時，應常規排除未熟淡水魚攝取史；確診 *D. latus* 感染後，投予單劑 Praziquantel（5–10 mg/kg）並**立即啟動高劑量非腸道途徑維生素 B12 甲基化搶救**。
3. **肝包蟲病（Echinococcosis）診斷嚴禁未經保護的盲目穿刺**：常規細針抽吸具誘發致死性過敏性休克與播散高風險；應以 WHO 超音波 CE 分期為核心，若需執行 PAIR 術式，必須在 Albendazole 全身預防性投藥掩護及能即時處置過敏休克的條件下進行。
4. **腸道豬肉絛蟲帶原者的嚴格公衛警覺**：若病患糞便排出 *T. solium* 節片，應立即視為神經囊蟲病自體感染與家戶傳播之潛在高危源；除徹底治療帶原者外，需嚴格指導衛生排便與手部清潔，防止蟲卵誤食形成致命性中樞囊蟲病。
