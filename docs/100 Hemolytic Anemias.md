# 臨床溶血性貧血全書：細胞膜結構、紅血球能量代謝與補體免疫失衡之病理與整合醫療策略
- **主講人/來源**：100 Hemolytic Anemias.pdf (Lucio Luzzatto, Lucia De Franceschi / *Harrison's Principles of Internal Medicine*)
- **核心主旨**：系統性剖析溶血性貧血之「紅血球內在缺陷」（細胞膜骨架、能量代謝、抗氧化酵素系統）與「紅血球外在因子」（自體抗體、補體異常活化、微血管剪力與外源氧化毒素）的病理生理機轉，建立跨越傳統血液學與功能醫學（細胞抗氧化、微量元素調控、免疫發炎平衡）之精準鑑別診斷與臨床管理架構。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **壽命縮短與代謝耗竭**：成熟紅血球喪失細胞核、粒線體及核糖體，無法合成新蛋白，完全依賴無氧醣解（Embden-Meyerhof 路徑）產生 ATP 以維持陽離子泵與膜結構；並依賴磷酸戊糖路徑（HMP Shunt / G6PD）產生 NADPH 維持還原型穀胱甘肽（GSH），以對抗氧化壓力。代謝衰竭最終導致膜結構受損、陽離子失衡、新抗原（如聚集之 Band 3）暴露而被網狀內皮系統吞噬清除。
  - **補體失控與膜破壞**：後天體細胞突變（如 *PIGA* 基因導致 GPI 錨定蛋白缺失）使 CD55/CD59 喪失，或先天補體調節蛋白（如 Factor H、MCP、Factor I）缺陷，引發補體膜攻擊複合物（MAC, C5b-9）非特異性穿透細胞膜，造成致命性血管內溶血或非典型溶血性尿毒症候群（aHUS）。
- **演講亮點與臨床洞察**：
  - **代償性溶血（Compensated Hemolysis）的隱匿性**：骨髓紅血球生成代償能力極高（EPO 調控），許多先天性膜缺陷或酵素缺乏患者在無壓力狀態下血紅素可維持正常；然而一旦遭遇感染（如 Parvovirus B19 抑制紅血球前驅細胞）、妊娠、葉酸缺乏或腎功能減退，將迅速轉化為急性危象（Aplastic/Hemolytic crisis）。
  - **鐵代謝的雙向病理表現**：慢性血管內溶血（IVH，如 PNH）因血紅素尿長期流失鐵質，導致缺鐵；而慢性血管外溶血（EVH）則因紅血球快速代謝及紅血球生成素釋放「紅血球鐵調節素（Erythroferrone）」強烈抑制 Hepcidin，導致腸道鐵過度吸收，即使未接受輸血亦可能產生續發性血鐵沉積症（Secondary Hemochromatosis）並損傷心臟與肝臟。
  - **治療範式轉移（Paradigm Shift）**：抗補體 C5 單株抗體（Eculizumab / Ravulizumab）阻斷了 PNH 的血管內溶血，但常使紅血球表面累積 C3d 轉變為血管外溶血（EVH）；此洞見催生了標靶上游 C3、Factor B 及 Factor D 的新一代抑制劑。同時，明確指出**遺傳性口形紅血球症（Stomatocytosis）嚴禁切脾**，以免誘發致死性血栓併發症。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準 |
| :--- | :--- | :--- |
| **網狀紅血球計數 (Reticulocytes)** | 評估骨髓紅血球生成代償能力；鑑別生成減少與破壞加速（初診必驗項目）。 | 百分比通常升高；**絕對計數 (ARC) 升高**；若溶血時網狀紅血球低下警惕造血再生危象。 |
| **未結合膽紅素 (Indirect Bilirubin)** | 反映血紅素異化代謝產物增加，多見於血管外溶血與代謝超載。 | 持續升高（臨床常伴黃疸與膽結石風險）。 |
| **乳酸脫氫酶 (LDH)** | 紅血球破裂釋放的胞漿標記；血管內溶血時呈極高度上升。 | 血管內溶血時可達正常上限之 **5~10 倍以上**。 |
| **結合珠蛋白 (Haptoglobin)** | 與游離血紅素結合；血管內溶血敏銳標記，甚至輕微血管外溶血亦會消耗。 | 血管內溶血時**顯著降低至無法測得（Undetectable）**。 |
| **MCHC 與 RDW** | MCHC 升高反映紅血球細胞脫水或球形化；RDW 評估紅血球大小不均程度。 | **MCHC > 34 g/dL 且 RDW > 14%** 強烈提示遺傳性球形紅血球症（HS）。 |
| **周邊血液塗片 (Blood Smear)** | 形態學評估：Bite/Blister cells、Heinz bodies（氧化性損傷）、Spherocytes（球形）、Elliptocytes（橢圓）、Basophilic stippling（嗜鹼性點彩）。 | 正常紅血球雙凹圓盤狀消失；出現裂片細胞（Schistocytes）代表微血管損傷。 |
| **直接抗球蛋白試驗 (DAT / Coombs Test)** | 區分免疫性（wAIHA, CAD, PCH）與非免疫性溶血；鑑別表面結合之 IgG 或補體 C3。 | 正常為陰性。診斷 AIHA 需確認陽性反應；高親和力抗體微量分子（30~40分子）即可致病。 |
| **流式細胞儀 CD55 / CD59 (PNH Clone)** | 檢測紅血球與顆粒球表面 GPI 錨定保護蛋白的缺失比例，為 PNH 黃金診斷標準。 | 診斷顯著 PNH 克隆：紅血球 $\ge 5\%$ 且中性顆粒球 $\ge 20\%$ 缺失。 |
| **紅血球酵素定量 (G6PD / PK Activity)** | 確診 G6PD 缺乏症、丙酮酸激酶缺乏症（PKD）；需注意急性溶血後網狀紅血球增多可能出現假陰性。 | 低於同批對照組正常活性區間（急性期後應複檢確認穩態活性）。 |
| **血清鐵蛋白 (Ferritin) 與 TSAT** | 評估因 erythroferrone 抑制 hepcidin 或反覆輸血所導致的全身鐵過載。 | 需定期追蹤，防範血鐵沉積損傷肝臟心臟；IVH 則需防範鐵缺乏。 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 紅血球能量代謝缺陷與氧化還原失衡（Redox & Glycolysis Failures）
- **無氧醣解路徑（Embden-Meyerhof Pathway）與 PK 缺乏症**：
  - 紅血球完全仰賴此路徑產生 ATP。若終末酵素丙酮酸激酶（Pyruvate Kinase, PK）缺乏，會阻礙 ATP 生成，導致膜陽離子泵失靈、滲透壓調節瓦解而發生溶血。
  - **代償機制**：PK 缺乏會使近端代謝物 **2,3-二磷酸甘油酸（2,3-DPG）** 顯著累積，降低血紅素對氧的親和力，使氧氣解離曲線右移，顯著促進周邊組織氧氣釋放；因此 PK 缺乏患者即使血紅素偏低，臨床貧血耐受力卻異常良好。
- **磷酸戊糖路徑（HMP Shunt）與 G6PD 缺乏症（氧化代償瓦解）**：
  - G6PD 是紅血球生成 **NADPH** 的唯一來源。NADPH 是穀胱甘肽還原酶維持 GSH、以及過氧化氫酶（Catalase）與過氧化物還原酶-2（Prx2）清除活性氧（ROS/$\text{H}_2\text{O}_2$）的必要輔酶（參見圖 100-6）。
  - 當暴露於外源氧化劑（蠶豆中的 Divicine、伯氨喹 Primaquine、磺胺類、Rasburicase 等）或嗜中性球呼吸爆發時，G6PD 缺乏的紅血球無法及時再生 GSH，導致血紅素氧化變性、形成 **Heinz 小體**，於脾臟中被微環境巨噬細胞「咬掉」受損膜形成 **Bite cells** 或因嚴重氧化引發急性血管內溶血。
- **核苷酸代謝與重金屬中毒表形模擬**：
  - 嘧啶 5'-核苷酸酶（P5N）缺乏會阻礙 RNA 降解產物代謝，導致核苷酸累積引發溶血，鏡檢特徵為**嗜鹼性點彩（Basophilic stippling）**。
  - **環境毒理學關聯**：鉛中毒（Lead toxicity）會直接抑制 P5N 活性，臨床表現出與遺傳性 P5N 缺乏完全相同的嗜鹼性點彩與溶血表型。

### 2. 細胞膜-細胞骨架複合體架構與離子通道病（Membrane Cytoskeleton & Channelopathies）
- **垂直與水平連結架構（Vertical vs. Horizontal Connections）**：
  - **垂直連結（Vertical Linkage）**：由 **Ankyrin 複合體**（包含 Ankyrin、Band 4.2、Band 3）連接膜脂質雙層與底層的 Spectrin 網絡。此路徑基因突變（*ANK1*, *SPTB*, *SPTA1*, *SLC4A1*, *EPB42*）削弱膜穩定性，導致微囊泡脫落、細胞表面積減少，形成「遺傳性球形紅血球症（HS）」（滲透脆性增加）。
  - **水平連結（Horizontal Linkage）**：由 **Junctional 複合體**（包含 Spectrin 二聚體自結合位點、Actin、Protein 4.1R、Dematin、Adducin）維持膜延展性。突變導致骨架網絡斷裂，形成「遺傳性橢圓形紅血球症（HE）」；雙等位基因嚴重突變則引發「遺傳性高溫異形紅血球症（HPP）」，表現出嚴重低 MCV（50~60 fL）與碎裂細胞。
- **離子通道病（Channelopathies / Stomatocytosis）與切脾禁忌**：
  - **脫水口形紅血球症（DHS / Xerocytosis）**：*PIEZO1*（機械力敏感通道）或 *KCNN4*（Gardos 鈣激活鉀通道）功能獲得性突變，引發細胞質鉀離子外洩、水份喪失、MCHC 顯著升高（> 36 g/dL）。
  - **過水性口形紅血球症（OHS）**：*RHAG* 氨通道突變，引發鈉水大量內流、MCHC 偏低（< 30 g/dL）。
  - **臨床致命陷阱**：口形紅血球症患者若接受脾臟切除手術，將引發**極高風險的猛爆性動靜脈血栓栓塞**，因此**脾切除在口形紅血球症中列為絕對禁忌**。

### 3. 補體級聯反應失調與後天克隆疾病（PNH & aHUS）
- **陣發性夜間血紅素尿症（PNH）**：
  - **造血幹細胞後天體細胞突變**：X 染色體上的 *PIGA* 基因突變，導致醣基磷脂醯肌醇（GPI）錨定結構合成受阻，所有 GPI 錨定保護蛋白（關鍵為阻斷 C3 轉化酶的 **CD55** 與阻斷 C9 聚合成 MAC 的 **CD59**）全面缺失。
  - **雙重打擊學說**：正常造血因自體免疫攻擊（如再生不良性貧血 AA）受損，GPI 缺失的突變幹細胞因缺乏免疫抗原標靶而獲得生存優勢並擴增。
  - **補體破壞與一氧化氮（NO）耗竭**：游離血紅素強烈清除內皮 NO，誘發劇烈血管收縮、食道痙攣、腹痛及致命性靜脈血栓（特別是腸系膜靜脈與肝靜脈 Budd-Chiari 症候群）。
  - **靶向治療與病理轉化**：C5 阻斷劑（Eculizumab / Ravulizumab）成功抑制 MAC 形成的血管內溶血；但由於紅血球仍缺乏 CD55，上游 C3b/C3d 持續沉積，使原本的血管內溶血轉化為巨噬細胞介導的**血管外溶血（EVH）**。
- **非典型溶血性尿毒症候群（aHUS）**：
  - 屬於「紅血球外在性」補體失控。患者帶有補體調控因子（CFH、MCP/CD46、CFI、C3、CFB）之遺傳突變，在感染或壓力下過度活化補體替代途徑，引發內皮損傷、微血管微血栓形成、血小板消耗與紅血球機械性破壞（裂片細胞 Schistocytes）。

### 4. 免疫自體抗體媒介機制（wAIHA vs. CAD vs. PCH）
- **溫抗體自體免疫溶血性貧血（wAIHA）**：
  - 最適溫度 37°C，多為 **IgG**（抗 Rh 抗原為主）。紅血球被 IgG 結合後，其 Fc 段被脾臟紅髓中的巨噬細胞 Fc 受體識別，引發**脾臟為主的血管外吞噬溶血**。一線治療為皮質類固醇與 Rituximab，難治型可考慮切脾。
- **冷凝集素症（CAD）**：
  - 慢性、低溫反應（4°C~30°C），由自體反應性 B 細胞克隆產生 **IgM**（常見 *KMT2D* 突變，多針對紅血球 I 抗原）。
  - IgM 強力結合併活化經典補體途徑；紅血球在末梢冷環境下結合 IgM 與 C1，回流中樞溫暖部位時 IgM 解離，但 C3b 活化產物已沉著於細胞膜，引發**肝臟為主的血管外溶血**，或進一步形成 MAC 造成血管內溶血。**類固醇與脾臟切除對 CAD 均無顯著療效**，首選為 Rituximab 或補體抑制劑。
- **陣發性冷血紅素尿症（PCH）**：
  - 兒童病毒感染後常見，具特殊的 **Donath-Landsteiner 抗體**（雙相溶血素，抗 P 特異性 IgG）：低溫結合紅血球，復溫至 37°C 時啟動全套補體造成急性爆發性血管內溶血與血紅素尿。

### 1. 功能性營養素與代謝輔助
- **高劑量葉酸（Folic Acid）補充（每日必備處方）**：
  - **劑量**：每日至少 **3~5 mg**（高於一般常規劑量）。
  - **機轉**：由於紅血球周轉代謝速度提升數倍至十倍，骨髓巨幼紅細胞生成對單碳代謝（葉酸）需求劇增；若未充分補充，極易併發巨幼紅細胞性危象（Megaloblastic crisis），迅速破壞骨髓代償平衡。
- **微量元素硒（Selenium）與穀胱甘肽過氧化物酶（GSHPX）維護**：
  - **臨床洞察**：新生兒時期特發性嚴重視網膜/紅血球異形症（Infantile poikilocytosis）與暫時性微量元素硒缺乏導致 GSHPX 活性低下高度相關。適量補充硒（成人 100~200 $\mu\text{g}$/天，以硒酵母或硒代甲硫胺酸型態）為紅血球胞內過氧化氫代謝的核心保護基質。
- **鐵代謝動態平衡管理（拒絕盲目補鐵）**：
  - 血管外溶血（如 HS、PK 缺乏、部分 AIHA）：內源鐵極度循環且腸道吸收亢進，**嚴禁盲目補充口服或靜脈鐵劑**。應定期監測 Ferritin 與肝臟鐵濃度，必要時給予鐵螯合劑（Iron Chelation Therapy），防止不可逆性肝硬化與心肌損傷。
  - 慢性血管內溶血（如未完全控制之 PNH）：持續血紅素尿與含鐵血黃素尿會導致顯著鐵耗竭，此時方需精準評估並在監控下小劑量給予鐵劑補充。

### 2. 環境毒素阻斷與氧化壓力隔離策略
- **絕對禁用氧化性藥物與環境化合物（G6PD 缺乏者必備衛教清單）**：
  - **環境毒素**：萘丸（Naphthalene/樟腦丸）、苯胺染料。
  - **食物與植化素**：蠶豆（Fava beans，含致敏性 Divicine/Convicine，烹煮或新鮮均嚴格禁食；注意花粉吸入並不會致病，其他豆類安全）。
  - **藥物絕對禁忌**：伯氨喹（Primaquine，需常規篩檢 G6PD）、氨苯碸（Dapsone）、磺胺甲基異㗁唑（Cotrimoxazole）、呋喃妥因（Nitrofurantoin）、Rasburicase（腫瘤溶解症候群用藥，產生大量 $\text{H}_2\text{O}_2$ 具致死性溶血風險）、亞甲藍（Methylene blue）。
  - **臨床處方陷阱**：在未確認 G6PD 活性前，**嚴禁執行高劑量維生素 C（>1 g/d）靜脈注射（IVC）**，以免強大的促氧化作用直接誘發致死性急性溶血。

### 3. 生活型態、抗發炎與免疫穩定架構
- **環境溫度恆定與微循環保護（CAD 患者）**：
  - 冷凝集素症（CAD）患者的核心療法為嚴格防寒保暖（肢體末端、頭頸部、呼吸道吸入加溫空氣）。輸血時**輸血袋與患者肢體必須嚴格加溫至 37°C**，否則體外輸注冷血將引發災難性體內全血凝集與猛爆性補體活化。
- **水合狀態與腎臟保護（針對血管內溶血事件）**：
  - 急性溶血爆發時，每日確保高容量液體攝取（維持尿量），防止游離血紅素在腎小管酸性環境下沉澱形成管型，降低急性腎衰竭（ATN）發生率。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **急性貧血初診黃金三聯檢（Triad Workup）**：
   面對急性血紅素驟降，切勿僅開立常規 CBC，必須同步檢驗 **「絕對網狀紅血球計數 (ARC) + 未結合膽紅素/LDH + 結合珠蛋白 (Haptoglobin)」**，快速區分骨髓造血停滯與外周溶血破壞。
2. **掌握脾切除（Splenectomy）之適應症與絕對禁忌**：
   - **高度推薦**：中重度遺傳性球形紅血球症（HS，建議延遲至 4~6 歲後實施，術前必須完整接種肺炎鏈球菌及腦膜炎雙球菌疫苗）。
   - **絕對禁忌**：遺傳性口形紅血球症（Stomatocytosis / DHS / OHS），術後極易誘發致命性大血管與內臟靜脈血栓。
   - **無效**：冷凝集素症（CAD，破壞場所主要在肝臟）及陣發性夜間血紅素尿症（PNH）。
3. **高風險藥物使用前的常規酵素篩檢**：
   在處方 Rasburicase、大劑量 Primaquine、Dapsone 或實施高劑量靜脈注射維生素 C 療法前，必須強制完成 **G6PD 活性定量篩檢**。
4. **補體抑制劑治療下的「溶血表型轉換」追蹤**：
   接受 C5 抑制劑（Eculizumab / Ravulizumab）治療的 PNH 患者，血管內溶血雖獲控制，但因 C3b/C3d 堆積常轉化為長期「血管外溶血」，需持續監測黃疸、肝脾狀態與鐵沉積指數，並評估是否銜接標靶上游之 C3 / Factor B 抑制新藥。
5. **常規性代謝支援處方**：
   凡確立為慢性溶血性疾病（不論是否具臨床貧血表型），應將 **葉酸（3~5 mg/d）** 列為長期基礎處方，並同步監測微量元素（硒）儲備與鐵過載指標，預防隱匿性代償失調危象。
