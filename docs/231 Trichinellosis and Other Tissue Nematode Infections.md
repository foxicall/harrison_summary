# 組織線蟲感染症之病理生理、臨床鑑別與精準處置（旋毛蟲症及幼蟲移行症）

- **主講人/來源**：Peter F. Weller / *Harrison's Principles of Internal Medicine*, Chap. 231: *Trichinellosis and Other Tissue Nematode Infections*
- **核心主旨**：人體作為組織線蟲的非自然或終宿主，幼蟲在體內組織（肌肉、神經、內臟、皮膚）移行與包埋會誘發強烈的 Th2 免疫超敏反應、嗜酸性球浸潤與肉芽腫病變；臨床診斷與介入需精準掌握病程分期，透過免疫抑制（皮質類固醇）與驅蟲藥物的適時搭配，避免免疫風暴造成的不可逆器官損傷。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **組織幼蟲移行與免疫過敏瀑布**：人體攝入感染性幼蟲或蟲卵後，幼蟲穿透腸道黏膜或皮膚屏障，經循環系統進入骨骼肌、中樞神經系統（CNS）、眼部或肝肺等實質器官。幼蟲移行與死亡會釋放大量外源性抗原，觸發劇烈的局部及全身性嗜酸性超敏反應、微血管炎性出血、肉芽腫性壞死及肌肉細胞轉分化（如旋毛蟲誘發的「護士細胞」Nurse-cell 形成）。
  - **宿主免疫病理反應之雙面刃**：組織器官的致命性損傷（如心肌炎、致死性嗜酸性腦膜炎）多源於宿主過度活化的發炎反應，而非幼蟲的直接物理破壞。
- **演講亮點與臨床洞察**：
  - **診斷陷阱——糞便鏡檢之無效性**：在內臟幼蟲移行症（VLM）及旋毛蟲組織期，因線蟲無法在人體腸道內發育為產卵成蟲，**常規糞便蟲卵與寄生蟲檢驗（Stool O&P）毫無診斷價值**。
  - **殺蟲治療的潛在反撲風險**：廣東住血線蟲（*Angiostrongylus cantonensis*）侵犯中樞神經引起嗜酸性腦膜炎時，**常規抗線蟲藥物（Larvicides）可能因蟲體崩解誘發更嚴重的致死性神經發炎**，臨床處置應以發炎抑制（類固醇）與對症減壓（反覆腰椎穿刺）為核心。
  - **眼幼蟲移行症（OLM）之臨床偽裝**：眼內單一肉芽腫病變易被誤診為視網膜母細胞瘤（Retinoblastoma），恐導致非必要之眼球摘除術（Enucleation）。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **周邊血嗜酸性球絕對計數與比例（Eosinophils）** | 反映全身性 Th2 免疫超敏反應強度；旋毛蟲症及內臟幼蟲移行症（VLM）高度活化指標 | 旋毛蟲感染 2~4 週常 **>50%**；VLM 時可極端攀升至 **90%**；輕症常為唯一異常 |
| **肌酸磷酸激酶（CPK）及肌酵素** | 評估骨骼肌受侵犯程度、活動性肌炎及肌肉細胞溶解壞死 | 旋毛蟲症急性肌炎期（第 2~3 週）普遍顯著升高 |
| **腦脊髓液（CSF）分析** | 診斷廣東住血線蟲引起之嗜酸性腦膜炎（Eosinophilic Meningitis）之必要檢查 | 初壓升高、白血球 150~2000/μL、**嗜酸性球比例 >20%**、蛋白質升高、葡萄糖正常 |
| **特異性抗體血清學檢驗（ELISA）** | 確認旋毛蟲或犬蛔蟲（*Toxocara*）抗原致敏；輔助臨床診斷 | 旋毛蟲抗體通常在**感染後第 3 週才轉陽**（太早檢驗易有偽陰性） |
| **肌肉切片組織病理學檢查（Muscle Biopsy）** | 旋毛蟲症確診黃金標準；觀察嗜鹼性橫紋肌纖維化、幼蟲囊包（Fig. 231-2） | 取疑似受累肌肉（近肌腱處）**≥1 g** 新鮮組織夾於玻片加壓鏡檢，避免常規切片漏檢 |
| **總免疫球蛋白（Total IgG/IgE）** | 評估多株 B 細胞活化與高免疫球蛋白血症（Hypergammaglobulinemia） | VLM 患者常伴隨高丙種球蛋白血症及白血球增多（Leukocytosis） |

## 三、 關鍵機制詳解與重點筆記

### 1. 旋毛蟲症（Trichinellosis）：從腸道穿透到肌肉「護士細胞」轉化
- **生命週期演進**：
  - **腸道期（第 1 週）**：攝入含有包囊幼蟲的未煮熟肉類（豬肉、野豬、熊肉等），胃酸與胃蛋白酶釋出幼蟲，幼蟲侵入小腸黏膜並於 1~2 週內成熟交配；母蟲釋出新生幼蟲進入微循環。此期表現為噁心、腹痛、腹瀉。
  - **移行與侵入期（第 2 週起）**：幼蟲沿血流播散至橫紋肌。引發強烈血管炎與微血管滲漏，呈現**眼眶周圍水腫（Periorbital edema）**、顏面水腫、結膜下及指甲床**裂片狀出血（Splinter hemorrhages）**、高熱與極度嗜酸性球增多。此期若侵犯心肌可致嚴重**心肌炎與致死性心律不整**。
  - **肌肉包囊期（第 2~3 週起）**：幼蟲進入橫紋肌纖維（最常見於眼外肌、二頭肌、咀嚼肌、頸部、下背肌及橫膈膜），誘導肌纖維去分化並建立一層玻璃樣囊包（*T. pseudospiralis* 等少數品種除外），形成長期寄生的「護士細胞」（Nurse-cell complex），引發持續數週至數月的嚴重肌痛與肌無力。

```
[攝入未熟肉品含幼蟲] 
      │
      ▼
[胃酸分解釋出幼蟲] ──(1~2週)──> [侵入小腸黏膜成熟] ──> 腸道症狀（腹瀉/絞痛）
                                          │
                                   (母蟲釋出新生幼蟲)
                                          │
                                          ▼
[幼蟲血行循環播散] ──(第2週)───> [過敏反應/血管炎] ──> 眼眶水腫、裂片狀出血、心肌炎
                                          │
                                          ▼
[侵入橫紋肌組織] ──(2~3週)──> [重塑為 Nurse Cell 包囊] ──> 劇烈肌炎、CPK飆升、長期乏力
```

### 2. 幼蟲移行症（Larva Migrans Syndromes）：迷航幼蟲引發的免疫破壞
- **內臟幼蟲移行症（VLM）**：
  - 主因幼童經口食入受犬蛔蟲（*Toxocara canis*）卵污染之泥土（異食癖 Pica）。幼蟲在人體腸道孵化後無法成熟為成蟲，遂於肝、肺、中樞神經等處盲目移行，引發巨噬細胞與嗜酸性球形成的**嗜酸性肉芽腫**。臨床可見肝脾腫大、氣喘、喘鳴、發燒及極端嗜酸性球血症（可達 90%）。
- **眼幼蟲移行症（OLM）**：
  - 常見於無異食癖的較大兒童或青年，幼蟲侵入眼後極視網膜形成局部肉芽腫，導致視力減退、斜視或眼內炎。**此族群周邊血通常無明顯嗜酸性球增生**，且常被誤診為惡性腫瘤。
- **皮膚幼蟲移行症（CLM, "Creeping Eruption"）**：
  - 由貓狗鉤蟲（如 *Ancylostoma braziliense*）幼蟲穿透裸露皮膚引起，於真皮與表皮交界處蜿蜒爬行（每日推進數公分），產生劇烈搔癢之匐行疹。

### 3. 廣東住血線蟲症（Angiostrongyliasis）：嗜酸性腦膜炎的急症處置
- **感染途徑**：生食受感染之陸生蝸牛、蛞蝓（如非洲大蝸牛 *Achatina fulica*）、受蛞蝓黏液污染之生菜，或淡水蝦、蟹等保幼宿主。
- **神經致病機轉**：第三期幼蟲穿透腸道入血，嗜神經性移行至中樞神經系統。在腦實質或蜘蛛膜下腔死亡時誘發劇烈嗜酸性發炎、出血與壞死，表現為突發或隱匿之劇烈頭痛（額葉、枕葉或雙顳葉）、頸部僵硬及感覺異常。

## 四、 臨床介入處方與醫療指引（Therapeutic Strategies）

根據臨床實證與指南（Table 231-1），依病程嚴重度進行分層階梯式治療：

```
                              [組織線蟲感染嚴重度評估]
                                         │
         ┌───────────────────────────────┼───────────────────────────────┐
         ▼                               ▼                               ▼
    【輕度感染】                    【中度感染】                    【重度感染】
(自限性/輕微症狀)              (明顯肌炎/活動性蟲體移行)       (心肌炎/神經侵犯/呼吸衰竭)
         │                               │                               │
  • 臥床休息                      • 抗蠕蟲藥物治療                • 立即啟用高劑量皮質類固醇
  • 症狀控制                      - Albendazole (400mg bid)      (Prednisone 1 mg/kg/d × 5d)
    (解熱鎮痛劑)                  - 或 Mebendazole               • 合併抗蠕蟲治療 (依病原評估)
                                  • 密切監測心肺機能              • 廣東住血線蟲：反覆腰椎穿刺減壓
                                                                  (禁用單純殺蟲劑，避免腦水腫)
```

### 1. 規範藥物治療劑量與方針（依 Table 231-1）
- **旋毛蟲症（Trichinellosis）**：
  - *輕度*：支持性療法（臥床休息、解熱鎮痛劑）。
  - *中度*：**Albendazole** 400 mg bid 共 8~14 天；或 **Mebendazole** 200~400 mg tid 共 3 天，接著 500 mg tid 共 10 天（主要消滅腸道成蟲以阻斷新幼蟲釋放；對已包埋幼蟲療效有限）。
  - *重度（伴隨嚴重心肌炎或肌炎）*：立即加用皮質類固醇 **Prednisone** 1 mg/kg/day 连续 5 天，抑制過敏性破壞。
- **幼蟲移行症（Larva Migrans）**：
  - *VLM 輕中度*：支持性治療；*重度（CNS、肺、心臟受累）*：全身性類固醇 Prednisone。
  - *OLM*：**Albendazole**（成人 800 mg bid；兒童 400 mg bid）合併皮質類固醇治療 5~20 天。
  - *CLM（皮膚型）*：**Ivermectin** 單一劑量（200 μg/kg）或 **Albendazole** 200 mg bid 共 3 天。
- **廣東住血線蟲症（Angiostrongyliasis）**：
  - **禁忌單獨給予殺蟲劑**（Larvicides 會造成大量蟲體死亡，惡化腦部發炎）。
  - 核心治療為支持性療法、鎮痛鎮靜劑；**反覆腰椎穿刺引流 CSF** 可有效緩解顱內高壓頭痛；重症個案投予全身性皮質類固醇。
- **顎口線蟲症（Gnathostomiasis）**：
  - **Ivermectin** 200 μg/kg/day 連續 2 天；或 **Albendazole** 400 mg bid 連續 21 天。

### 2. 環境毒素阻斷、飲食安全與生活型態預防策略
- **食物病原阻斷原則（肉品熱穿透）**：
  - 徹底烹煮肉類（特別是豬肉、野豬肉、熊肉），直至完全無粉紅色（內部中心溫度達標）。
  - *低溫冷凍陷阱*：常規豬肉旋毛蟲在 −15°C 冷凍 3 週可被殺滅；然而北極圈之 **北極旋毛蟲（*Trichinella nativa*）具高度耐寒性**，即使在野味（北極熊肉、海象肉）經長時間冷凍仍可存活，必須依靠徹底加熱。
- **生鮮農產品與水產管理**：
  - 嚴格避免生食或未煮熟之淡水蝸牛、福壽螺、蛞蝓、淡水蝦、螃蟹及特定海魚。
  - 生食蔬菜前需徹底清洗與檢視，避免誤食受蝸牛/蛞蝓分泌黏液污染之葉菜類。
- **環境與寵物衛生**：
  - 禁止犬貓在公共沙坑、遊樂場排便；定期為家犬（特別是哺乳期母犬與幼犬）進行系統性驅蟲，切斷 *Toxocara canis* 的垂直與糞口傳播鏈。
  - 嚴格矯正幼童之異食癖（Pica），阻斷泥土中蟲卵攝入。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **鎖定高度懷疑臨床四聯徵**：
   凡遇到病患出現「**不明原因發燒 + 眼眶周圍水腫 + 劇烈肌痛 + 顯著周邊血嗜酸性球增多（>50%）**」，合併近期野生動物肉品或未全熟豬肉攝食史，應立即將旋毛蟲症列入首要鑑別診斷。
2. **掌握血清學轉陽空窗期**：
   旋毛蟲特異性抗體在感染後第 3 週前多呈陰性；急性期若高度懷疑，應追蹤抗體力價上升，或在肌腱附著處取肌肉切片進行壓片鏡檢（Fresh muscle compression test），避免僅依賴單一切片組織學檢驗而漏診。
3. **區分幼蟲移行症之檢驗禁忌與盲點**：
   疑診犬蛔蟲幼蟲移行症（VLM/OLM）時，**切勿開立糞便蟲卵檢查**（幼蟲不產卵，結果必為陰性造成誤導），應開立專一性 Toxocara 抗體 ELISA 檢測。
4. **謹記廣東住血線蟲之處置紅線**：
   面對生食螺類、蝸牛後爆發劇烈頭痛及 CSF 嗜酸性球增多症（>20%）病患，**切勿冒然給予抗蠕蟲殺蟲藥（避免赫氏反應誘發腦疝）**，應即刻以反覆腰穿減壓及皮質類固醇為優先線路。
5. **眼科病變之跨科照會防禦**：
   兒童單側視網膜白斑或肉芽腫合併視力模糊，在動刀眼球摘除前務必進行眼寄生蟲學鑑別，排除眼蛔蟲幼蟲移行症（OLM），可嘗試 Albendazole 併用類固醇搶救視力。
