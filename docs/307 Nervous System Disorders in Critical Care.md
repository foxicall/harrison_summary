# 重症神經系統疾病與急重症神經保護策略（Nervous System Disorders in Critical Care）
- **主講人/來源**：307 Nervous System Disorders in Critical Care.pdf（*Harrison's Principles of Internal Medicine*, 21st Edition）
- **核心主旨**：急重症神經醫學的核心在於阻斷原發性病灶引發的「缺血級聯反應（Ischemic Cascade）」並全力杜絕次發性腦損傷（Secondary Brain Insults）；透過精準調控顱內壓（ICP）、腦灌注壓（CPP）、血流自動調節機制、神經代謝輔酶及全身發炎網絡，實現最大程度的神經組織挽救與功能復原。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **能量代謝衰竭與興奮毒性**：當氧氣與葡萄糖供應中斷（3–5 分鐘以上），三磷酸腺苷（ATP）耗竭，引發大量興奮性神經傳導物質（麩胺酸 Glutamate）釋放，導致鈣離子（$\text{Ca}^{2+}$）與鈉離子（$\text{Na}^+}$）大量內流，活化蛋白酶與脂肪酶，誘發嚴重的膜脂質過氧化、自由基風暴與粒線體損傷，最終導致細胞毒性水腫、壞死與細胞凋亡（Apoptosis）。
  - **惡性循環迴路（Vicious Cycle）**：血管源性水腫（血腦屏障 BBB 瓦解）與細胞毒性水腫導致顱內壓（ICP）升高 $\rightarrow$ 腦灌注壓（CPP）下降 $\rightarrow$ 組織缺血加劇 $\rightarrow$ 血管代償性擴張 $\rightarrow$ 顱內血容量（CBV）增加 $\rightarrow$ ICP 進一步飆升與腦組織位移/腦疝（Herniation）。
  - **全身-大腦發炎軸（Systemic-Brain Inflammatory Axis）**：敗血症與全身發炎反應症候群（SIRS）釋放的大量發炎介質（TNF-$\alpha$、IL-1、IL-2、IL-6）可直接破壞微血管內皮與星狀膠質細胞，誘發神經細胞凋亡與腦微循環障礙（敗血症相關腦病變 SAE）。
- **演講亮點與臨床洞察**：
  - **次發性腦損傷的致命累積性**：低血壓（收縮壓 $<90\text{ mmHg}$ 僅持續 10 分鐘）或低血氧（$\text{SpO}_2 <90\%$）、發燒及高血糖，在臨床上往往無立即性神經學惡化表徵，但會倍增細胞代謝消耗，造成不可逆的累積性致死與長期神經失能。
  - **血管自動調節的逆轉悖論**：在嚴重腦損傷下，腦血管自主調節曲線呈現平坦化（壓力依賴型）。在特定狀態下給予血管收縮劑拉高平均動脈壓（MAP），反可改善局部灌注、誘發代償性微血管收縮，進而降低顱內血容量並**反向降低 ICP**。
  - **代謝輔酶剝奪陷阱**：未補足維生素 $\text{B}_1$（Thiamine）前冒然輸注葡萄糖液，會急遽耗盡丙酮酸去氫酶（PDH）與 $\alpha$-酮戊二酸去氫酶輔酶，阻斷克氏循環並累積大量乳酸與興奮毒性，誘發急性 Wernicke 腦病變或不可逆的間腦/乳頭體壞死。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **顱內壓（ICP）** | 評估顱內順應性（Intracranial Compliance）與腦疝風險 | 目標維持 $< 20\text{ mmHg}$（超過 $20\sim25\text{ mmHg}$ 持續 $>5\text{ min}$ 需啟動降壓階梯處置） |
| **腦灌注壓（CPP）** | $\text{CPP} = \text{MAP} - \text{ICP}$，維持腦微循環毛細血管床之最低驅動壓 | 目標維持 $\ge 60\text{ mmHg}$ |
| **神經元特異性烯醇化酶（NSE）** | 評估心跳停止復甦後（HIE）腦實質全面性神經元壞死程度 | 心跳停止後第 $3\sim5$ 天血清值 $> 33\ \mu\text{g/L}$ 強烈預示極差神經預後 |
| **星狀膠質細胞蛋白 S-100$\beta$** | 反映血腦屏障破壞程度、星狀膠質細胞活化及腦缺血損傷（如敗血症腦病變） | 數值異常顯著升高提示微血管內皮受損與神經細胞凋亡 |
| **血清鈉離子校正速率** | 預防滲透壓劇烈變動導致之腦橋中央髓鞘溶解症（ODS） | 矯正速度嚴格限制：$24\text{ h} \le 8\text{ mmol/L}$（$8\text{ mEq/L}$）；$48\text{ h} \le 15\text{ mmol/L}$ |
| **血清滲透壓（Osmolality）** | 監測高滲透壓脫水劑（Mannitol）療效，防止急性腎小管壞死 | 目標維持在 $< 320\text{ mosmol/kg}$ |
| **動脈血二氧化碳分壓（$\text{PaCO}_2$）** | 調控腦動脈收縮度以緊急降壓（過度換氣法） | 短期處置目標：$30\sim35\text{ mmHg}$（嚴格避免過低造成缺血加劇） |
| **隨機血糖（Serum Glucose）** | 預防高血糖加劇缺血組織乳酸中毒與自由基生成 | 目標維持在 $< 10.0\text{ mmol/L}$（$< 180\text{ mg/dL}$），同時嚴防低血糖 |
| **呼吸力學（MIF 與 VC）** | 評估周邊神經肌肉疾病（GBS、MG、CIP/CIM）患者呼吸衰竭風險 | 最大吸氣力（MIF）$< -25\text{ cmH}_2\text{O}$ 或肺活量（VC）$< 1\text{ L}$ 為插管指標 |

## 三、 關鍵機制詳解與投影片重點筆記

- **缺血級聯反應、細胞毒性與半影區（Ischemic Cascade & Penumbra）**：
  - **半影區（Penumbra）**：指受缺血波及但尚未形成不可逆壞死之神經組織，為神經加護保護的主要挽救對象。
  - **生化失衡瀑布**：缺血 $\rightarrow$ 粒線體氧化磷酸化停滯 $\rightarrow$ 膜電位喪失 $\rightarrow$ 突觸間隙高濃度 Glutamate 無法回收 $\rightarrow$ NMDA/AMPA 受體持續過度刺激 $\rightarrow$ $\text{Ca}^{2+}$ 內流超載 $\rightarrow$ 激活 Calpain、磷脂酶 $\text{A}_2$ 與氧化氮合成酶（NOS） $\rightarrow$ 產生脂質過氧化自由基（ROS/RNS） $\rightarrow$ 細胞膜破裂壞死與粒線體途徑凋亡。

- **腦血流自動調節（CBF Autoregulation）與 Monro-Kellie 假說**：
  - **生理恆定區間**：正常狀況下，MAP 在 $50\sim150\text{ mmHg}$ 之間時，大腦小動脈透過收縮（高壓時防過度灌注）與舒張（低壓時維持灌注）維持 CBF 恆定（約 $55\text{ mL/100 g/min}$）。
  - **重症病理崩潰（圖 307-1）**：重度腦創傷或缺血時，自動調節受損，CBF 曲線呈現斜向線性關係（壓力依賴型）。極端高壓造成突破性血管擴張、微血管漏出與水腫（如 PRES）；極端低壓造成大腦微循環塌陷與廣泛性腦梗塞。
  - **化學性調節**：$\text{PaCO}_2$ 上升促使組織酸中毒，引發腦血管擴張並增加 CBV；$\text{PaCO}_2$ 下降使組織鹼化，誘導血管強烈收縮。

- **代謝性與發炎性腦病變病理生理**：
  - **敗血症相關腦病變（SAE）**：非中樞神經系統感染所致之瀰漫性大腦失能。SIRS 促使外周促發炎細胞因子穿透受損的 BBB，誘導微膠質細胞（Microglia）活化、粒線體功能失調及神經元凋亡；常見臨床表現為意識混亂、震顫、肌躍症（Myoclonus）與額葉釋放徵象。
  - **魏尼凱氏腦病變（Wernicke's Disease）**：維生素 $\text{B}_1$ 缺乏導致三碳酸循環關鍵酵素失能。病理標誌為第三、四腦室周圍及下視丘乳頭體（Mammillary bodies）之微血管內皮增生、點狀出血、去髓鞘與膠質增生，MRI 常見乳頭體異常高訊號（圖 307-6）。
  - **可逆性後腦病變症候群（PRES）**：內皮細胞功能受損（如 Calcineurin 抑制劑 Cyclosporine/Tacrolimus 毒性、子癇症）合併血壓飆升突破後循環自動調節閾值，導致雙側枕葉-頂葉白質為主之血管源性水腫（圖 307-7）。

- **加護病房後天性衰弱（ICU-Acquired Weakness, ICUAW）**：
  - **危重症多發性神經病變（CIP）**：以遠端對稱性「軸突退化（Axonal Degeneration）」為特徵，與全身發炎細胞因子破壞微循環有關；病患表現為四肢無力、肌腱反射低下、脫機困難。
  - **危重症肌病變（CIM）**：主要特徵為「粗肌絲（Myosin）選擇性流失」與 Type II 肌纖維萎縮；常發生於合併使用大劑量皮質類固醇與非去極化神經肌肉阻斷劑（nd-NMBAs）的重症患者（如氣喘重積狀態）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **功能性微量營養素與神經代謝基質支持**：
  - **超高劑量維生素 $\text{B}_1$（Thiamine）搶救療法**：
    - *緊急劑量*：懷疑 Wernicke 腦病變或高風險營養不良患者，立即給予 **$\text{Thiamine } 500\text{ mg IV}$（加入生理食鹽水靜脈滴注），每 8 小時一次（TID），連續 2–3 天**。
    - *維持劑量*：隨後改為 $250\text{ mg IV/IM QD}$ 連續 5 天（協同綜合維生素 B 群），之後口服 $100\text{ mg QD}$ 直至風險解除。
    - *給藥鐵律*：**必須絕對先於任何葡萄糖輸液前投予**，防止誘發致死性急性代謝崩潰。
  - **細胞滲透壓與離子平衡維護**：
    - 滲透性脫水策略：首選高張食鹽水（$23.4\%\text{ NaCl } 30\text{ mL bolus}$）或甘露醇（Mannitol $25\sim100\text{ g } \text{q4h}$），監測血清滲透壓維持 $< 320\text{ mosmol/kg}$。
    - 電解質精準修復：緩慢校正低血鈉以杜絕 ODS；補足血清鎂離子（發揮天然 NMDA 受體生理性阻斷，減緩興奮毒性；子癇症抽搐首選硫酸鎂）；積極校正低血磷以防範橫紋肌溶解與呼吸衰竭。

- **細胞保護與代謝抑制策略**：
  - **目標溫度管理（Targeted Temperature Management, TTM）**：
    - 心跳停止復甦後無意識病患，建議維持核心體溫在 **$32\sim36^\circ\text{C}$ 恆定至少 24 小時**。
    - *機轉*：每降低 $1^\circ\text{C}$ 可降低約 6–7% 腦代謝率（$\text{CMRO}_2$），顯著抑制自由基釋放、下調缺血級聯反應並穩定血腦屏障。
  - **神經內分泌與血糖恆定**：
    - 連續性靜脈胰島素輸注以避免劇烈血糖波動，將血糖控制於 $< 10.0\text{ mmol/L}$（$< 180\text{ mg/dL}$），預防高血糖加重乳酸堆積與微血管內皮通透性。

- **醫源性神經毒性阻斷與重症環境優化**：
  - **保護性鎮靜與譫妄阻斷**：
    - 優先選用中樞 $\alpha_2$ 腎上腺素受體激抗劑 **Dexmedetomidine** 進行鎮靜，顯著優於 Benzodiazepine（如 Lorazepam、Midazolam），能大幅降低譫妄發生率並縮短呼吸器使用天數。
    - 降低環境干擾、維持日夜生理節律、鼓勵家屬探視陪伴以提供定向感支持。
  - **避免神經肌肉阻滯劑併發症**：
    - 限制 nd-NMBAs（Pancuronium、Vecuronium、Cisatracurium）使用時程；必須使用時，常規使用**周邊神經刺激器（Train-of-Four, TOF）**監控阻斷深度，預防長期受體後神經肌肉麻痺及粗肌絲溶解（CIM）。
  - **免疫檢查點抑制劑（ICI）與 CAR-T 神經毒性管理**：
    - CAR-T 引起的細胞因子釋放綜合徵（CRS）及免疫效應細胞相關神經毒性綜合徵（ICANS）：及早使用 IL-6 受體單株抗體 **Tocilizumab** 搭配皮質類固醇處置。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **嚴格防堵次發性腦損傷「四重奏」**：在加護照護中，全面杜絕「低血壓（$\text{SBP} < 90\text{ mmHg}$ 哪怕僅 10 分鐘）」、「低血氧（$\text{SpO}_2 < 90\%$）」、「體溫過高（發燒）」與「極端血糖波動」，此四者是摧毀半影區細胞的元凶。
2. **重症靜脈營養啟動前之 B 群鎖定原則**：對任何慢性酗酒、營養不良、長期嘔吐、癌症或敗血症昏迷患者，**在輸入任何含葡萄糖輸液前，必須立即常規靜脈注射高劑量維生素 $\text{B}_1$（$500\text{ mg}$）**，徹底阻斷 Wernicke 腦病變與不可逆失憶性精神病（Korsakoff's psychosis）。
3. **低血鈉緩慢糾正生理準則**：處理嚴重慢性低血鈉時，嚴格遵守 **前 24 小時上升不超過 $8\text{ mmol/L}$、48 小時不超過 $15\text{ mmol/L}$**，以保護腦橋寡寡突膠質細胞，防止致死性滲透性去髓鞘症候群（ODS）。
4. **階梯式標準降顱內壓處置（Stepwise ICP Protocol）**：
   - 第一階：床頭抬高 $30^\circ$、頭頸部維持正中（解除靜脈回流受阻）。
   - 第二階：腦室外引流管（EVD）引流腦脊髓液。
   - 第三階：滲透性治療（高張食鹽水或甘露醇，維持滲透壓 $< 320\text{ mosmol/kg}$）。
   - 第四階：短暫保護性過度換氣（$\text{PaCO}_2\ 30\sim35\text{ mmHg}$，僅作緊急橋接，不可長期使用）。
   - 第五階：升壓劑維持足夠 MAP 確保 $\text{CPP} \ge 60\text{ mmHg}$。
   - 後線頑固性處置：減壓去骨瓣手術（Decompressive craniectomy）或低溫療法。
5. **預防加護病房後天性衰弱（ICUAW）之脫機障礙**：面對呼吸器脫機困難之敗血症康復病患，應高度懷疑 CIP/CIM；照護端應落實嚴格血糖管理、盡可能避免併用大劑量類固醇與肌肉鬆弛劑，並每日執行鎮靜中斷評估（Sedation vacation）與早期復健介入。
