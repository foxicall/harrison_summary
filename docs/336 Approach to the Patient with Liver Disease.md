# 肝臟疾病的臨床評估與功能病理生理學剖析（Approach to the Patient with Liver Disease）
- **主講人/來源**：336 Approach to the Patient with Liver Disease.pdf（出自 *Harrison's Principles of Internal Medicine, 21st Edition*，執筆作者：Marc G. Ghany, Jay H. Hoofnagle；附錄包含臨床營養與再灌食症候群精要）
- **核心主旨**：精準整合臨床病史、微循環解剖生理（肝腺泡分區）、血清功能生化指標與非侵入性纖維化/脂肪成像技術，建構肝臟疾病從病因診斷（Etiology）、發炎活動度（Grading）到纖維化分期（Staging）的全面評估體系。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **微環境與細胞基質病變**：肝臟功能單位為**肝腺泡（Acinus）**。血液自 Zone 1（門脈周圍，高氧、高營養）流向 Zone 3（中央靜脈周圍，低氧、富含 CYP450 酵素，易受缺血與毒素損傷）。竇狀隙內皮細胞具孔洞（Fenestrae），使血漿直接進入**迪氏腔（Space of Disse）**與肝細胞微絨毛接觸。當肝臟受損發炎時，靜止的**星狀細胞（Stellate/Ito cells）**被活化轉化為肌成纖維細胞，大量合成膠原蛋白與細胞外基質（ECM），導致竇狀隙毛細血管化（Capillarization）與不可逆的纖維化/硬化。
  - **再灌食代謝失衡（Refeeding Crash）**：慢性營養不良或飢餓狀態下驟然給予碳水化合物，會刺激胰島素大量分泌，驅動磷（P）、鉀（K）、鎂（Mg）急速轉移至細胞內合成葡萄糖-6-磷酸（G6P）與肝醣，引發嚴重低磷血症、三磷酸腺苷（ATP）耗竭、抗利尿鈉滯留（水腫/急性心衰竭）及致死性魏尼凱腦病變（急症硫胺素/維生素 B1 耗竭）。
- **演講亮點與臨床洞察**：
  - **診斷思維的典範轉移（Paradigm Shift）**：肝切片（Liver Biopsy）傳統上是黃金標準，但近年非侵入性檢測（如 Transient Elastography [FibroScan]、MRI-PDFF、FIB-4、APRI）已大幅取代切片用於脂肪變性與纖維化分期；切片角色退居於病因不明或非典型表現之診斷。
  - **生化指標的臨床極限**：血清轉氨酶（ALT/AST）僅反映**當前肝細胞壞死/發炎活動度（Grade）**，完全不能代表**組織纖維化程度或疾病分期（Stage）**。在晚期肝硬化或靜止期慢性肝炎中，轉氨酶數值常呈現「假性正常」。血小板下降往往是門脈高壓與嚴重纖維化最早出現的警訊。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與病理生理評估目標 | 理想 / 關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **ALT / AST** | 肝細胞壞死與發炎指標（Hepatocellular pattern）。ALT 較具肝臟特異性。 | 正常值依各實驗室；急性重症常 $>10\times$ ULN；肝硬化晚期可能正常。 |
| **AlkP & $\gamma$-GT (GGT)** | 膽汁淤積指標（Cholestatic pattern）。$\gamma$-GT 用於確認高 AlkP 是否來自肝膽系統，並反映酒精或異物代謝負荷。 | 膽汁淤積時 AlkP 與 $\gamma$-GT 顯著平行上升；單獨 AlkP 高需排除骨骼病變。 |
| **總膽紅素 / 直接膽紅素** | 評估肝細胞結合、排泄能力及膽道通暢度。黃疸嚴重度與預後指標。 | 臨床肉眼黃疸通常於血清膽紅素 $>2.5\text{ mg/dL}$ ($>43\ \mu\text{mol/L}$) 出現。 |
| **白蛋白 (Albumin) & PT/INR** | 肝臟實質**真正合成功能（True Function）**指標。反映肝實質合成儲備量。 | Albumin $<3.0\text{ g/dL}$、INR $>1.7$ 提示嚴重肝功能失代償（Child-Pugh 計分項）。 |
| **血小板計數 (Platelet Count)** | 脾腫大（脾臟功能亢進）與門脈高壓之間接標記；早期纖維化篩檢關鍵。 | 進行性降低（例如 $<150 \times 10^9/\text{L}$）常提示顯著纖維化進展。 |
| **FIB-4 指數** | 基於年齡、AST、ALT、血小板的非侵入性纖維化計算模型。 | $<1.45$ 排除嚴重纖維化；$>3.25$ 高度懷疑進展性纖維化/硬化。 |
| **APRI 指數** | AST 與血小板比值指數，簡便篩檢進行性肝纖維化。 | $>1.0$ 提示顯著纖維化；$>1.5 \sim 2.0$ 提示肝硬化。 |
| **瞬時彈性成像 (TE / FibroScan)** | 剪切波速度測定肝組織硬度（Liver Stiffness Measurement, LSM）。 | $>7.3\text{ kPa}$ 提示嚴重纖維化（Advanced fibrosis）；$>15\text{ kPa}$ 強烈提示肝硬化。 |
| **MRI-PDFF / CAP** | 肝臟質子密度脂肪分率 / 受控衰減參數，定量評估肝臟脂肪變性程度。 | MRI-PDFF 為無創定量肝脂肪之黃金標準；CAP 用於床邊半定量評估。 |
| **再灌食監控：血清磷、鉀、鎂** | 預防再灌食症候群（Refeeding Syndrome）引發的細胞內離子移轉與猝死。 | 嚴重低磷血症（$<2.0\text{ mg/dL}$ 或 $<0.65\text{ mmol/L}$）需立即停滯加碳並靜脈補充。 |

## 三、 關鍵機制詳解與重點筆記

### 1. 肝臟微循環解剖與功能單位架構
- **肝腺泡（Acinus）的代謝分區**：
  - **Zone 1（門脈周圍區，Periportal）**：最先接觸來自肝動脈（20% 血流，高氧）與門靜脈（80% 血流，腸道營養與毒素）的混合血液。此區氧濃度最高，主要進行糖質新生、脂肪酸 $\beta$-氧化及膽汁酸分泌。
  - **Zone 3（中央靜脈周圍區，Perivenular）**：處於氧氣灌流末端，微環境相對低氧，為解毒代謝中樞（高濃度 CYP450 活性），此區對**缺血缺氧（Ischemia）**、**藥物毒性（如 Acetaminophen 毒性）**及**酒精性脂肪堆積**最為敏感，壞死常由 Zone 3 開始擴展。
- **竇狀隙微環境與迪氏腔（Space of Disse）**：
  - 竇狀隙內皮缺乏基底膜並具有大穿孔（Fenestrae），使富含大分子蛋白質的血漿可自由滲入迪氏腔，直接與肝細胞質膜表面微絨毛交換物質。
  - **庫弗氏細胞（Kupffer cells）**：定居於竇狀隙腔內的巨噬細胞，清除來自腸道的內毒素（LPS）與老舊血球。
  - **星狀細胞（Ito cells）**：平時於迪氏腔儲存維生素 A；受發炎細胞因子（如 TGF-$\beta$、TNF-$\alpha$）刺激後轉化為成纖維細胞，分泌 I 型與 III 型膠原蛋白，破壞內皮穿孔，導致肝細胞營養交換中斷。

---

### 2. 臨床表現模式之生化與病因鑑別
臨床肝病常歸納為三種表現表型（圖 336-1 演算法）：
```
                ┌── 急性 (<6個月) ─── 病毒性肝炎 (HAV/HBV)、藥物性 (DILI)、急性酒精性、膽管炎
                │
肝損傷呈現型態 ─┼── 肝細胞型 (Hepatitic: ALT/AST 顯著上升) ── 酒精性、病毒性、自體免疫性、代謝性脂肪肝
                │
                ├── 膽汁淤積型 (Cholestatic: AlkP/GGT 顯著上升) ─ 膽道結石、PBC、PSC、藥物性膽汁鬱積
                │
                └── 慢性 (>6個月) ─── HCV、ALD、NASH、HBV、AIH、血鐵沉積症、威爾森氏症
```
- **黃疸與膽紅素代謝動力學**：
  - **非結合型（間接）高膽紅素血症**：溶血（Hemolysis）或遺傳性結合障礙（如 Gilbert 症候群——常於斷食、壓力、感染時發作；罕見重症為 Crigler-Najjar 症候群）。尿液顏色正常（非水溶性，不經腎臟過濾）。
  - **結合型（直接）高膽紅素血症**：肝細胞排泄障礙或肝內外膽道阻塞。尿液呈深茶色（結合型膽紅素經尿液排出），大便呈灰白色（缺乏糞膽原）併發脂肪瀉與全身性搔癢（膽鹽沈積於周邊神經）。

### 3. 肝硬化併發症與臨床預後分期系統
- **門脈高壓與體循環高動力狀態（Hyperdynamic Circulation）**：
  - 內臟血管床受 NO 刺激過度擴張，有效循環血量下降，活化 RAAS 與交感神經，導致嚴重的鈉水滯留、心搏輸出量代償性增加（脈壓增寬）。
  - 側支循環建立：腹壁靜脈曲張（水母頭 Caput medusae）、食道胃底靜脈曲張、痔瘡。
  - **肝肺症候群（Hepatopulmonary Syndrome, HPS）**：肝病＋低血氧＋肺內微血管擴張，特徵為**直立性呼吸困難與直立性去氧合（Platypnea-Orthodeoxia）**。
- **肝腦病變（Hepatic Encephalopathy, HE）**：
  - 由於門脈體循環分流與肝功能衰竭，血氨及神經毒性物質未經肝臟清除進入中樞。
  - 早期徵象：睡眠週期顛倒、專注力下降、**連數字測驗（Trail-Making Test）耗時延長（正常 15~30 秒）**；進展期出現撲翼樣震顫（Asterixis）、肝臭（Fetor hepaticus）、昏迷。
- **臨床評分系統（Staging Tools）**：
  - **Child-Pugh 分級**：包含膽紅素、白蛋白、INR、腹水、肝腦病變。
    - Class A（5~6 分）：代償期（Compensated）。
    - Class B（7~9 分）：失代償期，為肝臟移植評估臨界點。
    - Class C（10~15 分）：嚴重失代償期。
  - **MELD 評分**：採用客觀連續變數（INR、血清膽紅素、血清肌酸酐、血清鈉），專門用於終末期肝病死亡率預測與器官分配。

### 4. 營養代謝危象：再灌食症候群（Refeeding Syndrome）病理機轉
- **代謝開關劇變**：長期禁食或嚴重消耗性疾病（如肝硬化惡病質、厭食症、慢性酒精中毒）中，能量代謝以脂肪酸與酮體為主。
- **級聯反應**：
  $$\text{急遽給予碳水化合物} \longrightarrow \uparrow \text{胰島素分泌} \longrightarrow \begin{cases} \text{刺激腎小管鈉再吸收} \longrightarrow \text{細胞外液（ECF）膨脹、急性肺水腫/心衰竭} \\ \text{驅動 } \text{PO}_4^{3-}, \text{K}^+, \text{Mg}^{2+} \text{ 入細胞} \longrightarrow \text{嚴重低磷/低鉀/低鎂血症} \longrightarrow \text{心律不整、骨骼肌溶解} \\ \text{大量消耗游離維生素 } \text{B}_1 \longrightarrow \text{急症魏尼凱腦病變（Wernicke's Encephalopathy）} \end{cases}$$

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 功能性營養素與代謝輔助處方
- **神經與代謝重啟前置防護（再灌食關鍵）**：
  - **維生素 B1（Thiamine）**：任何長期營養不良、酒精依賴或肝病患者在**接受任何葡萄糖輸注或高碳水飲食前**，必須常規預防性給予高劑量 Thiamine（100~500 mg IV/IM 或口服），以防止丙酮酸無法進入 TCA 循環產生乳酸堆積及不可逆性腦幹神經壞死。
  - **巨量礦物質平衝**：主動監測並預防性補充磷（Phosphate）、鎂（Magnesium Glycinate/Citrate 300~400 mg/d）與鉀離子，維持細胞膜電位與 ATP 生成。
- **肝細胞抗氧化與解毒路徑支持**：
  - **穀胱甘肽前驅物（NAC, N-Acetylcysteine）**：每日 600~1800 mg，補充肝內穀胱甘肽（GSH）儲備，對抗 Zone 3 細胞色素代謝過程中產生的親電子自由基與親脂性毒素。
  - **水飛薊素（Silymarin / Silybin）**：高生物利用度複合物，穩定肝細胞膜結構、抑制星狀細胞轉化為肌成纖維細胞，減緩膠原合成。
  - **磷脂醯膽鹼（Phosphatidylcholine）**：每日 1.5~3 g，促進極低密度脂蛋白（VLDL）組裝與分泌，預防甘油三酯鬱積於肝細胞胞漿內。

### 2. 營養調配與飲食再餵養策略
- **漸進式再餵養（Slow-up Feeding）**：
  - 針對高風險或長期消耗患者，起始熱量限制於 $10 \sim 15\text{ kcal/kg/day}$，碳水化合物限制於總熱量的 $40\% \sim 50\%$ 以下，嚴格限制鈉鹽供給以避免水腫及左心室超載。確認電解質平穩後，耗時 4~7 天逐步調升至目標熱量。
- **肝硬化與慢性肝病蛋白質供給原則**：
  - 破除傳統「肝硬化全面嚴格限蛋白」的過時觀念；除非發生急性嚴重昏迷且血氨極度失控，慢性肝病患者應維持 **$1.2 \sim 1.5\text{ g/kg/day}$** 的優質蛋白質，以避免肌少症（Sarcopenia，肝硬化死亡的獨立危險因子）。可增加植物性蛋白或富含**支鏈胺基酸（BCAA）**的來源，減少芳香族胺基酸產生。
- **鈉水控制**：合併腹水或門脈高壓水腫者，嚴格限制鈉攝取（$<2\text{ g/day}$ 即 $<88\text{ mmol/day}$）。

### 3. 環境毒素阻斷、代謝排毒與生活型態介入
- **完全戒除乙醇（Zero-Tolerance Alcohol）**：
  - 女性每天 $>20\text{ g}$、男性每天 $>30\text{ g}$ 即顯著增加酒精性肝硬化風險。臨床應以 **CAGE 問卷**落實篩檢（任一題回答「是」即應警惕，兩題以上高度懷疑酒精成癮）。
  - 對已有慢性肝炎（如 HBV、HCV、NASH）者，任何劑量的酒精均會與病毒/代謝因子產生協同致癌與致纖維化效應。
- **藥物與草藥清單審查（Deprescribing）**：
  - 停用未經證實安全性之草藥濃縮物、非必要膳食補充劑與非類固醇抗發炎藥（NSAIDs，會劇烈惡化門脈高壓引起的腎血流灌注，誘發肝腎症候群）。
- **腸-肝軸（Gut-Liver Axis）微生態調節**：
  - 透過水溶性膳食纖維、益生元及必要時使用乳果糖（Lactulose）酸化腸道，將氨（$\text{NH}_3$）轉化為不可吸收的銨離子（$\text{NH}_4^+$）排出體外，抑制致病菌產生內毒素，減輕庫弗氏細胞的促發炎刺激。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **區分發炎活動度（Grade）與纖維化分期（Stage）**：
   - 看到轉氨酶（ALT/AST）正常時，切勿輕易排除嚴重肝病；務必檢視血小板計數、白蛋白、INR，並善用 **FIB-4** 或 **FibroScan（TE）** 進行無創纖維化評估（若 TE $>7.3\text{ kPa}$ 或 FIB-4 $>3.25$ 應高度警惕進展期纖維化）。
2. **面對長期禁食或重度消耗患者，切勿立即高糖輸注**：
   - 首要步驟為監測血清磷、鉀、鎂數值，並**在給予葡萄糖前先行常規給予維生素 B1（Thiamine）**，碳水化合物應緩慢加量，嚴格限制鈉水，預防致死性再灌食症候群。
3. **門診問診落實 CAGE 評估與肝炎傳染暴露史追蹤**：
   - 對所有肝功能異常個案，詳細詢問注射藥物史、1992 年前輸血史、不安全性行為及刺青穿洞史；對高風險孕婦監控 HBV DNA，落實產前抗病毒治療與新生兒被動/主動免疫阻斷。
4. **精準選擇影像學工具**：
   - 膽道系統異常首選 US 或 MRCP（避免侵入性 ERCP 之胰臟炎風險）；肝臟脂肪變性定量首選 **MRI-PDFF**；肝細胞癌（HCC）高危險群應每 6 個月定期進行超音波合併甲型胎兒蛋白（AFP）篩檢，可疑病灶採用 **LI-RADS** 規範之對比增強 CT/MRI 或 CEUS 進一步確認。
