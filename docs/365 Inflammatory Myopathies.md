# 發炎性肌病變（Inflammatory Myopathies, IMs）之精準鑑別、病理機制與整合臨床處方指引
- **主講人/來源**：Chapter 365: Inflammatory Myopathies (Steven A. Greenberg, Anthony A. Amato) / 365 Inflammatory Myopathies.pdf
- **核心主旨**：深入剖析皮肌炎（DM）、多發性肌炎（PM）、免疫介導壞死性肌病變（IMNM）、抗合成酶症候群（AS）與包涵體肌炎（IBM）之分子病理（第一型干擾素毒性、補體反應與蛋白質自噬/粒線體老化凋亡），建立從自體抗體精準分型、肌肉切片診斷到整合免疫與代謝支持的臨床閉環策略。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **皮肌炎（DM）的病理典範轉移**：打破傳統單純「缺血壞死」理論，當前證據確立其核心為**第一型干擾素（Type I IFN，特別是 IFN-β）訊息傳遞路徑的過度活化**，導致微血管病變與肌束周圍肌纖維毒性損傷（Perifascicular atrophy）。
  - **壞死性肌病變（IMNM）的補體驅動**：缺乏廣泛發炎細胞浸潤，主要由抗體（anti-HMGCR 或 anti-SRP）引發膜攻擊複合物（MAC）沉積於非壞死肌膜，導致嚴重的補體介導肌纖維溶蝕壞死。
  - **包涵體肌炎（IBM）的「免疫-老化退化」雙重表型**：CD8+ T 細胞直接侵入非壞死肌纖維（自體免疫），同時伴隨**蛋白質恆定失衡（Proteostasis breakdown）**、自噬溶酶體衰退（p62/LC3、TDP-43 聚集）、內質網壓力（ER stress）與粒線體呼吸鏈損耗（COX-negative 及 ragged red fibers），具備高度細胞衰老（Cellular Senescence）與退化性特徵。
- **演講亮點與臨床洞察**：
  - **Statin 誘發之 anti-HMGCR 肌病變無法自限**：與常見的 Statin 毒性肌痛不同，anti-HMGCR IMNM **在停用 Statin 後病程依然持續惡化**，必須採取積極免疫治療（如 IVIG、類固醇與免疫抑制劑）。
  - **IBM 對傳統免疫抑制劑具備高度抵抗性**：臨床上好發於 50 歲以上男性，特徵為不對稱的**深層手指屈肌（FDP）與股四頭肌（股內/外側肌萎縮，相對保留股直肌）**無力，常被誤診為多發性肌炎（PM），過度使用免疫抑制劑無益，需轉向功能維持與防跌策略。
  - **惡性腫瘤高度共病警訊**：成年 DM（約 15% 伴隨癌症，尤其是抗 TIF1/p155 與抗 NXP2 抗體）與 anti-HMGCR IMNM 具備顯著腫瘤相關性，確診時必須全面啟動腫瘤篩檢。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **肌酸激酶（Creatine Kinase, CK）** | 評估骨骼肌急性破壞與壞死程度之最敏感指標；鑑別肌病變或神經源性病變 | 正常值常 <200 U/L；IMNM/急性 DM/PM 常 **>10× 至 50× 正常上限（>2000 U/L）**；IBM 則正常或輕微上升（**<10× 正常上限**） |
| **肌炎特異性自體抗體（MSAs）** | 判定特定臨床亞型、預後與併發症風險：<br>• **anti-MDA5**：無肌病型 DM、掌部紅斑、數位潰瘍、急速進展型間質性肺病（RPILD）<br>• **anti-TIF1 (p155) / anti-NXP2**：強烈關聯成人惡性腫瘤<br>• **anti-Mi-2**：典型皮膚病灶，預後良好且對治療反應佳<br>• **anti-HMGCR / anti-SRP**：壞死性肌病變（IMNM），前者可由 statin 誘發<br>• **anti-Jo-1（抗合成酶抗體）**：關節炎、雷諾氏現象、技工手（mechanic hands）、ILD<br>• **anti-cN-1A**：高度特異性指向包涵體肌炎（IBM） | 定性檢測陽性/陰性；輔助早期分型以精準擬定侵襲性治療或抗癌防範策略 |
| **黏液病毒抗性蛋白 A（MxA）染色** | DM 肌肉切片免疫組化檢查，評估第一型干擾素活性途徑之專一標記 | 較傳統肌束周圍萎縮更具高敏感度與特異度（於微血管與肌纖維呈現強陽性梯度染色） |
| **自噬與蛋白沉積標記（p62, TDP-43, 剛果紅）** | 評估 IBM 之蛋白質降解與自噬障礙；鑑別 PM 與 IBM | p62 陽性細胞質包涵體為 IBM 最敏感標記；冰凍切片剛果紅染色可見 β-sheet 類澱粉蛋白 |
| **粒線體呼吸鏈組織化學染色（COX / GOMORI 染色）** | 評估粒線體 DNA 缺失、氧化磷酸化受損與老化去適應程度（IBM 鑑別核心） | 觀察是否有 Cytochrome Oxidase (COX) 陰性纖維及破碎紅纖維（Ragged-red fibers, RRF） |
| **流式細胞儀淋巴球亞群（Flow Cytometry）** | 評估 IBM 之全身性免疫老化與異常 T 細胞克隆增生 | 偵測是否存在異常**大顆粒淋巴球（LGL）**族群，以及 **CD4/CD8 比例倒置（CD8 計數顯著升高）** |
| **肌肉核磁共振（MRI Muscle - STIR 序列）** | 評估急性肌肉/筋膜水腫（發炎活動度）、脂肪浸潤與肌肉特異侵犯分佈 | **STIR 高訊號**（水腫/活動性發炎）；IBM 顯示股內側肌/外側肌嚴重病變但相對保留股直肌（Rectus femoris sparing） |
| **硫代嘌呤甲基轉移酶（TPMT）** | Azathioprine 使用前之藥物基因毒性評估 | 篩檢酵素活性；缺乏者嚴禁使用 AZA，以避免致命性骨髓抑制 |

## 三、 關鍵機制詳解與重點筆記

### 1. 皮肌炎（DM）與壞死性肌病變（IMNM）的微血管毒性與補體破壞
- **皮肌炎（DM）的 Type I IFN 軸心**：
  - 傳統觀點認為 DM 是體液免疫導致的微血管破壞與肌肉缺血性梗塞。當前分子病理證實，內皮細胞幾乎無免疫球蛋白直接沉積，補體沉積屬次發性反應。
  - **核心驅動因子是 Type I IFN（主要為 IFN-β）**。IFN 誘導下游蛋白如 MxA（Myxovirus resistance protein A）大量表現於毛細血管與肌膜周邊，造成微血管毒性及基底角質形成細胞受損（出現細胞稀少性界面皮炎，Cell-poor interface dermatitis）。
- **IMNM 的補體級聯反應**：
  - 活化的抗體（anti-HMGCR/anti-SRP）觸發補體活化，使膜攻擊複合物（MAC, C5b-9）沉積於非壞死肌纖維肌膜。
  - 組織學特徵為：瀰漫散在的壞死纖維與巨噬細胞吞噬（Myophagocytosis），但**無明顯間質淋巴球浸潤**，病程具侵略性，需三合一免疫療法控制。

```
[自體抗原暴露 (如 Statin 誘導 HMGCR 上調)]
                │
                ▼
[產生專一性抗體 (anti-HMGCR / anti-SRP)]
                │
                ▼
[補體系統活化 ➔ MAC (C5b-9) 沉積於非壞死肌膜]
                │
                ▼
[快速肌纖維溶解壞死 (CK > 10-50x) ➔ 巨噬細胞吞噬 (少有淋巴球發炎浸潤)]
```

### 2. 包涵體肌炎（IBM）的蛋白質恆定崩解與粒線體衰老（Proteotoxicity & Mitochondrial Aging）
- **雙重致病假說（Autoimmune & Degenerative）**：
  - **自體免疫層面**：MHC-I 類分子廣泛異常上調，CD8+ 細胞毒性 T 細胞包圍並穿透非壞死肌纖維。
  - **退化老化層面**：類似阿茲海默症（AD）等神經退化疾患，肌纖維內出現錯誤摺疊的 β-sheet 蛋白聚合物（Amyloid）、TDP-43、LC3 及 p62。
- **自噬溶酶體衰退與內質網壓力（ER Stress）**：
  - 慢性發炎誘發異常「免疫蛋白酶體（Immunoproteasome）」表現，打亂了正常蛋白質合成與降解機制。
  - 電鏡下可見 **15–21 nm 之管狀絲狀包涵體（Tubulofilamentous inclusions）**，伴隨邊緣空泡（Rimmed vacuoles, 但 20~30% 切片可能遺漏）。
- **粒線體功能障礙**：
  - 伴隨大量的 COX 陰性纖維與破碎紅纖維，表明局部能量代謝耗竭與老化突變累積，解釋了為何對單純免疫抑制劑治療無反應。

### 3. 發炎性肌病變的臨床鑑別陷阱：復發 vs. 類固醇肌病變（Steroid Myopathy）
- 當使用高劑量 Prednisone 過程中患者肌力再次下降時，必須迅速鑑別：
  - **肌炎復發（Myositis Relapse）**：通常發生於類固醇減量過程中；**CK 水平再次攀升**；肌電圖（EMG）出現**自發性纖維顫動波（Fibrillations）與正銳波（Positive sharp waves）**等膜激惹現象。
  - **類固醇肌病變（Steroid Myopathy）**：發生於維持高劑量類固醇治療期；**CK 水平正常**；外觀具庫欣氏表型（Moon facies、瘀斑）；EMG **無肌膜激惹放電**；本質為皮質醇過量導致的肌肉蛋白質分解代謝亢進（Muscle catabolism）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 標準階梯免疫治療與藥物監控（整合西醫精準處方）
- **第一線急性誘導治療**：
  - **Prednisone**：0.75–1.5 mg/kg/day（成人通常以 60 mg/day 起始），早晨單次口服。若合併重症、心肌炎或間質性肺病（ILD），先予 **IV Methylprednisolone 1 g/day × 3 天**。
  - 維持治療至肌力恢復或達到平台期（通常 3–6 個月），隨後每 2–4 週減量 5 mg；降至 20 mg/day 後減速為每 2–4 週減量 2.5 mg，目標維持量 $\le$10 mg/day。
- **第二線免疫調節劑（早期併用以達 Steroid-sparing）**：
  - **Methotrexate (MTX)**：首選第二線藥物。起始 7.5–10 mg/週，漸增至 25 mg/週（口服或轉為皮下注射）。**處方必須常規併用葉酸（Folic acid 1–5 mg/day）或活性甲醯四氫葉酸（Folinic acid）**，以阻斷骨髓抑制、口角炎與肝毒性。
  - **Mycophenolate Mofetil (MMF)**：**合併間質性肺病（ILD）患者之首選第二線藥物**（成人 1–1.5 g BID），不具腎臟與肝臟毒性。
  - **Intravenous Immunoglobulin (IVIG)**：2 g/kg 於 2–5 天內輸注完畢，每月一次。**近年大型試驗證實為 anti-HMGCR 壞死性肌病變的重要首選/單一有效療法**。
  - **Rituximab**：針對頑固性 DM、抗合成酶症候群或重症 IMNM，清除 CD20+ B 細胞。

### 2. 功能性營養素/粒線體與肌少修復支持
- **保護肌肉合成與阻斷分解代謝**：
  - **支鏈胺基酸（BCAA）特別是白胺酸（L-Leucine, 3–5 g/day）或高濃度必須胺基酸（EAAs）**：激活 mTORC1 路徑，拮抗長期類固醇誘導的泛素-蛋白酶體肌肉萎縮途徑。
  - **一水肌酸（Creatine Monohydrate, 3–5 g/day）**：在發炎穩定期補充，改善肌細胞能量儲備（Phosphocreatine），協助肌力恢復。
- **粒線體支持與自噬優化（特別針對 IBM 與慢性粒線體衰退）**：
  - **CoQ10（Ubiquinol 200–400 mg/day）**：尤其針對曾有 Statin 暴露史、IMNM 或肌肉切片見大量 COX-negative 者，重建呼吸鏈電子傳遞。
  - **乙醯左旋肉鹼（ALCAR 1000–2000 mg/day）與 PQQ（20 mg/day）**：促進粒線體生物合成（Biogenesis）與脂肪酸 β-氧化。
  - **維生素 D3（3000–5000 IU/day）+ K2（MK-7 100–200 mcg/day）**：骨骼-肌肉軸線保護，預防高劑量類固醇引起的骨質疏鬆與肌肉萎縮。

### 3. 飲食、代謝調理與環境毒素阻斷
- **類固醇誘發型高血糖防禦飲食（Low-GI Anti-Inflammatory Diet）**：
  - 長期高劑量 Prednisone 極易誘發胰島素阻抗、內臟脂肪沉積與糖尿病。採取**低升糖負荷（Low-GL）、高纖維（>35 g/day）抗發炎飲食**，充足蛋白質攝取（1.2–1.6 g/kg/day，腎功能正常下），避免肌肉耗損。
  - 戒除高糖、超加工食品與致炎多元不飽和脂肪（高 Omega-6 種子油），增加 Omega-3 脂肪酸（EPA/DHA 2–4 g/day）以調節發炎前驅物質（Resolvins/Protectins）。
- **嚴格環境因子阻斷與防護**：
  - **嚴格光防護（Photoprotection）**：皮肌炎（DM）病患皮膚對紫外線（UV）高度過敏，UV 輻射可誘發角質形成細胞凋亡並驅動全身性 Type I IFN 活化，造成皮疹與肌力全面惡化。必備 SPF 50+ 物理性防曬與遮陽配備。
  - **環境藥物排查**：絕對停用所有 Statin 類藥物（即使是 IMNM 緩解後亦不可重啟），評估 Red Yeast Rice（紅麴）等含天然 lovastatin 成分之補充品，避免再次刺激免疫反應。

### 4. 運動復健與功能醫學生活型態介入
- **活動性急性發炎期**：避免高強度阻力訓練及過度「離心收縮（Eccentric contraction）」，以免加劇細胞膜破裂與肌球蛋白尿；此階段以關節活動度（Passive/Active ROM）及輕度本體感覺訓練為主，預防攣縮。
- **穩定期/慢性期與 IBM 功能性運動**：
  - **漸進式向心阻力訓練（Concentric training）**：每週 2–3 次，提升運動單位徵召。
  - **IBM 專屬功能處方**：IBM 患者由於手指屈肌與股四頭肌嚴重萎縮，臨床介入核心在於**職能治療（如輔助抓握工具、手部支架）**、**物理治療（加強防跌訓練、骨盆帶肌代償訓練）**與**吞嚥復健（預防隱性吸入性肺炎）**。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **全面進行自體抗體精準分型（MSAs Profiling）**：
   對所有疑似肌病變患者即刻抽檢包含 anti-MDA5、TIF1、NXP2、Mi-2、HMGCR、SRP、Jo-1、cN-1A 的 Myositis Panel。若 anti-TIF1/NXP2 陽性，應在 2–3 年內每半年啟動系統性惡性腫瘤排查。
2. **標準化切片採檢決策（Biopsy Stewardship）**：
   肌肉切片必須選定**臨床有受波及但未完全萎縮之肌群（MRC 肌力評級 4/5 級肌群）**，切忌切取 0–2 級之終末期纖維化肌肉；切片染色務必涵蓋 **MxA**（確認 DM）與 **p62/COX 染色**（抓出非典型 IBM）。
3. **免疫抑制劑合併與毒性預防處方**：
   - 處方 Methotrexate 時，**必備活性葉酸/亞葉酸處方**。
   - 處方 Azathioprine 前，**必須常規檢測 TPMT 基因型或酵素活性**，預防嚴重骨髓衰竭。
   - 長期類固醇使用病患，第一天起常規啟動骨密度監測、鈣/D3/K2 補充與血糖自我監控。
4. **包涵體肌炎（IBM）去毒害與防跌管理**：
   面對 50 歲以上進行性手指無力、常跌倒（膝打軟）、CK 僅輕度上升之患者，高度警惕 IBM。切勿無休止升級大劑量類固醇或化療藥物；及早介入**吞嚥攝影評估（VFSS）**與**下肢支架防跌復健**，守護病患生活自理能力與壽命。
