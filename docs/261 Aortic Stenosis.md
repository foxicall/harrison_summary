# 主動脈瓣狹窄（Aortic Stenosis）：從退化性鈣化病理機制、心肌重塑到介入決策與預防醫學整合思維
- **主講人/來源**：261 Aortic Stenosis.pdf
- **核心主旨**：主動脈瓣狹窄（AS）並非單純被動的老化磨損，而是由內皮受損、氧化脂質沉積與慢性發炎驅動的「瓣膜間質細胞成骨化轉化」進程；臨床上須把握不可逆機械性梗阻前的代謝與發炎介入黃金期，而當進展至嚴重狹窄伴隨血液動力學異常時，則需藉由精準影像分期與心臟團隊決策（TAVI vs. SAVR）挽救患者生命。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **活化性成骨進程**：瓣膜受機械壓力、輻射或內皮受損後，載脂蛋白（LDL、Lp[a]）滲入並氧化，召喚巨噬細胞、肥大細胞與 T 細胞釋放發炎因子（TNF-α、IL-1β、IL-6），進而啟動 WNT3a/BMP2 傳導路徑，誘發瓣膜間質細胞（VICs）轉化為成骨前驅細胞，透過 RUNX2、MSX2 及鹼性磷酸酶（ALP）沉積羥基磷灰石（Calcium Hydroxyapatite）骨基質。
  - **心肌重塑與失代償**：根據拉普拉斯定律（$S = Pr/h$），左心室初期以「向心性肥厚」代償後負荷增加以維持心輸出量（CO）；晚期則因肥厚心肌毛細血管密度不足、心室充盈壓（LVEDP）攀升壓迫內膜下動脈，引發心肌缺血與不可逆纖維化，最終導致收縮力衰竭。
- **演講亮點與臨床洞察**：
  - **典範轉移（Paradigm Shift）**：瓣膜硬化（Aortic Sclerosis）是心血管死亡與心肌梗塞的獨立危險因子，其本質是與動脈粥狀硬化同源的主動性生物發炎疾病，而非被動鈣化。
  - **藥物限制與介入轉折點**：Statins 與 RAAS 抑制劑無法逆轉已形成的瓣膜狹窄與鈣化，確立嚴重狹窄時不可盲目延誤手術。
  - **微創介入革新**：TAVI（經導管主動脈瓣置換）已拓展至全手術風險族群（低、中、高與極高風險），但對於年齡 <65 歲或合併升主動脈病變者，SAVR（傳統外科開胸換瓣）仍是首選。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **主動脈瓣血流峰速 ($V_{max}$)** | 反映瓣膜狹窄與血液動力學受阻程度 | 正常：<2.5 m/s；輕度：2.5–2.9 m/s；中度：3.0–3.9 m/s；**嚴重：≥4.0 m/s**（極嚴重：≥5.0 m/s） |
| **平均跨瓣壓力差 ($\Delta P_{mean}$)** | 評估左心室克服出口阻力所需承受的平均壓力負荷 | 輕/中度：<40 mmHg；**嚴重：≥40 mmHg**（低血流低梯度型除外） |
| **瓣膜開口面積 (AVA) / 指數 (AVAi)** | 定量瓣膜解剖開口狹窄的絕對與相對程度 | 正常：3.0–4.0 cm²；中度：1.0–1.5 cm²；**嚴重：<1.0 cm²**（或 **<0.6 cm²/m²**） |
| **左心室射出分率 (LVEF) 與 縱向應變 (GLS)** | 監控左心室代償性收縮功能與亞臨床心肌受損 | LVEF **<50%** 為失代償指標（需介入）；GLS 可於 EF 下降前早期預警收縮障礙 |
| **每搏輸出量指數 (SVI)** | 判別是否為低血流（Low-flow）亞型之關鍵依據 | **SVI <35 mL/m²** 定義為低血流狀態（Low-Flow AS） |
| **心臟電腦斷層瓣膜鈣化積分 (CT Calcium Score)** | 定量瓣膜鈣質沉積，用於低流速低梯度型 AS 確診 | 區分真性嚴重 AS 與偽性嚴重狹窄（尤其在不適用多酚丁胺試驗時） |
| **脂蛋白(a) [Lp(a)] & 氧化低密度脂蛋白 (Ox-LDL)** | 驅動瓣膜內皮發炎與成骨轉化的核心致病脂質微粒 | Lp(a) >50 mg/dL 或 >125 nmol/L 提示瓣膜鈣化高風險，需嚴格控管 |
| **多巴酚丁胺壓力超音波 (DSE)** | 評估「低血流、低梯度伴隨低 EF」患者的心肌流速儲備 | **每搏輸出量增加 ≥20%** 代表具有「血流儲備（Flow Reserve）」，手術預後較佳 |
| **心臟核磁共振延遲顯影 (CMR-LGE)** | 評估心肌間質反應性纖維化與不可逆性壞死疤痕 | 偵測心肌替代性纖維化，判斷術後心肌功能恢復潛力與猝死風險 |

## 三、 關鍵機制詳解與投影片重點筆記

- **瓣膜纖維鈣化之分子病理進程（解析圖 261-3）**：
  - **初期（脂質浸潤與內皮功能障礙）**：機械剪切力（如二葉瓣異常渦流）或輻射損傷瓣膜內皮，導致血循環中的 LDL 與 Lp(a) 進入瓣葉基質。內皮型一氧化氮合酶（eNOS）解偶聯，產生活性氧自由基（ROS），催化生成 Ox-LDL 與 Ox-PL。
  - **中期（慢性發炎迴圈）**：單核球、肥大細胞、T 細胞受趨化因子召喚浸潤，分泌基質金屬蛋白酶（MMPs）、組織蛋白酶、TNF-α、IL-1β 及 IL-6。局部腎素-血管張力素-醛固酮系統（RAAS）活化（Chymase 與 ACE 作用增加 Angiotensin II），進一步刺激瓣膜間質細胞（VICs）增生與表型轉換。
  - **晚期（成骨分化與異位骨化）**：在 Wnt3a/β-catenin 與 BMP2 途徑刺激下，VICs 轉化為具有骨骼成骨細胞特性的細胞，表現轉錄因子 **RUNX2** 與 **MSX2**；高表達鹼性磷酸酶（ALP）將焦磷酸鹽（PPi）分解為無機磷（Pi），與鈣結合成羥基磷灰石晶體，形成鈣化微囊泡，並透過細胞凋亡沉積骨基質，最終導致瓣葉攣縮、融合與石化。

- **血流動力學失代償與臨床三聯徵**：
  - **心絞痛（Angina, 發生後平均餘命 ~3 年）**：嚴重左心室肥厚使得心肌需氧量倍增；心室舒張末期壓（LVEDP）異常升高，大幅降低主動脈舒張壓至左心室腔之冠狀動脈灌注壓差；加上微血管密度未隨心肌肥厚等比例增生，即便冠狀動脈無解剖阻塞，亦會出現嚴重內膜下心肌缺血。
  - **運動性暈厥（Syncope, 發生後平均餘命 ~3 年）**：運動時骨骼肌血管大幅擴張以增加灌注，但固定狹窄的主動脈瓣使心輸出量無法代償性提升，加上左心室極高內壓刺激心室壁壓力受器引發血管舒張反射（Bezold-Jarisch-like 反射），導致全身動脈血壓驟降或引發致死性室性心律不整。
  - **呼吸困難與心衰竭（Dyspnea / Heart Failure, 發生後平均餘命 ~1.5–2 年）**：向心性肥厚導致心室順應性劇降，舒張期充盈受限，左心房壓及肺微血管楔壓（PCWP）顯著升高引發肺淤血；後期出現後負荷不匹配（Afterload Mismatch），心室收縮衰竭、EF 下降，進展至全心衰竭。

- **先天性雙葉性主動脈瓣（BAV）與主動脈壁病變（Aortopathy）**：
  - **遺傳背景**：最常見的先天性心臟結構畸形（0.5–1.4%），男性居多（2–4:1）。常染色體顯性遺傳伴不完全外顯，涉及 NOTCH1、GATA5、GATA4 等基因突變。
  - **主動脈擴張機轉**：BAV 合併升主動脈瘤（30–40%）並非單純狹窄後的血流衝擊所致，而是「內在血管中層退化（Medial Degeneration）」與「非對稱性偏斜渦流剪切力」雙重作用，即便瓣膜尚未嚴重狹窄，主動脈夾層與動脈瘤破裂風險已顯著增高。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

> **重要臨床認知**：已形成的嚴重機械性瓣膜鈣化無法單純透過營養素逆轉；功能醫學介入的核心在於**極早期阻斷「內皮受損—氧化脂質—發炎成骨」軸線**，以延緩硬化進展，並在不可逆心肌纖維化發生前協同常規醫療進行瓣膜置換。

- **功能性營養素/植化素補充**：
  - **維生素 K2（MK-7 形式，建議 100–360 mcg/天）**：
    - *機轉*：活化基質 Gla 蛋白（Matrix Gla Protein, MGP）的羧化作用，MGP 是體內強效的軟組織鈣化天然抑制因子，能阻斷鈣離子沉積於動脈壁與瓣膜基質。
  - **高濃度純化 Omega-3 脂肪酸（EPA/DHA，2–4 g/天）**：
    - *機轉*：下調 NF-κB，抑制 TNF-α、IL-1β 及 IL-6 等促炎細胞因子分泌，降低 sPLA2 與 Lp-PLA2 活性，減少瓣膜間質細胞的成骨訊號。
  - **多酚與強效抗氧化劑（反式白藜蘆醇 100–250 mg/天、薑黃素 500–1000 mg/天、輔酶 Q10 100–200 mg/天）**：
    - *機轉*：改善內皮細胞 eNOS 偶聯，降低活性氧自由基（ROS）生成，阻止 LDL 及 Lp(a) 氧化為具有成骨活性的 Ox-LDL 與 Ox-PL。
  - **高吸收率螯合鎂（甘胺酸鎂或牛磺酸鎂，300–400 mg/天）**：
    - *機轉*：維持細胞外液 Ca/Mg 恆定，作為天然鈣通道阻斷效應，調節磷酸鹽代謝，抑制血管平滑肌與瓣膜組織異位鈣化。

- **飲食與禁食策略**：
  - **抗動脈粥狀硬化／低晚期糖化終產物（Low-AGEs）地中海飲食**：
    - 強調富含多酚之特級初榨橄欖油、深海魚類、多色漿果與綠葉蔬菜；嚴格限制精緻糖、反式脂肪與加工肉品，降低全身性代謝發炎與氧化壓力。
  - **間歇性斷食（如 16/8 斷食法）**：
    - 在心功能未受損的代謝症候群期進行，旨在提高胰島素敏感性、啟動自噬作用（Autophagy）以清除衰老細胞及變性蛋白，下調促成骨分化途徑（Wnt/β-catenin）。
  - **水份平衡與電解質維持**：
    - 嚴重 AS 患者之左心室極度依賴充分的舒張期「前負荷（Preload）」以維持每搏輸出量；**臨床上嚴防過度禁食、脫水或大劑量利尿劑**，否則極易誘發心輸出量崩跌與突發性休克。

- **環境毒素阻斷/代謝排毒/生活型態**：
  - **嚴格戒菸與重金屬排毒**：
    - 香菸煙霧與重金屬（鎘、鉛）是強烈內皮毒素，會直接加劇活性氧堆積與瓣膜內皮破壞，應定期進行毒性重金屬暴露評估與螯合支持。
  - **心臟安全運動處方（精準風險分層）**：
    - **重度 AS（無論有無症狀）**：嚴格禁止競技性體育活動、高強度等長收縮阻力訓練（如大重量硬舉、重度閉氣 Valsalva 動作），以防左心室收縮壓失控攀升引發破裂或室性心律失常。
    - **輕中度或無症狀患者**：經醫師與運動心電圖（ETT）評估安全後，可執行規律低強度有氧運動（如散步、慢速自行車），以增進周邊肌肉氧合與血管微循環。
  - **口腔黏膜與牙周微生態屏障管理**：
    - 瓣膜內皮受損極易附著菌血症細菌形成贅生物（心內膜炎，IE）；必須落實牙周疾病治療與良好口腔衛生，預防口腔鏈球菌引起的菌血症。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **早期攔截瓣膜動脈硬化因子**：
   - 將「主動脈瓣硬化（Aortic Sclerosis）」視為全身血管動脈硬化的高危訊號。常規監測 **Lp(a)、Ox-LDL、hs-CRP、HOMA-IR**，透過生活型態與功能性抗炎抗鈣化營養處方（如 K2、Omega-3、抗氧化劑），於無症狀期減緩向嚴重狹窄進展的速率。
2. **高度警惕三大「死亡倒數」症狀**：
   - 門診隨訪主動詢問：**運動性心絞痛（Angina）、運動性暈厥（Syncope）、運動性呼吸困難/體力衰退（Dyspnea）**。一旦出現上述任一症狀，即進入極高猝死風險期（1.5~3 年內死亡率極高），必須於 1~3 個月內啟動心臟外科/結構心臟介入團隊評估。
3. **無症狀重度狹窄（Stage C）之轉介介入紅旗**：
   - 即使患者主訴無症狀，凡符合以下任一條件，應即刻轉介心臟團隊進行 AVR 評估：
     - **左心室射出分率下降（LVEF <50%）**。
     - **超音波峰速極高（$V_{max} \ge 5.0\text{ m/s}$）或平均梯度 $\ge 60\text{ mmHg}$**。
     - **運動跑步機試驗（ETT）誘發血壓下降或運動耐受力異常減退**。
     - **血清 BNP/NT-proBNP 升高大於正常值 3 倍以上**。
4. **精準選擇置換策略（TAVI vs. SAVR）**：
   - **年齡 <65 歲**：因生物瓣膜壽命限制（10 年衰敗率約 30%），強烈建議選擇 **SAVR**（評估機械瓣或 Ross 手術）。
   - **年齡 >80 歲或高手術風險/虛弱（Frailty）族群**：首選 **經股動脈 TAVI（TF-TAVI）**，可顯著縮短住院日數並降低圍術期中風及大出血風險。
   - **年齡 65–80 歲**：由多專科心臟團隊（Heart Team）依據解剖血管條件（股動脈口徑、鈣化程度、冠狀動脈開口高度）進行共同決策。
5. **用藥禁忌與容量管理守則**：
   - 伴隨高血壓之 AS 患者，降壓藥物（如 ACEi、ARB、Beta-blockers）應從小劑量開始緩慢滴定，**嚴禁過度使用強效血管擴張劑與利尿劑**，以防前負荷不足引發不可逆之低血壓性休克。
