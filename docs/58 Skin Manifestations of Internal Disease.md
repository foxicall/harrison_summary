# 內科疾病的皮膚表現：系統性病理的鏡像與功能醫學評估全解析 (Skin Manifestations of Internal Disease)
- **主講人/來源**：Jean L. Bolognia, Jonathan S. Leventhal, Irwin M. Braverman / *Harrison's Principles of Internal Medicine* (Chap. 58)
- **核心主旨**：皮膚是人體代謝、免疫、內分泌與微循環狀態的「外在投影」；透過形態學（型態、顏色、分佈）、血流動力學與微結構特徵的精準解構，臨床醫師能繞過侵入性探查，及早洞察潛在的惡性腫瘤、自體免疫風暴、代謝紊亂與隱性微量營養素匱乏。

---

## 一、 核心要點精華（Executive Clinical Summary）

### 核心病理生理機制
1. **微循環障礙與血管內皮發炎**：自體抗體沉積（如白血球破碎性血管炎 LCV、IgA 血管炎）、微血栓形成（DIC、TTP、抗磷脂質症候群 APS、單株冷凍球蛋白血症）及膽固醇栓塞，直接導致真皮血管破裂或缺血壞死（紫斑、網狀青斑、壞疽性潰瘍）。
2. **代謝紊亂與異常基質沉積**：胰島素阻抗驅動表皮棘層肥厚（黑棘皮症）；血脂異常引發巨噬細胞吞噬脂質沉著（黃色瘤）；尿酸鹽結晶沉積（痛風石）；異常類澱粉蛋白浸潤血管壁引發血管脆性劇增（Pinch purpura 捏拉性紫斑）。
3. **神經-內分泌-免疫軸失衡**：垂體 POMC 衍生物（ACTH 與 $\alpha$-MSH）過量刺激黑色素生成（Addison 氏病）；自體免疫攻擊黑色素細胞或毛囊幹細胞（白斑、圓禿），常合併多發性自體免疫內分泌病群（APS I/II 型、橋本氏甲狀腺炎）。
4. **細胞外基質合成與共價鍵斷裂**：微量營養素缺乏（如維生素 C 缺乏導致離胺醯/脯胺醯羥化酶失活）破壞膠原三股螺旋穩定性，造成毛囊角化伴隨血管周圍滲血（壞血病）。
5. **副腫瘤免疫交互作用**：腫瘤抗原與自體細胞抗原交叉反應或腫瘤釋放生長因子，誘發匍行性環狀紅斑（Erythema gyratum repens）、急性發熱性嗜中性白血球皮膚病（Sweet syndrome）、Bazex 症候群或突然爆發的脂漏性角化症（Leser-Trélat sign）。

### 演講亮點與臨床洞察
- **形態與顏色導向的鑑別架構**：跳脫「先知疾病再對照皮膚」的思維，改採「皮膚型態（丘疹鱗屑、紅皮、水泡、紫斑、顏色）$\rightarrow$ 內科系統關聯」的逆向鑑別診斷。
- **可觸摸性 vs. 不可觸摸性紫斑（Palpable vs. Nonpalpable Purpura）**：不可觸摸性紫斑核心在於**凝血因子缺陷、血小板減少、血管壁機械脆弱性或單純管腔內血栓**；可觸摸性紫斑則是**血管壁炎性浸潤（血管炎）或具炎性反應的感染性栓塞（如腦膜炎雙球菌、心內膜炎）**的絕對警訊。
- **甲褶微血管鏡檢（Capillaroscopy）的無創價值**：狼瘡（紅斑狼瘡）表現為彎曲迂迴的「腎小球樣（glomeruli-like）」血管微袢；硬皮症與皮肌炎則呈現微血管叢脫失（capillary dropout）伴隨代償性巨大擴張微血管，是評估結締組織病變微循環受損的窗口。

### 1. 代謝紊亂、微量營養素缺乏與基質沉積機制
- **黑棘皮症（Acanthosis Nigricans）**：
  - 代謝型：高濃度游離胰島素直接結合或經由旁路刺激纖維母細胞與角質形成細胞上的 **IGF-1 受體（IGF-1R）**，促使表皮棘層細胞過度增生與過度角化。
  - 惡性腫瘤型（Paraneoplastic）：胃腸道腺癌等腫瘤細胞分泌大量 **TGF-$\alpha$ 或 EGF**，刺激 EGFR 途徑，造成突發性、廣泛性天鵝絨樣色素沉著。
- **壞血病（Scurvy）與微血管完整性**：
  - 抗壞血酸（維生素 C）是內質網中**離胺醯羥化酶（Lysyl hydroxylase）與脯胺醯羥化酶**的關鍵還原輔因子。缺乏維生素 C 導致原膠原（Procollagen）無法形成穩定的三股螺旋氫鍵結構，毛囊周圍脆弱微血管無法承受血流剪力而破裂，形成特殊的「螺旋狀軟木塞毛髮（Corkscrew hairs）」及毛囊周圍出血。
- **煙鹼酸缺乏（Pellagra - 4D 症候群）**：
  - 缺乏 NAD/NADP 輔酶合成前驅物（Niacin/Tryptophan），導致高能量需求與高細胞更新組織（皮膚、消化道、中樞神經）DNA 修復障礙。光照後引發自由基堆積，出現邊界鮮明、伴隨亮光漆樣脫屑（varnish-like scale）的日光暴露區紅斑與色素沉著。
- **遲發性皮膚紫質症（PCT）**：
  - **尿紫質原去羧酶（UROD）**活性受阻（常因酒精、鐵過載、C 型肝炎病毒或遺傳突變誘發）。過量紫質進入體循環沉積於皮膚真皮微血管周圍；當吸收 UV-A（Soret band, 400–410 nm）光能後躍遷至激發態，釋放活性氧自由基（ROS），造成表皮下真皮微血管基底膜損傷、水泡破裂及真皮硬化（Milia、水泡、日光性脆弱）。

### 2. 微循環障礙、血管炎與紫斑病理學
- **紫斑的臨床形態分流核心原則**：
  - **非發炎/不可觸摸性紫斑（Nonpalpable Purpura）**：
    1. *凝血/血小板障礙*：ITP、血小板功能不良、凝血因子耗竭。
    2. *結締組織與血管結構支撐衰退*：類澱粉沉積（毛細血管脆性增加，輕觸即誘發 Pinch purpura）、老年性/日光性紫斑、長期皮質類固醇導致真皮膠原萎縮。
    3. *網狀非發炎微血栓（Retiform Purpura with Thrombi）*：DIC（暴發性紫斑 Purpura fulminans）、香豆素性壞死（Warfarin-induced necrosis，起因於蛋白質 C 半衰期短暫導致的抗凝-促凝短暫失衡）、單株冷凍球蛋白血症、抗磷脂質症候群（APS）。組織學見血管內纖維蛋白/球蛋白栓塞，**無**顯著血管壁嗜中性白血球破壞。
  - **發炎性/可觸摸性紫斑（Palpable Purpura）**：
    1. *白血球破碎性血管炎（LCV）*：免疫複合物（IgA、IgG、IgM）沉積於真皮後微靜脈，活化補體 C5a，趨化嗜中性白血球釋放溶酶體酶與活性氧，造成纖維蛋白樣壞死（Fibrinoid necrosis）與紅血球外滲。病灶邊緣呈均勻圓形。
    2. *感染性膿毒栓塞（Septic Emboli）*：腦膜炎雙球菌血症、淋病雙球菌、綠膿桿菌壞疽性深膿疱（Ecthyma gangrenosum）。栓子造成組織缺血壞死，邊緣多呈**不規則星狀（Angulated/Irregular infarct）**，常伴隨中央槍灰色壞死或出血性水泡。

### 3. 副腫瘤皮膚徵候群與基因性神經脊異常
- **匍行性環狀紅斑（Erythema Gyratum Repens）**：
  - 臨床表現為多重、快速移動的同心圓弧形紅斑，狀似「木紋（wood grain）」。**> 80% 合併內在惡性腫瘤**（特別是肺癌、食道癌、乳癌）。為腫瘤抗原與皮膚基底膜角質形成細胞交叉抗原引發的免疫波。
- **Leser-Trélat 徵象**：
  - 短時間內突然爆發數十至數百顆具發炎性基底的脂漏性角化症（Seborrheic keratoses），常合併皮贅（Acrochordons）與黑棘皮症。高度提示消化道腺癌（胃癌、大腸癌）。
- **Bazex 症候群（Acrokeratosis Neoplastica）**：
  - 鼻尖、耳廓、手足末端出現對稱性牛皮癬樣（Psoriasiform）過度角化性鱗屑斑塊。最常見於**上呼吸消化道鱗狀細胞癌（Squamous cell carcinoma of upper aerodigestive tract）**。
- **神經脊分化異常（Neurocristopathies）**：
  - **Waardenburg 症候群與 Shah-Waardenburg 症候群**：因 *PAX3*、*MITF* 或 *EDNRB/SOX10* 基因突變，導致源自神經脊的黑色素細胞及肌間神經節細胞遷移異常。臨床呈現花斑癬樣白斑（Piebaldism）、額前白髮（White forelock）、虹膜異色、感音神經性耳聾，以及巨結腸症（Hirschsprung disease）。

### 4. 結締組織病變之黏膜皮膚微結構標記
- **甲褶毛細血管微鏡特徵（Nailfold Capillary Microscopy）**：
  - 全身性硬化症（SSc）與皮肌炎（DM）：毛細血管壁嚴重破壞，微血管袢普遍脫失（Drop-out），殘存微血管代償性顯著擴張（Giant loops）伴隨微出血。
  - 全身性紅斑狼瘡（SLE）：毛細血管排列混亂、高度屈曲扭曲呈「腎小球樣（glomeruli-like loops）」，但較少出現大範圍微血管完全缺失。
- **壞疽性膿皮症（Pyoderma Gangrenosum, PG）與嗜中性白血球皮膚病**：
  - 具備**潛行性、壞死性紫羅蘭色邊緣（undermined necrotic violaceous border）**伴周邊紅暈。高達 50% 合併**發炎性腸道疾病（潰瘍性結腸炎 UC、克隆氏症 Crohn's）**或骨髓增生異常症候群（MDS/AML）。具備顯著**創傷反應性（Pathergy）**，微小外傷即可誘發新壞死潰瘍。

### 1. 功能性營養素 / 植化素補充
- **高生物利用度維生素 C（複方生物類黃酮）**：
  - **劑量**：500–1000 mg/day，分次補充。
  - **機轉**：維持離胺醯/脯胺醯羥化酶的亞鐵離子（$Fe^{2+}$）還原活性，強化血管周圍原膠原基質合成；對抗微血管脆性、非發炎性滲血及壞血病樣微出血。
- **活性型 B 群（甲基 B12、5-MTHF、活性維生素 B6 及 Niacinamide）**：
  - **劑量**：Niacinamide 100–500 mg/day；活性葉酸 800 $\mu$g/day；甲基 B12 1000 $\mu$g/day。
  - **機轉**：補充 NAD+ 池，促進紫外線誘導之角質形成細胞 DNA 損傷修復（改善癩皮病樣紅斑與色素紊亂）；降低同半胱胺酸（Homocysteine），減輕血管內皮發炎性氧化損傷。
- **微量元素（甘胺酸鋅 Zinc Bisglycinate）**：
  - **劑量**：25–45 mg/day 元素鋅（建議長期服用時搭配 1–2 mg 銅）。
  - **機轉**：鋅指轉錄因子輔助蛋白，加速表皮基底層角質形成細胞增殖、毛囊修復與免疫調節，改善休止期落髮與非特異性皮炎。

### 2. 飲食與代謝調控策略
- **逆轉高胰島素血症之抗發炎低升糖飲食（Low-GL / Mediterranean Diet）**：
  - **核心策略**：嚴格限制精緻糖類、高果糖玉米糖漿與超加工食品，大幅壓降空腹胰島素水準，阻斷 IGF-1R 介導的表皮棘層肥厚（逆轉代謝型黑棘皮症），並減少發疹性黃色瘤的乳糜微粒與 VLDL 堆積。
- **腸道-皮膚軸排除與修復飲食（Elimination Diet / Gut Protocol）**：
  - **針對適應症**：壞疽性膿皮症（合併 IBD）、結節性紅斑、蕁麻疹性血管炎及疱疹樣皮炎（Dermatitis herpetiformis）。
  - **執行原則**：嚴格無麩質（針對天疱瘡樣/疱疹樣皮炎的 Gluten-sensitive enteropathy）；排除乳製品、精緻大豆及食品添加劑。補充 L-麩醯胺酸（L-Glutamine 5–10 g/day）與高活性多菌株益生菌，降低腸道通透性（Leaky Gut），阻斷內毒素（LPS）移位觸發的皮膚嗜中性白血球浸潤。

### 3. 環境毒素阻斷 / 代謝排毒 / 生活型態
- **肝臟解毒管道支援與微量化學物質阻斷**：
  - **PCT 與光敏感排毒**：嚴格戒酒；避免接觸氯化烴（Chlorinated hydrocarbons）；監測並治療 C 型肝炎；針對鐵沉積患者執行放血療法（Phlebotomy）或使用鐵螯合劑，使血清 Ferritin 降至 20–50 ng/mL，恢復 UROD 酵素活性。
  - **藥物誘發性皮膚病監控**：詳細審視引發 DRESS、AGEP、TEN、乾癬惡化（鋰鹽、$\beta$-blockers、TNF 抑制劑）之致病藥物，必要時立即停藥。
- **微循環優化與生活防護**：
  - **雷諾氏現象與硬皮症/SLE 微循環危機**：杜絕尼古丁暴露（禁菸）；維持核心與肢端恆溫，避免冷暴露誘發之低溫球蛋白沉澱或嚴重血管痙攣壞死；慎選溫和水療，避免高壓強烈衝擊（預防壞疽性膿皮症的 Pathergy 反應）。
  - **廣譜光防護（UV-A + UV-B）**：針對紫質症、亞急性皮膚紅斑狼瘡（SCLE）、皮肌炎及藥物性光毒性患者，採用物理性氧化鋅防曬，阻斷穿透力強之長波 UV-A（320–400 nm）。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實「觸診」紫斑**：臨床遇見紫斑病灶時，必須親自觸診。**平坦（Nonpalpable）**者立即排查血小板計數、凝血功能、蛋白質 C/S、抗磷脂抗體及血清維生素 C 水準；**隆起（Palpable）**者立即排查全身性小血管炎（尿常規看血尿、ANCA、補體、免疫球蛋白）及感染性栓塞（血液培養、心臟超音波）。
2. **警惕急性「木紋斑」與「皮贅/脂漏性角化暴增」**：若成年患者突然出現木紋樣同心圓匍行紅斑（Erythema gyratum repens）或短期內爆發性長出無數具發炎紅底的脂漏性角化症（Leser-Trélat sign），切勿單純當作濕疹或皮膚老化，應啟動全套內臟惡性腫瘤篩檢（特別是胸部 CT、腸胃道內視鏡）。
3. **甲褶與口腔黏膜的常規視診**：面對不明原因關節痛、肌痛或雷諾現象患者，常規以皮表透光鏡（Dermoscopy）檢查指甲摺微血管（尋找巨血管微袢或微血管脫失）及硬腭/口腔黏膜（尋找無痛性潰瘍、微血管擴張、口周色素斑），早期鑑別 SLE、全身性硬化症、皮肌炎或 Peutz-Jeghers 症候群。
4. **難治性皮膚潰瘍嚴禁盲目清創**：對於疑似壞疽性膿皮症（Pyoderma gangrenosum）的紫羅蘭色潛行性潰瘍，必須詳細詢問發炎性腸道疾病史（腹瀉、黏液便），嚴禁進行外科擴創手術（Debridement），否則創傷反應性（Pathergy）將迅速導致潰瘍幾何級數惡化與擴大。
5. **代謝性皮膚表徵的逆向追蹤**：發現頸部、腋下黑棘皮症時，常規檢測空腹胰島素計算 HOMA-IR；發現眼瞼黃斑瘤或軀幹結節性黃色瘤時，即使血脂表面正常亦需警惕高三酸甘油酯血症（>1000 mg/dL 易誘發急性胰臟炎）或單株漿細胞病變（Normolipemic plane xanthoma）。
