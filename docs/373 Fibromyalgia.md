# 纖維肌痛症（Fibromyalgia）的中樞病理機制與全方位臨床整合管理
- **主講人/來源**：373 Fibromyalgia.pdf（Leslie J. Crofford 教授，節錄自 *Harrison's Principles of Internal Medicine* 第 373 章）
- **核心主旨**：纖維肌痛症本質為中樞神經系統「痛覺敏感化與下行抑制路徑失調」所驅動的慢性廣泛性神經痛覺異常與神經精神症候群；臨床處置核心需由「消滅周邊疼痛」轉向「中樞神經迴路重塑、生活功能恢復與共病多靶點整合管理」。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **中樞敏化（Central Sensitization）與下行抑制受損**：痛覺傳導路徑中的下行有害抑制控制（DNIC）失能，導致痛覺過敏（Hyperalgesia）與異常疼痛（Allodynia）；功能性磁振造影（fMRI）證實大腦在非傷害性刺激下即活化疼痛網絡。
  - **神經傳導與單胺類代謝異常**：血清素（Serotonin）與正腎上腺素等單胺類物質的代謝、受體及轉運蛋白基因多型性，促發中樞神經生理失調。
  - **神經-內分泌-壓力軸失衡與小纖維病變**：長期心理/生理壓力誘發中樞壓力生理機制異常；部分亞群患者合併周邊小纖維神經病變（Small fiber neuropathy）。
- **演講亮點與臨床洞察**：
  - **診斷思維典範轉移**：最新診斷標準打破過往「18 個壓痛點需符合 11 個」的嚴格門檻，轉為聚焦於「多部位/廣泛性疼痛（≥3 個月）」合併「核心神經精神症狀」（非恢復性睡眠、疲勞、腦霧、情緒障礙）。
  - **周邊觸發與中樞放大的雙軌架構**：退化性關節炎、肌腱炎或自體免疫疾病常扮演「周邊疼痛產生器（Peripheral pain generators）」，在 10–30% 風濕免疫病患中進一步誘發中樞性纖維肌痛症。
  - **臨床用藥禁忌與多症狀靶點導向**：**強效鴉片類藥物無效且會惡化痛覺敏感性與功能，嚴格列為禁忌**；非類固醇消炎止痛藥（NSAIDs）與類固醇僅能處理周邊發炎觸發因子，無法緩解纖維肌痛本質。處方應依據「疼痛＋失眠」或「疼痛＋疲勞/憂鬱」等核心症狀群精準匹配單一多效型藥物。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）
纖維肌痛症常規檢驗與影像通常為**正常**，實驗室與影像檢查的核心目的為**鑑別排除其他器質性疾病，並評估潛在的周邊發炎觸發源或代謝共病**：

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **ESR / 高敏 C 反應蛋白 (hs-CRP)** | 排除活動性自體免疫或發炎性關節炎（如風濕性多發性肌痛症 PMR、類風濕性關節炎 RA） | 純纖維肌痛症應為正常範圍；顯著上升需追查自體免疫發炎 |
| **TSH / 甲狀腺功能** | 排除甲狀腺功能低下或亢進引發的肌肉無力、慢性疲倦與瀰漫性痠痛 | 臨床正常參考區間；需維持在理想代謝功能範圍 |
| **全血細胞計數 (CBC)** | 評估貧血、慢性感染或血液系統異常導致的廣泛疲勞與缺氧虛弱 | 正常參考標準 |
| **生化代謝全項 (CMP)** | 評估肝腎功能代謝狀態、電解質平衡及潛在代謝性肌病 | 正常參考標準 |
| **ANA / Anti-SSA / Anti-SSB** | 鑑別全身性紅斑狼瘡（SLE）或修格連氏症（乾燥症）等結締組織疾病 | 依臨床自體免疫表徵選擇性檢查；陰性為佳 |
| **RF / Anti-CCP** | 鑑別類風濕性關節炎等慢性周邊關節發炎誘發因子 | 陰性或正常值 |
| **肌酸激酶 (CPK)** | 排除發炎性肌病（多發性肌炎）或藥物引發的肌病（如 Statins） | 正常範圍（避免藥物性肌溶解或肌炎） |
| **感染性血清檢查 (HCV, HIV, Lyme, EBV, Parvo B19)** | 排除病毒性肝炎、慢性萊姆病、EB 病毒等引發之感染後慢性疲勞/肌痛 | 陰性反應 |
| **壓痛點檢查 (Tender-point examination)** | 評估痛覺敏感度；以拇指施加約 $4\text{ kg/m}^2$ 壓力（指甲反白程度）於 18 處解剖特定點 | 舊制標準為 18 處中達 ≥11 處疼痛（現作為評估疼痛過敏參考） |
| **脊椎 MRI / 骨關節 X 光** | **常規強烈不建議進行 MRI**，僅在具神經根壓迫徵候或中軸炎性脊椎病變紅旗警訊時使用 | 避免過度檢查造成不必要的醫療焦慮與致病化行為 |

## 三、 關鍵機制詳解與投影片重點筆記
- **中樞敏化與大腦神經網絡異常活化**：
  - **神經痛覺感知異常**：中樞神經系統對感覺傳入訊息的處理異常，下行疼痛抑制路徑（DNIC）功能低下，引發對微弱刺激的痛覺過敏（Hyperalgesia）及非痛性刺激引發疼痛（Allodynia）。
  - **fMRI 客觀佐證**：功能性神經影像學證實，健康受試者無痛的輕微刺激，在纖維肌痛患者大腦內會引起顯著且廣泛的疼痛中樞網絡活化。
  - **小纖維神經病變關聯**：部分符合診斷之亞群出現周邊小無髓鞘神經纖維（Small fiber neuropathy）受損，可能代表神經發炎或周邊-中樞互動的生理表型。
- **慢性重疊疼痛症候群（Chronic Overlapping Pain Syndromes, COPS）與共病串聯**：
  - **共病網絡**：纖維肌痛常與慢性疲勞症候群（ME/CFS）、顳顎關節疾患（TMD）、大腸激躁症（IBS）、間質性膀胱炎/骨盆腔疼痛及偏頭痛高度重疊，共享中樞調節障礙路徑。
  - **周邊觸發因子（Peripheral Triggers）的作用**：關節炎、滑囊炎、肌腱炎或關節過度活動（Hypermobility）等周邊病灶持續向中樞傳遞傷害性訊號，成為促發與維持中樞痛覺擴散的導火線。
  - **心理神經免疫交織**：高達 80% 的患者終生罹患情緒障礙（憂鬱/焦慮）；壓力賀爾蒙、創傷後壓力症候群（PTSD）與童年逆境事件會與中樞疼痛迴路產生交互作用，加劇「災難化思維（Catastrophizing）」並惡化功能受損。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）
- **神經調節與多靶點藥理介入**：
  - **疼痛伴隨失眠/肌肉痙攣**：首選具鎮靜效果的神經調節劑，包括環苯扎林（Cyclobenzaprine）、三環抗憂鬱劑（Amitriptyline），或電壓門控鈣離子通道 $\alpha_2\delta$ 配體（Pregabalin、Gabapentin），可同步改善痛覺與促進深度睡眠。
  - **疼痛伴隨慢性疲勞/情緒困擾**：首選血清素與正腎上腺素再吸收抑制劑（SNRIs，如 Duloxetine、Milnacipran），提升下行疼痛抑制系統的單胺類傳導物質濃度，兼具鎮痛與抗憂鬱/抗焦慮效能。
  - **輔助鎮痛**：Tramadol（具微弱 SNRI 活性的非典型鴉片類藥物）在臨床試驗具療效證據，可作為短期輔助；**嚴禁使用強效鴉片類藥物（Strong Opioids）**。
- **身心調節與能量醫學（Mind-Body & Integrative Modalities）**：
  - **經皮神經電刺激（TENS）**：臨床實證能有效降低活動引發的疼痛（Movement-evoked pain）並改善疲勞感。
  - **身心流動與傳統療法**：氣功、瑜伽、太極（Tai Chi）與針灸、水療法（Hydrotherapy），能調節自律神經張力，重置大腦痛覺過敏連結。
- **生活型態與功能性行為重建**：
  - **漸進式低強度運動（Cornerstone of Therapy）**：
    - 活動嚴重耐受不良或長期久坐者，由「溫水水中有氧運動（Water-based programs）」或超低強度有氧訓練啟動。
    - 採取「階梯式慢速漸進（Start low, go slow）」策略，達成有氧目標後再納入肌力阻力訓練，避免劇烈波動誘發運動後疼痛發作（Post-exertional flare）。
  - **認知行為療法（CBT）與睡眠衛生**：
    - 打破「疼痛—災難化焦慮—失眠—疼痛加劇」的惡性循環，增強自我效能（Self-efficacy）。
    - 建立規律晝夜節律睡眠衛生，積極篩檢並排除阻塞型睡眠呼吸中止症（OSA）與不寧腿症候群（RLS）。
  - **醫病關係與疾病行為去化（De-medicalizing Illness Behavior）**：
    - 衛教重點置於「恢復日常生活功能與生活品質」，而非承諾「完全消除疼痛」。
    - 減少頻繁、無效的重複性侵入檢查與就醫行為，引導患者主動參與生活型態管理。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **確立診斷思維轉向**：遇到慢性廣泛性疼痛病患，應即刻評估核心神經精神四聯症（疲勞、未恢復性睡眠、腦霧、焦慮/憂鬱），不拘泥於 18 處壓痛點計數，早期確診以終結病患盲目求醫歷程。
2. **精準鑑別周邊與中樞**：全面評估並積極治療潛在的周邊疼痛觸發器（如退化性關節炎、肌腱炎或自體免疫發炎），但當疼痛超出解剖範圍並合併中樞症狀時，應即刻啟動中樞神經調節治療，避免無止盡加重抗發炎消炎藥劑量。
3. **單一藥物多靶點匹配，嚴禁強效鴉片類**：依患者表型選擇「鎮靜修復型（Pregabalin/Amitriptyline）」或「抗疲勞抗鬱型（Duloxetine/Milnacipran）」；堅決避開強效鴉片類止痛藥，防止疼痛過敏及中樞功能惡化。
4. **處方化漸進式運動療法**：將低強度有氧運動（如溫水水中有氧、太極）視為一線處方，嚴格遵循「從超低強度開始、進展緩慢而持續」原則，並配合衛教減低災難化恐懼。
5. **重塑以功能為核心的醫病盟友關係**：臨床目標設定為「角色功能 fulfillment、恢復社交與精神生活品質」，而非痛覺量表上的絕對零分，協助患者建立強大的健康自我管理效能。
