# 臨床微生物與宿主免疫防禦專題：李斯特菌（*Listeria monocytogenes*）與伺機性革蘭氏陽性桿菌的病理機制及臨床全人防治

- **主講人/來源**：151 Listeria monocytogenes Infections.pdf（節選自權威內科學《Harrison's Infectious Diseases》第 151 章及相關革蘭氏陽性菌章節）
- **核心主旨**：深入剖析李斯特菌（*Listeria monocytogenes*）及相關放線菌/棒狀桿菌的細胞內寄生與免疫逃避機制，確立胃酸屏障、細胞介導免疫（CMI）與微環境鐵代謝在宿主防禦中的核心地位，提供從病理生理、神經/產科高危表型識別到臨床精準處置的完整架構。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **化學與黏膜屏障崩解**：低胃酸狀態（如長期使用 PPI）降低感染閾值；細菌經由腸道上皮跨細胞移行（Transcytosis）進入腸系膜淋巴結與血流，靶向肝、脾並突破血腦屏障（BBB）與胎盤屏障。
  - **細胞內逃逸與直接細胞間傳播**：利用孔洞形成細胞溶素（Listeriolysin O, LLO）與磷脂酶破壞吞噬溶酶體並逸入宿主細胞質；表面蛋白 ActA 驅動宿主肌動蛋白重塑形成「彗星尾」，促成直接細胞間跳躍，完全避開體液免疫（抗體與補體）。
  - **微環境鐵代謝依賴**：鐵離子顯著促進李斯特菌體外生長，鐵過載狀態（如血色素沉著症 Hemochromatosis）為侵襲性感染的強烈易感因子。
  - **細胞介導免疫缺損**：先天免疫依賴 IFN-γ 與 TNF-α 活化巨噬細胞，後天防禦完全仰賴 CD8+ 毒殺型 T 細胞；體液免疫幾無保護作用。
- **演講亮點與臨床洞察**：
  - **破除類固醇神經保護迷思**：在李斯特菌神經病變（Neurolisteriosis）中，使用地塞米松（Dexamethasone）**反而會增加死亡率**，此與典型化膿性腦膜炎之常規處置截然不同。
  - **低溫冷藏（4°C）耐受性**：李斯特菌具嗜冷、耐低 pH、耐高鹽特性，一般冷藏環境仍可持續增殖，使輕度污染在存放後轉變為高菌量感染。
  - **單核球減少症（Monocytopenia <200 cells/μL）之不良預後**：菌血症患者若合併絕對單核球計數偏低，與 3 個月高死亡率（整體達 46%）顯著相關。
  - **雙相性菱腦炎（Rhombencephalitis）**：特異性侵犯健康年長者之腦幹與小腦，初發發燒頭痛，數日後進展為不對稱腦神經麻痺與呼吸衰竭，CSF 異常往往輕微，**MRI 明顯優於 CT 診斷**。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準（文獻依據） |
| :--- | :--- | :--- |
| **絕對單核球計數 (Absolute Monocyte Count, AMC)** | 反映單核-巨噬細胞系統之先天防禦儲備；重度低下為李斯特菌血症死亡的獨立預測因子 | **關注危險值：< 200 cells/μL**（與死亡率顯著上升相關） |
| **腦脊髓液 (CSF) 常規與生化分析** | 評估中樞神經感染（Neurolisteriosis）；與典型化膿性腦膜炎相比，反應較為溫和 | 白血球常 **< 1,000/μL**（75% 患者），嗜中性球比例不顯著；約 **30–40%** 患者出現 CSF 葡萄糖降低 |
| **無菌部位培養 (Blood / CSF / 羊水)** | 侵襲性感染黃金診斷標準；產婦疑似感染時需常規抽血培養（陽性率約 50%） | 正常應為無菌；可見短小革蘭氏陽性桿菌、具翻滾運動性（Tumbling motility） |
| **CSF 多重聚合酶連鎖反應 (Multiplex PCR)** | 快速鑑別中樞神經感染，彌補革蘭氏染色陰性或呈現擬似球菌/類白喉桿菌之偽陰性 | 陰性（若陽性可快速鎖定 *L. monocytogenes*） |
| **鐵代謝標記 (Serum Ferritin, Transferrin Saturation)** | 評估宿主微環境鐵負荷；游離鐵或過量鐵儲存顯著促進胞內菌生長 | 鐵飽和度過高、高儲鐵蛋白需高度警惕侵襲性感染風險 |
| **胃酸 pH 值 / 質子幫浦抑制劑 (PPI) 暴露史** | 胃酸屏障功能評估；化學屏障低落導致極低菌量即可跨越胃腸道 | 維持生理性強酸（pH < 3.0）以抑制外源病原體存活 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 胞內逃逸、運動性動力學與體液免疫逃避
- **LLO 與 Phospholipases 逃逸胞室**：李斯特菌被宿主細胞吞噬進入內吞泡（Phagosome）後，立即分泌孔洞形成毒素 Listeriolysin O 及磷脂酶，破壞空泡膜逃逸至宿主細胞質溶膠（Cytosol），避免進入吞噬溶酶體被降解。
- **ActA 蛋白引導的細胞間轉移**：菌體表面 ActA 誘導宿主肌動蛋白（Actin）聚合，形成極性推進力（Actin tail），將細菌推至細胞膜邊緣並向鄰近細胞突出偽足樣突起；鄰近細胞將其內吞後再次破泡釋放。**整個傳播過程完全不暴露於胞外環境**，徹底規避了循環抗體、補體系統的調理與清除。

### 2. 宿主免疫監視、TNF-α 阻斷與類固醇禁忌
- **Th1 / CD8+ T 細胞與先天細胞激素**：清除胞內菌的關鍵在於活化單核-巨噬細胞，其中 **IFN-γ 與 TNF-α** 是維持先天抗病力的中樞樞紐；CD8+ 毒殺型 T 細胞則是長效保護力的主要貢獻者。
- **TNF-α 抑制劑之黑框警告**：FDA 明確將李斯特菌感染列入 TNF-α 抑制劑之黑框警語，證實細胞免疫軸線阻斷將使潛伏或微量攝入之李斯特菌演變為致死性侵襲感染。
- **Dexamethasone 的不良反應**：在常規細菌性腦膜炎中，類固醇可減輕發炎引起的腦水腫，但在李斯特菌腦膜腦炎中，使用地塞米松會削弱清除細胞內菌所需的細胞免疫，臨床研究證實其與**更高死亡率**直接相關。

### 3. 神經嗜性與特殊神經表型（Rhombencephalitis）
- **高發生率腦膜腦炎**：高達 84% 的神經李斯特菌病以腦膜腦炎（Meningoencephalitis）呈現，而非單純腦膜炎；伴隨意識改變、癲癇或局部神經學缺損。
- **小腦與腦幹腦炎（菱腦炎）**：好發於免疫功能看似正常的年長者。臨床呈現典型雙相病程：
  - *第一階段*：先驅發燒、劇烈頭痛。
  - *第二階段*：數日後突發不對稱腦神經麻痺（如面癱、吞嚥困難）、共濟失調（Ataxia）、震顫、半側偏癱或半身感覺缺損；近半數併發呼吸中樞抑制衰竭。
  - *影像學金標準*：CT 敏感度極差且 CSF 常僅輕度異常，**必須及早實施腦部 MRI 評估**。

### 4. 妊娠期母胎軸線與新生兒致死併發症
- **懷孕第三期免疫耐受風險**：為維持母體對胎兒的免疫耐受，生理性細胞介導免疫下調，使第三孕期孕婦成為李斯特菌主要受害族群。
- **母體微症狀 vs. 胎兒災難性後果**：孕婦多僅表現為自限性類流感症狀（發燒、頭痛、關節肌痛），極少發生神經感染；但病原體可經胎盤垂直感染胎兒，僅約 5% 母體能維持完全正常的足月生產與產後過程。
  - 胎兒死亡率（24%）、早產（45%）、足月異常生產（21%）。
  - **早產型敗血症（Early-onset sepsis）**：生後 48 小時內發病，多為子宮內感染引發，死亡率 10–50%。
  - **嬰兒肉芽腫性敗血症（Granulomatosis infantiseptica）**：特異性宮內重度感染，特徵為皮膚、肝臟、脾臟出現廣泛微膿瘍與肉芽腫，多致死產或產後迅速夭折。

### 5. 延伸伺機性革蘭氏陽性菌的病理特徵（差異鑑別）
- ***Rhodococcus equi*（馬紅球菌）**：
  - 專性胞內寄生菌（巨噬細胞），抗酸染色常呈陽性（弱抗酸），易與結核桿菌或諾卡氏菌（*Nocardia*）混淆。
  - 易感族群：HIV/AIDS 等重度免疫不全者；典型表現為肺上葉空洞性/結節性肺炎及肉芽腫壞死乾酪化。
  - **治療禁忌**：**β-Lactam 類抗生素無效**；首選為能穿透細胞膜之抗生素（Vancomycin 為首選藥物，或併用 Macrolides、Rifampin、TMP-SMX）。
- ***Arcanobacterium haemolyticum*（溶血阿坎棒狀桿菌）**：
  - 青少年咽喉炎合併軀幹/近端肢體猩紅熱樣皮疹（常被誤診為猩紅熱、TSS 或合併 EBV 感染）。
  - 糖尿病患易好發菌血症、軟組織壞死、骨髓炎或空洞性肺炎。**對 TMP-SMX 及 Tetracycline 原發抗藥**。
- ***Corynebacterium minutissimum*（微小棒狀桿菌）**：
  - 造成紅癬（Erythrasma），Wood 氏燈照射呈現特異性**珊瑚紅螢光（Coral red fluorescence）**。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 1. 免疫代謝與營養屏障支持
- **鐵恆定管理（Iron Regulation）**：避免在急性感染期或不明原因發燒時盲目高劑量補鐵；鐵過載患者應積極評估放血或螫合治療，限制細菌利用游離鐵進行對數生長。
- **細胞介導免疫（Th1/CD8+）營養調控**：維持足量活性維生素 D3（調節巨噬細胞活性與抗菌胜肽）、鋅離子與抗氧化儲備（如 N-乙醯半胱胺酸 NAC、穀胱甘肽），以健全單核球抗胞內菌反應。

### 2. 胃腸道化學屏障維護與用藥審查
- **PPI / H2 阻斷劑適應症重估**：胃酸是阻斷李斯特菌經口感染的第一道關鍵防線。對於長者、免疫低下或孕婦，應嚴格評估並減少不必要的胃酸抑制劑處方，維持胃內強酸殺菌屏障。
- **腸黏膜完整性支持**：藉由麩醯胺酸（L-Glutamine）與水溶性膳食纖維維持緊密連接蛋白（Tight junctions），降低跨細胞移行（Transcytosis）風險。

### 3. 高危險群食品安全與生活型態處方（懷孕、高齡 >59 歲、免疫抑制族群）
- **嚴格規避高風險冷藏/即食食品**：
  - 絕對避免未殺菌生乳及以生乳製作的軟質乳酪（如 Camembert、Brie、Feta）。
  - 避免食用冷藏即食熟肉、冷盤肉品（Deli meats）、熱狗（除非加熱至滾燙起泡）。
  - 避免生食豆芽、未加熱之冷藏沙拉、未清洗的哈密瓜等甜瓜類水果。
- **冷藏環境管理**：李斯特菌能在 4°C 繁殖，冷藏庫溫度應維持低於 4°C（最好在 1–3°C），且即食熟食冷藏時間不得過長，需落實徹底加熱殺菌再食用。

### 4. 急性期臨床治療精準方針
- **抗生素選擇**：
  - 李斯特菌感染標準治療依賴穿透性高的殺菌性藥物（如高劑量 Ampicillin/Penicillin G，常合併 Gentamicin 具協同殺菌作用；對青黴素過敏者首選 TMP-SMX）。
  - **Cephalosporins 原發性無效**：李斯特菌對所有頭孢菌素類抗生素具有內生性抗藥性，不得單用經驗性頭孢菌素治療不明原因之中樞神經感染。
- **Neurolisteriosis 嚴禁常規類固醇**：若疑似李斯特菌腦膜腦炎或菱腦炎，**切勿常規給予 Dexamethasone**，以免阻抑 CD8+ 清除功能而增加死亡率。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **老年中樞神經感染的經驗處方思維**：對年齡 >50 歲、免疫抑制或酗酒的社群型腦膜炎患者，經驗性抗生素**必須涵蓋 Ampicillin**，絕不能僅依賴 Ceftriaxone + Vancomycin，且若懷疑李斯特菌應**暫停/避免使用 Dexamethasone**。
2. **神經病徵合併非典型 CSF 須警惕菱腦炎**：若長者出現發燒合併不對稱腦神經麻痺、共濟失調或呼吸衰竭，即使 CSF 葡萄糖與白血球增加不顯著，應立即安排**腦部 MRI** 並啟動抗李斯特菌治療。
3. **懷孕第三期發燒的警覺原則**：孕婦出現任何無法解釋的發燒、畏寒與類流感症狀，必須立即進行**血液培養**；切勿輕易歸咎為一般病毒性感冒，及早介入抗生素可防止子宮內致命性感染（胎兒死產或肉芽腫性敗血症）。
4. **住院病患爆發感染之食物溯源**：院內新發李斯特菌症常與醫院供應之特定冷藏即食食品（預切芹菜、冰淇淋、三明治、未殺菌起司）有關，感控團隊應具備利用 WGS（全基因體定序）溯源之意識。
5. **鑑別馬紅球菌（*R. equi*）與結核感染**：在免疫低下（如 HIV）出現上葉空洞性病灶時，除了肺結核與諾卡氏菌外，務必鑑別 *R. equi*；此菌對 β-Lactam 無效，需選用 Vancomycin、巨環類或 TMP-SMX。
