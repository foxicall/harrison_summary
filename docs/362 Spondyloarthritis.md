# 脊椎關節炎（Spondyloarthritis）全解析：從腸—關節軸、組織微環境到標靶免疫與功能醫學整合

- **主講人/來源**：362 Spondyloarthritis.pdf（Joel D. Taurog, Lianne S. Gensler, Nigil Haroon / *Harrison's Principles of Internal Medicine*）
- **核心主旨**：脊椎關節炎（SpA）本質上是由「力學壓力敏感之著骨點炎（Enthesitis）」與「腸道黏膜微生態屏障受損（Gut-Joint Axis）」驅動的全身性自體發炎疾病；臨床需掌握組織異質性細胞因子網絡（TNF/IL-23/IL-17）、核磁共振（MRI）早期診斷，並結合腸道修復與生物力學運動介入以終止疾病進程與異位骨化。

---

## 一、 核心要點精華（Executive Clinical Summary）

### 核心病理生理機制
1. **著骨點微環境與力學敏感性（Biomechanical Stress & Enthesitis）**：
   - 著骨點（纖維軟骨附著處）是承受肌肉牽拉應力的核心解剖位點。遺傳背景（如 HLA-B27、*TYK2*、*CARD9*）與微生態代謝物降低了力學發炎的臨界閾值，使微損傷引發組織駐留固有免疫細胞（如表現 IL-23R 的 $\gamma/\delta$ T 細胞）活化。
2. **腸—關節軸失調（Gut-Joint Axis）**：
   - 高達 60%~70% 的 SpA 患者伴隨腸道黏膜亞臨床發炎。具「黏液降解特性（Mucolytic）」的菌群過度擴增，削弱腸道黏膜屏障，促使內毒素（LPS）移位與發炎因子釋放，引導表現 CD163/CD68 的巨噬細胞與活化淋巴球向關節滑膜及著骨點移動。
3. **異位新骨形成與 Wnt 通路去阻遏**：
   - 脊椎發炎（如 Romanus 病灶）經脂肪化過渡後，由膜內成骨轉向軟骨內成骨，其機制與 Wnt 訊息通路抑制劑（DKK-1、Sclerostin）的下調密切相關，最終導致韌帶骨贅（Syndesmophytes）增生與脊椎「竹節化（Bamboo spine）」。

### 演講亮點與臨床洞察（Paradigm Shifts）
- **自體發炎（Autoinflammatory）勝於傳統自體免疫（Autoimmune）**：SpA 缺乏典型的致病性自體抗體（類風濕因子 RF、抗 CCP 均為陰性），其本質是由固有免疫、組織細胞浸潤與細胞因子網絡失衡主導。
- **組織特異性細胞因子階層（Cytokine Hierarchy Discrepancy）**：
  - **軸心關節（Axial spine）**：對抗 TNF 與抗 IL-17A 反應極佳，但**抗 IL-23 抑制劑在軸心無效**。臨床研究證實脊椎著骨點存在一群「不表現 IL-23 受體卻能獨立產生 IL-17A」的 $\gamma/\delta$ T 細胞。
  - **周邊關節、著骨點與皮膚（PsA/Psoriasis）**：對抗 TNF、抗 IL-17A 及抗 IL-23 皆具顯著療效。
  - **腸道（IBD）**：對抗 TNF 與抗 IL-23 有效，但**抗 IL-17 治療反而可能誘發或加重發炎性腸道疾病**。
- **nr-axSpA 到 AS 的連續光譜**：無放射學表現的軸心型脊椎關節炎（nr-axSpA）與僵直性脊椎炎（AS/r-axSpA）屬於同一個疾病光譜，早期 MRI 的脂肪抑制（STIR/T1 造影）骨髓水腫偵測是攔截不可逆結構破壞的黃金窗口。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與評估目標 | 理想 / 關注數值標準 |
| :--- | :--- | :--- |
| **HLA-B27 基因型** | 軸心受累的高度遺傳易感標記；白人 AS 陽性率高達 80-90%，評估預後與家族風險 | 陽性需警惕發炎性下背痛與葡萄膜炎風險 |
| **骨盆/薦腸關節 MRI (STIR / T1 + Contrast)** | 評估活動性薦腸關節炎、骨髓水腫（Bone Marrow Edema）、軟骨下脂肪浸潤與骨侵蝕 | 雙側關節周圍出現 STIR 高訊號骨髓水腫即符合活動性發炎標準 |
| **發炎性下背痛（IBP）臨床準則** | 區別退化/機械性背痛與發炎性背痛（ASAS 標準：發病年齡 <40、隱匿起病、活動後改善、休息無效、夜間痛） | 符合 4 項或以上具備推定診斷意義 |
| **高敏感度 CRP (hs-CRP) / ESR** | 評估全身性系統性發炎程度與放射學快速惡化（Syndesmophyte 形成）的預測因子 | AS 患者常輕度至中度升高；但正常數值不可排除活動性 axSpA |
| **糞便發炎與黏膜完整性（Calprotectin / Zonulin）** | 評估次臨床腸道發炎、腸漏（Leaky Gut）及共病未診斷之 IBD（Crohn's/UC） | 糞便 Calprotectin 升高反映腸-關節軸發炎活動度 |
| **Modified Schober Test (腰椎前屈測試)** | 客觀量化腰椎矢狀面活動度與發炎攣縮/關節強直進展 | 站立標記點（雙側髂後上棘連線與其上方 10 cm 處），前彎增加距離 **$\ge$ 2 cm** 為正常；< 2 cm 提示受限 |
| **胸廓活動度（Chest Expansion）** | 評估肋椎關節與胸骨柄關節受累程度，量化第四肋間或劍突吸呼差異 | 正常值 **$\ge$ 2.5 cm**；< 2.5 cm 提示胸壁擴張受阻 |
| **側彎距離（Lateral Lumbar Bending）** | 量化腰椎側向活動受損狀況（中指沿大腿外側滑動距離） | 正常值 **> 10 cm** |
| **血清 IgA / MMP-3** | 反映黏膜免疫激活狀態（IgA 常升高）及關節軟骨/骨重塑發炎活躍度（MMP-3） | 數值與疾病活動性（BASDAI/ASDAS）顯著正相關 |
| **類風濕因子 (RF) & 抗 CCP 抗體** | 用於排除類風濕性關節炎（RA）的血清陰性鑑別 | 通常為陰性（PsA 中 <10% 出現抗 CCP 低滴度） |

## 三、 關鍵機制詳解與重點筆記

### 1. 著骨點力學微損傷與新骨形成路徑（Mechanotransduction & Enthesitis）
- **微環境敏感性**：著骨點是肌腱/韌帶止於骨骼的解剖界面。力學牽張引發局部的微血管滲透性增加與固有免疫啟動。在易感基因體質下，正常力學負荷即可誘發過度的 TNF、IL-17 及 IL-22 分泌。
- **成骨/破骨偶聯失衡**：
  - 早期發炎期破骨細胞增加（受 TNF 與 RANKL 調控），導致椎體邊緣「侵蝕（Erosions）」與「骨質疏鬆（Osteoporosis）」。
  - 進入修復期時，局部 Wnt 訊息路徑被異常去阻遏（DKK-1 與 Sclerostin 受抑制），促進間質幹細胞（MSCs）分化為軟骨細胞並進行軟骨內骨化，最終形成從椎骨邊緣向上垂直生長的**邊緣性韌帶骨贅（Marginal syndesmophytes）**。

### 2. 「腸—關節軸」（Gut-Joint Axis）與黏膜微生態失衡
- **黏液降解與菌群移位**：患者腸道中降解黏液素（Mucin-degrading）的細菌比例增高，侵蝕腸上皮表面的黏液屏障；*Erwinia*、*Pseudomonas* 等特定腸道移位病原菌增加。
- **白血球歸巢機制（Leukocyte Homing）**：受腸道發炎刺激而活化的淋巴細胞與表現 CD163 的巨噬細胞，經由血管內皮細胞黏附分子（ICAM-1、VCAM-1）靶向遷移至富含微血管網的關節滑膜與著骨點，形成「腸發炎—全身循環—關節著骨點浸潤」的發炎放大迴路。

### 3. 組織特異性細胞因子網絡與標靶策略（圖 362-3 解析）

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

### 功能性營養素與植化素精準處方
1. **腸道黏膜修復與屏障封閉（Targeting Gut-Joint Translocation）**：
   - **左旋麩醯胺酸（L-Glutamine）**：每日 5~10 g，支持腸黏膜上皮代謝，修復微絨毛緊密連接（Tight junctions）。
   - **肌肽鋅（Zinc Carnosine）**：每日 75~150 mg，加速腸黏膜潰瘍癒合，下調黏膜局部促炎細胞因子。
2. **IL-17 / TNF / NF-$\kappa$B 訊息抑制與抗氧化**：
   - **高純度 Omega-3 脂肪酸（EPA/DHA 比例約 2:1~3:1）**：每日 3,000~4,000 mg，競爭性抑制花生四烯酸代謝路徑，抑制前列腺素 $E_2$（$\text{PGE}_2$ 參與著骨點新生骨形成）。
   - **脂質體薑黃素（Curcumin）/ 綠茶萃取物（EGCG）**：每日 1,000 mg，阻斷 NF-$\kappa$B 與 JAK/STAT 磷酸化，協同降低 IL-17A 與 TNF-α。
3. **骨代謝與自體免疫平衡維護**：
   - **維生素 D3 + K2 (MK-7)**：維生素 D3 維持血清 25(OH)D 於 50~70 ng/mL，發揮 T-reg 免疫誘導功能；配合維生素 K2 引導鈣質沈積於骨基質，預防 SpA 常見的「局部新骨贅形成但軸心小樑骨嚴重疏鬆」的骨代謝矛盾。

### 飲食與禁食策略
- **低澱粉 / 自身免疫方案（Autoimmune Protocol, AIP）**：
  - 臨床文獻指出，過度精緻的碳水化合物與可溶性澱粉容易滋生腸道克雷伯氏菌（*Klebsiella pneumoniae*）及黏液降解菌；採用低精緻澱粉、低升糖、無麩質之抗發炎飲食，有助於降低腸黏膜抗原刺激。
- **移除促炎與過敏原觸發點**：
  - 剔除精緻糖、種子油（高 Omega-6 促發炎脂質）、酒精及乳製品中易引發腸漏的成分。
- **間歇性斷食（如 16/8 斷食法）**：
  - 藉由空腹期誘發細胞自噬（Autophagy），輔助清除腸上皮細胞氧化微損傷，促進腸道黏膜微生態多元化。

### 運動醫學、生物力學與環境毒素管理
- **每日脊椎柔軟度與擴胸運動處方（不可中斷之核心策略）**：
  - 維持胸廓擴張度與脊椎活動度（如貓牛式、麥肯基伸展療法、水中伸展），預防肋椎關節與小面關節骨化強直。
  - **絕對禁忌**：**禁止盲目的快速暴力脊椎整脊旋轉手法（Spinal manipulation）**！進展期 AS 患者韌帶骨化且伴隨嚴重骨質疏鬆，極易造成下頸椎骨折與脊髓損傷。
- **減少生物力學重複衝擊**：
  - 著骨點炎急性發作期，減少高衝擊性單腳跳躍或過度跑步，改採游泳、橢圓機等低衝擊訓練，降低著骨點微損傷閥值。
- **戒菸與毒素阻斷**：
  - 吸菸是加速軸心關節炎放射學惡化（Syndesmophyte 快速增生形成竹節化）最強烈的獨立環境風險因子，必須進行嚴格戒菸介入。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **落實紅旗特徵早期鑑別**：凡遇到 **< 40 歲**、慢性背痛超過 **3 個月**且具備「活動後改善、晨間僵硬 > 30 分鐘、夜間翻身痛」的病患，切勿僅當成一般肌肉扭傷或椎間盤突出；應優先安排骨盆 **MRI (STIR 序列)** 及 **HLA-B27** 篩檢，爭取在骨質融合前介入。
2. **落實「腸—關節」一體化思維**：診斷 axSpA 或 PsA 時，常規詢問排便性狀並檢測腸道屏障功能；對難治性關節炎患者，積極修復次臨床腸道發炎（黏液層保護與益生元重建）。
3. **因應組織異質性選擇生物製劑 / 標靶**：
   - 純軸心發炎（axSpA）：選用 **TNF 抑制劑** 或 **IL-17A 抑制劑**，切勿選用 IL-23 抑制劑。
   - 合併活動性腸炎（IBD）者：**禁用 IL-17 抑制劑**（首選抗 TNF 或抗 IL-23）。
   - 周邊型乾癬性關節炎（PsA）：抗 IL-17、抗 IL-23、抗 TNF 與 JAK 抑制劑均可精準應用。
4. **堅持生活處方：晨間伸展 + 嚴格戒菸 + 避免暴力整脊**：將物理伸展運動作為每日「非藥物處方」；告知病患抽菸將倍增脊椎竹節化速度，並嚴格警告不可接受頸椎及腰椎之衝擊性整脊扭轉。
