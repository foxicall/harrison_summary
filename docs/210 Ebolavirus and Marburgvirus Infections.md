# 絲狀病毒感染（伊波拉與馬堡病毒）之病理生理、臨床演變與系統性修復臨床筆記
- **主講人/來源**：Jens H. Kuhn, Ian Crozier / *Harrison's Principles of Internal Medicine*, Chapter 210: *Ebolavirus and Marburgvirus Infections*
- **核心主旨**：絲狀病毒（Filovirus）透過抑制先天第一型干擾素路徑與瓦解血管內皮屏障，引發高致死率之全身性多重器官衰竭與瀰漫性血管內凝血（DIC）；針對存活者的免疫特權器官病毒殘留與長期發炎後遺症，臨床需建立從急性期重症代謝支持到康復期系統性修復的整合性照護視角。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  1. **先天免疫癱瘓與細胞激素風暴**：病毒結構蛋白（VP35、VP40、VP24）強烈拮抗宿主第 I 型干擾素（IFN-I）抗病毒途徑；巨噬細胞受感染後釋放大量發炎性細胞激素，而樹突細胞成熟與抗原呈現（MHC-II）受抑，伴隨淋巴器官廣泛細胞凋亡（Lymphoid depletion）與嚴重淋巴球低下。
  2. **內皮細胞滲漏與微血管通透性劇增**：病毒表面棘蛋白（GP₁‚₂）結合細胞內 NPC1 受體造成細胞趨性廣泛感染，直接損傷內皮並引發一氧化氮（NO）及血管活性因子異常分泌，誘發微血管嚴重滲漏、體液外移、低血容積性與感染性休克。
  3. **肝功能衰竭與消耗性凝血障礙（DIC）**：肝細胞壞死導致凝血因子合成枯竭，組織因子（Tissue Factor）釋放與蛋白質 C（Protein C）下降，導致全身微血栓形成與重度消耗性凝血病變。
- **演講亮點與臨床洞察**：
  - **致死率認知轉變**：過去文獻將 EVD 概括為 90% 致死率，現代流行病學顯示其異質性極大（平均約 44.6%），存活率高度依賴早期單株抗體與高階生命維持支持（PALM 臨床試驗證實 mAb114 與 REG-EB3 之生存獲益）。
  - **免疫特權區域之病毒宿存（Viral Persistence）**：病毒可在睪丸/精液、中樞神經系統（腦脊髓液）、眼球前房（眼內液）及胎盤中長期潛伏數月甚至數年，具備性傳播、引起遲發性葡萄膜炎（Uveitis）或復發性腦膜腦炎並重燃疫情之風險。
  - **伊波拉後症候群（Post-Ebola Syndrome）**：存活者面臨長期的失能性關節肌肉痛、重度疲倦（Asthenia）、掉髮、神經認知減退、聽力喪失與情緒障礙，臨床表徵類似重度長新冠（Long COVID）及全身性慢性粒線體/免疫衰竭。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與病理生理評估目標 | 理想 / 關注異常數值標準 |
| :--- | :--- | :--- |
| **RT-PCR（血液/體液）** | 確診黃金標準；監測急性期血中病毒載量與免疫特權體液清除狀況 | 偵測極限約 $1000 \sim 5000\text{ PFU/mL}$；急性期重症常 $>10^6\text{ PFU/mL}$ |
| **全血球計數（CBC w/ Diff）** | 評估骨髓抑制與免疫瓦解；監測早期嚴重白血球減少、核左移及後續反應性嗜中性球增多 | 早期 WBC $<1000/\mu\text{L}$；血小板計數（PLTs）常降至 $<50,000/\mu\text{L}$ |
| **凝血功能（PT, aPTT, D-dimer, Fibrinogen）** | 評估瀰漫性血管內凝血（DIC）與肝臟合成衰竭程度 | PT/aPTT 顯著延長；D-dimer 大幅飆升；Protein C 濃度進行性驟降 |
| **肝膽生化（AST, ALT, GGT, Bilirubin）** | 評估肝細胞急性溶解與毒素排除機能；絲狀病毒具特異性 AST 顯著高於 ALT 現象 | AST 顯著大於 ALT；伴隨高膽紅素血症（Hyperbilirubinemia）與低白蛋白血症 |
| **腎功能與電解質（BUN, Cr, Na⁺, K⁺, Ca²⁺, Mg²⁺）** | 評估腎前性/腎性急性腎衰竭（AKI）、第三腔隙液體外移與電解質瓦解 | BUN/Cr 顯著攀升；嚴重低血鉀或高血鉀、低血鈉、低血鈣、低血鎂 |
| **代謝與能量指標（Lactate, HCO₃⁻, Blood Glucose）** | 組織灌流不足、無氧代謝、粒線體功能受損與敗血性休克評估 | 乳酸（Lactate）升高、$\text{HCO}_3^-$ 降低（代謝性酸中毒）；突發性嚴重低血糖（Hypoglycemia） |
| **發炎與肌溶解標記（hs-CRP, CPK, Myoglobin）** | 全身性重度發炎反應、橫紋肌溶解及心肌發炎受損程度 | CRP 顯著升高；CPK 異常暴增伴隨肌紅蛋白尿（Myoglobinuria） |

## 三、 關鍵機制詳解與重點筆記

### 1. 病毒侵入、干擾素阻斷與免疫麻痺
```
[Filovirion (GP1,2)] ──> [Macrophage / Monocyte / DC 感染]
                              │
    ┌─────────────────────────┴─────────────────────────┐
    ▼                                                   ▼
[VP35 / VP24 / VP40 蛋白]                         [釋放促發炎細胞激素]
    │                                                   │
    ├─> 阻斷 Type I IFN (IFN-α/β) 抗病毒反應           └─> 招募更多發炎細胞 (惡性循環)
    └─> 抑制樹突細胞 MHC-II 抗原呈現
    ▼
[適應性免疫失能] ──> 大量淋巴球凋亡 (脾臟/胸腺/淋巴結) ──> 嚴重淋巴球低下 (Viremia >10⁶ PFU/mL)
```
- **受體結合機制**：病毒外被棘蛋白 $\text{GP}_{1,2}$ 媒介宿主細胞吸附後，於內膜系統結合關鍵細胞內受體 **NPC1**（NPC intracellular cholesterol transporter 1），啟動膜融合。
- **先天防線全滅**：病毒蛋白 VP35 作為聚合酶輔助因子同時拮抗 RIG-I 訊號傳遞，VP24 阻斷 STAT1 進入細胞核，完全切斷干擾素基因刺激路徑（ISGs）。

### 2. 內皮屏障崩解、凝血級聯瓦解與多器官衰竭
- **微血管滲漏路徑**：病毒直接感染血管內皮細胞，加上巨噬細胞受刺激後持續釋放大量一氧化氮（NO）與發炎因子，引發內皮間質連接解離、重度低蛋白血症與水分外滲，導致組織間質水腫及頑固性低血容積休克。
- **微血栓與臟器梗塞**：單核巨噬系統異常高表現組織因子（Tissue Factor），消耗血小板與凝血因子，導致纖維蛋白於性腺（睪丸/卵巢）、腎臟與脾臟沉積形成微血管栓塞，進而誘發缺血性壞死與後續出血傾向（黏膜、穿刺點出凝血異常）。

### 3. 康復期「病毒宿存」與慢性發炎後遺症（Post-Viral Sequelae）
- **免疫特權區潛伏**：血-睪屏障（Blood-Testis Barrier）、血-腦屏障（BBB）與血-視網膜屏障使得病毒可避開全身性循環抗體與 T 細胞之清除，潛伏於睪丸精液（長達數月至逾一年）、眼球房水（引發遲發性葡萄膜炎 Uveitis）、中樞神經系統（復發性腦膜腦炎）。
- **全身性後遺症**：存活者因長時間細胞骨架受損、自律神經調節障礙及潛在低度免疫活化，出現廣泛關節肌肉痛、慢性疲憊症候群（CFS）、記憶力受損與神經精神病症（創傷後壓力症候群、憂鬱）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

> **特別說明**：絲狀病毒感染為 WHO 第四級危險群（Risk Group 4）高致死性法定傳染病，急性期必須於嚴格負壓與高規格防護裝備（PPE）隔離環境進行常規重症救治；功能醫學、臨床營養與代謝支持側重於**急性期器官代償支持**與**康復期/後遺症期（Post-Ebola Syndrome）之系統性修復**。

### 1. 急性期高階重症支持與代謝內環境校正
- **循環與體液重置**：依循敗血性休克指引，立即予以精準等張晶體溶液輸注（校正第三腔隙喪失），視情況早期使用血管加壓素（Vasopressors），嚴密監控動脈血壓與微循環灌流。
- **電解質與酸鹼重度校正**：
  - **鉀/鎂/鈣聯合平衡**：嚴防因嚴重嘔吐腹瀉導致的致死性低血鉀、低血鈣與低血鎂，需以靜脈點滴即時補充，防止心律不整。
  - **低血糖防禦**：定時監測血糖，必要時連續靜脈給予葡萄糖輸注，逆轉因肝醣衰竭引發的低血糖性腦病變。
- **特異性標靶抗體治療**：確診後應立即單次靜脈給予核准之單株抗體——**mAb114 (Ansuvimab-zykl)** 或三合一抗體 **REG-EB3 (Atoltivimab / Maftivimab / Odesivimab-ebgn)**。

### 2. 康復期功能性營養素修復處方（針對 Post-Viral Syndrome & 內皮/粒線體修復）
- **血管內皮與細胞屏障修復**：
  - **高純度 Omega-3 脂肪酸 (EPA/DHA)**：每日 $2000 \sim 3000\text{ mg}$，協助解離後發炎反應，下調促發炎前列腺素，修復內皮通透性。
  - **槲皮素 (Quercetin) / 芸香苷 (Rutin)**：每日 $500 \sim 1000\text{ mg}$，穩定肥大細胞與微血管壁，減少微血管脆性與水腫。
- **抗氧化與肝臟解毒支持**：
  - **N-乙醯半胱氨酸 (NAC)**：每日 $1200 \sim 1800\text{ mg}$ 分次給予，恢復細胞內穀胱甘肽（GSH）儲量，減輕肝細胞壞死後氧化壓力。
  - **微量元素鋅 (Zinc Glycinate) 與 硒 (Selenium)**：鋅每日 $30 \sim 50\text{ mg}$，硒每日 $200\text{ }\mu\text{g}$，重塑胸腺萎縮後之 T 細胞免疫分化，調節甲狀腺素周邊轉換。
- **粒線體能量重啟（對抗嚴重 Asthenia 與慢性疲勞）**：
  - **輔酶 Q10 (Ubiquinol)**：每日 $200 \sim 300\text{ mg}$，促進電子傳遞鏈 ATP 生成。
  - **乙醯左旋肉鹼 (ALCAR) 與 硫辛酸 (Alpha-Lipoic Acid)**：改善神經認知功能低下（Brain fog）與末梢神經痛。

### 3. 生活型態醫學、微生態阻斷與公共衛生防禦
- **精液排毒與安全性行為屏障**：男性存活者精液排毒期不可預期，必須在精液連續兩次 RT-PCR 檢測呈陰性前，嚴格執行安全性行為（使用保險套）或禁慾，杜絕性傳播重燃社區疫情。
- **抗發炎全食物飲食**：急性期過後過渡至低抗原、低升糖指數、富含多酚之抗發炎全食物（如地中海型飲食架構），提供足量優質蛋白質（$1.2 \sim 1.5\text{ g/kg/day}$）以逆轉重症消耗期造成的嚴重肌肉流失與低白蛋白血症。
- **眼科與神經系統長期隨訪**：建立存活者葡萄膜炎早期篩查機制，定期進行裂隙燈檢查，防止因遲發性眼內發炎導致失明。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **建立急性接觸史與紅色警訊快篩意識**：凡具有熱帶非洲流行區旅遊史、蝙蝠/洞穴暴露、未煮熟野味（Bushmeat）接觸史，並出現急性發燒併胃腸道症狀與凝血異常者，應立即通報並啟動最高等級感染管制（隔離與 BSL-4 轉檢）。
2. **早期代謝恆定救治優於單純等待抗病毒**：嚴密監控並糾正低血容積、急性腎損傷（AKI）、代謝性酸中毒與隱形低血糖，提供早期器官支持（透析、呼吸支持）能大幅拓寬免疫重建的生存窗口。
3. **抗體標靶藥物即時介入**：對 PCR 陽性確診個案，應於第一時間給予 mAb114 或 REG-EB3 單次劑量輸注，越早給藥，降低病毒載量與死亡率之效果越顯著。
4. **追蹤免疫特權區的病毒殘留風險**：對出院康復個案需進行精液病毒核酸監測計畫，並將遲發性眼疾（葡萄膜炎）、突發性神經病變列為常規隨訪項目。
5. **啟動全人功能性後遺症復原計畫**：針對伊波拉存活者長期失能之關節炎、肌痛與認知功能衰退，整合粒線體營養素（Q10、肉鹼）、抗發炎抗氧化劑（NAC、Omega-3）與心理創傷支持，重建神經-免疫-內分泌軸線之動態平衡。
