# 急性骨髓性白血病（Acute Myeloid Leukemia, AML）之病理機制、基因體分型與全人整合治療策略
- **主講人/來源**：104 Acute Myeloid Leukemia.pdf (Harrison's Principles of Internal Medicine, 21st Edition, Chap. 104 by William Blum, MD)
- **核心主旨**：深入剖析由年齡老化、表觀遺傳突變（CHIP）與代謝異常驅動之骨髓造血幹細胞惡性轉化，並整合當代精準基因體分型（WHO/ELN）、標靶代謝治療與化療支持療法之臨床決策路徑。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **造血幹細胞老化與株落演進（Clonal Evolution）**：隨年齡增加累積之體細胞突變，誘發「未定潛能株落造血」（CHIP），主要涉及表觀遺傳調控基因（*DNMT3A*、*TET2*、*ASXL1*）。
  - **代謝重編程與腫瘤代謝物（Oncometabolite）**：*IDH1*/*IDH2* 突變使三羧酸循環（TCA cycle）代謝異常，產生致癌代謝物 2-羥基戊二酸（2-Hydroxyglutarate, 2-HG），抑制 $\alpha$-酮戊二酸依賴性雙加氧酶，導致全基因體高甲基化與細胞分化阻滯。
  - **全身性促發炎微環境（Pro-inflammatory State）**：突變擴增之單核球分泌促發炎因子，不僅促進骨髓微環境免疫逃脫，更顯著加速血管內皮動脈粥狀硬化斑塊形成。
- **演講亮點與臨床洞察**：
  - **心血管與血液惡性腫瘤的共同交叉點**：文獻明確指出，攜帶 CHIP 的高齡個體，其血液惡性腫瘤風險增加 10 倍，同時心血管死亡率顯著上升；其根源在於「發炎性單核球」對血管及骨髓微環境的慢性浸潤破壞。
  - **精準分子風險分層取代傳統型態分類**：歐洲白血病網絡（ELN 2017）標準確認，單純形態學已不足以指導治療；*NPM1*、*CEBPA*（雙突變）、*FLT3-ITD* 等位基因比率（Allelic Ratio）及 *TP53*、*RUNX1* 成為決定異體造血幹細胞移植（Allo-HCT）的決定性指標。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **周邊血與骨髓芽細胞（Blasts）** | 診斷 AML 之核心準則；評估完全緩解（CR）狀態 | 診斷需 $\ge 20\%$（具 $t(15;17)$ 等遺傳異常者除外）；完全緩解（CR）標準為骨髓 Blasts $< 5\%$ 且周邊血無芽細胞 |
| **嗜中性白血球絕對計數（ANC）** | 評估感染風險及骨髓功能恢復狀態 | 嚴重骨髓抑制關注值 $< 500/\mu\text{L}$；完全緩解（CR）標準需恢復至 $\ge 1000/\mu\text{L}$ |
| **血小板計數（Platelet Count）** | 評估自發性出血與凝血功能衰竭風險 | 預防性輸血門檻一般為 $< 10,000/\mu\text{L}$；伴隨發燒/DIC 需提升；CR 標準為 $\ge 100,000/\mu\text{L}$ |
| **血清尿酸（Uric Acid）** | 反映高細胞代謝率及腫瘤溶解症候群（TLS）風險 | 預防尿酸性腎病變；化療前常規投予 Allopurinol 或 Rasburicase 降至正常區間 |
| **溶菌酶（Lysozyme）** | 單核球系分化標記；高濃度可能誘發腎小管損傷 | 於急性單核球白血病（Monocytic AML）顯著升高，須監測腎小管功能障礙 |
| **凝血指標（PT/INR, aPTT, Fibrinogen, D-dimer）** | 監測瀰漫性血管內凝血（DIC）及微血栓形成 | 特別好發於急性前骨髓細胞白血病（APL/M3）；須維持纖維蛋白原於安全範圍避免致命性出血 |
| **分子突變檢測（NPM1, FLT3-ITD, CEBPA, IDH1/2）** | 遺傳風險分層、預後預測及精準標靶用藥依據 | *FLT3-ITD* 高/低等位基因比值（臨界點為 0.5）；*CEBPA* 需確認為雙等位基因突變（Biallelic） |
| **微量殘留病灶（MRD via RT-PCR/Flow）** | 評估達到 CR 後深層白血病細胞清除率與復發風險 | 持續監測 *NPM1*、*PML-RARA*、*RUNX1-RUNX1T1* 轉錄本；陰性為長期無病存活指標 |

## 三、 關鍵機制詳解與投影片重點筆記

- **老化相關株落造血（CHIP）與心血管/血液雙重病理路徑**：
  - 隨年齡老化，造血幹細胞在環境毒素、DNA 修復失衡下產生體細胞突變。年逾 70 歲者中，約 5–6% 體內存在具擴增優勢之突變株（*DNMT3A*, *TET2*, *ASXL1*）。
  - **發炎惡性循環**：突變之骨髓單核球具高侵略性與促炎特性，釋放發炎介質破壞血管內皮（加速冠狀動脈粥狀硬化），同時改造骨髓基質微環境，削弱免疫監視系統，促成二次打擊（Second-hit mutations，如 *FLT3*, *NPM1*），終至惡化為白血病。
- **腫瘤代謝與表觀遺傳調控（IDH1/IDH2 與 2-HG）**：
  - *IDH1*（細胞質）或 *IDH2*（粒線體）發生突變後，失去原有的異檸檬酸氧化脫羧功能，獲得新功能（Neomorphic activity），將 $\alpha$-酮戊二酸（$\alpha\text{-KG}$）還原為致癌代謝物 **(R)-2-羥基戊二酸（2-HG）**。
  - 2-HG 結構類似 $\alpha\text{-KG}$，競爭性抑制 TET 甲基胞嘧啶加雙氧酶（導致 DNA 高甲基化）及組蛋白去甲基酶（Jumonji 結構域），全面封鎖骨髓前驅細胞的基因轉錄與正常分化程序。
- **2017 ELN 遺傳風險分層體系（Risk Stratification）**：
  - **良好預後（Favorable）**：$t(8;21)(q22;q22)$ (*RUNX1-RUNX1T1*)、$inv(16)(p13.1q22)$ 或 $t(16;16)$ (*CBFB-MYH11*)、突變型 *NPM1*（無 *FLT3-ITD* 或伴 *FLT3-ITD*low）、雙等位基因突變 *CEBPA*。
  - **中度預後（Intermediate）**：突變型 *NPM1* 伴 *FLT3-ITD*high；野生型 *NPM1*（無 *FLT3-ITD* 或伴 *FLT3-ITD*low 且無不利基因）；$t(9;11)(p21.3;q23.3)$ (*MLLT3-KMT2A*)。
  - **不良預後（Adverse）**：$t(6;9)(p23;q34.1)$ (*DEK-NUP214*)、11q23 重排 (*KMT2A*)、$t(9;22)(q34.1;q11.2)$ (*BCR-ABL1*)、$inv(3)$、$-5$/$del(5q)$、$-7$、複雜核型（$\ge 3$ 個不相關染色體異常）、單體核型（Monosomal karyotype）、野生型 *NPM1* 伴 *FLT3-ITD*high、突變型 *RUNX1*、*ASXL1* 或 *TP53*。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

- **現代抗癌標靶與低強度代謝化療整合**：
  - **粒線體抗凋亡標靶**：針對高齡（$\ge 60–65$ 歲）或不耐受高強度誘導治療之患者，採用 **Venetoclax（BCL-2 抑制劑）** 聯合去甲基化藥物（HMA：Azacitidine 或 Decitabine），顯著提升完全緩解率（達 ~60%）。
  - **細胞代謝標靶**：針對具 *IDH1* 或 *IDH2* 突變者，給予專一性口服 IDH 抑制劑，阻斷 2-HG 蓄積以誘導骨髓母細胞逆轉分化。
  - **激酶標靶**：合併 *FLT3-ITD* 突變者，第一線誘導加入 Midostaurin；復發難治者使用 Gilteritinib 單藥治療。
- **高強度化療之細胞保護與支持療法**：
  - **標準「7 + 3」誘導方案**：Cytarabine $100–200\text{ mg/m}^2/\text{day}$ 連續靜脈注射 7 天，合併 Daunorubicin $60–90\text{ mg/m}^2/\text{day}$（或 Idarubicin $12\text{ mg/m}^2$）注射 3 天。高齡（$>65$ 歲）避免 $90\text{ mg/m}^2$ 之高劑量，以降低心肌與全身毒性；次發性或 MDS 轉變之 AML 可選用微脂體製劑（CPX-351）。
  - **高尿酸血症與腎功能防護**：化療啟動前充分水合，常規投予 Allopurinol；若出現嚴重高尿酸或急性腎受損傾向，迅速給予單劑重組尿酸氧化酶 **Rasburicase**。
  - **免疫低下抗感染階梯治療**：嗜中性白血球缺乏期常規使用 Quinolone 類抗細菌及 Posaconazole 抗黴菌預防；發燒即刻給予抗綠膿桿菌廣效抗生素（如 Cefepime、Piperacillin/Tazobactam 或 Carbapenem），若持續發熱 4–7 天則升級抗黴菌藥物（Caspofungin、Voriconazole、Isavuconazonium 或微脂體 Amphotericin B）。
- **環境毒素阻斷與骨髓微環境保護原則**：
  - **二度致癌因子阻斷**：嚴格避免苯（Benzene）、石油有機溶劑、殺蟲劑、游離輻射及吸菸接觸；既往癌症患者需審慎評估烷化劑（易引發 4–6 年後 monosomy 5/7 之 AML）與 Topoisomerase II 抑制劑（易引發 1–3 年後 11q23 重排之單核球性 AML）之累積劑量與監測。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **早期檢測基因體與代謝標記**：AML 確診當下，應同步進行次世代定序（NGS）與細胞遺傳學分析，優先釐清 *NPM1*、*CEBPA*、*FLT3*、*IDH1/2* 及 *TP53*，並將細胞活體冷凍保存以備後續精準醫療之需。
2. **警惕高齡族群 CHIP 誘發的心血管危機**：常規血液常規檢驗若發現無法解釋的輕微血球異常伴隨動脈粥狀硬化進展，應考慮 CHIP 可能，積極改善全身代謝健康並監測骨髓狀態。
3. **分層制定鞏固與移植計畫**：非良好預後（Intermediate 及 Adverse risk）之合適患者，應於第一緩解期（CR1）盡早安排人類白血球抗原（HLA）配對，儘速啟動異體造血幹細胞移植（Allo-HCT）評估。
4. **精準評估血品輸注與出血預防**：嚴格維持血小板 $\ge 10,000/\mu\text{L}$（發燒、出血或 APL 伴隨 DIC 時需更高標準），採用「減除白血球（Leukodepleted）」與「放射線照射」血品以防範同種免疫抗體產生與輸血相關移植物抗宿主疾病（TA-GVHD）。
