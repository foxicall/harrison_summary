# 急重症意識障礙、神經代謝崩解與腦幹反射評估全解析（Coma & Altered Consciousness）
- **主講人/來源**：28 Coma.pdf（改編自 Harrison's Principles of Internal Medicine 第 28 章；S. Andrew Josephson, Allan H. Ropper, Stephen L. Hauser）
- **核心主旨**：昏迷為大腦皮質雙側網絡或腦幹網狀致活系統（RAS）功能喪失的極致表現；臨床應透過精準的腦幹反射階層檢查與急迫代謝/粒線體能量危機之逆轉，迅速鑑別「結構性腦疝」與「代謝/毒物性腦病變」，把握腦神經保護與拯救的黃金窗口。

---

## 一、 核心要點精華（Executive Clinical Summary）

- **核心病理生理機制**：
  - **能量基質耗竭與粒線體衰竭**：大腦缺乏能量儲備，葡萄糖儲量在血流中斷後僅能維持約 2 分鐘，氧氣僅存 8–10 秒。低血糖、缺氧缺血、低灌流會迅速造成三磷酸腺苷（ATP）崩解、離子通道幫浦衰竭與去極化細胞腫脹。
  - **神經代謝毒素與星狀膠質細胞腫脹**：在肝性腦病變（HE）中，高氨誘發星狀膠質細胞內合成過量麩醯胺酸（Glutamine），引發細胞滲透壓腫脹、活性氧與活性氮（ROS/RNS）釋放、抑制性神經傳導物質 GABA 活性升高與「假性神經傳導物質」蓄積；尿毒症則伴隨甲基胍等神經毒素累積、血腦屏障破壞與鈣離子紊亂。
  - **機械性空間壓迫與腦疝路徑**：顱內腔室受大腦鐮與小腦天幕分隔，局部腫塊引發鉤回疝脫（Uncal herniation）壓迫動眼神經與對側大腦腳（Kernohan-Woltman 徵候），或引發中央天幕疝脫（Central herniation），由上而下漸進破壞間腦、中腦、橋腦至延腦，最終壓迫心肺中樞致死。

- **演講亮點與臨床洞察**：
  - **代謝毒物性遠多於結構性損害**：急診與加護病房中，昏迷絕大多數屬於代謝、中毒或缺氧性因素，腦部電腦斷層（CT）正常絕不能排除昏迷的嚴重致死病因（如早期基底動脈血栓、瀰漫性軸索損傷、腦炎或非抽搐性癲癇重積狀態）。
  - **譫妄預防典範轉移**：無任何抗精神病藥或膽鹼酯酶抑制劑獲證實可有效「預防」譫妄；臨床核心轉向日夜節律調整、早期活動、感官輔助與褪黑激素受體促效劑（Ramelteon/Melatonin）介入，並極小化高致譫妄鎮靜劑（優先使用 Dexmedetomidine）。
  - **假性昏迷（Pseudocoma）與意識光譜鑑別**：閉鎖症候群（Locked-in syndrome）保留垂直眼動與眨眼；無動性緘默症（Akinetic mutism）源於額葉內側或視丘損傷；緊張症（Catatonia）具備主動抗拒張眼、視威脅反射正常與蠟狀屈曲（Waxy flexibility），不可混同於皮質受損。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）

| 檢測項目 / 生物標記 | 臨床意義與病理機制評估目標 | 關鍵病理閾值與警訊標準 |
| :--- | :--- | :--- |
| **血清鈉離子 (Serum Na⁺)** | 評估大腦水腫或脫水性神經元皺縮；急速滲透壓變動會誘發癲癇與昏迷 | `<125 mmol/L` 引起意識混亂；`<119 mmol/L` 誘發昏迷與痙攣；校正過快易導致滲透性去髓鞘症候群 (ODS) |
| **血清滲透壓 (Serum Osmolarity)** | 評估高滲透壓高血糖狀態 (HHS) 或外源性滲透分子蓄積 | 昏迷通常出現在 `>350 mosmol/L` |
| **血氨 (Serum Ammonia, NH₃)** | 評估肝性腦病變、粒線體尿素循環障礙及星狀膠質細胞腫脹風險 | 急劇上升常伴隨三相波 (Triphasic waves) 與大腦水腫 |
| **動脈血氣體 (ABG: pH, PaCO₂, PaO₂)** | 評估高碳酸血症性腦病變（抑制作感與皮質活性）及代謝性酸中毒（代償性 Kussmaul 呼吸） | PaCO₂ 急劇上升程度與意識抑制深淺呈直接正相關 |
| **血液乙醇與毒物篩檢** | 排除中樞神經受體抑制性藥物（鎮靜安眠藥、鴉片類、抗膽鹼藥） | 乙醇濃度 `>43 mmol/L (0.2 g/dL)` 認知受損；`>65 mmol/L (0.3 g/dL)` 進入木僵；慢性耐受者可達 `>87 mmol/L` |
| **腦電圖 (EEG)** | 鑑別非抽搐性癲癇重積、特定腦炎與腦病變嚴重度 | **三相波**（代謝性）；**瀰漫性β波**（苯二氮平過量）；**Alpha coma**（橋腦/皮質廣泛缺氧壞死，預後極差）；**Extreme delta brush**（抗 NMDA 受體腦炎） |
| **核心體溫 (Core Body Temp)** | 排除極端低體溫引起的細胞電生理抑制與代謝停滯 | 核心體溫 `<31°C (87.8°F)` 本身即直接引起昏迷 |

## 三、 關鍵機制詳解與投影片重點筆記

### 1. 腦幹反射階層與結構性脫疝壓迫（Brainstem Reflex Ladder）
```
[大腦皮質 / 半球病灶] ───┐
                         ▼
[間腦 (Diencephalon)] ── 縮瞳 (1-2.5mm)、嗜睡、Cheyne-Stokes 呼吸
                         ▼
[中腦 (Midbrain)] ────── 單側散瞳/對光無反應 (鉤回疝脫)；雙側散瞳 (完全天幕疝脫)
                         ▼
[橋腦 (Pons)] ────────── 針尖樣瞳孔 (<1mm)、角膜反射消失、洋娃娃眼/冷熱試驗失效
                         ▼
[延腦 (Medulla)] ─────── 瀕死喘息 (Agonal gasps)、呼吸停止、不可逆休克 (枕骨大孔疝脫)
```
- **瞳孔反射（中腦與 CN III）**：
  - **單側散瞳固定（>6 mm）**：高度警訊！表示顳葉內側鉤回疝脫，同側動眼神經（副交感神經纖維位於神經外圍）受壓迫。
  - **針尖樣微小瞳孔（<1 mm）**：常見於嚴重橋腦出血（交感降行纖維中斷，副交感獨大）或鴉片類藥物過量（後者對 Naloxone 有反應且保留眼球運動反射）。
  - **中間大小固定瞳孔（2.5–5 mm）**：中腦受損中立位置；若仍有光反射則多半排除中腦結構損害，指向雙側半球或代謝抑制。
- **眼動與前庭動眼反射（橋腦至中腦 MLF 連通網絡）**：
  - **自發性水平游移（Conjugate horizontal roving）**：單憑此點即可證實中腦與橋腦之動眼路徑結構完整。
  - **凝視病灶偏向原則**：大腦額葉皮質受損時，雙眼「看向上游病灶側」；橋腦破壞性病灶時，雙眼「看向對側（遠離病灶）」。
  - **洋娃娃眼（Oculocephalic）與冷水卡路里試驗（Oculovestibular）**：皮質喪失抑制時呈現完整的反向補償眼動；若腦幹核間神經中斷則眼球不隨轉動移動。
- **角膜反射（CN V 傳入、CN VII 傳出）**：評估橋腦功能核心；鎮靜劑過量時，角膜反射常在眼動反射消失後、但瞳孔反射消失之前被抑制。

### 2. 神經元生物能量學崩解與代謝性昏迷（Bioenergetics & Metabolic Encephalopathy）
- **基質供應斷絕模式**：
  - 腦細胞代謝完全仰賴持續的腦血流量（CBF）、氧氣與葡萄糖。血流阻斷 10 秒內氧儲耗盡，腦電活動轉為瀰漫性慢波，隨後電活動歸零。
  - 缺氧缺血性腦病變（HIE）會觸發興奮性毒性（麩胺酸大釋放）、細胞內鈣離子超載，啟動粒線體凋亡路徑；相較之下，單純電解質或毒素異常在早期多屬可逆性生化傳導抑制。
- **神經滲透壓與膜電位危機**：
  - **急劇低血鈉（<120 mmol/L）**：水分滲透入腦細胞造成急性腦水腫與顱內壓增高。
  - **高滲透壓（>350 mosmol/L）**：腦組織脫水皺縮，造成神經元連結中斷及微小血管破裂出血。

### 3. 日夜節律失調與神經毒性發展（Delirium to Coma Continuum）
- 譫妄與昏迷處於意識障礙的同一個病理光譜。加護病房中長期持續的微發炎反應、睡眠結構被剝奪（缺乏慢波睡眠與 REM）以及感覺剝奪，會使微膠質細胞異常活化。
- **節律醫學介入**：利用褪黑激素（Melatonin）或高親和力受體促效劑（Ramelteon）重建視交叉上核（SCN）調控，能顯著降低神經發炎級聯反應並阻遏急性大腦功能衰竭。

### 4. 腦死（Brain Death）之病理生理學本質
- **定義**：全大腦皮質與全腦幹功能的不可逆終止（但脊髓反射仍可存在）。
- **確認兩大支柱**：
  1. 排除所有混淆因素（核心體溫必須校正、無中樞抑制性毒物殘留、無神經肌肉阻斷劑）。
  2. 腦幹反射全面消失（包含瞳孔、角膜、前庭動眼、咽喉反射）且**呼吸中止試驗（Apnea test）陽性**（PaCO₂ 需上升至足以刺激延腦門檻，通常於脫機狀態下 CO₂ 上升速度約 2–3 mmHg/min，且未見任何自主呼吸作功）。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）

```
[病患抵達急診 / 突發昏迷]
  │
  ├── 1. 呼吸道與灌流急救 (ABC)：插管保護氣道 (防範逆流吸入)、維持 MAP、糾正缺氧
  ├── 2. 核心神經代謝「甦醒雞尾酒」：
  │      ├─ 靜脈注射 Thiamine (100mg) ── 必須先於或同時給予 Glucose！
  │      ├─ 50% 高滲透葡萄糖 (Dextrose) ── 立即逆轉低血糖腦危象
  │      └─ Naloxone (0.4-2mg IV) ────── 懷疑鴉片類藥物中毒時給予
  ├── 3. 滲透壓與顱內壓 (ICP) 危機控管：
  │      ├─ 嚴格禁用低張輸液 (避免加重腦水腫)
  │      ├─ 緩慢校正低血鈉 (<8-10 mmol/L/24hr，杜絕 ODS 橋腦去髓鞘)
  │      └─ 懷疑腦疝：過度換氣 (短暫引導低碳酸血症) + 高滲透脫水劑 (Mannitol / 高張鹽水)
  └── 4. 感染與發炎控制：
         └─ 疑似細菌性腦膜炎：立即抽血培養後給予 Dexamethasone + Vancomycin + 3rd Cephalosporin
```

### 1. 急重症神經元能量復甦方針
- **先維生素 B1 後高張糖（Thiamine before Glucose）**：
  - **機制**：維生素 B1（焦磷酸硫胺素）是丙酮酸去氫酶（PDH）與轉酮醇酶（Transketolase）的關鍵輔酶。若在 B1 缺乏狀態下盲目灌注大量葡萄糖，將導致丙酮酸無法進入克氏循環（TCA cycle），急劇堆積大量乳酸引發不可逆的乳酸中毒與 **Wernicke 腦病變**（乳頭體與導水管周圍神經壞死）。
- **解毒劑之精準給藥**：
  - **Naloxone**：針對瞳孔針尖樣、呼吸抑制患者，可反覆滴定。
  - **Flumazenil**：苯二氮平受體拮抗劑；但在昏迷病因不明時**不建議常規經驗性使用**，因極易誘發戒斷性頑固型癲癇重積狀態。
  - **Fomepizole**：針對懷疑乙二醇（防凍劑）或甲醇中毒患者，競爭性抑制醇去氫酶。

### 2. 神經重症加護與節律維持（預防二次腦損傷）
- **體溫管理**：杜絕高體溫（發燒每升高 1°C 即大幅提高腦組織耗氧代謝率）；針對心跳停止復甦後病患實施目標體溫管理（TTM, 32–36°C），抑制缺血再灌流發炎反應。
- **重症環境節律化**：日間提供充足光照與感官刺激（佩戴眼鏡、助聽器），夜間保持低噪音與黑暗；適時使用非 GABA 受體鎮靜途徑（如 α2-促效劑 Dexmedetomidine），保留睡眠腦波架構。

## 五、 臨床實踐行動清單（Key Takeaways）

1. **不可跳過維生素 B1**：昏迷病患給予高張葡萄糖前，常規併用靜脈注射 **Thiamine 100 mg**，防止誘發致死性急性 Wernicke 腦病變。
2. **瞳孔檢查為腦疝最前線**：遇意識改變者，第一時間檢查兩側瞳孔大小與光反應；一旦發現**單側瞳孔不等大散瞳（>6 mm）**，應立即啟動降低顱內壓措施（如抬高床頭 30 度、高張鹽水/甘露醇、神經外科降壓評估），嚴防數十分鐘內腦幹遭到完全輾壓。
3. **電解質校正嚴守速度界限**：治療慢性低血鈉昏迷時，24 小時內血鈉上升幅度不可超過 **8–10 mmol/L**，防止引發致命且無法挽回的橋腦中央髓鞘溶解症（Osmotic Demyelination Syndrome）。
4. **CT 正常不等於腦部無大礙**：突發不明原因昏迷且頭部 CT 呈現陰性時，必須立即將「基底動脈血栓（Basilar thrombosis）」、「早期腦幹中風」、「非抽搐性癲癇重積（NCSE）」與「自體免疫性/感染性腦炎」列入鑑別診斷，盡早安排 CTA/MRI、急診連續性 EEG 或腰椎穿刺。
5. **重症監護全面導入抗譫妄節律管理**：極小化苯二氮平類藥物鎮靜，落實 ICU 每日定時喚醒試驗（Daily sedation interruption），維持患者晝夜環境週期，保護大腦微環境代謝平衡。
