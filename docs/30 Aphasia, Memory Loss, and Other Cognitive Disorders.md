# 失語症、記憶喪失與其他認知障礙（Aphasia, Memory Loss, and Other Cognitive Disorders）
- **主講人/來源**：M.-Marsel Mesulam / 30 Aphasia, Memory Loss, and Other Cognitive Disorders.pdf (摘自《哈里森內科學》（Harrison's Principles of Internal Medicine, 21e）第 30 章)
- **核心主旨**：人類高階大腦功能並非由單一孤立中心調控，而是由五大解剖網絡（語言、空間導向、面孔/物件識別、外顯記憶、執行功能/行為）相互交織整合；臨床評估需從精確的神經網絡定位出發，結合神經退化路徑、代謝發炎驅動因子與多維度支持策略，進行全人認知障礙管理。

---

## 一、 核心要點精華（Executive Clinical Summary）
- **核心病理生理機制**：
  - **大腦聯合皮質（Association Cortex）網絡退化**：全腦約 200 億顆神經元中，僅 10% 為初級感覺/運動皮質，其餘 90% 為聯合皮質。認知障礙起因於五大特定網絡之神經退化蛋白病變（如 Aβ 斑塊沉積、過度磷酸化 Tau 蛋白神經纖維糾結、TDP-43 蛋白質沉積及 Lewy 小體）、神經血管病變、突觸喪失、神經發炎（Neuroinflammation）與腦部能量代謝失衡。
  - **白質微結構與連結中斷**：皮質與皮質下核團（如尾狀核、背內側視丘）或皮質間聯絡纖維受損（如前額葉斷聯、胼胝體壓部/壓部前纖維離斷），阻斷神經迴路統合能力。
- **演講亮點與臨床洞察**：
  - **典範轉移（Paradigm Shift）**：打破傳統「語言理解僅限於 Wernicke 區」之舊觀點。原發性進行性失語症（PPA）證實**句子理解**是由 Broca 與 Wernicke 區廣泛分佈網絡協同調控，而**單詞/字詞語意理解**之核心重鎮實為「左前顳葉（Anterior Temporal Lobe）」。
  - **失語症雙重機轉辨析**：區分單向性檢索障礙（Retrieval-based / One-way naming deficit，能指認但講不出）與雙向性語意缺損（Comprehension-based / Two-way semantic deficit，無法命名亦無法理解指認）。
  - **工作記憶（Working Memory） vs. 外顯記憶（Explicit Memory）之本質解構**：工作記憶為「在線（On-line）即時訊息處理與維持」（受額葉-皮質下網絡調控），外顯記憶為「離線（Off-line）編碼儲存與提取」（受海馬迴-邊緣系統 Papez 迴路調控）。重度失憶症患者其工作記憶（如順向數字廣度）可完全正常，臨床切忌混淆。

## 二、 核心評估指標與功能醫學檢驗（Assessment & Lab Testing）
| 檢測項目/生物標記 | 臨床意義與評估目標 | 理想/關注數值標準（若有提及） |
| :--- | :--- | :--- |
| **字母語言流暢度（Verbal Fluency Test）** | 評估前額葉執行功能、主動檢索與在線搜尋儲存庫之能力（測試 1 分鐘內說出以 a, f, s 開頭之字詞） | **正常標準：每字母 $\ge 12$ 個字/分鐘**；低於此值提示前額葉網絡功能障礙 |
| **數字廣度測試（Digit Span Test）** | 評估前額葉/注意力網絡之「工作記憶（Working memory）」容量與在線操控能力 | **正常標準：順向（Forward）7 位數，逆向（Reverse）5 位數** |
| **逆向月份背誦（Months in Reverse）** | 快速床邊篩檢前額葉注意力維持與工作記憶流暢度 | **正常標準：$< 15$ 秒完成**；延長反映前額葉網絡處理速度變慢或注意缺陷 |
| **視覺目標刪除與雙側刺激測試（Visual Cancellation & Double Stimulation）** | 鑑別右側頂額網絡損傷之單側忽略（Neglect）與雙側對稱受損之同時失認症（Simultanagnosia） | 正常人能完整圈出雙側大小目標且無「消退現象（Extinction）」；漏圈大字提示同時失認（Bálint 症候群），漏圈左側提示左側空間忽略 |
| **維生素 $B_{12}$、葉酸與同半胱胺酸（Homocysteine）** | 評估甲基化循環、髓鞘生成與多發性神經病變/可逆性前額葉網絡症候群（Frontal network syndrome） | 排除高同半胱胺酸血症引起的微血管病變與神經毒性；維持血清 $B_{12}$ 於高生理適當區間 |
| **代謝與發炎驅動指標（hs-CRP、血糖/HbA1c/HOMA-IR、電解質）** | 評估慢性神經膠質發炎、代謝性腦病變（引起繼發性編碼/檢索記憶缺陷）與脫水引起的譫妄風險 | 預防譫妄及神經代謝崩潰；維持正常水合狀態與代謝恆定 |

## 三、 關鍵機制詳解與投影片重點筆記
### 1. 大腦五大核心神經網絡及其臨床神經退化症候群
- **左側大腦外側裂周圍語言網絡（Left Perisylvian Network）**：
  - *Broca 區（額下回）*：主責語音流暢性、語法結構與言語運動；受損致非流暢、電報式語言（Agrammatism）。
  - *Wernicke 區（顳頂交界區）*：傳統與字詞/句子理解相關；受損致流暢但無意義之贅語、新字混亂（Jargon aphasia）。
  - *原發性進行性失語症（PPA）三大亞型*：
    - **非流暢/語法缺失型（Agrammatic PPA）**：左額下回萎縮，以 FTLD-tau 為主。
    - **語意型（Semantic PPA）**：雙側/左側前顳葉萎縮，雙向性語意喪失，病理多為 FTLD TDP-43 (Type C)。
    - **詞彙缺乏型（Logopenic PPA）**：顳頂交界處萎縮，單詞檢索暫停、覆誦受損，病理高度關聯於典型阿茲海默症（AD）。
- **右側頂額空間導向網絡（Parietofrontal Network for Spatial Orientation）**：
  - 包含**扣帶皮質**（空間動機地圖）、**後頂葉皮質**（顯著事件感覺運動表徵）及**額葉眼動區（FEF）**（探索馬達策略）。
  - *單側忽略（Hemispatial Neglect）*：右腦掌控全視野注意，左腦僅掌控右視野，故右腦損傷致嚴重左側忽略。
  - *Bálint 症候群*：雙側頂葉受損，出現**同時失認症（Simultanagnosia，只見樹木不見森林）**、**視失調（Optic ataxia）**與**眼球運動失用症（Oculomotor apraxia）**。常見於後皮質萎縮症候群（Posterior Cortical Atrophy, PCA）。
- **邊緣系統外顯記憶網絡（Limbic Network & Papez Circuit）**：
  - 由海馬迴、內嗅皮質、後旁邊緣區與視丘邊緣核組成。
  - 核心病理：阿茲海默型失智症（DAT）病理最早侵犯內嗅皮質與海馬迴，導致選擇性順向外顯記憶損害（無法儲存新記憶）；內隱記憶（Implicit memory，如運動技能）相對保留。
- **前額葉執行與行為網絡（Prefrontal Network）**：
  - **冷執行功能（背外側前額葉 DLPFC）**：注意力、工作記憶、計畫、抽象思維與概念轉移；受損表現為**意志缺乏症候群（Abulic syndrome）**。
  - **熱執行功能/社會情緒（眼眶額葉 OFC / 腹內側前額葉 VMPFC / 前扣帶回）**：衝動抑制、同理心、社會行為規則；受損表現為**脫抑制症候群（Disinhibition syndrome）**（如常規行為失控、暴食甜食、缺乏病識感與悔意），為行為變異型額顳葉失智症（bvFTD）之特徵。

### 2. 腦血管意外（CVA）與神經退化性失語症的關鍵鑑別診斷
- **傳導性失語症（Conduction Aphasia）**：流暢、理解良好，但「覆誦嚴重受損」，病灶破壞弓狀束（Arcuate fasciculus）等音韻迴路。
- **皮質透發性失語症（Transcortical Aphasias）**：最大特色為**覆誦能力完整保留**（核心語言區未毀損，僅周邊聯合區分開）。
- **純字盲（Pure Alexia without Agraphia）**：左側大腦後動脈梗塞累及左側枕葉與胼胝體壓部（Splenium）；右側視野盲，左側視野影像無法跨越胼胝體傳至左側語言區，呈現「能寫不能讀」。

## 四、 臨床介入處方與生活型態策略（Therapeutic Strategies）
### 1. 藥物與精準分子治療路徑（依據病理表型區分）
- **乙醯膽鹼酯酶抑制劑（Cholinesterase Inhibitors）**：
  - 適用：阿茲海默症（Donepezil, Rivastigmine, Galantamine）、巴金森失智症（Rivastigmine）。
  - 路易氏體失智症（DLB）：對治療冷漠、視幻覺及抑鬱反應顯著，可避免使用高毒性抗精神病藥物。
- **NMDA 受體拮抗劑（Memantine）**：
  - 適用：中度至重度 AD，可延緩機構化並降低照護者負擔（改善穿衣理容阻抗）。
  - **臨床警訊**：DLB 病患應**極度謹慎或禁用**，以免惡化精神激躁與混亂。
- **蛋白質錯誤摺疊與標靶單株抗體**：
  - 抗 Aβ 單株抗體（如 Aducanumab），專注於清除類澱粉蛋白沉積。

### 2. 功能醫學、代謝排毒與非藥物生活型態策略
- **主動式防譫妄策略（Delirium Prevention Protocol）**：
  - 頻繁進行時空再定向（Frequent re-orientation）、認知微刺激活動。
  - **感官輸入最佳化**：矯正聽力障礙（佩戴助聽器）、視力障礙（配鏡），阻斷感覺剝奪導致之認知去代償。
  - **體液平衡與微循環**：嚴格糾正脫水、電解質失衡與代謝性酸鹼紊亂。
  - **睡眠架構強化**：建立強固晝夜節律（日間光照刺激、夜間褪黑激素環境維護），預防日落症候群（Sundowning）。
- **非藥物行為與認知代償策略（Non-drug Behavioral Therapy）**：
  - **前驅結構化環境**：利用清單、視覺化時程表、大型日曆、物品標籤彌補外顯記憶缺失。
  - **保留性程序記憶喚醒**：鼓勵患者維持熟悉的日常活動、散步、簡易體操及既有嗜好（如園藝、手工藝），利用未受損的內隱/程序記憶強化自我效能。
  - **照護者溝通技術**：面對患者因喪失駕駛、理財控制權產生的憤怒與阻抗，切忌敵對或邏輯爭辯；應採用「**安撫、轉移注意力、平靜肯定（Reassurance, distraction, and calm positive statements）**」。
  - **失語症音樂療法**：Broca 失語症患者可透過右半腦保存之音樂旋律迴路，施予**旋律音調治療法（Melodic Intonation Therapy, MIT）**，重啟言語表達。

## 五、 臨床實踐行動清單（Key Takeaways）
1. **落實辦公室外顯行為調查（Informant History First）**：額葉脫抑制症候群患者在診間結構化環境下往往能維持高度智能與應答表現，診斷必須高度依賴家屬提供之真實生活歷史（如投資詐騙、個性驟變、嗜甜、社交禮節喪失）。
2. **失語症診斷切勿見樹不見林**：務必評估「命名、自發言語、理解、覆誦、閱讀、書寫」六大構面。純粹的構音障礙（Dysarthria）、言語失用症（Apraxia of speech）或緘默症（Mutism）不可逕行診斷為失語症。
3. **區分記憶編碼失敗 vs. 檢索失敗**：延遲回憶障礙若能透過「多選一指認（Multiple choice）」答對，代表海馬迴儲存編碼尚存，主要問題在於額葉檢索迴路；若指認依然失敗，則強烈指向內嗅皮質-海馬迴結構性硬化或 AD 早期病變。
4. **即刻排查可逆性「前額葉網絡症候群」因子**：遇到冷漠、執行功能衰退病患，優先抽血檢驗維生素 $B_{12}$、甲狀腺功能，並排除隱性水腦症、多發性腔隙性腦梗塞與潛在自體免疫腦炎。
5. **啟動照護者抗倦怠防護網（Caregiver Burnout Protection）**：照護者的抑鬱、內疚與倦怠直接影響患者預後。早期轉介失智症支持團體（如阿茲海默協會）、喘息服務與日間照護中心，為全人整合治療不可或缺之核心環節。
